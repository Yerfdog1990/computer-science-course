# Master Theorem — Summary Tables

## 1. Master Theorem for Dividing Functions

**Recurrence form:** T(n) = a·T(n/b) + f(n), where a ≥ 1, b > 1, and f(n) = Θ(nᵏ · logᵖ n)

Let **c = log_b(a)**. Compare c to k:

| Case | Condition | Result (Θ) | Example from notes |
|---|---|---|---|
| 1 | c > k | Θ(n^c) | T(n) = 4T(n/2) + 1 → Θ(n²) |
| 2a | c = k, and p > −1 | Θ(nᵏ · log^(p+1) n) | T(n) = 2T(n/2) + n → Θ(n log n) |
| 2b | c = k, and p = −1 | Θ(nᵏ · log log n) | T(n) = 2T(n/2) + n/log n → Θ(n log log n) |
| 2c | c = k, and p < −1 | Θ(nᵏ) | T(n) = 2T(n/2) + n/log²n → Θ(n) |
| 3a | c < k, and p ≥ 0 | Θ(nᵏ · logᵖ n) | T(n) = 2T(n/2) + n²log n → Θ(n² log n) |
| 3b | c < k, and p < 0 | Θ(nᵏ) | T(n) = 2T(n/2) + n²/log n → Θ(n²) |

*Note:* Case 1 (c > k) is the same as saying f(n) grows slower than the recursive term, so the recursion dominates. Cases 2 and 3 are further split by the exponent p on the log factor in f(n) — when p = 0, these reduce to the more commonly taught 3-case version of the Master Theorem (f(n) = Θ(nᵏ) exactly, without a log factor).

## 2. Master Theorem for Decreasing (Subtractive) Functions

**Recurrence form:** T(n) = a·T(n−b) + f(n), where a > 0, b > 0, and f(n) = O(nᵏ), k ≥ 0

| Case | Condition | Result (O) | Example from notes |
|---|---|---|---|
| 1 | a < 1 | O(nᵏ) = O(f(n)) | — (not worked in notes) |
| 2 | a = 1 | O(n^(k+1)) = O(n · f(n)) | T(n) = T(n−1) + n → O(n²) |
| 3 | a > 1 | O(nᵏ · a^(n/b)) = O(f(n) · a^(n/b)) | T(n) = 2T(n−1) + n → O(n · 2ⁿ) T(n) = 3T(n−1) + 1 → O(3ⁿ) |

*Note:* This version applies when the recursive call shrinks the input by a fixed amount (n − b) rather than a fixed fraction (n/b) — e.g., simple linear recursions like T(n) = T(n−1) + O(1).

---

### One-line takeaway
- **Dividing recurrences** (T(n/b)) → compare the "levels of recursion" work (n^log_b a) against the "work done outside the recursion" (f(n) = nᵏ logᵖ n); whichever grows faster wins, with a log-bump when they tie.
- **Decreasing recurrences** (T(n−b)) → compare a to 1; a < 1 means the extra work dominates, a = 1 means it adds up linearly, and a > 1 means you get exponential blow-up.
