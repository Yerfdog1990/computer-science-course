## 2.1. Introduction

A programming problem is a problem where we have an objective which is to be fulfilled under certain restrictions. The moment this objective and these restrictions are converted into a mathematical expression and mathematical equations or inequalities, respectively, the problem is called a mathematical programming problem. When this mathematical expression and these equations or inequalities are linear in form — that is, the relationship between the variables is linear, in which each variable will only have a power of one, and product-of-variables, logarithmic, exponential, trigonometric, etc. terms are not allowed — then the mathematical programming problem is called a linear programming problem (LPP).

Hence, a linear programming problem is a special type of mathematical programming problem which either maximizes or minimizes a linear objective function while satisfying a set of linear equality and/or inequality constraints (restrictions). Mathematical programming problems are optimization problems. In general, a problem where we maximize or minimize a numerical function of variables under some constraints or restrictions, which are also in the form of numerical functions, is called an optimization problem. These types of problems may have a number of feasible solutions which satisfy all the constraints, out of which one is selected, which optimizes our objective function.

Any general linear programming problem with n variables and m linear constraints can be written as:

Maximize or Minimize Z = c₁x₁ + c₂x₂ + ... + cₙxₙ  (Linear objective function)

Subject to the constraints

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ (≤, =, ≥) b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ (≤, =, ≥) b₂
⋮
aᵢ₁x₁ + aᵢ₂x₂ + ... + aᵢₙxₙ (≤, =, ≥) bᵢ
⋮
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ (≤, =, ≥) bₘ   ...(2.1)

x₁, x₂, ..., xₙ ≥ 0  (Non-negative restriction)

The linear inequalities and/or equations represent the restrictions on available resources like man-hours, machine-hours, land, and so on. Here, aᵢⱼ, bᵢ, cⱼ, where i = 1, 2, ..., m and j = 1, 2, ..., n, are assumed to be constants. The coefficients c₁, c₂, ..., cₙ are the unit profit/cost coefficients of the decision variables x₁, x₂, ..., xₙ, respectively, in the objective function.

The inequality Σⱼ₌₁ⁿ aᵢⱼxⱼ ≤ bᵢ (i = 1, 2, ..., m) represents the i-th functional constraint (restriction) on the consumption of the i-th resource, where aᵢⱼ, the coefficient of xⱼ (j = 1, 2, ..., n), gives the amount of resource i consumed by one unit of activity j; xⱼ is the level of activity j; and bᵢ is the maximum availability of the i-th resource.

The objective is to determine the non-negative values of the variables x₁, x₂, ..., xₙ which will satisfy all the constraints on available resources and optimize the objective function. (2.1) can also be written more compactly as:

Maximize or Minimize Z = Σⱼ₌₁ⁿ cⱼxⱼ

Subject to Σⱼ₌₁ⁿ aᵢⱼxⱼ (≤, =, ≥) bᵢ, i = 1, 2, ..., m   ...(2.2)

xⱼ ≥ 0, j = 1, 2, ..., n

Or in matrix form, the same can be written as:

Maximize or Minimize Z = CX

Subject to AX (≤, =, ≥) b, X ≥ 0   ...(2.3)

Here, b(m×1) = (b₁, b₂, ..., bₘ), C(1×n) = (c₁, c₂, ..., cₙ), X′(1×n) = (x₁, x₂, ..., xₙ), and A(m×n) is the m×n matrix whose (i, j)-th entry is aᵢⱼ:

A(m×n) =
```
| a11  a12  ...  a1n |
| a21  a22  ...  a2n |
|  :    :    :    :  |
| am1  am2  ...  amn |
```

**Solution:** An n-tuple (x₁, x₂, ..., xₙ) of real numbers which satisfies the constraints of (2.1) is called a solution to the general linear programming problem.

**Feasible Solution:** A solution to a linear programming problem is known as a feasible solution if it also satisfies the non-negative restriction of the problem.

**Basic Feasible Solution:** If a basic solution to the given linear programming problem satisfies the non-negativity conditions also, then the solution is called a basic feasible solution.

Basic feasible solutions are of two types:

(i) **Degenerate:** A basic feasible solution is called degenerate if the value of at least one basic variable is zero.

(ii) **Non-degenerate:** A basic feasible solution is called non-degenerate if the values of all the basic variables are greater than zero.

**Optimal Basic Feasible Solution:** If a basic feasible solution to a given linear programming problem optimizes the objective function, then it is called an optimal basic feasible solution.

*Note.* If a problem has a feasible solution, then it will also have a basic feasible solution.

**Example.** Minimize z = x₁ + 2x₂

Subject to
x₁ + 2x₂ ≥ 10
10x₁ + 3x₂ ≥ 20
x₁, x₂ ≥ 0

This is a minimization problem with two decision variables and two constraints. Here, c₁ = 1, c₂ = 2, b₁ = 10, b₂ = 20, a₁₁ = 1, a₁₂ = 2, a₂₁ = 10, and a₂₂ = 3.

x₁ = −1, x₂ = 15 is a solution to the given problem, but it is not a feasible one, as x₁ < 0.

x₁ = 0.588235, x₂ = 4.705882 is an optimal basic feasible solution to the given problem, and the corresponding minimum value of z is 10.

## 2.2. Assumptions in a Linear Programming Problem

To solve any real-life problem by the linear programming (LP) approach, the following assumptions are made:

**1. Certainty.** This assumption requires that all the parameters of the model be known before solving a given LP problem. In other words, the coefficients cⱼ of the objective function, the coefficients of the constraints aᵢⱼ, and the resource vector bᵢ must all be known and fixed. However, using sensitivity analysis (discussed later in this text), the decision maker can explore the effects of changing some parameters over a range of values.

**2. Linearity.** This is a property of the mathematical function. Linearity denotes a stable relationship between a dependent and independent variables, which when plotted on a graph would be represented by a straight line. In linear programming, the relationship of the various decision variables, either in the objective function or in any of the constraints, should be linear. Note that in a linear relationship, all variables have an exponent of one, and no variables are put in product form. The following three properties clarify the implications of linearity:

(i) **Proportionality.** This requires that the value of the objective function be proportional to the value of the decision variables. For example, in an objective function Max 25x₁ + 38x₂, each unit of x₁ should contribute 25 (a proportionality constant) to the value of the objective function, and hence the total contribution of any activity in the objective function depends on the level of activity, or the value of the decision variable. In the constraints, the amount of each resource used must be proportional to the value of the decision variable. For example, let x₁ + 4x₂ ≤ 50 be a constraint of a given LPP; then each unit of x₂ will consume 4 units (a proportional amount) of the available resource (in this case, 50).

(ii) **Additivity.** Linearity also requires that the effect of the value of each variable on the values of the objective function and the constraints is additive. In other words, there can be no interactions between the effects of different activities. For the objective function Max 25x₁ + 38x₂, for example, if x₁ = 2 and x₂ = 1, this property asserts that the contributions of 50 and 38, respectively, must add together to give a sum of 88.

(iii) **Divisibility (or continuity).** This postulate allows the variables to have a continuous range of values. This means that the variables may take any fractional or decimal value and will not necessarily be a whole number or integer. However, in many real-life situations there may be cases where the variables are allowed to have only integer values, and in such situations LP may be used to provide an approximate answer by rounding off the solution to the nearest integer value — but doing so may cause a significant departure from optimality. If integer solutions are required, then the given linear programming problem is a special type of problem called a linear integer programming problem (discussed later).

## 2.3. Theorems on Extreme Points

**Theorem 2.1.** The set of feasible solutions to a given LPP forms a convex set.

*Proof.* Let S denote the set of feasible solutions to the following LPP:

Max Z = CX, subject to AX ≤ b, X ≥ 0   ...(2.4)

where S = {X | AX ≤ b, X ≥ 0}.

Let X₁, X₂ ∈ S, such that

AX₁ ≤ b   ...(2.5)
AX₂ ≤ b   ...(2.6)

Let X′ denote the point on the line segment joining X₁ and X₂; then

X′ = λX₁ + (1 − λ)X₂, 0 ≤ λ ≤ 1   ...(2.7)

Multiplying both sides of (2.7) by A, we get

AX′ = λAX₁ + (1 − λ)AX₂ ≤ λb + (1 − λ)b = b  (from (2.5) and (2.6))

⇒ AX′ ≤ b, which implies that X′ ∈ S.

Hence, the set of feasible solutions to a given LPP is a convex set. ∎

**Theorem 2.2.** If the set of feasible solutions to a given LPP is a convex polyhedron, then at least one extreme point of the problem will be the optimum solution of the LPP.

*Proof.* Let Max z = cx, subject to Ax = b, x ≥ 0, ...(2.8) be a given LPP, and let S be the set of feasible solutions to (2.8), which is a convex polyhedron. Also let x₁, x₂, ..., xₖ denote the extreme points of S, and let x* ∈ S be the optimum solution of (2.8), that is, z* = cx* ≥ cx for all x.

If x* is not an extreme point of S, then

x* = Σᵢ₌₁ᵏ λᵢxᵢ, λᵢ ≥ 0, Σᵢ₌₁ᵏ λᵢ = 1   ...(2.9)

This implies

z* = cx* = Σᵢ₌₁ᵏ λᵢ(cxᵢ)   ...(2.10)

Let max cxᵢ = cxₚ for all i = 1, 2, ..., k. Now (2.10) can be written as

cx* ≤ Σᵢ₌₁ᵏ λᵢ(cxₚ) = cxₚ, since Σᵢ₌₁ᵏ λᵢ = 1

But cx* is the maximum value of z, hence cx* = cxₚ ⇒ x* = xₚ (one of the extreme points).

Hence, the optimum solution of the LPP is attained at one of the extreme points. ∎

**Theorem 2.3.** Let S = {x ∈ Rⁿ : Ax = b, x ≥ 0} be the set of feasible solutions of the following LPP: Max z = cx, subject to Ax = b, x ≥ 0. Then x* ∈ S is a basic feasible solution of the given problem if and only if it is an extreme point of S.

*Proof (Part 1).* Let x* ∈ S be a basic feasible solution of the given problem, such that

Ax* = b, x* ≥ 0   ...(2.11)

We have to prove that this is an extreme point; that is, we have to show that two points do not exist in the set such that x* can be written as a convex combination of these points.

On the contrary, let us assume that x* is not an extreme point of the set of feasible solutions; then two solutions x′ and x″ ∈ S exist, such that

x* = λx′ + (1 − λ)x″, 0 < λ < 1   ...(2.12)

Further, let x* = [x*_B, x*_NB], x′ = [x′_B, x′_NB], x″ = [x″_B, x″_NB]   ...(2.13)

where x*_B, x′_B, and x″_B are m-component vectors (the basic variables) and x*_NB, x′_NB, and x″_NB are (n − m)-component vectors (the non-basic variables).

From (2.12) and (2.13), we have

[x*_B, x*_NB] = λ[x′_B, x′_NB] + (1 − λ)[x″_B, x″_NB]   ...(2.14)

Since x* ∈ S is a basic feasible solution, we have x*_NB = 0 and Bx*_B = b, where B is the m × m basic matrix for the given LPP.

Now, looking at the non-basic components of (2.14):

0 = λx′_NB + (1 − λ)x″_NB, where 0 < λ < 1

⇒ x′_NB = x″_NB = 0   ...(2.15)

Further, Ax′ = Bx′_B = b and Ax″ = Bx″_B = b ⇒ x′_B = x″_B = x*_B, and hence x* = x′ = x″, which contradicts our assumption. Therefore, x* is an extreme point of S.

*(Part 2).* Here we show that if x* ∈ S is an extreme point, then it is a basic feasible solution to the given LPP.

x* is an n-component vector. Let us assume that its r components are positive and the rest are zero, such that

Σⱼ₌₁ʳ Aⱼxⱼ* = b, xⱼ* > 0, j = 1, 2, ..., r   ...(2.16)

where Aⱼ denotes the j-th column of A.

In order to prove that x* is a basic feasible solution, we have to show that the (column) vectors associated with the positive components of x* are linearly independent.

To prove it, let us assume on the contrary that these vectors are linearly dependent, that is:

Σⱼ₌₁ʳ βⱼAⱼ = 0, where at least one βⱼ is non-zero   ...(2.17)

Now consider θ = min{ xⱼ*/βⱼ : βⱼ ≠ 0, j = 1, 2, ..., r }, a positive number.

If we take 0 < ε < θ, then xⱼ* − εβⱼ > 0 and xⱼ* + εβⱼ > 0, for j = 1, 2, ..., r   ...(2.18)

In vector form, define

x′ = x* + εβ and x″ = x* − εβ, where x*, x′, x″, β are n-component vectors   ...(2.19)

Also, x′, x″ ≥ 0, that is, both are feasible solutions, and hence we have

Ax′ = Ax* + εAβ = Ax* = b  (since Aβ = 0, from (2.17))

Similarly, Ax″ = Ax* − εAβ = Ax* = b

Further, from (2.19) we can write x* = ½x′ + ½x″, which contradicts the fact that x* is an extreme point.

Hence, our assumption is wrong. This proves that the vectors associated with the positive variables are linearly independent, and hence the extreme point is a basic feasible solution. ∎

**Theorem 2.4.** If an optimum value of the objective function occurs at any two extreme points of the feasible region, then all the points on the line segment joining these points also give the optimal value of the objective function.

*Proof.* Let the maximum value of the objective function of the LPP, Max z = cx, subject to Ax = b, x ≥ 0, occur at the extreme points x₁ and x₂; then let Max z = z* = cx₁ = cx₂.

Let x′ be a point on the line segment joining x₁ and x₂; then

x′ = λx₁ + (1 − λ)x₂, 0 ≤ λ ≤ 1

⇒ cx′ = λcx₁ + (1 − λ)cx₂ = λz* + (1 − λ)z* = z*

⇒ x′ is also an optimal solution of the problem, and hence the theorem is proved. ∎

## 2.4. Areas of Application of LPPs

**I. Product Mix Problem.** Here we have to determine the right mix and quantities of products to be manufactured so as to maximize the profit. A firm can produce different types of products which require different resources in different quantities, and each product contributes a certain amount towards profit. The final product mix must take into consideration the limited resources, expected demand for each product, and various policies of the company, while maximizing profit.

**II. Blending Problem.** In this type of problem, several raw materials are mixed into the final product, which must fulfill certain specifications. Each of the raw materials contributes certain properties to the final product and involves a certain cost.

**III. Media Allocation Problem.** Suppose a company has a fixed budget to be utilized for advertising a particular product in different media, where each medium has a different impact and reach. The cost of inserting an advertisement into each medium is different and known. The problem is to determine the number of allocations of an advertisement in different media so as to maximize exposure of the product to its target population, which maximizes sales.

**IV. Production Scheduling and Inventory Planning.** Suppose the demand for a particular product fluctuates over a period of time. Varying production rates have proven to be costly. The problem is to determine a smooth production schedule that meets anticipated demand while maintaining a reasonable inventory level that minimizes overall production and inventory-carrying cost.

**V. Purchasing Problem.** Linear programming can also be used to decide on the purchase of various products available at different discounts and prices for different quantity ranges. The problem is to determine the quantity of each product that should be purchased so as to maximize (minimize) overall profit (cost).

**VI. Assignment and Transportation Problem.** The transportation and assignment problems can always be formulated as a special type of linear integer programming problem, satisfying the various row and column requirements while minimizing the cost of assignment or transportation.

## 2.5. Formulation of Linear Programming Models

The following steps are needed for a successful formulation of an LP model:

I. Understand the problem.
II. Identify the decision variables involved in the problem.
III. Identify the various coefficients of the objective function.
IV. Identify the various restrictions of the problem.
V. Represent the objective function in the form of a linear expression involving decision variables.
VI. Represent all the restrictions in the form of linear expressions involving decision variables.

**Example 2.1 (Product Mix).** A small plant manufactures two models of a product, A and B. Two resources, R1 and R2, are required for manufacturing. One unit of A consumes 10 units of R1 and 15 units of R2. One unit of B consumes 12 units of R1 and 17 units of R2. The company has 800 units of R1 and 600 units of R2 available per week, and each unit of model A and B gives a profit of $50 and $70, respectively. Formulate this as a linear programming problem to find the optimal weekly production levels for these two models.

*Solution.* Let x₁ and x₂ denote the weekly production levels of model A and model B, respectively. The LP model is:

Max z = 50x₁ + 70x₂  (Objective function)

Subject to
10x₁ + 12x₂ ≤ 800  (R1 resource)
15x₁ + 17x₂ ≤ 600  (R2 resource)
x₁, x₂ ≥ 0  (Non-negative condition)

**Example 2.2 (Production Scheduling).** A firm manufactures three versions of the same product, with unit profit contributions of 2, 3, and 3.5. In the final part of the manufacturing process, there are assembly, polishing, and packing operations. The time (in hours) required for these operations, per unit, is:

| Product version | Assembly | Polishing | Packing |
|---|---|---|---|
| 1 | 4 | 3 | 3 |
| 2 | 5 | 1 | 4 |
| 3 | 2 | 4 | 1.5 |

Each year, the firm has 1,000 hours of assembly time, 800 hours of polishing time, and 950 hours of packing time available. Formulate a linear programming problem to find the number of each version the company should make per year to maximize profit.

*Solution.* Let x₁, x₂, and x₃ be the number of units of the first, second, and third version produced per year. The LP model is:

Max z = 2x₁ + 3x₂ + 3.5x₃  (Objective function)

Subject to
4x₁ + 5x₂ + 2x₃ ≤ 1000  (Assembly)
3x₁ + x₂ + 4x₃ ≤ 800  (Polishing)
3x₁ + 4x₂ + 1.5x₃ ≤ 950  (Packing)
x₁, x₂, x₃ ≥ 0  (Non-negativity condition)

**Example 2.3 (Purchasing Problem).** A firm is planning to buy two types of cupboards for its new office room, which has a maximum area of 110 square feet for the cupboards. The first type costs $150 per unit, requires five square feet of floor space, and holds nine cubic feet of files. The second type costs $170 per unit, requires seven square feet of floor space, and holds eleven cubic feet of files. The firm has a total budget of $10,000. How many of each type of cupboard should the firm buy to maximize storage volume?

*Solution.* Let x₁ and x₂ be the number of units of the first and second type of cupboards, respectively. The LP model is:

Max z = 9x₁ + 11x₂

Subject to
150x₁ + 170x₂ ≤ 10000  (Cost restriction)
5x₁ + 7x₂ ≤ 110  (Floor restriction)
x₁, x₂ ≥ 0  (Non-negativity condition)

**Example 2.4 (Transportation Problem).** A consumer durable company that manufactures a single product has three plants, I, II, and III, producing 100, 150, and 120 units, respectively. The firm has committed to selling 80 units to customer A, 100 to B, 70 to C, and 120 to D. The net unit cost of transportation from each plant to each customer is:

| Plant | A | B | C | D |
|---|---|---|---|---|
| I | 10 | 20 | 15 | 18 |
| II | 21 | 10 | 19 | 11 |
| III | 18 | 14 | 22 | 13 |

Formulate this as a linear programming problem to minimize the total cost of transportation.

*Solution.* Let xᵢⱼ (i = 1, 2, 3 and j = 1, 2, 3, 4) denote the number of units transported from the i-th plant to the j-th customer. The objective function is:

Min z = 10x₁₁ + 20x₁₂ + 15x₁₃ + 18x₁₄ + 21x₂₁ + 10x₂₂ + 19x₂₃ + 11x₂₄ + 18x₃₁ + 14x₃₂ + 22x₃₃ + 13x₃₄

Subject to

Row (supply) constraints:
Σⱼ₌₁⁴ x₁ⱼ = 100
Σⱼ₌₁⁴ x₂ⱼ = 150
Σⱼ₌₁⁴ x₃ⱼ = 120

Column (demand) constraints:
Σᵢ₌₁³ xᵢ₁ = 80
Σᵢ₌₁³ xᵢ₂ = 100
Σᵢ₌₁³ xᵢ₃ = 70
Σᵢ₌₁³ xᵢ₄ = 120

and xᵢⱼ ≥ 0 for all i, j  (non-negativity condition)

**Example 2.5 (Media Allocation Problem).** A company has an advertising budget of $1,000,000 and is planning to advertise its products in three different media: television, radio, and newspapers. Television advertising is further divided into prime time and non-prime time. The objective is to have maximum exposure of the product to potential customers. A market survey gives the following results:

| | TV — Prime time | TV — Non-prime time | Radio | Newspaper |
|---|---|---|---|---|
| Cost per unit ($) | 50,000 | 28,000 | 20,000 | 19,000 |
| Potential customers reached per unit | 700,000 | 350,000 | 250,000 | 180,000 |
| Female potential customers reached per unit | 500,000 | 100,000 | 110,000 | 87,000 |

The company decided it will spend no more than 50% of the total budget on television. Management is also unwilling to have more than 7 and 10 insertions in radio and newspapers, respectively. Finally, the company wants a minimum of 1.5 million exposures among women. Formulate this as an LP model to maximize the total reach of potential customers.

*Solution.* Let x₁, x₂, x₃, and x₄ denote the number of insertions in prime time, non-prime time (TV), radio, and newspapers, respectively. The LP model is:

Max z = 700000x₁ + 350000x₂ + 250000x₃ + 180000x₄  (Maximize potential reach)

Subject to
50000x₁ + 28000x₂ + 20000x₃ + 19000x₄ ≤ 1,000,000  (Budget constraint)
50000x₁ + 28000x₂ ≤ 500,000  (Restriction on television advertisement)
500000x₁ + 100000x₂ + 110000x₃ + 87000x₄ ≥ 1,500,000  (Minimum female reach)
x₃ ≤ 7, x₄ ≤ 10  (Upper limits on radio and newspaper insertions)
x₁, x₂, x₃, x₄ ≥ 0

## 2.6. Graphical Method

The graphical method can be used to solve any LPP with two variables only. There are two different approaches for solving an LPP using the graphical method:

### 2.6.1. Extreme Point Approach

The following steps are followed with this approach:

I. Draw an xy-plane and select the set of points (x, y) which satisfy the non-negative restrictions of the given LPP. This set of points is the set of feasible solutions to the given problem, and all such points lie in the first quadrant of the xy-plane.

II. Draw all the constraints in the xy-plane and identify the common region — the set of solutions (x, y) that satisfy all the constraints and lie in the first quadrant. This is called the common region of feasible solutions.

III. Identify the corner points (extreme points) of the common region of feasible solutions, and find the value of the objective function at these points. Select the point which optimizes the objective function; this represents the optimal solution.

IV. Interpret the result.

*Note.* The common feasible region of any LP problem always forms a convex set, and its optimum solution lies at one of the extreme points of the convex set.

### 2.6.2. ISO-Profit (Cost) Function Line Approach

After completing steps I and II from Section 2.6.1, continue with the following:

I. Draw an ISO-profit (ISO-cost) line for a small value of the objective function without violating any of the given restrictions.

II. Continue drawing ISO-profit (ISO-cost) lines parallel to one another in the direction of increasing (or decreasing) the value of the objective function.

III. The last point of the feasible region where this line touches before it moves out of the feasible region — for which the value of ISO-profit (ISO-cost) is maximum (minimum) — is the optimal solution.

We'll discuss the steps involved in solving a simple linear programming model graphically with the help of examples. In this book, our main focus is on the extreme point approach.

Subject to the constraints:
x₁ + 3x₂ ≤ 21
x₁ + x₂ ≤ 8
x₁, x₂ ≥ 0

*Solution.* In the xy-plane, we take x₁ on the x-axis and x₂ on the y-axis. Plotting the two constraints along with the non-negativity conditions produces a feasible region OABC with the following extreme points:

*Extreme point approach:* the shaded region OABC is the feasible region for the given problem, and the optimum solution lies at one of its extreme points. The value of the objective function z at each of these points is:

I. at O (0, 0), z = 0
II. at A (0, 7), z = 28
III. at B (1.5, 6.5), z = 29
IV. at C (8, 0), z = 16

We can clearly see that z = 29 is the maximum value of z, occurring at point B. Hence, the optimum solution of the problem is (x₁, x₂) = (1.5, 6.5), and the corresponding maximum value of the objective function is z* = 29.

*ISO-profit (cost) function line approach:* To get an iso-profit line, set the objective function equal to some arbitrary small number. This gives a linear equation in x₁ and x₂ that can be plotted in the xy-plane; all the points on an iso-profit line give the same profit. To start, let z = 10. Then the equation becomes 2x₁ + 4x₂ = 10, and this line contains all the points that have a profit of exactly 10.

Now find the highest value of the iso-profit line that still touches the feasible region, by plotting a number of parallel lines, moving away from the origin, until the line last touches a corner point of the feasible region. Here, the iso-profit line touches corner point B for the first time. The coordinates of the corner points can be read from the graph or computed as the intersection of the relevant pairs of constraint lines.

Therefore, the optimum solution of the problem is x₁ = 1.5, x₂ = 6.5, and the corresponding maximum value of the objective function is z* = 29.

**Example 2.8.** Maximize z = 4x₁ + x₂

Subject to the constraints:
2x₁ + x₂ ≤ 100
x₁ + x₂ ≤ 80
x₁ ≤ 40
x₁, x₂ ≥ 0

*Solution.* Plotting the three constraints along with the non-negativity conditions gives a feasible region OABCD. The values of z at these extreme points are:

I. at O (0, 0), z = 0
II. at A (0, 80), z = 80
III. at B (20, 60), z = 140
IV. at C (40, 20), z = 180
V. at D (40, 0), z = 160

Clearly, z = 180 is the maximum value of z, occurring at point C (40, 20). Hence, the optimum solution of the problem is (x₁ = 40, x₂ = 20), and the corresponding maximum value of the objective function is z* = 180.

The following section discusses some special cases in linear programming problems.

## 2.8. Special Cases

### 2.8.1. Problem with Multiple Solutions

In some linear programming problems, instead of having a unique optimal basic feasible solution, we may have an infinite number of optimal basic feasible solutions. This case occurs when the objective function line is parallel to one of the constraint lines and lies along one of the edges of the feasible region, as illustrated below.

**Example 2.9.** Maximize z = x₁ + 2x₂

Subject to the constraints:
6x₁ + 4x₂ ≤ 24
x₁ + 2x₂ ≤ 6
−x₁ + x₂ ≤ 1
x₂ ≤ 2
x₁, x₂ ≥ 0

*Solution.* Plotting the constraints along with the non-negativity conditions gives a feasible region OABCDE. The values of z at the labeled extreme points are:

I. at O (0, 0), z = 0
II. at A (0, 1), z = 2
III. at B (1, 2), z = 5
IV. at C (2, 2), z = 6
V. at D (3, 1.5), z = 6

The maximum value of z is 6, occurring at two points, C and D. This is therefore a case of multiple solutions: all the points on the line segment joining C and D also give this same value of z.

*Note.* If a problem has two points giving the same optimum value of the objective function, then the problem has an infinite number of optimal solutions — every point on the line segment joining the two points — and all of them give the same value of the objective function.

### 2.8.2. The Problem with Unbounded Solutions

In some problems, the solution space is unbounded in at least one variable — that is, the value of that variable may be increased indefinitely without violating any of the given constraints, giving an infinitely large (or small) value of the objective function. This kind of problem has an unbounded solution. An unbounded solution space is usually a sign that the problem has been poorly designed.

**Example 2.10.** Maximize z = 4x₁ + 10x₂

Subject to the constraints:
x₁ ≤ 10
x₁ + 2x₂ ≥ 6
x₁, x₂ ≥ 0

*Solution.* In the solution space satisfying the constraints and the non-negativity restrictions, the value of x₂ can be increased indefinitely because of the second constraint, x₁ + 2x₂ ≥ 6. As a result, the value of the objective function can also be increased indefinitely. Hence, the given LP problem has an unbounded solution.

### 2.8.3. The Problem with Inconsistent Constraints

The constraints of a given problem are said to be inconsistent if they are mutually exclusive — that is, if no point satisfies all of the constraints simultaneously, and hence there is no common region of feasible solutions. (Sometimes a common region of solutions exists, but none of its points satisfy the non-negative restriction.) In either situation, there is no solution to the given problem. Such a problem arises from a wrong or improper formulation with conflicting constraints. A problem with inconsistent constraints is said to be infeasible. Infeasibility is purely due to the constraints of the problem; the objective function has no role in it.

**Example 2.11.** Maximize z = x₁ + 4x₂

Subject to the constraints:
x₁ + 2x₂ ≥ 40
x₁ + x₂ ≤ 15
x₁, x₂ ≥ 0

*Solution.* Plotting the two constraints along with the non-negativity conditions shows that there is no common region between them, and hence no feasible solution for the problem. This is a problem with inconsistent constraints, and it possesses no solution.

### 2.8.4. The Problem with Redundant Constraint Equations

An LPP is said to have a redundant constraint if at least one of the constraints plays no role in determining the optimal solution — that is, if removing it produces the same solution as when it was present.

**Example 2.12.** Maximize z = 2x₁ − x₂

Subject to the constraints:
x₁ + 4x₂ ≤ 50
x₁ + x₂ ≤ 20
1.5x₁ + x₂ ≤ 30
x₁, x₂ ≥ 0

*Solution.* The feasible region is OABC. The values of z at these extreme points are:

I. at O (0, 0), z = 0
II. at A (0, 12.5), z = −12.5
III. at B (10, 10), z = 10
IV. at C (20, 0), z = 40

The maximum value of z is 40, occurring at point C. It can be clearly seen that with or without the third constraint, the optimal solution of the problem remains the same — because the second constraint (x₁ + x₂ ≤ 20) and the third constraint (1.5x₁ + x₂ ≤ 30) meet the x₁-axis at exactly the same point, x₁ = 20. Hence, the constraint 1.5x₁ + x₂ ≤ 30 is redundant.
