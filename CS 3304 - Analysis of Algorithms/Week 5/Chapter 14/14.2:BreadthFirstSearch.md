# Breadth First Search (BFS) for a Graph 

## 1. What is BFS?

Breadth First Search (BFS) is a graph traversal algorithm that starts from a source node and explores the graph **level by level**: first all nodes directly adjacent to the source, then the adjacent nodes of those nodes, and so on until every reachable node is visited.

- **BFS vs DFS:** BFS visits the *closest* vertices first (level by level, using a queue); DFS goes as deep as possible first (using a stack/recursion).
- Popular algorithms built on BFS: **Dijkstra's shortest path**, **Kahn's algorithm** (topological sort), **Prim's MST**.
- BFS itself solves: shortest path in an unweighted graph, cycle detection (directed and undirected), connected components, and more.
- Note: **Branch and Bound** generates its state space tree in BFS order, while Backtracking uses DFS.

## 2. Examples

**Example 1 (connected):**

```
adj = [[1, 2], [0, 2], [0, 1, 3, 4], [2], [2]]
Output: [0, 1, 2, 3, 4]
```

From 0: visit 0 → its neighbors 1, 2 → then 2's unvisited neighbors 3, 4.

**Example 2 (disconnected):**

```
adj = [[2, 3], [2], [0, 1], [0], [5], [4]]
Output: [0, 2, 3, 1, 4, 5]
```

From 0: visit 0 → neighbors 2, 3 → 2's unvisited neighbor 1. Component {4, 5} is unreachable from 0, so start a second BFS at 4: visit 4 → 5.

## 3. How BFS Works (Core Idea)

1. Put the **source** in a queue and mark it visited.
2. Loop while the queue is not empty: **dequeue** the front vertex, add it to the result.
3. **Enqueue** every unvisited neighbor of that vertex, marking each visited *when enqueued*.

Since graphs may contain **cycles**, a vertex could be visited multiple times — the **visited array** prevents revisiting (and infinite loops). Marking at enqueue time (not dequeue time) prevents the same vertex sitting in the queue twice.

## 4. BFS from a Given Source (Connected Graph) — Java

```java
import java.util.*;

class GfG {

    // BFS for single connected component
    static ArrayList<Integer> bfs(ArrayList<ArrayList<Integer>> adj) {
        int V = adj.size();
        boolean[] visited = new boolean[V];
        ArrayList<Integer> res = new ArrayList<>();

        int src = 0;
        Queue<Integer> q = new LinkedList<>();
        visited[src] = true;
        q.add(src);

        while (!q.isEmpty()) {
            int curr = q.poll();
            res.add(curr);

            // visit all the unvisited neighbours of current node
            for (int x : adj.get(curr)) {
                if (!visited[x]) {
                    visited[x] = true;
                    q.add(x);
                }
            }
        }
        return res;
    }

    public static void main(String[] args) {
        // adj = [[1,2], [0,2], [0,1,3,4], [2], [2]]
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        int[][] edges = {{1,2}, {0,2}, {0,1,3,4}, {2}, {2}};
        for (int[] row : edges) {
            ArrayList<Integer> list = new ArrayList<>();
            for (int v : row) list.add(v);
            adj.add(list);
        }
        System.out.println(bfs(adj));  // [0, 1, 2, 3, 4]
    }
}
```

**Time complexity: O(V + E)** — every vertex and edge is processed exactly once.
**Auxiliary space: O(V)** — the queue (plus visited array) holds at most all vertices.

## 5. BFS of a Disconnected Graph — Java

A single source can't reach every vertex in a disconnected graph. Fix: iterate over **all** vertices; whenever one is unvisited, run BFS with it as the source. This covers every connected component.

```java
import java.util.*;

class GfG {

    // BFS for a single connected component
    static void bfsConnected(ArrayList<ArrayList<Integer>> adj, int src,
                             boolean[] visited, ArrayList<Integer> res) {
        Queue<Integer> q = new LinkedList<>();
        visited[src] = true;
        q.add(src);

        while (!q.isEmpty()) {
            int curr = q.poll();
            res.add(curr);

            for (int x : adj.get(curr)) {
                if (!visited[x]) {
                    visited[x] = true;
                    q.add(x);
                }
            }
        }
    }

    // BFS for all components (handles disconnected graphs)
    static ArrayList<Integer> bfs(ArrayList<ArrayList<Integer>> adj) {
        int V = adj.size();
        boolean[] visited = new boolean[V];
        ArrayList<Integer> res = new ArrayList<>();

        for (int i = 0; i < V; i++) {
            if (!visited[i])
                bfsConnected(adj, i, visited, res);
        }
        return res;
    }

    public static void main(String[] args) {
        // adj = [[2,3], [2], [0,1], [0], [5], [4]]
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        int[][] edges = {{2,3}, {2}, {0,1}, {0}, {5}, {4}};
        for (int[] row : edges) {
            ArrayList<Integer> list = new ArrayList<>();
            for (int v : row) list.add(v);
            adj.add(list);
        }
        System.out.println(bfs(adj));  // [0, 2, 3, 1, 4, 5]
    }
}
```

**Time complexity: O(V + E)** — the outer loop starts BFS from every unvisited vertex, but the shared visited array ensures each vertex/edge is processed once, keeping the total linear.
**Auxiliary space: O(V)**.

## 6. Applications of BFS

1. **Shortest path in unweighted graphs** — BFS reaches every vertex using the minimum number of edges from the source. (In unweighted graphs any spanning tree is an MST, so BFS/DFS can build one; BFS also gives an MST in weighted graphs if all weights are equal and non-negative.)
2. **Cycle detection** — in undirected graphs (BFS or DFS), and in directed graphs too.
3. **Connected components** — find all components of an undirected graph, or all nodes reachable from a given node.
4. **Path finding** — check whether a path exists between two vertices.
5. **Topological sorting** — Kahn's BFS-based algorithm on DAGs.
6. **Bipartite testing** — 2-color the graph level by level.
7. **Peer-to-peer networks** (e.g., BitTorrent) — find all neighbor nodes.
8. **Web crawlers** — build the index breadth-first from a source page; levels/depth can be limited.
9. **Social networks** — find all people within distance k (run BFS for k levels).
10. **GPS navigation** — find all neighboring locations.
11. **Network broadcasting** — a broadcast packet propagates in BFS order to reach all nodes.
12. **Garbage collection** — Cheney's copying GC uses BFS (better locality of reference than DFS).
13. **Ford–Fulkerson max flow** — using BFS (Edmonds–Karp) bounds the worst case at O(V·E²).
14. **AI game trees**, **network security scans** (find all connected devices), **image processing** (flood fill, connected pixel components), **recommender systems** (similar items in a similarity graph).
15. Dijkstra's and Prim's algorithms use BFS-like structures (queue → priority queue).

## 7. Advantages and Disadvantages

**Advantages**

- Never gets trapped exploring one path forever (unlike DFS on deep/infinite branches).
- **Complete**: if a solution exists, BFS will find it.
- **Optimal** for uniform step costs: among multiple solutions, BFS finds the one with fewest steps (shallowest).
- Simple to program.

**Disadvantage: memory**

Each level must be stored to generate the next. Space is **O(bᵈ)** where b = branching factor (out-degree) and d = depth — exponential in depth. In practice BFS is severely space-bound and can exhaust typical memory quickly on wide/deep graphs, whereas DFS needs only O(d) space along the current path.

## 8. Quick Reference

| | BFS | DFS |
|---|---|---|
| Data structure | Queue (FIFO) | Stack / recursion (LIFO) |
| Order | Level by level, closest first | Deep first, then backtrack |
| Time | O(V + E) | O(V + E) |
| Space | O(V) for graphs; O(bᵈ) in tree-search terms | O(V); O(d) along current path |
| Shortest path (unweighted) | Yes | No |
| Used by | Dijkstra, Kahn, Prim, Edmonds–Karp, Branch & Bound | Backtracking, topological sort (DFS variant), SCC |
