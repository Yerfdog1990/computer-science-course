# Depth First Search (DFS) for a Graph 

## 1. What is DFS?

Depth First Search (DFS) traverses adjacent vertices one by one — but when it moves to an adjacent vertex, it **completely finishes** the traversal of all vertices reachable through that vertex before trying the next one.

- Similar to **preorder traversal of a binary tree**: fully traverse the left subtree, then move to the right subtree.
- Key difference from trees: graphs may contain **cycles** (a node could be visited more than once), so a boolean **visited array** is used to avoid processing a node multiple times.
- There can be **multiple valid DFS traversals** of the same graph, depending on the order adjacent vertices are picked (here: insertion order).

## 2. Examples

**Example 1 (connected):**

```
adj = [[1, 2], [0, 2], [0, 1, 3, 4], [2], [2]]
Output: [0, 1, 2, 3, 4]
```

Start at 0 → move to 1 → move to 2 → move to 3 (backtrack to 2) → move to 4 (backtrack to 2 → 1 → 0).

**Example 2 (disconnected):**

```
adj = [[2, 3], [2], [0, 1], [0], [5], [4]]
Output: [0, 2, 1, 3, 4, 5]
```

Start at 0 → 2 → 1 (backtrack to 2, then 0) → 3 (backtrack to 0). Component {4, 5} is unreachable → start again at 4 → 5.

## 3. How DFS Works (Core Idea)

DFS starts from a source vertex and explores **one path as deeply as possible**. When it reaches a vertex with no unvisited neighbors, it **backtracks** to the previous vertex to explore other unvisited paths, continuing until all reachable vertices are visited.

1. Mark the current vertex as visited and process it (e.g., add to result).
2. Recursively visit each **unvisited** neighbor of the current vertex.
3. If a vertex has no unvisited neighbors, the recursion returns — that *is* the backtrack.

The visited array prevents infinite loops on cycles.

## 4. DFS from a Given Source (Undirected) — Java

```java
import java.util.ArrayList;

class GFG {

    static void dfsRec(ArrayList<ArrayList<Integer>> adj,
                       boolean[] visited, int s, ArrayList<Integer> res) {
        visited[s] = true;
        res.add(s);

        // Recursively visit all adjacent vertices
        // that are not visited yet
        for (int i : adj.get(s)) {
            if (!visited[i]) {
                dfsRec(adj, visited, i, res);
            }
        }
    }

    static ArrayList<Integer> dfs(ArrayList<ArrayList<Integer>> adj) {
        boolean[] visited = new boolean[adj.size()];
        ArrayList<Integer> res = new ArrayList<>();
        dfsRec(adj, visited, 0, res);
        return res;
    }

    static void addEdge(ArrayList<ArrayList<Integer>> adj, int u, int v) {
        adj.get(u).add(v);
        adj.get(v).add(u);   // undirected
    }

    public static void main(String[] args) {
        int V = 5;
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < V; i++)
            adj.add(new ArrayList<>());

        addEdge(adj, 1, 2);
        addEdge(adj, 1, 0);
        addEdge(adj, 2, 0);
        addEdge(adj, 2, 3);
        addEdge(adj, 2, 4);

        // Perform DFS starting from vertex 0
        System.out.println(dfs(adj));  // [0, 1, 2, 3, 4]
    }
}
```

**Time complexity: O(V + E)**.
**Auxiliary space: O(V + E)** — the visited array of size V plus the recursion call stack.

## 5. DFS of a Disconnected Graph — Java

Some vertices may not be reachable from a single source. Fix: loop through **all** vertices; whenever one is unvisited, run DFS from it. This explores every connected component.

```java
import java.util.ArrayList;

public class GFG {

    private static void dfsRec(ArrayList<ArrayList<Integer>> adj,
                               boolean[] visited, int s, ArrayList<Integer> res) {
        visited[s] = true;
        res.add(s);
        for (int i : adj.get(s)) {
            if (!visited[i]) {
                dfsRec(adj, visited, i, res);
            }
        }
    }

    public static ArrayList<Integer> dfs(ArrayList<ArrayList<Integer>> adj) {
        boolean[] visited = new boolean[adj.size()];
        ArrayList<Integer> res = new ArrayList<>();

        // Loop through all vertices to handle disconnected graphs
        for (int i = 0; i < adj.size(); i++) {
            if (!visited[i]) {
                dfsRec(adj, visited, i, res);
            }
        }
        return res;
    }

    static void addEdge(ArrayList<ArrayList<Integer>> adj, int u, int v) {
        adj.get(u).add(v);
        adj.get(v).add(u);
    }

    public static void main(String[] args) {
        int V = 6;
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < V; i++)
            adj.add(new ArrayList<>());

        addEdge(adj, 1, 2);
        addEdge(adj, 0, 3);
        addEdge(adj, 2, 0);
        addEdge(adj, 5, 4);

        System.out.println(dfs(adj));  // [0, 3, 2, 1, 4, 5]
    }
}
```

**Time complexity: O(V + E)** — every vertex is visited at most once; every edge is traversed once (directed) or twice (undirected).
**Auxiliary space: O(V + E)** — visited array + recursion stack.

## 6. DFS on a Directed Graph

In directed graphs, edges have a direction — you can only travel the way the edge points. DFS works the same way; only edge insertion changes (`addEdge` adds one direction).

**Example 1:** V = 5, edges = {(1,2), (1,0), (2,0), (2,3), (2,4)}, source = 1 → Output: `1 2 0 3 4`
Start at 1 → 2 → 0 (backtrack) → 3 (backtrack) → 4; all of 1's reachable nodes done.

**Example 2:** V = 5, edges = {(0,2), (0,3), (2,4), (1,0)}, source = 2 → Output: `2 4`
Only vertices reachable *along edge directions* from the source are printed.

### From a given source — Java

```java
import java.util.ArrayList;
import java.util.List;

class GfG {
    // Add edge from vertex s to t (directed)
    static void addEdge(List<List<Integer>> adj, int s, int t) {
        adj.get(s).add(t);
    }

    static void DFSRec(List<List<Integer>> adj, boolean[] visited, int s) {
        visited[s] = true;
        System.out.print(s + " ");
        for (int i : adj.get(s)) {
            if (!visited[i]) {
                DFSRec(adj, visited, i);
            }
        }
    }

    static void DFS(List<List<Integer>> adj, int s) {
        boolean[] visited = new boolean[adj.size()];
        DFSRec(adj, visited, s);
    }

    public static void main(String[] args) {
        int V = 5;
        List<List<Integer>> adj = new ArrayList<>(V);
        for (int i = 0; i < V; i++)
            adj.add(new ArrayList<>());

        int[][] edges = {{1, 2}, {1, 0}, {2, 0}, {2, 3}, {2, 4}};
        for (int[] e : edges)
            addEdge(adj, e[0], e[1]);

        int source = 1;
        System.out.println("DFS from source: " + source);
        DFS(adj, source);   // 1 2 0 3 4
    }
}
```

### Complete traversal of a disconnected directed graph — Java

The source-based version prints only vertices **reachable from the source**. To print *all* vertices with no source given (graph may be disconnected), start DFS from every unvisited vertex:

```java
import java.util.ArrayList;
import java.util.List;

class GfG {
    static void addEdge(List<List<Integer>> adj, int s, int t) {
        adj.get(s).add(t);
    }

    static void DFSRec(List<List<Integer>> adj, boolean[] visited, int s) {
        visited[s] = true;
        System.out.print(s + " ");
        for (int i : adj.get(s)) {
            if (!visited[i]) {
                DFSRec(adj, visited, i);
            }
        }
    }

    // DFS for the entire graph, no source needed
    static void DFS(List<List<Integer>> adj, int V) {
        boolean[] visited = new boolean[V];

        // Loop through all vertices to handle disconnected graph
        for (int i = 0; i < V; i++) {
            if (!visited[i]) {
                DFSRec(adj, visited, i);
            }
        }
    }

    public static void main(String[] args) {
        int V = 6;
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < V; i++)
            adj.add(new ArrayList<>());

        int[][] edges = {{1, 2}, {2, 0}, {0, 3}, {4, 5}};
        for (int[] edge : edges)
            addEdge(adj, edge[0], edge[1]);

        System.out.println("Complete DFS of the graph:");
        DFS(adj, V);   // 0 3 1 2 4 5
    }
}
```

**Time complexity: O(V + E)** for both — each vertex visited at most once, each edge traversed at most once (twice in undirected).
**Auxiliary space: O(V + E)** — visited array + recursion stack.

## 7. Quick Reference

| | DFS | BFS |
|---|---|---|
| Data structure | Recursion / stack (LIFO) | Queue (FIFO) |
| Order | One path as deep as possible, then backtrack | Level by level, closest first |
| Tree analogy | Preorder traversal | Level-order traversal |
| Time | O(V + E) | O(V + E) |
| Space | O(V + E) with recursion stack | O(V) |
| Shortest path (unweighted) | No | Yes |
| Typical uses | Backtracking, topological sort, SCC, cycle detection | Shortest paths, Kahn, Dijkstra/Prim structure |

DFS is the traversal order behind **backtracking** (see Backtracking notes) — choose, recurse deep, undo, try the next branch.
