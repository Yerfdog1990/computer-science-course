## 3.4 Modification of the Database

Beyond extracting data, relational algebra provides a mechanism to change the state of the database. These modifications—adding, removing, or changing information—are expressed using the **assignment operation** ($\leftarrow$).

---

### 3.4.1 Deletion
Deletion removes selected tuples from a relation. It is important to note that we can only delete **whole tuples**; we cannot delete specific attribute values using this operation (that would be an update).

* **Mathematical Formula:** $r \leftarrow r - E$
* **Explanation:** The new state of relation $r$ is defined as the current set of tuples in $r$ minus the set of tuples returned by the expression $E$.

**Examples:**
* **Delete Smith’s account records:**
  $$\text{depositor} \leftarrow \text{depositor} - \sigma_{\text{customer-name} = \text{"Smith"}}(\text{depositor})$$
* **Delete loans between 0 and 50:**
  $$\text{loan} \leftarrow \text{loan} - \sigma_{\text{amount} \geq 0 \wedge \text{amount} \leq 50}(\text{loan})$$
* **Delete accounts at Needham branches:**
  We use temporary relations to find accounts associated with branches in "Needham":
    1. $r_1 \leftarrow \sigma_{\text{branch-city} = \text{"Needham"}}(\text{account} \bowtie \text{branch})$
    2. $r_2 \leftarrow \Pi_{\text{branch-name, account-number, balance}}(r_1)$
    3. $\text{account} \leftarrow \text{account} - r_2$

---

### 3.4.2 Insertion
To add data, we specify a new tuple or a set of tuples generated by a query. The inserted data must match the **arity** (number of columns) and the **domain** (data type) of the target relation.

* **Mathematical Formula:** $r \leftarrow r \cup E$
* **Explanation:** The new state of $r$ is the union of the existing tuples and the result of expression $E$.

**Examples:**
* **Insert a specific single tuple (Smith's new account):**
  $$\text{account} \leftarrow \text{account} \cup \{(\text{A-973, "Perryridge", 1200})\}$$
  $$\text{depositor} \leftarrow \text{depositor} \cup \{(\text{"Smith", A-973})\}$$

* **Insert based on a query (Gift accounts for Perryridge loan customers):**
  Here, we provide a $200 gift account to all Perryridge borrowers.
    1. $r_1 \leftarrow (\sigma_{\text{branch-name} = \text{"Perryridge"}}(\text{borrower} \bowtie \text{loan}))$
    2. $r_2 \leftarrow \Pi_{\text{loan-number, branch-name}}(r_1)$
    3. $\text{account} \leftarrow \text{account} \cup (r_2 \times \{(200)\})$
    4. $\text{depositor} \leftarrow \text{depositor} \cup \Pi_{\text{customer-name, loan-number}}(r_1)$

### 3.4.3 Updating
Updating allows us to change specific attribute values within a tuple without removing the entire record. This is achieved using **Generalized Projection**.

#### General Update Formula
$$r \leftarrow \Pi_{F_1, F_2, \dots, F_n}(r)$$
* Each $F_i$ is either the original attribute (if unchanged) or a new expression (if updated).

#### Conditional Update Formula
To update only specific rows matching a condition $P$:
$$r \leftarrow \Pi_{F_1, F_2, \dots, F_n}(\sigma_P(r)) \cup (r - \sigma_P(r))$$
* **Left side:** Updates the selected tuples.
* **Right side:** Keeps the tuples that did not match the condition.

**Examples:**
* **Increase all balances by 5%:**
  $$\text{account} \leftarrow \Pi_{\text{account-number, branch-name, balance} * 1.05}(\text{account})$$

* **Differentiated interest (6% for balances over $10,000, 5% otherwise):**
  $$\text{account} \leftarrow \Pi_{AN, BN, \text{balance} * 1.06}(\sigma_{\text{balance} > 10000}(\text{account})) \cup \Pi_{AN, BN, \text{balance} * 1.05}(\sigma_{\text{balance} \leq 10000}(\text{account}))$$
  *(Where $AN$ = account-number and $BN$ = branch-name)*

### Summary Table: Modification Logic

| Operation | Formal Notation | Set Logic Equivalent |
| :--- | :--- | :--- |
| **Deletion** | $r \leftarrow r - E$ | **Subtraction:** Remove $E$ from the set $r$. |
| **Insertion** | $r \leftarrow r \cup E$ | **Addition:** Add $E$ to the set $r$. |
| **Updating** | $r \leftarrow \Pi_F(\sigma_P(r)) \cup (r - \sigma_P(r))$ | **Replacement:** Replace a subset with modified values. |
