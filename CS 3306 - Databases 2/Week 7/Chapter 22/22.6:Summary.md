# Section 22.6: Summary

## Decision-Support Systems

- Decision-support systems analyze online data collected by transaction-processing systems to help people make business decisions
- Since most organizations are extensively computerized today, a very large body of information is available for decision support
- Decision-support systems come in various forms, including OLAP systems and data mining systems

## Online Analytical Processing (OLAP)

- OLAP tools help analysts view data summarized in different ways so they can gain insight into the functioning of an organization
- OLAP tools work on multidimensional data, characterized by dimension attributes and measure attributes
- The data cube consists of multidimensional data summarized in different ways
- Precomputing the data cube helps speed up queries on summaries of data
- Cross-tab displays permit users to view two dimensions of multidimensional data at a time, along with summaries of the data
- Drill down, rollup, slicing, and dicing are among the operations that users perform with OLAP tools

## SQL:1999 OLAP Extensions

- The OLAP component of the SQL:1999 standard provides a variety of new functionality for data analysis
- New features include:
  - New aggregate functions
  - Cube and rollup operations
  - Ranking functions
  - Windowing functions (support summarization on moving windows)
  - Partitioning (with windowing and ranking applied inside each partition)

## Data Mining

- Data mining is the process of semiautomatically analyzing large databases to find useful patterns
- Applications of data mining include:
  - Prediction of values based on past examples
  - Finding associations between purchases
  - Automatic clustering of people and movies

## Classification

- Classification deals with predicting the class of test instances by using attributes of test instances, based on attributes of training instances and the actual class of training instances
- Classification can be used to:
  - Predict credit-worthiness levels of new applicants
  - Predict performance of applicants to a university

### Types of Classifiers

**Decision-Tree Classifiers**:
- Perform classification by constructing a tree based on training instances with leaves having class labels
- Tree traversed for each test instance to find a leaf
- Class of leaf is the predicted class
- Several techniques available to construct decision trees, most based on greedy heuristics

**Bayesian Classifiers**:
- Simpler to construct than decision-tree classifiers
- Work better in case of missing/null attribute values

## Association Rules

- Association rules identify items that co-occur frequently (e.g., items that tend to be bought by the same customer)
- Correlations look for deviations from expected levels of association

## Other Types of Data Mining

- Clustering
- Text mining
- Data visualization

## Data Warehousing

- Data warehouses help gather and archive important operational data
- Warehouses used for decision support and analysis on historical data (e.g., to predict trends)
- Data cleansing from input data sources is often a major task in data warehousing
- Warehouse schemas tend to be multidimensional, involving:
  - One or a few very large fact tables
  - Several much smaller dimension tables

## Information-Retrieval Systems

- Information-retrieval systems used to store and query textual data such as documents
- Use simpler data model than database systems, but provide more powerful querying capabilities within the restricted model
- Queries attempt to locate documents of interest by specifying sets of keywords
- Query that user has in mind usually cannot be stated precisely
- Information-retrieval systems order answers on basis of potential relevance

## Relevance Ranking

Relevance ranking makes use of several types of information:

- **Term Frequency**: How important each term is to each document
- **Inverse Document Frequency**
- **Site Popularity**: Page rank and hub/authority rank are two ways to assign importance to sites on basis of links to the site

## Document Similarity

- Similarity of documents used to retrieve documents similar to an example document
- Synonyms and homonyms complicate the task of information retrieval
