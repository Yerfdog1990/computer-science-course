# Mobile Application Development 

---

## 1. What are Mobile Applications?

- Software programs that **run on a mobile device**
- Typical enterprise mobile apps use mobile computing technology to **retrieve information from a main server** to the mobile device — anytime, anywhere
- Mobile applications using the **Cloud as a backend** are increasingly popular

### Development Challenges
- **Not as straightforward** as desktop PC application development
- Developers must carefully consider the **context** in which the application will be used
- From a business point of view, it is **difficult for project managers to estimate risk** due to the varying capabilities of existing mobile platforms

---

## 2. Mobile Platform Landscape

Early mobile platforms have grown significantly in number and complexity:

| Era | Platforms |
|---|---|
| **Early/Legacy** | Symbian, Microsoft Windows Mobile, Linux, BlackBerry OS |
| **Modern Additions** | Apple iPhone OS X, Android, Palm's Web OS |

> The addition of newer platforms adds a **layer of complexity** for developers when choosing a target platform.

---

## 3. Architecture of Mobile Application Development

Mobile applications sit on top of **two distinct layers**:

### Layer 1 — Mobile Device Platform
- Refers to the **mobile hardware device** + its **operating system** and/or integrated software
- Example: Microsoft Windows Mobile 5.0 OS installed on a Dell AXIM X51v device

### Layer 2 — Mobile Application Development Platform
- The combination of **programming languages**, **general development APIs**, and the **runtime environment**
- Runs on top of the Mobile Device Platform
- Provides an **extra layer of software as a protection barrier** to limit damage from erroneous or malicious software
- Example: Microsoft Visual Studio 2005/2008 + Windows Mobile 6.0 SDK

```
┌─────────────────────────────────────────┐
│         Mobile Applications             │
├─────────────────────────────────────────┤
│   Mobile Application Development        │
│   Platform (Languages, APIs, Runtime)   │
├─────────────────────────────────────────┤
│   Mobile Device Platform                │
│   (Hardware + OS)                       │
└─────────────────────────────────────────┘
```

### Key Question Before Development:
> *Are you developing for a **specific device** or for an **application development platform**?*

## 4. Developing for a Specific Device (10.2.1)

When writing for a specific device or OS, the **device vendor provides**:
- An **SDK** (Software Development Kit)
- An **emulator**
- Other platform-specific tools

## 5. Developing for an Application Platform (10.2.2)

Developers must consider whether their preferred language and environment are suited to mobile. Common options include:

- Java
- .NET (C#, VB)
- C / C++
- And others

### Important Consideration — Java's Portability Challenge:
- Java's traditional strength is **portability** — widely available across many mobile devices
- However, **the exact same Java is NOT on all devices**
- To fit diverse platforms, Java's architecture is broken into **configurations and profiles**, which differ by device and its capabilities
- Writing to Java's platform **may not reach all intended customers**

## 6. Mobile Device Platforms (10.2.3)

### 6.1 Windows Mobile
- Derived from **Windows CE** (originally released in 1996)
- Provides a **subset of Microsoft Windows APIs** on a compact real-time OS for mobile computing and wireless terminals
- Notable success on: **Motorola Q** and some **Treo devices**
- Supports:
    - Application development in **C or C++**
    - Managed code via **.NET Compact Framework**
- Microsoft provides **ActiveSync** technology for synchronization (personal and enterprise users)

---

### 6.2 Symbian OS
- A **proprietary OS** designed for mobile devices
- Developed by **Symbian Ltd.**; originated as *EPOC Release 5* (Psion's last EPOC release, via a joint venture)
- Very powerful platform — programmable in **C++** using Symbian's frameworks
- The Symbian platform itself runs **Java ME**, so Symbian phones can run **both**:
    - Native Symbian applications
    - Java ME applications

---

### 6.3 iPhone
- An **internet-connected multimedia smartphone** designed and marketed by **Apple Inc.**
- A **closed platform** — mobile apps only through its robust **WebKit-based browser (Safari)**
- No physical keyboard — uses a **multi-touch screen** with a virtual keyboard
- **Development language**: Objective-C (based on C)
- **IDE**: Xcode — Apple's suite of tools for Mac OS X software development

---

### 6.4 Android
- An **open and free software stack** for mobile devices
- Includes: **operating system, middleware, and key applications**
- **Development language**: Java (exclusively)
- Requires the **Android-specific Java SDK**, which includes:
    - A debugger
    - Libraries
    - Handset emulator (based on QEMU)
    - Documentation, sample code, and tutorials

**Supported development platforms:**
- Linux (x86 architecture, any modern desktop distribution)
- Mac OS X 10.4.8 or later
- Windows XP or Vista

**Additional requirements:**
- Java Development Kit (JDK)
- Apache Ant
- Python 2.2 or later

**Officially supported IDE**: Eclipse (3.2 or later) with the **Android Development Tools (ADT) Plug-in**
*(Developers may also use any text editor + command line tools)*

## 7. Mobile Application Development Platforms (10.2.4)

### 7.1 Java Micro Edition (Java ME)
- Formerly called **Java 2 Micro Edition (J2ME)**
- Spans **lightweight mobile devices** and other non-traditional computing devices (set-top boxes, media devices)
- Originally promised **"write once, run anywhere"**
- Java ME skills are among the **most transferable** from device to device
- Lower-level languages like C/C++ require intimate knowledge of platform-specific APIs (e.g., Windows Mobile or Symbian OS APIs) — Java ME avoids this
- ⚠️ There are **different implementations of Java ME** for the immense variety of supported devices

---

### 7.2 .NET Compact Framework
- A version of the **.NET Framework for Windows CE platforms**
- A **subset** of the standard .NET Framework
- Also includes **additional classes** addressing specific mobile device needs

**Available versions:**
| Version | Notes |
|---|---|
| V1.0 | Most compatible — runs on virtually all devices; later versions are backwards compatible |
| V2.0 | Introduces new features; must be installed on target device to run V2.0 apps |
| V3.5 | Latest version with the most features |

> **Version selection tip**: Choosing V1.0 ensures the broadest compatibility. If you use features exclusive to V2.0+, that specific runtime must be installed on the target device.

---

### 7.3 Native C++
- C++ applications run **natively on the device**
- **Less portable** than Java, but offers:
    - **More speed**
    - **More control** over the device

**Common IDE tools for Native C++:**
- Microsoft Visual C++ 6 / .NET
- Eclipse IDE + specific C++ SDK
- Borland C++ Builder
- For Symbian OS: **Metrowerks CodeWarrior Studio** + Symbian C++ SDK (from Nokia)

---

### 7.4 Binary Runtime Environment for Wireless (BREW)
- A programming platform developed by **Qualcomm** for **CDMA-based phones**
- Provides **SDK and emulator** for developing and testing apps written in **C or C++**

**Required development tools:**
- BREW SDK
- ARM RealView compilation tools
- Visual C++

## 8. The Next Wave of Mobile Applications (10.2.5)

Next-generation mobile applications are emerging wherever cell phone/PDA coverage is high, driven by:
- **Mobile service providers** seeking new value-added services
- Taking advantage of **3G systems** and other wireless data infrastructures

### Why Traditional Apps Are No Longer Enough
- Voice and simple data services (e.g., internet surfing) are insufficient for today's consumers
- Users demand:
    - **Content-rich entertainment**
    - **Ubiquitous information access**
    - **Agile business operations**

### Unsaturated Markets in Mobile:
- Telematics systems
- M-commerce and M-enterprise services
- Mobile multimedia streaming
- Mobile messaging
- Location-based mobile computing

> Many exciting technological breakthroughs and innovations in mobile computing are expected in the coming years.

## 9. DB2 Everyplace (10.2.6)

**DB2 Everyplace** is IBM's DB2 edition specifically for mobile devices.

### Features:
- **Small-footprint relational database**
- **High-performance data synchronization solution**
- Enables enterprise applications and data to be **extended securely to mobile devices**

