# Backing Up Your Data

## Introduction

Microsoft Windows 2000 provides a backup utility called **Backup** for creating backups on local and remote systems. This utility enables you to archive files and folders, restore archived data, access media pools, access remote resources, create system state snapshots, schedule backups, and create emergency repair disks.

## Getting Started with the Backup Utility

### Access Methods

You can access Backup through several methods:

1. **Computer Management**:
   - Expand System Tools → System Information
   - Click Tools menu → Windows → Backup

2. **Run Command**:
   - Click Start → Run
   - Type `ntbackup` and click OK

3. **Start Menu**:
   - Start → Programs → Accessories → System Tools → Backup

### Backup Utility Interface

The Backup utility features four main tabs:

1. **Welcome Tab**:
   - Introduction to Backup
   - Buttons for Backup Wizard, Restore Wizard, and Emergency Repair Disk creation

2. **Backup Tab**:
   - Main interface for selecting data to back up
   - Supports local drives and mapped network drives

3. **Restore Tab**:
   - Main interface for restoring archived data
   - Can restore to original or alternate network locations

4. **Schedule Jobs Tab**:
   - Month-by-month job schedule for backups
   - View executed jobs and future scheduled jobs

### Permissions and User Rights

**Full Authority Groups**:
- Administrators group
- Backup Operators group
- Can back up and restore any file type regardless of ownership or permissions

**Limited Authority**:
- File owners
- Users with Read, Read and Execute, Modify, or Full Control permissions
- Can only back up files they own or have permissions for

> **Note**: Local accounts work only with local systems, while domain accounts have domain-wide privileges.

### Special Data Extensions

Backup provides extensions for special data types:

1. **System State Data**:
   - Essential system files needed for local system recovery
   - Must be backed up in addition to other files for complete system restoration
   - All computers have system state data

2. **Exchange Server Data**:
   - Exchange information store and data files
   - Required for Exchange server recovery
   - Only available on systems running Microsoft Exchange Server

3. **Removable Storage Data**:
   - Stored in `%SystemRoot%\System32\Ntmsdata`
   - Can restore Removable Storage configuration using advanced restore option

4. **Remote Storage Data**:
   - Stored in `%SystemRoot%\System32\Remote-storage`
   - Can restore by copying data back to this directory

## Setting Default Options for Backup

### Accessing Options

Click Tools → Options to view or change default backup options. There are five categories:

1. General
2. Restore
3. Backup Type
4. Backup Log
5. Exclude Files

### General Backup Options

| Option | Description |
|--------|-------------|
| Compute Selection Information Before Backup And Restore Operations | Calculates number of files and bytes before backup/restore procedure |
| Use The Catalogs On The Media To Speed Up Building Restore Catalogs On Disk | Uses archive logs on media rather than scanning entire archive |
| Verify Data After The Backup Completes | Checks archive data against original data to ensure integrity |
| Back Up The Contents Of Mounted Drives | Allows backup of data on mounted network drives |
| Show Alert Message When I Start Backup And Removable Storage Is Not Running | Displays alert if Removable Storage service isn't running |
| Show Alert Message When I Start Backup And There Is Compatible Import Media Available | Displays alert if new media available in import media pool |
| Show Alert Message When New Media Is Inserted Into Removable Storage | Displays alert when Removable Storage detects new media |
| Always Move New Import Media To Backup Pools | Automatically moves new media to backup media pool |

### Restore Options

| Option | Description |
|--------|-------------|
| Do Not Replace The Files On My Computer (Recommended) | Doesn't copy over existing files |
| Replace The File On Disk Only If The File On Disk Is Older | Replaces older files with newer files from backup |
| Always Replace The File On My Computer | Replaces all files on disk with files from backup |

### Backup Type Options

| Option | Description |
|--------|-------------|
| Default Backup Type | Sets default backup type: Normal, Copy, Differential, Incremental, or Daily |

### Backup Log Options

| Option | Description |
|--------|-------------|
| Detailed | Logs all operations, including file names |
| Summary | Logs only key information and backup failures |
| None | Disables logging |

## Viewing and Setting Backup Exclusions

### Viewing Exclusions

1. Click Tools → Options
2. Select Exclude Files tab
3. File exclusions are based on file ownership
4. Can view exclusions for all users or current logged-on user

### Creating Exclusions

1. In Options dialog box, choose Exclude Files tab
2. For all users: Click Add New under "Files Excluded For All Users"
3. For current user: Click Add New under "Files Excluded For User Administrator"
4. Exclude by:
   - **Registered File Type**: Click file type in list box
   - **Custom File Type**: Type period and file extension (e.g., .DOC, .WBK)
5. Enter drive or file path in "Applies To Path"
6. Clear "Applies To All Subfolders" to restrict to specific folder
7. Click OK

### Changing Exclusions

1. Select Exclude Files tab in Options dialog box
2. **To edit**: Select exclusion and click Edit
3. **To remove**: Select exclusion and click Remove
4. Click Apply when finished

## Backing Up Data with the Backup Wizard

### Step-by-Step Process

1. **Start Backup Wizard**:
   - Start Backup → Welcome tab → Backup Wizard → Next

2. **Select What to Back Up**:
   - **Back Up Everything On My Computer**: All data including system state
   - **Back Up Selected Files, Drives, Or Network Data**: Only selected data
   - **Only Back Up The System State Data**: System state data only

3. **Select Data (if applicable)**:
   - Select/clear check boxes for drives or folders
   - Click plus sign (+) to expand drives for individual file/folder selection
   - Shaded checkmark indicates partial selection

4. **Select Backup Media Type**:
   - **File**: Back up to a file (.BKF extension by default)
   - **Storage Device**: Back up to tape or removable disk

5. **Specify Backup Destination**:
   - For files: Type path and filename or click Browse
   - For tapes/disks: Choose specific tape or disk

6. **Advanced Options (optional)**:
   - **Backup Type**: Normal, Copy, Differential, Incremental, Daily
   - **Backup Migrated Remote Storage Data**: Archives Remote Storage placeholder files
   - **Verify Data After Backup**: Compares backup files to originals
   - **Use Hardware Compression, If Available**: Compresses data if device supports it

7. **Media Options**:
   - **Append This Backup To The Media**: Adds after existing data
   - **Replace The Data On The Media With This Backup**: Overwrites existing data
   - **Allow Only The Owner And Administrator Access**: Restricts archive file access

8. **Label Settings**:
   - **Backup Label**: Applies to current backup only
   - **Media Label**: Sets label for tape or removable disk (only changed when writing to blank tape or overwriting)

9. **Schedule Settings**:
   - **Now**: Run backup immediately
   - **Later**: Schedule for specific date/time
   - For scheduled backups: Set job name and schedule

10. **Complete Backup**:
    - Click Finish to start backup
    - Can cancel during backup process
    - Click Close when complete or Report to view backup log

### System State Data Details

**Windows 2000 Professional and Non-Domain Controller Servers**:
- Essential boot and system files
- Windows registry
- COM+ class registration database

**Domain Controllers**:
- Active Directory directory service data
- Files stored on system volume (Sysvol)
- Plus all standard system state components

## Backing Up Files Without the Wizard

### Manual Backup Process

1. **Start Manual Backup**:
   - Start Backup → Backup tab
   - Clear existing selections: Job menu → New → Yes

2. **Select Data to Back Up**:
   - Select/clear check boxes for drives or folders
   - Click plus sign (+) to expand for individual selection
   - Select System State for system state data
   - Select Microsoft Exchange icon for Exchange server backup

3. **Choose Backup Destination**:
   - Use Backup Destination selection list
   - File or storage device options

4. **Specify Backup Media/File**:
   - Type path and filename or click Browse
   - Choose tape or disk for media backup

5. **Configure Backup Job**:
   - Click Start Backup → Backup Job Information dialog box
   - **Backup Description**: Sets backup label
   - **Append/Replace options**: Media handling preferences
   - **Media Label**: Identifies media (only changed when writing to blank tape or overwriting)

6. **Advanced Options**:
   - **Back Up Data That Is In Remote Storage**: Archives Remote Storage placeholder files
   - **Verify Data After Backup**: Compares backup to original
   - **If Possible, Compress Backup Data To Save Space**: Hardware compression if available
   - **Automatically Back Up System Protected Files With The System State**: Includes all system files in %SystemRoot%
   - **Backup Type**: Select backup method

7. **Schedule (optional)**:
   - Click Schedule → Save backup settings
   - Name backup selection script (.BKS extension)
   - Set job schedule in Scheduled Job Options

8. **Start Backup**:
   - Click Finish to begin backup
   - Cancel if needed during process
   - Click Close when complete or Report to view log

### File Locations

**Backup Selection Scripts**: `%USERPROFILE%\Local Settings\Microsoft\WindowsNT\NTBackup\Data\` (.BKS extension)

**Backup Logs**: `%USERPROFILE%\Local Settings\Microsoft\WindowsNT\NTBackup\Data\` (.LOG extension, format: backup##.log)

### Important Considerations

**File Handling During Backup**:
- Open files: Attempts to back up last saved version
- Exclusively locked files: Not backed up
- Excluded files: Not backed up
- System state data: Only backed up if specifically selected

**System Protected Files Impact**:
- **Windows 2000 Professional**: Can add 200+ MB to backup size
- **Windows 2000 Server**: Can add 700-1000 MB to backup size

> **Caution**: Backing up system protected files can substantially increase backup size.

## Conclusion

The Windows 2000 Backup utility provides comprehensive backup capabilities through both wizard-guided and manual processes. Understanding the various options, permissions, and special data types ensures effective data protection and recovery strategies for your organization.
