# Managing Media Pools

## Introduction

Collections of tapes are organized into media pools, which are managed through the Removable Storage node in Computer Management. Media pools provide a dynamic and hierarchical system for organizing and managing backup media across libraries and applications.

## Understanding Media Pools

### Management Location

Media pools are managed through:
- **Computer Management** → **Removable Storage** node
- All media belongs to a pool of specific media type
- Dynamic concept allowing multiple media pools per library
- Media pools can span multiple libraries

### Hierarchical Structure

Media pools can establish hierarchies where:
- **Top-level media pools** contain lower-level media pools
- **Lower-level media pools** contain collections of tapes or discs
- Provides flexible organization for large-scale backup operations

## Media Pool Types

Removable Storage categorizes media pools into four main types:

### 1. Unrecognized Media Pools
- **Contents**: Media that Removable Storage doesn't recognize
- **Includes**: New media that hasn't been written to yet
- **Action Required**: Move media to Free media pool to make available for use
- **Consequence**: If ejected before moving to Free pool, media automatically deleted from Removable Storage database and no longer tracked

### 2. Free Media Pools
- **Contents**: Media not currently in use and without useful data
- **Status**: Available for use by applications
- **Purpose**: Reservoir of unused media ready for allocation

### 3. Import Media Pools
- **Contents**: Media recognized by Removable Storage but not used before in particular system
- **Example**: Media transferred from one office to another
- **Action Required**: Move media to Free media or Application media pools for reuse
- **Use Case**: Handling media from different locations or systems

### 4. Application Media Pools
- **Contents**: Media allocated to and controlled by specific applications
- **Example**: Windows 2000 Backup
- **Control**: Members of Administrators and Backup Operators groups can control these pools
- **Features**: Can configure to automatically draw media from Free media pools
- **Restriction**: Once allocated, cannot move Application media between media pools

### System vs. Application Media Pools

**System Media Pools**:
- Free, Unrecognized, and Import media pools
- Cannot be deleted
- Managed by system

**Application Media Pools**:
- Can be deleted (when no longer needed)
- Controlled by specific applications
- User-configurable

## Preparing Media for Use in the Free Media Pool

### Purpose

Prepare media that contains unwanted information for reuse in the Free media pool by:
- Initializing the media
- Destroying existing information
- Moving media to Free media pool

### Step-by-Step Process

1. **Access Removable Storage**:
   - Computer Management → Removable Storage
   - Double-click Physical Locations

2. **Navigate to Media**:
   - Expand the library by double-clicking
   - Expand the library's Media folder by double-clicking

3. **Prepare Media**:
   - Right-click the media you want to prepare
   - Click Prepare

4. **Confirm Action**:
   - Click Yes to confirm preparation

> **Result**: Information on media is destroyed and media moved to Free media pool

## Moving Media to Different Media Pools

### Purpose

Move media to different pools to:
- Make media available for use
- Allocate media to specific applications

### Step-by-Step Process

1. **Access Removable Storage**:
   - Computer Management → Removable Storage
   - Double-click Physical Locations

2. **Navigate to Media**:
   - Expand the library by double-clicking
   - Expand the library's Media folder by double-clicking

3. **Move Media**:
   - In Details pane, drag the media you want to move
   - Drop to applicable media pool in console tree

> **Caution**: Moving media to the Free media pool destroys the data on the media. Additionally, you cannot move read-only media to the Free media pool.

## Creating Application Media Pools

### Restriction

The only type of media pool you can create is an Application media pool.

### Creation Process

1. **Access Create Option**:
   - In Removable Storage, right-click Media Pools → Create Media Pool
   - OR right-click existing Application media pool → Create Media Pool

2. **Configure Media Pool**:
   - In Create New Media Pool Properties dialog box:
   - Type a name for the media pool
   - Type a description of the media pool

3. **Set Pool Type**:
   - **For Container Pool**: Select "Contains Other Media Pools"
   - **For Media Pool**: Click "Contains Media Of Type" and select appropriate media type from list

4. **Complete Creation**:
   - Click OK
   - Allocate media and configure security as necessary (see related sections)

## Changing Media Type in Media Pool

### Constraints

- Each media pool can only contain one type of media
- Media type normally assigned when creating media pool
- Can change media type only if no media is currently assigned to the media pool

### Change Process

1. **Access Media Pools**:
   - In Removable Storage, double-click Media Pools

2. **Access Properties**:
   - Right-click the media pool you want to modify
   - Select Properties

3. **Change Media Type**:
   - In General tab, select "Contains Media Of Type"
   - Select appropriate media type from the list
   - Click OK

## Setting Allocation and Deallocation Policies

### Purpose

Configure Application media pools to automatically:
- Allocate Free media when needed by applications
- Deallocate media back to Free media pool when no longer needed

### Configuration Process

1. **Access Media Pool Properties**:
   - In Removable Storage, double-click Media Pools
   - Right-click the media pool you want to configure
   - Select Properties
   - **Note**: Media pool must contain media of specific type and cannot be a container for other media pools

2. **Configure Allocation/Deallocation Policy**:
   In General tab, use these check boxes under Allocation/Deallocation Policy:

   - **Draw Media From Free Media Pool**:
     - Automatically draws unused media from Free media pool when needed
     - Ensures applications have media available

   - **Return Media To Free Media Pool**:
     - Automatically returns media to Free media pool when no longer needed
     - Frees up media for reuse

   - **Limit Reallocations**:
     - Limits the number of times tapes or discs can be reused
     - Use Reallocations field to set specific limit
     - Prevents overuse of media

3. **Apply Settings**:
   - Click OK to save changes

## Deleting Application Media Pools

### Deletion Process

1. **Access Media Pools**:
   - In Removable Storage, locate the Application media pool

2. **Delete Pool**:
   - Right-click the Application media pool
   - Select Delete

### Important Considerations

- **Only delete if you no longer need the media pool**
- **Do not delete Application media pools created by Windows 2000**, such as:
  - Backup
  - Remote Storage
- These system-created pools are used by the operating system

## Security and Access Control

### Administrative Access

- **Administrators group**: Full control over Application media pools
- **Backup Operators group**: Can control Application media pools
- **Regular users**: Limited access based on configured permissions

### Permission Configuration

Access permissions for Removable Storage can be configured to control:
- Who can access media pools
- What operations users can perform
- Application-specific access controls

## Best Practices

### Media Pool Management

1. **Regular Maintenance**:
   - Monitor media pool status
   - Move unrecognized media to appropriate pools
   - Clean up unused Application media pools

2. **Media Lifecycle**:
   - Track media age through reallocation limits
   - Replace aging media before failure
   - Maintain rotation schedules

3. **Application Integration**:
   - Configure automatic allocation/deallocation
   - Monitor application-specific media pools
   - Ensure proper media type assignments

### Troubleshooting

1. **Media Not Recognized**:
   - Check if media is in Unrecognized pool
   - Move to appropriate pool
   - Verify media type compatibility

2. **Allocation Issues**:
   - Verify Free media pool has available media
   - Check allocation policy settings
   - Confirm media type matches pool requirements

3. **Access Problems**:
   - Verify user permissions
   - Check group memberships
   - Review security settings

## Conclusion

Media pools provide a flexible and powerful system for organizing backup media across libraries and applications. Understanding the different pool types, proper media preparation procedures, and allocation policies ensures efficient media management and reliable backup operations. Regular maintenance and proper configuration of media pools are essential for maintaining a robust backup infrastructure.
