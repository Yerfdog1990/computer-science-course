# Recovering Your Data

## Introduction

You can restore files with the Windows 2000 Backup utility using either the Restore Wizard or the Restore tab. Both methods provide comprehensive options for recovering data from backup sets, including system state data, Exchange server data, and regular files and folders.

## Recovering Data Using the Restore Wizard

### Step-by-Step Process

1. **Prepare Backup Set**:
   - Ensure the backup set you want to work with is loaded into the library system
   - Start Backup → Welcome tab → Restore Wizard → Next

2. **Select Data to Restore**:
   - Left view displays files organized by volume
   - Right view displays media sets
   - Select check boxes next to drives, folders, or files to restore
   - If media set isn't shown, click Import File and type path to backup catalog

3. **System State Data Restoration**:
   - Select System State check box along with other data
   - **Original Location**: Current system state will be replaced
   - **Alternate Location**: Only registry, Sysvol, and system boot files are restored
   - **Important**: Can only restore system state data on a local system

> **Tip**: By default, Active Directory and other replicated data (like Sysvol) aren't restored on domain controllers. This information is replicated to the domain controller after restart to prevent accidental overwriting of essential domain information.

4. **Microsoft Exchange Data Restoration**:
   - Select Microsoft Exchange data to restore
   - Before restore starts, Restoring Microsoft Exchange dialog box appears
   - **Information Store Restore**: Type UNC name of Exchange server (e.g., `\\CorpMail`)
   - **Different Server Restore**: Select Erase All Existing Data (destroys existing data and creates new Information Store)

5. **Advanced Options (optional)**:
   - Click Next → Advanced to override default options
   - Follow steps 6-8 for advanced configuration
   - Skip to step 9 for default restore

6. **Select Restore Location**:
   - **Original Location**: Restores data to original folder/file location from backup
   - **Alternate Location**: Restores data to designated folder, preserving directory structure
   - **Single Folder**: Restores all files to single folder without preserving directory structure

> **Tip**: If unsure about overwriting original files, select Alternate Path and specify a new location (e.g., `C:\temp`). Compare files in temp directory with existing files before deciding whether to recover them. Always restore files backed up from NTFS drives to NTFS drives to maintain security permissions, compression, and encryption.

7. **Specify File Replacement Options**:
   - **Do Not Replace The Files On My Computer (Recommended)**: Doesn't copy over existing files
   - **Replace The File On Disk Only If The File On Disk Is Older**: Replaces older files with newer files from backup
   - **Always Replace The File On My Computer**: Replaces all files on disk with files from backup

8. **Security and System File Options** (if available):
   - **Restore Security**: Restores security settings for files and folders on NTFS volumes
   - **Restore Removable Storage Database**: Restores Removable Storage configuration if `%SystemRoot%\System32\Ntmsdata` was archived (deletes existing Removable Storage information)
   - **Restore Junction Points, Not The Folder And File Data They Reference**: Restores network drive mappings but not actual data to mapped network drives

9. **Complete Restore Operation**:
   - Click Next → Finish
   - If prompted, type path and name of backup set to use
   - Can cancel restore by clicking Cancel in Operation Status and Restore Progress dialog boxes
   - When completed, click Close to finish or click Report to view backup log

## Recovering Data Without the Wizard

### Manual Restore Process

1. **Load Backup Set**:
   - As necessary, load backup set into library system
   - Start Backup → Restore tab

2. **Select Data to Restore**:
   - Left view displays files organized by volume
   - Right view displays media sets
   - Select check boxes next to drives, folders, or files to restore
   - If media set isn't shown, right-click File in left view → Catalog → type name and path of catalog

3. **System State Data Restoration**:
   - Select System State check box along with other data
   - **Original Location**: Current system state will be replaced
   - **Alternate Location**: Only registry, Sysvol, and system boot files are restored
   - **Important**: Can only restore system state data on a local system

> **Tip**: By default, Active Directory and other replicated data (like Sysvol) aren't restored on domain controllers. Instead, this information is replicated after restart to prevent accidental overwriting of essential domain information.

4. **Microsoft Exchange Data Restoration**:
   - Select Microsoft Exchange data to restore
   - Restoring Microsoft Exchange dialog box appears before restore starts
   - **Information Store Restore**: Type UNC name of Exchange server (e.g., `\\CorpMail`)
   - **Different Server Restore**: Select Erase All Existing Data
   - **Note**: On Exchange server, Information Store and Directory services are stopped prior to restore. After restore, you may need to restart these services.

5. **Select Restore Location**:
   Use Restore Files To selection list:
   - **Original Location**: Restores data to original backup location
   - **Alternate Location**: Restores data to designated folder, preserving directory structure
   - **Single Folder**: Restores all files to single folder without preserving directory structure

6. **Configure File Replacement Options**:
   - Click Tools → Options → Restore folder
   - **Do Not Replace The Files On My Computer (Recommended)**: Doesn't copy over existing files
   - **Replace The File On Disk Only If The File On Disk Is Older**: Replaces older files with newer files from backup
   - **Always Replace The File On My Computer**: Replaces all files on disk with files from backup

7. **Start Restore Operation**:
   - In Restore tab, click Start Restore
   - Confirm Restore dialog box appears

8. **Advanced Restore Options** (optional):
   Click Advanced in Confirm Restore dialog box to set:
   - **Restore Security**: Restores security settings for files and folders on NTFS volumes
   - **Restore Removable Storage Database**: Restores Removable Storage configuration if `%SystemRoot%\System32\Ntmsdata` was archived (deletes existing Removable Storage information)
   - **Restore Junction Points, And Restore File And Folder Data Under Junction Points To The Original Location**: Restores network drive mappings and actual data to mapped network drives (use only for recovering remote system drives)
   - **When Restoring Replicated Data Sets, Mark The Restored Data As The Primary Data For All Replicas**: Restores replicated data and publishes to subscribers (ensures data replication)
   - **Preserve Existing Volume Mount Points**: Retains current mount points rather than those in archive (useful when drives have been remapped and additional volumes created)

9. **Complete Manual Restore**:
   - Click OK in Confirm Restore dialog box to start restore
   - If prompted, enter path and name of backup set to use
   - Can cancel restore by clicking Cancel in Operation Status and Restore Progress dialog boxes
   - When completed, click Close to finish or click Report to view backup log

## Important Considerations

### System State Data Limitations

- **Local System Only**: Can only restore system state data on local systems
- **Domain Controller Behavior**: Active Directory and replicated data aren't restored by default on domain controllers to prevent accidental overwriting
- **Replication Process**: Replicated data is replicated to domain controllers after restart

### Exchange Server Specifics

- **Service Impact**: Information Store and Directory services are stopped before restore
- **Service Restart**: May need to restart services after restore completion
- **Data Destruction**: Erase All Existing Data option destroys all current data and creates new Information Store

### File System Considerations

- **NTFS Requirements**: Always restore NTFS-backed up files to NTFS drives to maintain:
  - Security permissions
  - NTFS compression
  - Encryption settings
- **Directory Structure**: Alternate location restores preserve directory structure, while single folder restores flatten structure

### Advanced Restore Features

- **Junction Points**: Can restore network drive mappings with or without actual data
- **Replicated Data**: Can mark restored data as primary for all replicas
- **Volume Mount Points**: Can preserve existing mount points during full file system restores

## Conclusion

The Windows 2000 Backup utility provides flexible data recovery options through both wizard-guided and manual processes. Understanding the various restore locations, file replacement options, and special considerations for system state and Exchange data ensures successful data recovery while maintaining system integrity and security.
