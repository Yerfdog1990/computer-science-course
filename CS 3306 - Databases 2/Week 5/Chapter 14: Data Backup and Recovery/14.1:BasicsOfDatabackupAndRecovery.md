# The Basics of Database Backup and Recovery

## Introduction

Data is the heart of the enterprise, making it crucial to protect it through a comprehensive data backup and recovery plan. Backing up files protects against:
- Accidental loss of user data
- Database corruption
- Hardware failures
- Natural disasters

As an administrator, it's your responsibility to ensure backups are performed and backup tapes are stored securely.

## Creating a Backup and Recovery Plan

### The Insurance Plan Concept

Data backup serves as an insurance plan. Important files are accidentally deleted, mission-critical data can become corrupt, and natural disasters can destroy offices. A solid backup and recovery plan enables recovery from any of these scenarios.

### Key Planning Considerations

1. **Data Importance Assessment**
   - Critical data (e.g., databases) requires redundant backup sets extending back several periods
   - Less important data (e.g., daily user files) needs regular but less elaborate backup plans

2. **Information Type Analysis**
   - Data that seems unimportant to you may be crucial to others
   - Consider the type of information contained when determining backup needs

3. **Change Frequency Evaluation**
   - Data that changes daily should be backed up daily
   - Frequency of change affects backup scheduling

4. **Recovery Time Requirements**
   - Critical systems may require swift recovery
   - Time constraints may necessitate altered backup strategies

5. **Equipment Availability**
   - Backup hardware is essential: tape drives, optical drives, removable disk drives
   - Tape drives are generally less expensive but slower than other drive types

6. **Responsibility Assignment**
   - Designate a primary contact for the organization's backup and recovery plan
   - This person typically performs actual backup and recovery operations

7. **Backup Scheduling**
   - Schedule backups during low system usage periods
   - Carefully plan when key system data is backed up

8. **Off-site Storage Requirements**
   - Store backup tape copies off-site for disaster recovery
   - Include copies of necessary software for system reestablishment

## Basic Types of Backup

### Archive Attribute System

Windows Explorer uses an Archive attribute to determine backup requirements:
- Attribute ON: File/directory may need backing up
- Attribute OFF: File/directory doesn't need backing up

### Backup Types

1. **Normal/Full Backups**
   - All selected files backed up regardless of archive attribute
   - Archive attribute cleared after backup
   - Modified files have archive attribute set again

2. **Copy Backups**
   - All selected files backed up regardless of archive attribute
   - Archive attribute NOT modified (unlike normal backup)
   - Allows other backup types to be performed later

3. **Differential Backups**
   - Backs up files changed since last normal backup
   - Only files with archive attribute are backed up
   - Archive attribute NOT modified
   - Enables other backup types later

4. **Incremental Backups**
   - Backs up files changed since most recent normal or incremental backup
   - Only files with archive attribute are backed up
   - Archive attribute CLEARED after backup
   - Modified files have archive attribute set again

5. **Daily Backups**
   - Backs up files based on modification date
   - Files modified on the same day as backup are included
   - Archive attributes NOT changed

### Recommended Backup Strategy

- Perform full backups weekly
- Supplement with daily, differential, or incremental backups
- Create extended backup sets for monthly and quarterly periods
- Include additional files not regularly backed up

> **Tip**: Weeks or months may pass before missing files are noticed. Create extra backup sets for monthly/quarterly periods to ensure historical data recovery.

## Differential vs. Incremental Backups

### Key Differences

**Differential Backups:**
- Back up all files changed since last full backup
- Backup size grows over time
- Always references the last full backup

**Incremental Backups:**
- Back up files changed since most recent full OR incremental backup
- Backup size usually much smaller than full backup
- References the most recent backup of any type
