# Extra Quiz — Q&A: Unit 2 (Parallel Computing & Concurrency)

## Section 1: Multiple Choice

**Question 1.** Which of the following is not an advantage of parallel computing?
- It allows data to be split up across multiple cores.
- It can complete a large task in a shorter period of time.
- ✅ **It is harder to type.**
- It increases the raw throughput of concurrent calculations.

*The other three are genuine benefits of parallelism (data splitting, faster completion, higher throughput). "Harder to type" isn't a real technical property — it's the odd one out.*

**Question 2.** Parallel computing utilizes __________.
- physical relays
- ✅ **threads**
- standalone compilers
- non-executable code

*Parallel computing splits work across multiple threads (or processes/cores) that execute concurrently.*

**Question 3.** What occurs when two or more threads attempt to modify shared resources at the exact same time, causing unexpected or faulty states depending on execution order?
- Context Switching
- ✅ **Race Conditions**
- Deadlock
- Intermittent Spooling

*A race condition happens when the outcome depends on the unpredictable timing/order of concurrent thread execution over shared data. (Deadlock is threads permanently blocked waiting on each other; context switching is the CPU swapping which thread/process is running.)*

**Question 4.** Windows was a GUI that was later installed on top of which underlying operating system?
- Mac OS
- ✅ **MS-DOS**
- Unix
- Linux

*Early versions of Windows (1.x–3.x) ran as a graphical shell on top of MS-DOS, which handled the underlying OS functions.*

## Section 2: True or False

**Question 5.** Multi-threaded programs have multiple points of execution.
- ✅ **True**
- False

*Each thread is an independent point/flow of execution within the same process, running concurrently (or in parallel on multiple cores).*

**Question 6.** In most standard cases, only one raw instruction code is handled at a single given time within an individual core processor.
- ✅ **True**
- False

*In the classic single-core model, one instruction is fetched/executed at a time per core (ignoring advanced techniques like pipelining or superscalar execution, which the "standard case" framing here sets aside).*

**Question 7.** The process of saving the active computational state of a running process so another execution stream can temporarily take over memory space is called a Context Switch.
- ✅ **True**
- False

*A context switch saves the current process/thread's state (registers, program counter, etc.) so the CPU can switch to executing another one, later restoring the original state to resume it.*

## Section 3: Key Definitions

**SIMD (Single Instruction, Multiple Data)**
An execution model where one instruction is applied to multiple data elements simultaneously — used to speed up operations like vector/array math by processing many values in parallel with a single instruction.

**Amdahl's Law**
A formula predicting the maximum theoretical speedup of a task when only part of it can be parallelized. Even with infinite processors, the speedup is capped by the proportion of the program that must remain sequential.

**Process Isolation**
A core OS design principle where each process runs in its own protected memory space, so a crash or fault in one process can't corrupt or interfere with another process's memory.
