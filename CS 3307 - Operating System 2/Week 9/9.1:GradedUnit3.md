# Graded Quiz Unit 3 — Q&A (15 Questions)

**Question 1.** The table that holds the starting physical memory address for each virtual memory page is the __________ table.
- Process
- Frame
- Memory
- ✅ **Page**

*The page table maps each virtual page to the physical frame (starting address) it's stored in.*

**Question 2.** Both Paged Segmentation and Segmented Paging offer improved memory utilization and reduced _____.
- ✅ **Fragmentation**
- CPU utilization
- Context switching overhead
- Memory access time

*Combining paging and segmentation captures paging's fixed-block efficiency with segmentation's logical grouping, cutting down on wasted memory.*

**Question 3.** The memory type that typically serves as the primary working memory for active processes in a computer system is __________.
- Registers store immediate data for rapid calculations
- ROM (Read-Only Memory) stores permanent instructions
- ✅ **Main memory (RAM) acts as active temporary storage**
- Cache memory keeps recently accessed data nearby

*RAM holds the code/data of currently running processes; registers and cache are smaller/faster support layers, and ROM holds permanent instructions.*

**Question 4.** The limit on the total amount of virtual memory addresses a system can use is determined by __________.
- ✅ **The design of the CPU, specifically whether it's a 32-bit or 64-bit processor**
- How many programs are running simultaneously
- The total storage capacity of the hard drive
- How much physical RAM is installed

*Address width (32-bit vs. 64-bit) sets the maximum addressable virtual address space.*

**Question 5.** Why does the FIFO algorithm suffer from Belady's anomaly?
- It never chooses the oldest memory page when replacing
- ✅ **Increasing RAM frames might actually cause more page faults**
- It depends entirely on unpredictable page selection randomly
- Reducing memory frames consistently leads to fewer faults

*Belady's anomaly is the counterintuitive result that, under FIFO, adding more frames can increase rather than decrease the number of page faults.*

**Question 6.** What type of OS allows multiple users to use the system simultaneously?
- Embedded OS
- Real-time OS
- Single-task OS
- ✅ **Multi-user OS**

*A multi-user OS supports concurrent sessions/access for more than one user at a time.*

**Question 7.** What condition must be present for a deadlock to occur?
- Processes release resources quickly
- Synchronous communication
- ✅ **Mutual exclusion**
- No I/O operations

*Deadlock requires four conditions simultaneously: mutual exclusion, hold-and-wait, no preemption, and circular wait — mutual exclusion is the one listed.*

**Question 8.** Which of the following is a major advantage of threads over processes?
- Threads require more context switching
- ✅ **Threads share memory space**
- Threads consume more memory
- Threads are harder to debug

*Threads within the same process share the same address space, making communication and context switching cheaper than between separate processes.*

**Question 9.** Multithreading improves ______________________
- Static linking
- File fragmentation
- Hardware installation
- ✅ **Application speed and responsiveness**

*Running multiple threads concurrently lets an app overlap work (e.g., keep a UI responsive while background work runs), improving perceived speed.*

**Question 10.** Which of the following is not a scheduling algorithm?
- ✅ **FTP**
- SJF
- RR
- FCFS

*FTP (File Transfer Protocol) is a network protocol, not a CPU scheduling algorithm. FCFS, SJF, and RR are all real scheduling algorithms.*

**Question 11.** How did the transition from batch systems to interactive systems improve computing?
- Focused on job queueing only
- Eliminated operating systems entirely
- ✅ **Allowed real-time user input and feedback**
- Reduced user involvement

*Interactive systems let users respond to and influence a running program directly, instead of submitting a job and waiting for batched output.*

**Question 12.** What was a primary function of second-generation operating systems?
- ✅ **Batch processing**
- Real-time operations
- Graphical user interfaces
- Virtualization

*Second-generation OSes (transistor-era) were built around batch job processing to make efficient use of expensive mainframe time.*

**Question 13.** What was a key development in fourth-generation operating systems?
- Manual memory allocation
- Use of paper tape I/O
- ✅ **Graphical user interfaces (GUI)**
- Absence of multitasking

*Fourth-generation OSes (personal computing era) introduced GUIs, making computers accessible to non-technical users.*

**Question 14.** Which of the following describes a key architectural trend in modern OS?
- ✅ **Modular and microkernel architecture**
- Centralized punch card units
- Program-controlled loaders
- Manual interrupt handling

*Modern OS design favors breaking the kernel into modular/microkernel components for better maintainability, security, and extensibility.*

**Question 15.** Which of the following is a key advantage of Linux in enterprise environments?
- Poor networking support
- Limited customization
- ✅ **Security, stability, and cost-efficiency**
- Exclusive use of Windows applications

*Linux's open-source model, maturity, and lack of licensing fees make it attractive for enterprise servers and infrastructure.*
