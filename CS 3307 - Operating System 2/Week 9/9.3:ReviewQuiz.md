# Review Quiz — Q&A (40 Questions)

**Question 1.** High CPU usage with low disk activity often indicates a bottleneck in __________
- Network card
- Disk caching
- ✅ **Processor scheduling**
- Power supply

*Low disk I/O rules out storage; a pegged CPU with idle disk points to the CPU/scheduler as the constraint.*

**Question 2.** Which PowerShell cmdlet is used to retrieve performance counter data in Windows?
- Get-Process
- Get-EventLog
- Get-Service
- ✅ **Get-Counter**

*`Get-Counter` reads live/logged performance counters (CPU%, memory, disk queue, etc.).*

**Question 3.** A server's network performance has dropped. What tool should be checked first in Linux?
- whoami
- echo
- chmod
- ✅ **ifconfig**

*`ifconfig` (or `ip addr`) shows interface status, IP config, and error/drop counters.*

**Question 4.** How can you graphically monitor real-time CPU and memory usage in Linux?
- ✅ **htop**
- ls
- mkdir
- ping

*`htop` is an interactive terminal-based process/resource viewer.*

**Question 5.** What script type is best suited for automating Windows troubleshooting?
- BASH
- Ruby
- Python
- ✅ **PowerShell**

*PowerShell is native to Windows with deep system-management integration (WMI/CIM, event logs, services).*

**Question 6.** Which middleware component helps translate messages between systems?
- Thread pool
- Driver
- ✅ **Message broker**
- Scheduler

*A message broker (e.g., RabbitMQ, Kafka) receives, translates/routes, and delivers messages between systems.*

**Question 7.** How does message passing benefit communication in distributed systems?
- Central control
- ✅ **Decoupled communication**
- Synchronous dependency
- Static memory allocation

*Message passing lets senders/receivers communicate without tight coupling to location or timing.*

**Question 8.** One disadvantage of distributed computing is __________.
- Fault tolerance
- Increased performance
- Resource pooling
- ✅ **Synchronization overhead**

*Coordinating state and operations across independent nodes adds overhead a single machine doesn't have.*

**Question 9.** What supports asynchronous communication in distributed systems?
- RPC
- TCP
- FTP
- ✅ **Message Queues**

*Queues let a sender post a message and move on without waiting for immediate processing.*

**Question 10.** Why is RPC (Remote Procedure Call) used in distributed systems?
- File encryption
- ✅ **Execute code on remote systems as if local**
- Virtual memory management
- Data compression

*RPC lets a program call a remote function using local-call syntax/semantics, hiding network details.*

**Question 11.** SSL is less secure than TLS for encrypting communication.
- False
- ✅ **True**

*TLS succeeded SSL and fixed multiple cryptographic weaknesses; SSL is now deprecated/insecure.*

**Question 12.** A __________ is a type of malware designed to replicate and spread without user intervention.
- Virus
- Trojan Horse
- DDoS
- ✅ **Worm**

*Worms self-propagate automatically; viruses need a host file/user action, Trojans masquerade as legitimate software, DDoS is an attack, not malware.*

**Question 13.** What is the purpose of hashing in security?
- Execute programs
- Encrypt data
- Compress data
- ✅ **Ensure data integrity**

*A hash is a fingerprint of data — comparing hashes verifies the data wasn't altered.*

**Question 14.** How does a system determine access rights in Discretionary Access Control (DAC)?
- ✅ **Discretion of the owner**
- Roles
- Attributes
- Labels

*In DAC, the resource owner decides who gets access (vs. RBAC/roles, ABAC/attributes, MAC/labels).*

**Question 15.** Hash functions can be reversed to obtain the original data.
- True
- ✅ **False**

*Cryptographic hashes are one-way by design; reversal should be computationally infeasible.*

**Question 16.** Which component is essential in full virtualization for managing resources?
- Container Runtime
- Application Server
- ✅ **Virtual Machine Monitor (VMM)**
- Linux Kernel Modules

*The VMM (hypervisor) sits between hardware and guest OSes, allocating/managing physical resources.*

**Question 17.** Which mechanism enhances performance by allocating CPU, memory, and I/O bandwidth fairly among virtual machines?
- Hypercall dispatching
- VM cloning
- ✅ **Resource scheduling**
- Snapshotting

*The hypervisor's resource scheduler divides physical resources across competing VMs.*

**Question 18.** How is container-based virtualization implemented, and which of the following technologies is primarily used for it?
- VMware ESXi
- Xen
- ✅ **Docker**
- KVM

*Docker is the dominant container platform; ESXi, Xen, and KVM are hypervisors for full virtualization.*

**Question 19.** The file format typically used to define a container's environment and behavior is a __________.
- ✅ **Dockerfile**
- .ova
- .iso
- init.d

*A Dockerfile is a text script of instructions used to build a container image.*

**Question 20.** Kubernetes Pods can contain one or more containers that share storage and network resources.
- False
- ✅ **True**

*Containers in the same Pod share the network namespace (IP/ports) and can share mounted volumes.*

**Question 21.** Shell in an operating system:
- Is part of physical memory
- ✅ **Provides user interface**
- Manages the cache
- Controls hardware directly

*The shell is the interface layer through which users issue commands to the OS/kernel.*

**Question 22.** Device drivers are part of application software, not the OS.
- True
- ✅ **False**

*Device drivers are OS components that let the OS communicate with hardware.*

**Question 23.** Shared memory is a method of inter-process communication.
- ✅ **True**
- False

*Shared memory is a classic IPC mechanism, alongside message passing, pipes, and sockets.*

**Question 24.** A semaphore is used for:
- Scheduling batch jobs
- Formatting files
- ✅ **Controlling access to shared resources**
- Compiling programs

*Semaphores are synchronization primitives that manage concurrent access to shared resources.*

**Question 25.** Mutual exclusion is used to:
- Exclude users from processes
- Prevent deadlocks
- End all threads
- ✅ **Avoid race conditions by allowing only one thread in critical section**

*Mutual exclusion ensures only one thread executes a critical section at a time.*

**Question 26.** What is one benefit of data clustering in secondary storage management?
- Storage space is doubled for every file in the file system
- ✅ **Clustering ensures related data blocks are stored very close together**
- Files are always divided into smaller segments for splitting
- Encryption is applied to data blocks before they are written

*Storing related blocks contiguously reduces seek time and improves I/O throughput.*

**Question 27.** Disk mirroring is referred to by RAID __________.
- Level 0
- Level 3
- Level 2
- ✅ **Level 1**

*RAID 1 = mirroring (duplicate data on two+ disks); RAID 0 = striping (no redundancy).*

**Question 28.** The ext4 file system is commonly used in __________ and provides improved performance and reliability.
- macOS
- ✅ **Linux**
- Android
- Windows

*ext4 is the standard Linux filesystem, successor to ext2/ext3.*

**Question 29.** Which type of file contains distinct code segments that a loader can load into memory for execution?
- Source file
- Distributed file
- Text file
- ✅ **Executable file**

*Executable files are structured into segments (code/data) the OS loader maps into memory to run.*

**Question 30.** Which of the following is a common method for handling free space in a file system?
- ✅ **Linked lists of free blocks**
- Stack-based allocation
- Binary search trees
- Hash tables

*Free-space management commonly uses a bitmap or a linked list chaining free blocks together.*

**Question 31.** Too many page faults in a system can lead to a situation called thrashing, where system performance degrades rapidly.
- ✅ **True**
- False

*Thrashing occurs when the system spends more time swapping pages than doing useful work.*

**Question 32.** The memory component that offers the fastest access speed but has the smallest storage capacity is __________.
- Virtual memory
- ✅ **Register**
- Cache memory
- Main memory

*Registers sit at the top of the memory hierarchy: fastest, smallest, directly in the CPU.*

**Question 33.** Which two methods are commonly used to implement the LRU page replacement policy in hardware?
- ✅ **Stack & Counters**
- RAM & Registers
- Registers
- Queue

*Hardware LRU is typically implemented with a counter (timestamp per page) or a stack (move referenced pages to the top).*

**Question 34.** Which memory allocation technique is susceptible to internal fragmentation?
- Segmentation
- ✅ **Paging**
- Each of the listed techniques
- Segmentation with paging

*Paging's fixed-size frames often leave a process's last page partially used — wasted space inside the block. Segmentation instead suffers external fragmentation.*

**Question 35.** Which of the following best explains the principle of locality used in memory hierarchies?
- Data is evenly distributed across memory modules.
- ✅ **Recently accessed data or data near it is likely to be accessed again soon.**
- Data access patterns are random and unpredictable.
- Memory is divided into equal partitions for faster access.

*This is the basis of caching — temporal and spatial locality.*

**Question 36.** Modern operating systems are designed to support multitasking, networking, and real-time applications.
- ✅ **True**
- False

**Question 37.** Which of the following architectures uses a hierarchy of layers, each built on top of the lower one?
- Exokernel architecture
- Monolithic architecture
- Client-server model
- ✅ **Layered architecture**

*Each layer only interacts with the layer directly below it (classic example: THE OS).*

**Question 38.** One reason Linux is popular among developers is its:
- Limited programming tools.
- Lack of community support
- ✅ **Customizability and transparency**
- Dependence on one vendor

*Open-source code lets developers inspect, modify, and tailor the OS.*

**Question 39.** In UNIX-like systems, system configuration and services are primarily controlled through:
- Windows Registry
- ✅ **Command-line tools and scripts**
- BIOS interface
- GUI-only tools

*UNIX/Linux administration is traditionally done via shell commands, config files, and scripts.*

**Question 40.** UNIX influenced the development of which of the following OS?
- Tizen, QNX, Android TV
- ReactOS, BeOS, OS/2
- MS-DOS, CPM, VMS
- ✅ **Linux, BSD, Solaris**

*Linux and BSD are direct UNIX-like descendants; Solaris is a direct commercial descendant of UNIX (via SVR4).*
