# Graded Quiz Unit 6 — Q&A (15 Questions)

**Question 1.** What do containers running on the same host system share?
- Separate OS kernels for each container
- ✅ **The same OS kernel**
- A dedicated hypervisor per container
- Independent virtual memory spaces

*Unlike VMs, containers don't run a full guest OS each — they share the host's kernel, which is why they're lighter-weight than VMs.*

**Question 2.** Which Docker command is used to authenticate with a Docker registry?
- docker pull
- docker build
- ✅ **docker login**
- docker exec

*`docker login` authenticates your session against a registry (e.g., Docker Hub) so you can push/pull images.*

**Question 3.** Full virtualization allows unmodified guest operating systems to run because hardware is fully emulated (or hardware-assisted virtualization is used).
- ✅ **True**
- False

*Full virtualization presents complete emulated hardware to the guest, so the guest OS runs unmodified without knowing it's virtualized.*

**Question 4.** Which file defines the environment, dependencies, and behavior of a container?
- ✅ **Dockerfile**
- .ova
- .iso
- init.d

*A Dockerfile is the text script of instructions (base image, dependencies, commands) used to build a container image.*

**Question 5.** Which lightweight OS is designed specifically for running containers at scale in cloud-native environments?
- Windows Server
- ✅ **CoreOS**
- Ubuntu Desktop
- FreeBSD

*CoreOS was purpose-built as a minimal, container-focused OS for large-scale cloud-native deployments.*

**Question 6.** FAT (File Allocation Table) is commonly used for enterprise storage servers because of its advanced security features.
- True
- ✅ **False**

*FAT is a simple, older filesystem suited to flash drives/small devices; it lacks the security and reliability features enterprise storage needs. Enterprise servers use NTFS, ext4, ZFS, and similar.*

**Question 7.** What organizes files and directories on storage devices?
- ✅ **File System Structure**
- Kernel Scheduler
- Device Driver
- Boot Loader

*The file system structure defines how files and directories are laid out and managed on a storage device.*

**Question 8.** What stores comprehensive metadata about all files on secondary storage?
- File Allocation Table
- ✅ **Directory structure**
- Swap space
- Boot sector

*The directory (structure) tracks metadata like filenames, locations, sizes, and permissions for files on disk.*

**Question 9.** What is a common method for tracking free space in a file system?
- ✅ **Linked lists of free blocks**
- Round-robin queues
- Binary search trees
- Priority stacks

*Free-space management commonly uses a bitmap or a linked list chaining together the free blocks on disk.*

**Question 10.** What is one benefit of block-based storage allocation?
- ✅ **It divides storage media into blocks for faster and better access**
- It encrypts all data automatically
- It eliminates the need for a file system
- It doubles available storage capacity

*Block allocation reduces fragmentation and improves I/O performance compared to allocating arbitrary variable-sized chunks.*

**Question 11.** How does the Linux security model enforce access control?
- Windows Registry keys
- ✅ **File permissions and user groups**
- BIOS passwords
- Group Policy Objects

*Linux controls access via read/write/execute permissions combined with user and group ownership.*

**Question 12.** What is phishing?
- A method of encrypting network traffic
- ✅ **A technique to steal sensitive information by pretending to be a trustworthy entity**
- A type of RAID configuration
- A tool for compressing files

*Phishing is a social engineering attack, typically carried out via deceptive emails or fake websites impersonating a legitimate source.*

**Question 13.** Which file stores encrypted user passwords in Linux?
- /etc/passwd
- ✅ **/etc/shadow**
- /etc/hosts
- /etc/fstab

*`/etc/passwd` stores general account info; the actual encrypted/hashed password lives in `/etc/shadow`.*

**Question 14.** What do digital signatures ensure?
- Compression and speed
- ✅ **Authenticity and integrity**
- Anonymity and privacy
- Storage and redundancy

*A digital signature verifies both that a message came from the claimed sender (authenticity) and that it hasn't been altered (integrity).*

**Question 15.** What tool is used on Windows to apply and manage security policies across users and computers?
- Task Scheduler
- Device Manager
- ✅ **Group Policy Editor**
- Disk Management

*Group Policy Editor lets admins configure and enforce security and configuration policies across users/machines in a Windows environment.*
