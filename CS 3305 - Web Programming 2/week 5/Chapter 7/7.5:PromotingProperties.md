# 5.5: Promoting Properties

## Constructor Property Promotion

Constructor property promotion is a shorthand syntax introduced in PHP 8 that allows you to declare and assign class properties directly in the constructor parameters, eliminating the need for verbose property declarations and assignments.

## Traditional vs Promoted Properties

### Traditional (Verbose) Syntax

```php
class ClassName {
    access-specifier type $property;
    
    function __construct(type $arg) {
        $this->property = $arg;
    }
}
```

### Promoted Properties (Simplified) Syntax

```php
class ClassName {
    function __construct(access-specifier type $property) {
    }
}
```

## How Property Promotion Works

By adding an access specifier (public, private, or protected) before constructor parameters, the parameters are **promoted** so that:

1. Properties of the parameter names are automatically added to the class
2. Forwarding assignment to those properties occurs automatically in the constructor body
3. No need to declare the property separately
4. No need to manually assign `$this->property = $arg`

## Complete Example Comparison

### Traditional Approach (Paint_1)

```php
<?php
class Paint_1 {
    private string $color;
    
    function __construct(string $hue) {
        $this->color = $hue;
    }
    
    public function setColor(string $c) {
        $this->color = $c;
    }
    
    public function getColor() {
        return $this->color;
    }
}

// Usage
$pot_1 = new Paint_1();
echo $pot_1->getColor() . '<br>';    // Default value needed
echo $pot_1->setColor('Yellow');
echo $pot_1->getColor() . '<br>';
?>
```

### Promoted Properties Approach (Paint_2)

```php
<?php
class Paint_2 {
    function __construct(private string $color = 'Red') {
    }
    
    public function setColor(string $c) {
        $this->color = $c;
    }
    
    public function getColor() {
        return $this->color;
    }
}

// Usage
$pot_2 = new Paint_2();
echo $pot_2->getColor() . '<br>';    // Outputs: Red
echo $pot_2->setColor('Green');
echo $pot_2->getColor() . '<br>';    // Outputs: Green
?>
```

## Key Features of Property Promotion

### Benefits

1. **Reduced Code**: Eliminates repetitive property declarations
2. **Cleaner Syntax**: More concise and readable code
3. **Type Safety**: Maintains type hints and access specifiers
4. **Default Values**: Supports default parameter values
5. **PHP 8 Feature**: Modern PHP syntax improvement

### Limitations

1. **Constructor Only**: Only the `__construct()` method can have promoted properties
2. **No Mixing**: Avoid mixing standard and promoted properties for clarity
3. **PHP 8+**: Requires PHP 8.0 or higher

## Complete Working Example

```php
<?php
// Traditional approach
class Paint_1 {
    private string $color;
    
    function __construct(string $hue = 'Blue') {
        $this->color = $hue;
    }
    
    public function setColor(string $c) {
        $this->color = $c;
    }
    
    public function getColor() {
        return $this->color;
    }
}

// Promoted properties approach
class Paint_2 {
    function __construct(private string $color = 'Red') {
    }
    
    public function setColor(string $c) {
        $this->color = $c;
    }
    
    public function getColor() {
        return $this->color;
    }

// Test traditional approach
echo 'Traditional Approach:<br>';
$pot_1 = new Paint_1();
echo $pot_1->getColor() . '<br>';

```

## Advanced Usage Examples

### Multiple Promoted Properties

```php
class Car {
    function __construct(
        private string $make,
        private string $model,
        private int $year,
        private string $color = 'Black'
    ) {
    }
    
    public function getDetails() {
        return "$this->year $this->make $this->model ($this->color)";
    }
}

$car = new Car('Toyota', 'Camry', 2023, 'Blue');
echo $car->getDetails(); // Output: 2023 Toyota Camry (Blue)
```

### Mixed Access Specifiers

```php
class User {
    function __construct(
        private int $id,           // Private property
        public string $name,       // Public property
        protected string $email    // Protected property
    ) {
    }
    
    public function getId() {
        return $this->id;
    }
}
```

## Constructor Body Usage

Even with promoted properties, the constructor body can still contain statements:

```php
class Product {
    function __construct(
        private string $name,
        private float $price
    ) {
        // Constructor body can still have additional logic
        if ($this->price < 0) {
            $this->price = 0;
        }
        
        // Log product creation
        error_log("Product created: {$this->name}");
    }
}
```

## Property Access

Promoted properties can be accessed using setter and getter methods as usual:

```php
class Student {
    function __construct(private string $name = 'Unknown') {
    }
    
    public function getName() {
        return $this->name;
    }
    
    public function setName(string $name) {
        $this->name = $name;
    }
}

$student = new Student();
echo $student->getName(); // Output: Unknown
$student->setName('John Doe');
echo $student->getName(); // Output: John Doe
```

## Key Concepts Summary

1. **Property Promotion**: Shorthand syntax for declaring properties in constructor
2. **Access Specifiers**: Can be public, private, or protected
3. **Type Hints**: Maintains strong typing with parameter types
4. **Default Values**: Supports default parameter values
5. **PHP 8 Feature**: Requires PHP 8.0 or higher
6. **Constructor Only**: Only available in `__construct()` method
7. **Automatic Assignment**: Properties are automatically assigned from parameters

## Best Practices

1. **Use Consistently**: Choose either traditional or promoted properties for each class
2. **Avoid Mixing**: Don't mix standard and promoted properties in the same class
3. **Clear Naming**: Use descriptive parameter names that become property names
4. **Type Safety**: Always include type hints for better code reliability
5. **Default Values**: Provide sensible defaults where appropriate
6. **Documentation**: Document promoted properties for better code understanding
7. **PHP Version**: Ensure your environment supports PHP 8.0+

## When to Use Property Promotion

- **New Projects**: Ideal for new PHP 8+ projects
- **Simple Classes**: Perfect for data transfer objects and value objects
- **Constructor-Heavy Classes**: Classes with many constructor parameters
- **Clean Code**: When you want more concise, readable code
- **Type Safety**: When you want to enforce type hints from construction

## When to Avoid Property Promotion

- **Legacy Code**: When maintaining PHP 7.x compatibility
- **Complex Logic**: When constructor has complex initialization logic
- **Mixed Approaches**: When team prefers traditional syntax
- **Debugging**: When you need explicit property declarations for debugging
