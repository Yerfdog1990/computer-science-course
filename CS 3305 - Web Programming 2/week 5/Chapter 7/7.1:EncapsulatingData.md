# 5.1: Encapsulating Data

## Class Definition and Structure

A **class** is a data structure that can contain both variables and functions in a single entity. These are collectively known as its **"members"**:
- **Properties**: The variables within a class
- **Methods**: The functions within a class

### Class Declaration Syntax

```php
class ClassName {
    access-specifier $var1, $var2, $var3;
    
    access-specifier functionName1($arg1, $arg2, $arg3) {
        statements-to-execute;
    }
}
```

### Naming Conventions

- **Class names**: Begin with uppercase character (following PHP naming conventions)
- **Object names**: Begin with lowercase character

## Access Specifiers

Access to class members from outside the class is controlled by **access specifiers** in the class declaration:

### Public
- **public** members are accessible from any place where the class is visible
- Can be accessed from anywhere in the code

### Private
- **private** members are accessible only to other members of the same class
- Cannot be accessed from outside the class

### Protected
- **protected** members are accessible only to other members of the same class and members of classes derived from that class
- Used in inheritance (covered later in the chapter)

## Data Hiding and Encapsulation

**Data hiding** is the technique of denying direct access to class variables while allowing access to methods that can store and retrieve data from those variable members. This ensures that stored data is safely encapsulated within the class variable members and is the first principle of Object Oriented Programming (OOP).

### Benefits of Encapsulation

1. **Data Protection**: Prevents direct modification of class properties from outside
2. **Controlled Access**: Provides controlled access through getter and setter methods
3. **Maintainability**: Easier to maintain and modify code
4. **Security**: Protects data integrity

## Real-World Object Modeling

Any real-world object can be defined by its **attributes** and **actions**:
- **Attributes**: Properties that describe the object
- **Actions**: Methods that represent what the object can do

### Example: Dog Class

```php
class Dog {
    private $age;      // Attribute
    private $weight;   // Attribute  
    private $color;    // Attribute
    
    public function bark() {
        echo 'WOOF!';  // Action
    }
    
    // Plus methods here to store data in the properties
    // Plus methods here to retrieve data from the properties
}
```

## Creating Objects (Instances)

A class declaration only defines a data structure. To create an object, you must declare an **"instance"** of that data structure using the `new` keyword:

```php
$fido = new Dog();  // Creates an instance named "fido" of the "Dog" class
```

### Accessing Object Members

The **-> object operator** is used to reference visible class members:

```php
$fido->bark();  // Outputs WOOF!
```

**Important**: You must add parentheses after the class name when creating an instance object.

## Key Concepts Summary

1. **Encapsulation**: Grouping together of data and functionality in class members
2. **Data Hiding**: Restricting direct access to class properties
3. **Access Control**: Using public, private, and protected specifiers
4. **Object Instantiation**: Creating instances of classes with the `new` keyword
5. **Member Access**: Using the `->` operator to access visible members

## Best Practices

- Declare class properties as `private` to implement data hiding
- Provide `public` methods (getters and setters) to access private properties
- Use meaningful class and method names following PHP conventions
- Keep related data and functionality together in the same class
- Always include parentheses when creating class instances
