# 5.2: Creating an Object

## Accessor Methods

In order to assign and retrieve data from private members of a class, special public accessor methods must be added to the class:

- **Setter methods**: To assign data to private properties
- **Getter methods**: To retrieve data from private properties

### Naming Convention

Accessor methods are typically named as the variable they address, with:
- First letter made uppercase
- Prefixed by "set" or "get" respectively

**Example**: For an `age` variable, the methods would be named `setAge()` and `getAge()`.

## The $this Pseudovariable

The setter and getter methods can reference a member of the same class using a special **$this "pseudovariable"**, followed by the `->` object operator and the property name.

**Example**: Using `$this->age` to reference an age property.

## Complete Dog Class Example

### Class Declaration

```php
<?php
class Dog {
    private $age;
    private $weight;
    private $color;
    
    public function bark() {
        echo 'WOOF!';
    }
    
    // Setter methods - to assign individual argument values to each of the private variables
    public function setAge(int $yrs) {
        $this->age = $yrs;
    }
    
    public function setWeight(int $lbs) {
        $this->weight = $lbs;
    }
    
    public function setColor(string $fur) {
        $this->color = $fur;
    }
    
    // Getter methods - to retrieve individual values from each of the private variables
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
}
?>
```

## Public Interface, Private Data

In the class declaration, notice that:
- **All methods are declared public**
- **All variables are declared private**

This notion of **"public interface, private data"** is a key concept when creating classes.

## Creating and Using Objects

### Step 1: Declare an Instance

```php
$fido = new Dog();
```

### Step 2: Use Setter Methods to Assign Data

```php
$fido->setAge(3);
$fido->setWeight(15);
$fido->setColor('brown');
```

### Step 3: Use Getter Methods to Retrieve Data

```php
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';
echo 'Fido is ' . $fido->getAge() . ' years old<br>';
echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';
```

### Step 4: Call Regular Methods

```php
$fido->bark();
```

## Complete Working Example

```php
<?php
class Dog {
    private $age;
    private $weight;
    private $color;
    
    public function bark() {
        echo 'WOOF!';
    }
    
    public function setAge(int $yrs) {
        $this->age = $yrs;
    }
    
    public function setWeight(int $lbs) {
        $this->weight = $lbs;
    }
    
    public function setColor(string $fur) {
        $this->color = $fur;
    }
    
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
}

// Create an instance of the Dog class
$fido = new Dog();

// Set the properties using setter methods
$fido->setAge(3);
$fido->setWeight(15);
$fido->setColor('brown');

// Get the properties using getter methods
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';
echo 'Fido is ' . $fido->getAge() . ' years old<br>';
echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';

// Call the regular method
$fido->bark();
?>
```

## Key Concepts Summary

1. **Accessor Methods**: Public methods to access private properties
2. **Setter Methods**: Assign values to private properties (`setPropertyName()`)
3. **Getter Methods**: Retrieve values from private properties (`getPropertyName()`)
4. **$this Variable**: References the current object instance
5. **Public Interface, Private Data**: Key principle of encapsulation
6. **Method Chaining**: Multiple method calls on the same object

## Best Practices

- Always use private properties with public getter/setter methods
- Use descriptive method names following the `get/set` convention
- Include type hints in method parameters when appropriate
- Keep getter methods simple and focused on returning data
- Add validation in setter methods to ensure data integrity
- Use the `$this` variable to reference object properties within methods

## Expected Output

When the complete example is run, it will output:
```
Fido is a brown dog
Fido is 3 years old
Fido weighs 15 pounds
WOOF!
```
