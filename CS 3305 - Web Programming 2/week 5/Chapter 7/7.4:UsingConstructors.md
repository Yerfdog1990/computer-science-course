# 5.4: Using Constructors

## Constructor and Destructor Methods

Class variable members can be initialized by a special **constructor** method that is called whenever an instance of the class is created. The constructor method is always named `__construct()` and can accept arguments to set the initial value of class variables.

A constructor method has a companion **destructor** method that is called whenever an instance of the class is destroyed. The destructor method is always named `__destruct()`.

### Method Characteristics

- **No return value**: Both methods have no return value
- **Automatic calling**: They are called automatically and cannot be called explicitly
- **No access specifier**: Their declarations need no access specifier
- **Magic methods**: Both are PHP "magic methods" with special behavior

## Constructor Syntax

```php
function __construct(int $yrs = 2, int $lbs = 8, string $fur = 'black') {
    $this->age = $yrs;
    $this->weight = $lbs;
    $this->color = $fur;
}
```

### Destructor Syntax

```php
function __destruct() {
    echo '<br>Object Destroyed.';
}
```

## Creating Objects with Constructors

Values to initialize class variables are passed to the constructor method in the statement creating an object, in parentheses following the object name:

```php
// With arguments
$fido = new Dog(3, 15, 'brown');
$pooch = new Dog(4, 18, 'gray');

// With default values
$rover = new Dog();
```

## Complete Example with Constructor

### Dog Class with Constructor

```php
<?php
class Dog {
    private $age;
    private $weight;
    private $color;
    
    // Constructor method
    function __construct(int $yrs = 2, int $lbs = 8, string $fur = 'black') {
        $this->age = $yrs;
        $this->weight = $lbs;
        $this->color = $fur;
    }
    
    // Destructor method
    function __destruct() {
        echo '<br>Object Destroyed.';
    }
    
    public function bark() {
        echo 'WOOF!';
    }
    
    // Getter methods
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
    
    // Optional setter methods for changing values after construction
    public function setAge(int $yrs) {
        $this->age = $yrs;
    }
    
    public function setWeight(int $lbs) {
        $this->weight = $lbs;
    }
    
    public function setColor(string $fur) {
        $this->color = $fur;
    }
}
?>
```

### Creating Objects with Constructor

```php
// Create objects with constructor initialization
$fido = new Dog(3, 15, 'brown');
$pooch = new Dog(4, 18, 'gray');
$rover = new Dog(); // Uses default values

// Display object data
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';
echo 'Fido is ' . $fido->getAge() . ' years old<br>';
echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';
$fido->bark();

echo '<br>Pooch: ' . $pooch->getAge() . 'yrs ';
echo $pooch->getWeight() . 'lbs ' . $pooch->getColor() . '<br>';
$pooch->bark();

echo '<br>Rover: ' . $rover->getAge() . 'yrs ';
echo $rover->getWeight() . 'lbs ' . $rover->getColor() . '<br>';
$rover->bark();

// Objects will be automatically destroyed at script end
```

## PHP Class Interrogation Functions

PHP provides several functions to interrogate classes:

### Basic Existence Checks

- `class_exists(class)`: Returns TRUE if the class exists
- `method_exists(class, method)`: Returns TRUE if the method exists
- `property_exists(class, property)`: Returns TRUE if the property exists

### Member Lists

- `get_class_vars(class)`: Returns an array of visible class variables
- `get_class_methods(class)`: Returns an array of visible class methods

## Class Interrogation Example

```php
// Check if class exists
if (class_exists('Dog')) {
    echo 'Dog class exists<br>';
}

// Get visible variables
$items = get_class_vars('Dog');
echo 'Dog variables: ' . count($items) . '<br>'; // Will show 0 for private properties

// Get visible methods
echo 'Dog methods: ';
$items = get_class_methods('Dog');
foreach ($items as $item) {
    echo "$item, ";
}
```

```php

        $this->age = $yrs;

        $this->color = $fur;
    }
    
    function __destruct() {
        echo '<br>Object Destroyed.';
    }
    
    public function bark() {
        echo 'WOOF!';
    }
    
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
    
    public function setAge(int $yrs) {
        $this->age = $yrs;
    }
    
    public function setWeight(int $lbs) {
        $this->weight = $lbs;

// Create objects with constructor
$fido = new Dog(3, 15, 'brown');

$rover = new Dog();

// Display object information
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';

echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';

echo $pooch->getWeight() . 'lbs ' . $pooch->getColor() . '<br>';
$pooch->bark();

echo '<br>Rover: ' . $rover->getAge() . 'yrs ';
echo $rover->getWeight() . 'lbs ' . $rover->getColor() . '<br>';

// Class interrogation
echo '<br><br>Class Information:<br>';

}

// Script ends here - destructors will be called automatically
?>
```

## Encapsulation Demonstration

The number of visible variables is zero when properties are private, demonstrating encapsulation in action. If you temporarily change their access specifier to public, it becomes 3.

### Visibility Comparison

```php
// Private properties (encapsulated)
private $age;
private $weight;
private $color;
// get_class_vars() returns 0 visible variables

// Public properties (not encapsulated)
public $age;
public $weight;
public $color;
// get_class_vars() returns 3 visible variables
```

## Key Concepts Summary

1. **Constructor Method**: `__construct()` - automatically called on object creation
2. **Destructor Method**: `__destruct()` - automatically called on object destruction
3. **Automatic Initialization**: Properties set during object creation
4. **Default Parameters**: Constructor can have default values
5. **Method Implementation**: The definition of a class method
6. **Class Interrogation**: Functions to examine class structure
7. **Encapsulation**: Private properties are not visible to external inspection

## Best Practices

- Use constructors for mandatory initialization
- Provide default values for optional constructor parameters
- Use destructors for cleanup operations
- Keep constructors focused on initialization logic
- Add setter methods for post-creation property changes
- Use class interrogation functions for debugging and documentation
- Maintain encapsulation by keeping properties private

## Constructor vs Setter Methods

- **Constructor**: Sets initial values when object is created
- **Setter Methods**: Change values after object is created
- **Combined Approach**: Use constructor for initialization, setters for modifications
