# 5.8: Chaining Method Calls

## The Problem with Nested Conditional Tests

You may often want to call a method, or get a property, only if the result of one or more tested expressions are not null. This can quickly lead to deeply nested conditional tests, like these:

```php
$country = null;
if ($session !== null) {
    $user = $session->user;
    if ($user !== null) {
        $address = $user->getAddress();
        if ($address !== null) {
            $country = $address->country;
        }
    }
}
```

## The Nullsafe Operator (PHP 8)

The `?->` nullsafe operator is a great new feature introduced in PHP 8. The same series of conditional tests can be made more concisely in a single chain using the PHP `?->` "nullsafe" operator:

```php
$country = $session?->user?->getAddress()?->country;
```

## How the Nullsafe Operator Works

### Evaluation Order

The chain is evaluated from left to right. When an item at the left of the nullsafe operator evaluates to null, execution of the entire chain stops immediately and the chain evaluates to null.

### Short Circuiting

Skipping evaluation of the remainder of the chain when an item in a chain evaluates to null is known as **"short circuiting"**. When an item at the left hand side of the nullsafe operator does not evaluate to null, execution continues to evaluate the next item in the chain until the end of the chain is reached.

## Complete Example

### Class Definitions

```php
<?php
// Session class with null user property
class Session {
    public $user;
    
    function __construct() {
        $this->user = null; // Initially null
    }
}

// User class with getAddress method
class User {
    public function getAddress() {
        return new Address();
    }
}

// Address class with country property
class Address {
    public $country;
    
    function __construct() {
        $this->country = 'USA';
    }
}
?>
```

### Without Nullsafe Operator (Will Fail)

```php
<?php
$session = new Session();

// This will cause a fatal error when $session->user is null
$country = $session->user->getAddress()->country;
echo 'Location: ' . $country;
?>
```

**Result**: Fatal error - trying to call method on null object.

### With Nullsafe Operator (Safe)

```php
<?php
$session = new Session();

// This will gracefully handle the null value
$country = $session?->user?->getAddress()?->country;
echo 'Location: ' . $country; // Outputs: Location: 
?>
```

**Result**: No error - outputs empty string when chain encounters null.

### Successful Chain Example

```php
<?php
// Modified Session class with actual User object
class Session {
    public $user;
    
    function __construct() {
        $this->user = new User(); // Now has actual User object
    }
}

$session = new Session();
$country = $session?->user?->getAddress()?->country;
echo 'Location: ' . $country; // Outputs: Location: USA
?>
```

**Result**: Success - outputs "Location: USA".

## Complete Working Example

```php
<?php
// Session class
class Session {
    public $user;
    
    public function __construct($hasUser = false) {
        $this->user = $hasUser ? new User() : null;
    }
    
    public function setUser($user) {
        $this->user = $user;
    }
}

// User class
class User {
    public function getAddress() {
        return new Address();
    }
}

// Address class
class Address {
    public $country;
    
    public function __construct() {
        $this->country = 'USA';
    }
}

// Test with null user
$session1 = new Session(false);
$country1 = $session1?->user?->getAddress()?->country;
echo 'Session 1 (null user): ' . ($country1 ?? 'NULL') . '<br>';

// Test with actual user
$session2 = new Session(true);
$country2 = $session2?->user?->getAddress()?->country;
echo 'Session 2 (with user): ' . ($country2 ?? 'NULL') . '<br>';

// Test setting user later
$session3 = new Session(false);
$session3->setUser(new User());
$country3 = $session3?->user?->getAddress()?->country;
echo 'Session 3 (user set later): ' . ($country3 ?? 'NULL') . '<br>';
?>
```

## Expected Output

When the complete example is run, it will output:
```
Session 1 (null user): NULL
Session 2 (with user): USA
Session 3 (user set later): USA
```

## Comparison: Traditional vs Nullsafe

### Traditional Approach (Verbose)

```php
$country = null;
if ($session !== null) {
    $user = $session->user;
    if ($user !== null) {
        $address = $user->getAddress();
        if ($address !== null) {
            $country = $address->country;
        }
    }
}
```

### Nullsafe Operator (Concise)

```php
$country = $session?->user?->getAddress()?->country;
```

## Key Concepts

### Nullsafe Operator Characteristics

1. **PHP 8 Feature**: Requires PHP 8.0 or higher
2. **Left-to-Right Evaluation**: Chain evaluates from left to right
3. **Short Circuiting**: Stops at first null encountered
4. **Null Return**: Entire chain returns null if any part is null
5. **Method Calls**: Works with both method calls and property access
6. **Error Prevention**: Avoids fatal errors from null object access

### Chain Evaluation Examples

```php
// All properties/methods exist, returns value
$result1 = $object?->property?->method()?->property;

// First property is null, returns null immediately
$result2 = $nullObject?->property?->method()?->property;

// Method returns null, chain stops there
$result3 = $object?->methodReturningNull()?->property?->method();
```

## Best Practices

1. **Use with Caution**: Only when null values are expected and acceptable
2. **Combine with Null Coalescing**: Use `??` operator for default values
3. **PHP Version Check**: Ensure server runs PHP 8.0+
4. **Clear Code**: Don't overuse when simple if statements are clearer
5. **Error Handling**: Still need proper error handling for other types of errors
6. **Testing**: Test chains with both null and non-null scenarios
7. **Documentation**: Document when null values are expected

## Common Use Cases

### Configuration Access

```php
$timeout = $config?->database?->connection?->timeout ?? 30;
```

### API Response Handling

```php
$userId = $response?->data?->user?->id ?? 'anonymous';
```

### Optional Object Properties

```php
$city = $user?->profile?->address?->city ?? 'Unknown';
```

## Advanced Usage

### Combining with Null Coalescing

```php
// Provide default value when chain returns null
$country = $session?->user?->getAddress()?->country ?? 'Unknown';

// Multiple levels with defaults
$postalCode = $user?->address?->postalCode ?? $user?->tempAddress?->postalCode ?? 'N/A';
```

### Method Chaining with Nullsafe

```php
class Builder {
    public function setName($name) { $this->name = $name; return $this; }
    public function setEmail($email) { $this->email = $email; return $this; }
    public function save() { /* save logic */ return $this; }
}

$user = new User();
$result = $user?->setName('John')?->setEmail('john@example.com')?->save();
```

## Key Concepts Summary

1. **Nullsafe Operator**: `?->` - PHP 8 feature for safe property/method access
2. **Short Circuiting**: Chain evaluation stops at first null encountered
3. **Left-to-Right Evaluation**: Sequential evaluation of chain elements
4. **Error Prevention**: Avoids fatal errors from null object access
5. **Code Conciseness**: Replaces nested if statements
6. **Null Return**: Entire chain returns null if any part is null
7. **Type Safety**: Provides safer object property access

## Migration Notes

### Before PHP 8

```php
// Traditional approach required
$country = null;
if ($session !== null && $session->user !== null) {
    $address = $session->user->getAddress();
    if ($address !== null) {
        $country = $address->country;
    }
}
```

### PHP 8 and Later

```php
// Modern approach with nullsafe operator
$country = $session?->user?->getAddress()?->country;
```
