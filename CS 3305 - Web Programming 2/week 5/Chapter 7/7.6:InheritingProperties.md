# 5.6: Inheriting Properties

## Inheritance in PHP

A PHP class can be created as a brand new class, like those in previous examples, or can be **derived** from an existing class. Importantly, a derived class inherits members of the **parent (base) class** from which it is derived – in addition to its own members.

## Benefits of Inheritance

The ability to inherit members from a base class allows derived classes to be created that share certain common properties, which have been defined in the base class. This is the second principle of Object Oriented Programming (OOP).

### Real-World Example

A "Polygon" base class may define width and height properties that are common to all polygons. Classes of "Rectangle" and "Triangle" could be derived from Polygon class – inheriting width and height properties, in addition to their own members defining their unique features.

## Inheritance Syntax

A derived class declaration adds the **extends** keyword after its class name, followed by the name of the class from which it derives:

```php
class DerivedClass extends BaseClass {
    // Derived class members
}
```

## Complete Inheritance Example

### Base Class (Polygon)

```php
<?php
class Polygon {
    private float $width;
    private float $height;
    
    function __construct(float $w = 10, float $h = 5) {
        $this->width = $w;
        $this->height = $h;
    }
    
    public function getWidth() {
        return $this->width;
    }
    
    public function getHeight() {
        return $this->height;
    }
}
?>
```

### Derived Classes (Rectangle and Triangle)

```php
<?php
// Rectangle class inherits from Polygon
class Rectangle extends Polygon {
    public function area() {
        return ($this->getWidth() * $this->getHeight());
    }
}

// Triangle class inherits from Polygon
class Triangle extends Polygon {
    public function area() {
        return ($this->getWidth() * $this->getHeight() / 2);
    }
}
?>
```

### Creating and Using Derived Classes

```php
<?php
// Create instances of derived classes
$rect = new Rectangle();
$trio = new Triangle();

// Call methods on derived class instances
echo 'Rectangle Area: ' . $rect->area() . '<br>';
echo 'Triangle Area: ' . $trio->area();
?>
```

## Complete Working Example

```php
<?php
// Base class
class Polygon {
    private float $width;
    private float $height;
    
    function __construct(float $w = 10, float $h = 5) {
        $this->width = $w;
        $this->height = $h;
    }
    
    public function getWidth() {
        return $this->width;
    }
    
    public function getHeight() {
        return $this->height;
    }
}

// Derived class - Rectangle
class Rectangle extends Polygon {
    public function area() {
        return ($this->getWidth() * $this->getHeight());
    }
}

// Derived class - Triangle
class Triangle extends Polygon {
    public function area() {
        return ($this->getWidth() * $this->getHeight() / 2);
    }
}

// Create instances of derived classes
$rect = new Rectangle();
$trio = new Triangle();

// Output results
echo 'Rectangle Area: ' . $rect->area() . '<br>';
echo 'Triangle Area: ' . $trio->area();

// With custom dimensions
$rect2 = new Rectangle(20, 10);
$trio2 = new Triangle(20, 10);

echo '<br><br>With custom dimensions:<br>';
echo 'Rectangle Area (20x10): ' . $rect2->area() . '<br>';
echo 'Triangle Area (20x10): ' . $trio2->area();
?>
```

## Key Concepts

### Base Class (Parent Class)
- The original class from which other classes inherit
- Contains common properties and methods
- Also called "parent" or "superclass"

### Derived Class (Child Class)
- Inherits members from the base class
- Can add its own unique properties and methods
- Also called "child" or "subclass"

### Inheritance Flow
```
Base Class (Polygon)
    ↓ inherits
Derived Class (Rectangle/Triangle)
    ↓ adds own members
Final Class with inherited + unique members
```

## Access to Inherited Members

### Public Methods
Derived classes can access public methods of the base class:

```php
class Rectangle extends Polygon {
    public function area() {
        // Can access public methods from base class
        return ($this->getWidth() * $this->getHeight());
    }
}
```

### Private Properties
Derived classes cannot directly access private properties of the base class:

```php
class Rectangle extends Polygon {
    public function area() {
        // ❌ Cannot access private properties directly
        // return ($this->width * $this->height);
        
        // ✅ Must use public getter methods
        return ($this->getWidth() * $this->getHeight());
    }
}
```

## Expected Output

When the complete example is run, it will output:
```
Rectangle Area: 50
Triangle Area: 25

With custom dimensions:
Rectangle Area (20x10): 200
Triangle Area (20x10): 100
```

## Important Distinctions

### Class Instances vs Derived Classes

- **Class Instance**: A copy of a class created with `new` keyword
- **Derived Class**: A new class that inherits properties from a base class

Don't confuse these concepts:
```php
// Instance - copy of a class
$rect = new Rectangle();

// Derived class - new class inheriting from another
class Square extends Rectangle {
    // Square inherits from Rectangle
}
```

## PHP Inheritance Limitations

### Single Inheritance Only

In PHP, a derived class is always dependent on a single base class – multiple inheritance is not supported.

```php
// ✅ Valid - single inheritance
class Rectangle extends Polygon {
}

// ❌ Invalid - multiple inheritance not supported
class Rectangle extends Polygon, Shape {
}
```

## Key Concepts Summary

1. **Inheritance**: Mechanism for creating derived classes from base classes
2. **Base Class**: Parent class that provides common members
3. **Derived Class**: Child class that inherits from base class
4. **extends Keyword**: Used to declare inheritance relationship
5. **Method Access**: Derived classes can access public methods of base class
6. **Single Inheritance**: PHP supports only single inheritance
7. **Code Reuse**: Inheritance promotes code reuse and maintainability

## Best Practices

1. **Logical Hierarchy**: Create meaningful inheritance relationships
2. **Common Properties**: Put shared properties in base classes
3. **Protected Access**: Use protected when derived classes need access
4. **Method Overriding**: Override base class methods when needed
5. **Composition Over Inheritance**: Consider composition when appropriate
6. **Documentation**: Document inheritance relationships clearly
7. **Testing**: Test both base and derived class functionality

## When to Use Inheritance

- **Is-A Relationship**: When derived class "is a" type of base class
- **Shared Behavior**: When classes share common properties and methods
- **Code Reuse**: To avoid duplicating common code
- **Polymorphism**: When you want to treat derived objects as base objects
- **Extensibility**: When you want to extend existing functionality

## Common Inheritance Patterns

### Shape Hierarchy
```php
class Shape { /* common properties */ }
class Circle extends Shape { /* circle-specific */ }
class Rectangle extends Shape { /* rectangle-specific */ }
```

### Vehicle Hierarchy
```php
class Vehicle { /* common vehicle properties */ }
class Car extends Vehicle { /* car-specific */ }
class Motorcycle extends Vehicle { /* motorcycle-specific */ }
```
