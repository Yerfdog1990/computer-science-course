# 5.3: Initializing Members

## Multiple Objects with Unique Attributes

A program can easily create multiple objects simply by declaring multiple instances of a class, and each object can have unique attributes by assigning individual values with its setter methods.

## Combined Setter Method

It is often convenient to combine the setter methods into a single method that accepts arguments for each private variable. This means that all values can be assigned with a single statement in the program, but the method will contain multiple statements.

### Benefits of Combined Setter Method

1. **Single Statement Assignment**: All values assigned in one call
2. **Type Safety**: Each parameter can specify permissible data types
3. **Default Values**: Parameters can specify default values
4. **Code Efficiency**: Reduces the number of method calls

## Combined Setter Method Syntax

```php
public function setValues(int $yrs = 2, int $lbs = 8, string $fur = 'black') {
    // Statements to assign values from passed arguments to class variables
    $this->age = $yrs;
    $this->weight = $lbs;
    $this->color = $fur;
}
```

### Method Parameters

- **Type Hints**: Each parameter specifies data type (`int`, `string`)
- **Default Values**: Parameters have default values if no arguments passed
- **Multiple Arguments**: Single method handles multiple property assignments

## Complete Example with Multiple Objects

### Modified Dog Class

```php
<?php
class Dog {
    private $age;
    private $weight;
    private $color;
    
    public function bark() {
        echo 'WOOF!';
    }
    
    // Combined setter method with type hints and default values
    public function setValues(int $yrs = 2, int $lbs = 8, string $fur = 'black') {
        $this->age = $yrs;
        $this->weight = $lbs;
        $this->color = $fur;
    }
    
    // Getter methods remain the same
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
}
?>
```

### Creating Multiple Objects

```php
// First object - passing all arguments
$fido = new Dog();
$fido->setValues(3, 15, 'brown');

// Second object - passing all arguments
$pooch = new Dog();
$pooch->setValues(4, 18, 'gray');

// Third object - using default values
$rover = new Dog();
$rover->setValues(); // Uses default values
```

### Retrieving Data from Multiple Objects

```php
// Display Fido's data
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';
echo 'Fido is ' . $fido->getAge() . ' years old<br>';
echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';
$fido->bark();

// Display Pooch's data
echo '<br>Pooch: ' . $pooch->getAge() . 'yrs ';
echo $pooch->getWeight() . 'lbs ' . $pooch->getColor() . '<br>';
$pooch->bark();

// Display Rover's data (using defaults)
echo '<br>Rover: ' . $rover->getAge() . 'yrs ';
echo $rover->getWeight() . 'lbs ' . $rover->getColor() . '<br>';
$rover->bark();
```

## Complete Working Example

```php
<?php
class Dog {
    private $age;
    private $weight;
    private $color;
    
    public function bark() {
        echo 'WOOF!';
    }
    
    public function setValues(int $yrs = 2, int $lbs = 8, string $fur = 'black') {
        $this->age = $yrs;
        $this->weight = $lbs;
        $this->color = $fur;
    }
    
    public function getAge() {
        return $this->age;
    }
    
    public function getWeight() {
        return $this->weight;
    }
    
    public function getColor() {
        return $this->color;
    }
}

// Create and configure first object
$fido = new Dog();
$fido->setValues(3, 15, 'brown');

// Create and configure second object
$pooch = new Dog();
$pooch->setValues(4, 18, 'gray');

// Create and configure third object with defaults
$rover = new Dog();
$rover->setValues(); // Uses default values: age=2, weight=8, color='black'

// Display all objects
echo 'Fido is a ' . $fido->getColor() . ' dog<br>';
echo 'Fido is ' . $fido->getAge() . ' years old<br>';
echo 'Fido weighs ' . $fido->getWeight() . ' pounds<br>';
$fido->bark();

echo '<br>Pooch: ' . $pooch->getAge() . 'yrs ';
echo $pooch->getWeight() . 'lbs ' . $pooch->getColor() . '<br>';
$pooch->bark();

echo '<br>Rover: ' . $rover->getAge() . 'yrs ';
echo $rover->getWeight() . 'lbs ' . $rover->getColor() . '<br>';
$rover->bark();
?>
```

## Type Safety and Error Handling

### Type Hints Benefits

- **Automatic Type Checking**: PHP ensures correct data types
- **Error Prevention**: Type errors are caught early
- **Code Documentation**: Makes expected types clear

### Example of Type Error

```php
// This would cause a type error
$dog = new Dog();
$dog->setValues("three", 15, "brown"); // Error: "three" is not an integer
```

## Default Values Usage

### When to Use Defaults

1. **Standard Objects**: When most objects have similar initial values
2. **Optional Parameters**: When some values are optional
3. **Convenience**: When creating objects with common settings

### Important Note

You must still call the initializer method to assign the default values to the class variables when passing no arguments. Default values are not automatically assigned.

WOOF!

## Key Concepts Summary

1. **Multiple Objects**: Creating several instances of the same class
2. **Combined Setter Method**: Single method to set multiple properties
3. **Type Hints**: Specifying data types for method parameters
4. **Default Values**: Providing fallback values for parameters
5. **Type Safety**: Automatic validation of argument types
6. **Method Efficiency**: Reducing multiple calls to single calls

## Best Practices

- Use type hints for better code reliability
- Provide sensible default values for common scenarios
- Combine related property assignments into logical methods
- Create descriptive method names that indicate their purpose
- Consider validation logic in setter methods
- Use default values to simplify object creation for common cases
