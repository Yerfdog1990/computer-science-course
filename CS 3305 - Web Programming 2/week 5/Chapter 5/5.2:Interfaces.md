# 5.2: Interfaces

## Introduction to Interfaces

An interface is a contract that defines a set of methods that a class must implement. It provides a way to enforce consistency across different classes and promote polymorphism by ensuring that all implementing classes have the same method signatures.

## Interface Definition and Purpose

### What is an Interface?
- **Contract**: Defines what methods a class must implement
- **Blueprint**: Specifies method signatures without implementation
- **Enforcement**: Guarantees that classes have specific methods
- **Consistency**: Ensures uniform behavior across different classes

### Key Characteristics
- **Method Signatures Only**: Contains method declarations, not implementations
- **No Properties**: Cannot contain property declarations
- **Multiple Implementation**: A class can implement multiple interfaces
- **Inheritance**: Interfaces can extend other interfaces

## Interface Syntax

### Basic Interface Declaration
```php
<?php
interface InterfaceName {
    public function methodName($parameter1, $parameter2);
    public function anotherMethod(): returnType;
}
?>
```

### Interface with Type Hints
```php
<?php
interface Drawable {
    public function draw(): void;
    public function getArea(): float;
    public function getPerimeter(): float;
}

interface Serializable {
    public function serialize(): string;
    public function unserialize(string $data): void;
}
?>
```

## Implementing Interfaces

### Class Implementation
```php
<?php
class ClassName implements InterfaceName {
    // Must implement all interface methods
    public function methodName($parameter1, $parameter2) {
        // Implementation code
    }
    
    public function anotherMethod(): returnType {
        // Implementation code
        return $value;
    }
}
?>
```

## Complete Interface Example

### Interface Definition
```php
<?php
// Interface for payment processing
interface PaymentProcessor {
    public function processPayment(float $amount): bool;
    public function getTransactionId(): string;
    public function getStatus(): string;
}

// Interface for logging
interface Logger {
    public function log(string $message): void;
    public function getLogs(): array;
    public function clearLogs(): void;
}
?>
```

### Class Implementations
```php
<?php
// Credit card payment processor
class CreditCardProcessor implements PaymentProcessor {
    private $transactionId;
    private $status;
    
    public function processPayment(float $amount): bool {
        // Credit card processing logic
        $this->transactionId = 'CC_' . uniqid();
        $this->status = 'completed';
        return true;
    }
    
    public function getTransactionId(): string {
        return $this->transactionId;
    }
    
    public function getStatus(): string {
        return $this->status;
    }
}

// PayPal payment processor
class PayPalProcessor implements PaymentProcessor {
    private $transactionId;
    private $status;
    
    public function processPayment(float $amount): bool {
        // PayPal processing logic
        $this->transactionId = 'PP_' . uniqid();
        $this->status = 'completed';
        return true;
    }
    
    public function getTransactionId(): string {
        return $this->transactionId;
    }
    
    public function getStatus(): string {
        return $this->status;
    }
}

// File logger
class FileLogger implements Logger {
    private $logs = [];
    private $logFile;
    
    public function __construct(string $filename) {
        $this->logFile = $filename;
    }
    
    public function log(string $message): void {
        $timestamp = date('Y-m-d H:i:s');
        $logEntry = "[$timestamp] $message\n";
        $this->logs[] = $logEntry;
        file_put_contents($this->logFile, $logEntry, FILE_APPEND);
    }
    
    public function getLogs(): array {
        return $this->logs;
    }
    
    public function clearLogs(): void {
        $this->logs = [];
        file_put_contents($this->logFile, '');
    }
}
?>
```

### Usage Example
```php
<?php
// Payment processing with different methods
$creditCardProcessor = new CreditCardProcessor();
$paypalProcessor = new PayPalProcessor();

// Process payments
$creditCardProcessor->processPayment(100.00);
$paypalProcessor->processPayment(50.00);

// Get transaction details
echo "Credit Card Transaction: " . $creditCardProcessor->getTransactionId() . "\n";
echo "PayPal Transaction: " . $paypalProcessor->getTransactionId() . "\n";

// Logging
$logger = new FileLogger('transactions.log');
$logger->log('Credit card payment processed');
$logger->log('PayPal payment processed');
?>
```

## Interface Inheritance

### Extending Interfaces
```php
<?php
// Base interface
interface Shape {
    public function getArea(): float;
    public function getPerimeter(): float;
}

// Extended interface
interface ThreeDimensionalShape extends Shape {
    public function getVolume(): float;
    public function getSurfaceArea(): float;
}

// Class implementing extended interface
class Cube implements ThreeDimensionalShape {
    private $side;
    
    public function __construct(float $side) {
        $this->side = $side;
    }
    
    public function getArea(): float {
        return $this->side * $this->side;
    }
    
    public function getPerimeter(): float {
        return 4 * $this->side;
    }
    
    public function getVolume(): float {
        return $this->side * $this->side * $this->side;
    }
    
    public function getSurfaceArea(): float {
        return 6 * $this->getArea();
    }
}
?>
```

## Advanced Interface Features

### Constant Definitions
```php
<?php
interface ConfigInterface {
    public const DEFAULT_TIMEOUT = 30;
    public const MAX_RETRIES = 3;
    
    public function getTimeout(): int;
    public function getMaxRetries(): int;
}

class Config implements ConfigInterface {
    public function getTimeout(): int {
        return self::DEFAULT_TIMEOUT;
    }
    
    public function getMaxRetries(): int {
        return self::MAX_RETRIES;
    }
}
?>
```

### Static Methods in Interfaces
```php
<?php
interface FactoryInterface {
    public static function create(string $type): object;
    public static function getAvailableTypes(): array;
}

class ShapeFactory implements FactoryInterface {
    public static function create(string $type): object {
        switch ($type) {
            case 'circle':
                return new Circle(10);
            case 'square':
                return new Square(5);
            default:
                throw new Exception("Unknown shape type: $type");
        }
    }
    
    public static function getAvailableTypes(): array {
        return ['circle', 'square', 'triangle'];
    }
}
?>
```

## Benefits of Interfaces

### Design Benefits
1. **Contract Enforcement**: Ensures classes implement required methods
2. **Consistency**: Guarantees uniform behavior across implementations
3. **Polymorphism**: Allows different classes to be used interchangeably
4. **Documentation**: Serves as clear documentation of expected behavior
5. **Testing**: Enables easy mocking and testing of implementations

### Code Organization
1. **Separation of Concerns**: Interface defines what, class defines how
2. **Loose Coupling**: Classes depend on interfaces, not specific implementations
3. **Flexibility**: Easy to swap implementations without changing client code
4. **Scalability**: New implementations can be added without modifying existing code

## Best Practices

### Interface Design
1. **Small and Focused**: Each interface should have a single responsibility
2. **Descriptive Naming**: Use clear, meaningful interface names
3. **Complete Documentation**: Document purpose and usage of each method
4. **Version Consideration**: Consider backward compatibility when modifying
5. **Type Safety**: Use proper type hints for parameters and returns

### Implementation Guidelines
1. **Full Implementation**: Implement all methods defined in interface
2. **Consistent Signatures**: Match method signatures exactly
3. **Error Handling**: Handle errors appropriately in implementations
4. **Performance**: Consider performance implications of implementations
5. **Testing**: Test all interface methods thoroughly

## Key Concepts Summary

1. **Interface Contract**: Defines method signatures without implementation
2. **Implementation**: Classes provide concrete implementations of interface methods
3. **Multiple Interfaces**: Classes can implement multiple interfaces
4. **Interface Inheritance**: Interfaces can extend other interfaces
5. **Polymorphism**: Different classes can be treated through common interface
6. **Type Safety**: Interfaces provide strong typing for method signatures
7. **Loose Coupling**: Code depends on abstractions, not concrete implementations

Interfaces provide a powerful mechanism for creating flexible, maintainable, and extensible code by defining clear contracts that classes must follow, enabling polymorphism and promoting good software design principles.
