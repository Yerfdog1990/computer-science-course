# 5.3: Overriding Methods

## Introduction to Method Overriding

Method overriding is a fundamental concept in object-oriented programming that allows a child class to provide a specific implementation of a method that is already defined in its parent class. This enables customization and extension of functionality while maintaining the same interface.

## What is Method Overriding?

### Definition
- **Overriding**: When a child class provides its own implementation of a parent method
- **Same Signature**: The overriding method must have the same name and parameters
- **Runtime Binding**: The appropriate method implementation is called based on object type
- **Polymorphism**: Different objects respond differently to the same method call

### Purpose
1. **Customization**: Tailor parent behavior to child class needs
2. **Extension**: Add specialized functionality beyond parent implementation
3. **Specialization**: Provide specific behavior for specific types
4. **Maintainability**: Keep consistent interface while changing implementation

## Overriding Syntax

### Basic Override
```php
<?php
class ParentClass {
    public function methodName($param) {
        return "Parent implementation: $param";
    }
}

class ChildClass extends ParentClass {
    public function methodName($param) {
        return "Child implementation: $param";
    }
}
?>
```

### Access Modifier Rules
```php
<?php
class ParentClass {
    protected function protectedMethod() {
        return "Parent protected method";
    }
    
    public function publicMethod() {
        return "Parent public method";
    }
}

class ChildClass extends ParentClass {
    // Can make protected method public
    public function protectedMethod() {
        return "Child overridden protected method";
    }
    
    // Cannot make public method private - would cause error
    // private function publicMethod() { ... } // ERROR
    
    // Must maintain or increase visibility
    public function publicMethod() {
        return "Child overridden public method";
    }
}
?>
```

## Complete Overriding Example

### Parent Class
```php
<?php
class Vehicle {
    protected $brand;
    protected $model;
    protected $year;
    
    public function __construct($brand, $model, $year) {
        $this->brand = $brand;
        $this->model = $model;
        $this->year = $year;
    }
    
    public function getInfo() {
        return "$this->year $this->brand $this->model";
    }
    
    public function start() {
        return "Starting vehicle engine...";
    }
    
    public function stop() {
        return "Stopping vehicle engine...";
    }
    
    protected function getFuelType() {
        return "Gasoline";
    }
}
?>
```

### Child Classes with Overrides
```php
<?php
class Car extends Vehicle {
    private $doors;
    
    public function __construct($brand, $model, $year, $doors = 4) {
        parent::__construct($brand, $model, $year);
        $this->doors = $doors;
    }
    
    // Override getInfo to include car-specific details
    public function getInfo() {
        return parent::getInfo() . " ($this->doors doors)";
    }
    
    // Override start for car-specific behavior
    public function start() {
        return "Starting car with key and ignition...";
    }
    
    // Override getFuelType to be more specific
    protected function getFuelType() {
        return "Gasoline or Electric";
    }
}

class Motorcycle extends Vehicle {
    private $type;
    
    public function __construct($brand, $model, $year, $type = 'Sport') {
        parent::__construct($brand, $model, $year);
        $this->type = $type;
    }
    
    // Override getInfo for motorcycle-specific details
    public function getInfo() {
        return parent::getInfo() . " ($this->type motorcycle)";
    }
    
    // Override start for motorcycle-specific behavior
    public function start() {
        return "Starting motorcycle with kick-start...";
    }
    
    // Override getFuelType for motorcycle
    protected function getFuelType() {
        return "Gasoline";
    }
}
?>
```

### Usage Example
```php
<?php
$car = new Car('Toyota', 'Camry', 2023, 4);
$motorcycle = new Motorcycle('Harley-Davidson', 'Street Glide', 2022, 'Cruiser');

// Each object responds differently to the same method calls
echo $car->getInfo() . "\n";      // "2023 Toyota Camry (4 doors)"
echo $motorcycle->getInfo() . "\n";  // "2022 Harley-Davidson Street Glide (Cruiser motorcycle)"

echo $car->start() . "\n";         // "Starting car with key and ignition..."
echo $motorcycle->start() . "\n";     // "Starting motorcycle with kick-start..."
?>
```

## Accessing Parent Methods

### Using parent:: Operator
```php
<?php
class ChildClass extends ParentClass {
    public function methodName($param) {
        // Call parent method first
        $parentResult = parent::methodName($param);
        
        // Add child-specific functionality
        return $parentResult . " [Child Enhanced]";
    }
}
?>
```

### Complete Example with parent:: Usage
```php
<?php
class ElectricCar extends Car {
    private $batteryCapacity;
    
    public function __construct($brand, $model, $year, $doors, $batteryCapacity) {
        parent::__construct($brand, $model, $year, $doors);
        $this->batteryCapacity = $batteryCapacity;
    }
    
    public function getInfo() {
        // Get parent info and add electric-specific details
        return parent::getInfo() . " [Electric: {$this->batteryCapacity}kWh]";
    }
    
    public function start() {
        // Different starting behavior for electric cars
        return "Powering on electric vehicle silently...";
    }
    
    protected function getFuelType() {
        return "Electric";
    }
    
    // New method specific to electric cars
    public function getBatteryLevel() {
        return rand(20, 100) . "%";
    }
}

$electricCar = new ElectricCar('Tesla', 'Model 3', 2023, 4, 75);
echo $electricCar->getInfo() . "\n";
echo $electricCar->start() . "\n";
echo $electricCar->getBatteryLevel() . "\n";
?>
```

## Overriding Rules and Restrictions

### Signature Requirements
```php
<?php
class ParentClass {
    public function methodWithParams($param1, $param2 = 'default') {
        return "Parent: $param1, $param2";
    }
}

class ChildClass extends ParentClass {
    // Must match parent signature exactly
    public function methodWithParams($param1, $param2 = 'default') {
        return "Child: $param1, $param2";
    }
    
    // This would cause an error - different signature
    // public function methodWithParams($param1) { ... }
}
?>
```

### Access Modifier Constraints
```php
<?php
class ParentClass {
    public function publicMethod() { return "Public"; }
    protected function protectedMethod() { return "Protected"; }
    private function privateMethod() { return "Private"; }
}

class ChildClass extends ParentClass {
    // Allowed - can maintain same visibility
    public function publicMethod() { return "Child Public"; }
    
    // Allowed - can increase visibility
    public function protectedMethod() { return "Child Protected (now public)"; }
    
    // Not allowed - private methods cannot be overridden
    // private function privateMethod() { return "Child Private"; } // ERROR
}
?>
```

## Advanced Overriding Techniques

### Final Methods
```php
<?php
class ParentClass {
    // This method cannot be overridden by child classes
    final function cannotOverride() {
        return "This cannot be changed";
    }
    
    public function canOverride() {
        return "This can be changed";
    }
}

class ChildClass extends ParentClass {
    // This would cause a fatal error
    // public function cannotOverride() { ... } // FATAL ERROR
    
    public function canOverride() {
        return "Child implementation";
    }
}
?>
```

### Abstract Classes and Overriding
```php
<?php
abstract class Shape {
    protected $color;
    
    public function __construct($color) {
        $this->color = $color;
    }
    
    // Abstract method must be implemented by child classes
    abstract public function getArea(): float;
    
    // Concrete method that can be overridden
    public function getColor(): string {
        return $this->color;
    }
    
    // Method that can be overridden
    public function getDescription(): string {
        return "A $this->color shape";
    }
}

class Circle extends Shape {
    private $radius;
    
    public function __construct($color, $radius) {
        parent::__construct($color);
        $this->radius = $radius;
    }
    
    // Must implement abstract method
    public function getArea(): float {
        return pi() * $this->radius * $this->radius;
    }
    
    // Override parent method
    public function getDescription(): string {
        return "A $this->color circle with radius $this->radius";
    }
}

class Rectangle extends Shape {
    private $width;
    private $height;
    
    public function __construct($color, $width, $height) {
        parent::__construct($color);
        $this->width = $width;
        $this->height = $height;
    }
    
    // Must implement abstract method
    public function getArea(): float {
        return $this->width * $this->height;
    }
    
    // Override parent method
    public function getDescription(): string {
        return "A $this->color rectangle ($this->width x $this->height)";
    }
}
?>
```

## Best Practices for Method Overriding

### When to Override
1. **Specialization Needed**: When child class needs specific behavior
2. **Enhancement Required**: When adding to parent functionality
3. **Different Behavior**: When implementation should differ significantly
4. **Performance Optimization**: When child class can be more efficient

### Guidelines for Overriding
1. **Maintain Contract**: Keep the same method signature
2. **Preserve Invariants**: Don't break parent class assumptions
3. **Document Changes**: Clearly document why and how methods are overridden
4. **Use parent::**: Call parent method when appropriate
5. **Consider Final**: Use final for methods that shouldn't be overridden

### Common Patterns
```php
<?php
class DatabaseConnection {
    protected $connection;
    
    public function connect() {
        $this->connection = $this->createConnection();
        $this->onConnect();
    }
    
    protected function createConnection() {
        return new PDO('mysql:host=localhost;dbname=test', 'user', 'pass');
    }
    
    protected function onConnect() {
        echo "Connected to database\n";
    }
    
    public function disconnect() {
        $this->onDisconnect();
        $this->connection = null;
    }
    
    protected function onDisconnect() {
        echo "Disconnected from database\n";
    }
}

class MySQLConnection extends DatabaseConnection {
    protected function createConnection() {
        return new PDO('mysql:host=localhost;dbname=mysql', 'user', 'pass');
    }
    
    protected function onConnect() {
        echo "Connected to MySQL database\n";
    }
    
    protected function onDisconnect() {
        echo "Disconnected from MySQL database\n";
    }
}

class PostgreSQLConnection extends DatabaseConnection {
    protected function createConnection() {
        return new PDO('pgsql:host=localhost;dbname=postgres', 'user', 'pass');
    }
    
    protected function onConnect() {
        echo "Connected to PostgreSQL database\n";
    }
    
    protected function onDisconnect() {
        echo "Disconnected from PostgreSQL database\n";
    }
}
?>
```

## Key Concepts Summary

1. **Method Overriding**: Child classes provide their own implementation of parent methods
2. **Same Signature**: Overridden methods must match parent method signatures
3. **Runtime Polymorphism**: Method calls resolved at runtime based on object type
4. **parent:: Operator**: Allows calling parent method implementations
5. **Access Control**: Child methods must maintain or increase visibility
6. **Final Methods**: Cannot be overridden by child classes
7. **Abstract Classes**: Provide both abstract and concrete methods for overriding

## Benefits of Method Overriding

- **Specialization**: Tailor behavior to specific needs
- **Extensibility**: Add new functionality without changing parent
- **Polymorphism**: Same interface, different behaviors
- **Code Reuse**: Inherit common functionality, customize specific parts
- **Maintainability**: Changes to parent don't require child changes
- **Flexibility**: Easy to create variations of existing classes

Method overriding is a powerful mechanism for creating flexible and extensible class hierarchies while maintaining consistent interfaces and enabling polymorphic behavior.
