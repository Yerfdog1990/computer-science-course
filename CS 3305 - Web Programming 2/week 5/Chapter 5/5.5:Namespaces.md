# 5.5: Namespaces

## Introduction to Namespaces

Namespaces are a way to organize code and avoid naming conflicts in complex applications. They provide a logical grouping of related classes, interfaces, functions, and constants, allowing developers to create more organized and maintainable codebases.

## What are Namespaces?

### Definition
- **Code Organization**: Logical grouping of PHP code elements
- **Conflict Prevention**: Avoid naming collisions between different libraries
- **Hierarchy**: Can be nested to create organizational structure
- **Scope**: Define scope for classes, functions, and constants

### Key Benefits
1. **Name Collision Avoidance**: Different libraries can have same class names
2. **Code Organization**: Related functionality grouped together
3. **Readability**: Clear indication of where code comes from
4. **Autoloading**: Better support for modern autoloading mechanisms
5. **Modularity**: Separate concerns into different namespaces

## Namespace Syntax

### Basic Namespace Declaration
```php
<?php
namespace Vendor\Project\Module;

class ClassName {
    // Class implementation
}

function functionName() {
    // Function implementation
}

const CONSTANT_NAME = 'value';
?>
```

### Nested Namespaces
```php
<?php
namespace Vendor\Project\Module\Submodule;

class DeepClass {
    // Class in nested namespace
}

namespace Vendor\Project {
    class ModuleClass {
        // Class in parent namespace
    }
}
?>
```

### Namespace Definitions
```php
<?php
// src/Database/Connection.php
namespace MyApp\Database;

class Connection {
    private $connection;
    
    public function __construct($config) {
        $this->connection = $this->createConnection($config);
    }
    
    public function query($sql) {
        return $this->connection->query($sql);
    }
    
    private function createConnection($config) {
        // Database connection logic
        return new PDO($config['dsn'], $config['username'], $config['password']);
    }
}

// src/Database/QueryBuilder.php
namespace MyApp\Database;

class QueryBuilder {
    private $table;
    private $conditions = [];
    
    public function table($name) {
        $this->table = $name;
        return $this;
    }
    
    public function where($column, $operator, $value) {
        $this->conditions[] = "$column $operator '$value'";
        return $this;
    }
    
    public function get() {
        $sql = "SELECT * FROM {$this->table}";
        if (!empty($this->conditions)) {
            $sql .= " WHERE " . implode(' AND ', $this->conditions);
        }
        return $sql;
    }
}

// src/Auth/User.php
namespace MyApp\Auth;

class User {
    private $id;
    private $name;
    private $email;
    
    public function __construct($id, $name, $email) {
        $this->id = $id;
        $this->name = $name;
        $this->email = $email;
    }
    
    public function getId() {
        return $this->id;
    }
    
    public function getName() {
        return $this->name;
    }
    
    public function getEmail() {
        return $this->email;
    }
}

// src/Auth/Session.php
namespace MyApp\Auth;

class Session {
    private $user;
    private $sessionId;
    
    public function __construct() {
        $this->sessionId = session_id();
    }
    
    public function setUser(User $user) {
        $this->user = $user;
        $_SESSION['user_id'] = $user->getId();
    }
    
    public function getUser() {
        return $this->user;
    }
    
    public function isActive() {
        return $this->user !== null;
    }
}

// src/Utils/Logger.php
namespace MyApp\Utils;

class Logger {
    private $logFile;
    
    public function __construct($filename) {
        $this->logFile = $filename;
    }
    
    public function log($message) {
        $timestamp = date('Y-m-d H:i:s');
        $logEntry = "[$timestamp] $message\n";
        file_put_contents($this->logFile, $logEntry, FILE_APPEND);
    }
}

// src/Utils/Validator.php
namespace MyApp\Utils;

class Validator {
    public static function email($email) {
        return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
    }
    
    public static function required($value) {
        return !empty($value) && trim($value) !== '';
    }
    
    public static function numeric($value) {
        return is_numeric($value);
    }
}
?>
```

### Using Namespaced Code
```php
<?php
// public/index.php
require_once '../src/Database/Connection.php';
require_once '../src/Database/QueryBuilder.php';
require_once '../src/Auth/User.php';
require_once '../src/Auth/Session.php';
require_once '../src/Utils/Logger.php';
require_once '../src/Utils/Validator.php';

use MyApp\Database\Connection;
use MyApp\Database\QueryBuilder;
use MyApp\Auth\User;
use MyApp\Auth\Session;
use MyApp\Utils\Logger;
use MyApp\Utils\Validator;

// Application logic
$logger = new Logger('app.log');
$database = new Connection([
    'dsn' => 'mysql:host=localhost;dbname=myapp',
    'username' => 'user',
    'password' => 'pass'
]);

// Create query builder
$query = (new QueryBuilder())
    ->table('users')
    ->where('email', '=', 'john@example.com')
    ->get();

// Execute query and create user
$userData = $database->query($query);
if ($userData) {
    $user = new User($userData['id'], $userData['name'], $userData['email']);
    
    // Create session
    $session = new Session();
    $session->setUser($user);
    
    $logger->log("User logged in: " . $user->getName());
}
?>
```

## Advanced Namespace Features

### Aliasing
```php
<?php
// Import with alias
use MyApp\Database\Connection as DbConnection;
use MyApp\Auth\User as AuthUser;
use MyApp\Utils\Logger as Log;

// Use aliased classes
$connection = new DbConnection($config);
$user = new AuthUser($id, $name, $email);
$logger = new Log('app.log');
?>
```

### Global Namespace
```php
<?php
// Global namespace (no namespace declaration)
class GlobalClass {
    public function method() {
        return "Global class method";
    }
}

namespace MyApp {
    class LocalClass {
        public function method() {
            return "Local class method";
        }
    }
    
    function test() {
        $global = new \GlobalClass(); // Use \ to access global
        $local = new LocalClass();
        
        echo $global->method() . "\n"; // "Global class method"
        echo $local->method() . "\n";  // "Local class method"
    }
}
?>
```

### Multiple Namespaces in One File
```php
<?php
namespace FirstNamespace {
    class FirstClass {
        public function method() {
            return "First namespace class";
        }
    }
}

namespace SecondNamespace {
    class SecondClass {
        public function method() {
            return "Second namespace class";
        }
    }
}

namespace {
    // Global code
    $first = new FirstNamespace\FirstClass();
    $second = new SecondNamespace\SecondClass();
    
    echo $first->method() . "\n";
    echo $second->method() . "\n";
}
?>
```

## Namespace Best Practices

### Naming Conventions
1. **Vendor\Project**: Use vendor name followed by project name
2. **Hierarchy**: Create logical sub-namespaces for modules
3. **PascalCase**: Use PascalCase for namespace parts
4. **Descriptive**: Make namespace names meaningful
5. **Consistent**: Follow same pattern throughout project

### File Organization
```
VendorName/
├── ProjectName/
│   ├── Module1/
│   │   ├── Class1.php
│   │   └── Class2.php
│   ├── Module2/
│   │   ├── Class3.php
│   │   └── Class4.php
│   └── Common/
│       ├── Utility1.php
│       └── Utility2.php
└── Tests/
    ├── Module1/
    │   └── Class1Test.php
    └── Module2/
        └── Class3Test.php
```

### Autoloading with Namespaces
```php
<?php
// composer.json-example
{
    "autoload": {
        "psr-4": {
            "VendorName\\ProjectName\\": "src/"
        }
    }
}

// Custom autoloader
spl_autoload_register(function ($class) {
    $prefix = 'VendorName\\ProjectName\\';
    $base_dir = __DIR__ . '/src/';
    
    $len = strlen($prefix);
    if (strncmp($prefix, $class, $len) === 0) {
        $relative_class = substr($class, $len);
        $file = $base_dir . str_replace('\\', '/', $relative_class) . '.php';
        
        if (file_exists($file)) {
            require $file;
        }
    }
});
?>
```

## Common Namespace Patterns

### MVC Pattern
```php
<?php
// Controllers
namespace MyApp\Controllers;

class UserController {
    public function show($id) {
        // Controller logic
    }
}

// Models
namespace MyApp\Models;

class User {
    public function find($id) {
        // Model logic
    }
}

// Views
namespace MyApp\Views;

class UserView {
    public function render($user) {
        // View logic
    }
}
?>
```

### Service Layer
```php
<?php
namespace MyApp\Services;

class UserService {
    public function create($data) {
        // Service logic
    }
}

namespace MyApp\Services;

class EmailService {
    public function send($to, $subject, $message) {

    }

```

```php
    public function find($id) {
        // PostgreSQL-specific implementation
    }

```

## Key Concepts Summary

1. **Namespace Declaration**: `namespace` keyword defines code scope
2. **Hierarchical Organization**: Nested namespaces create logical structure
3. **Conflict Prevention**: Avoid naming collisions between libraries
4. **Use Statement**: Import classes with `use` keyword
5. **Aliasing**: Create alternative names for imported classes
6. **Global Access**: Use `\` prefix for global namespace access
7. **Autoloading**: Modern PHP supports namespace-based autoloading

## Benefits of Namespaces

- **Organization**: Logical grouping of related functionality
- **Conflict Resolution**: Prevent naming collisions in large projects
- **Readability**: Clear indication of code origin and purpose
- **Modularity**: Separate concerns into distinct namespaces
- **Maintainability**: Easier to locate and modify related code
- **Collaboration**: Multiple developers can work without conflicts
- **Testing**: Isolated testing of different components

Namespaces provide an essential tool for organizing complex PHP applications, preventing naming conflicts, and enabling maintainable, scalable code architecture.
