# Comparing Characters

---

## 1. What Is String Comparison?

PHP provides several built-in functions to compare two text strings. These functions work by examining each character's **ASCII value** in sequence, allowing PHP to determine whether one string is equal to, greater than, or less than another.

---

## 2. Understanding ASCII Values

Every character has a standard numerical **ASCII** (American Standard Code for Information Exchange) value. This is the universal standard character coding scheme that PHP uses when comparing strings.

| Character Group | ASCII Range | Example |
|---|---|---|
| Uppercase A–Z | 65–90 | `A` = 65, `B` = 66, `Z` = 90 |
| Lowercase a–z | 97–122 | `a` = 97, `b` = 98, `z` = 122 |

### Key Point — Case Matters

Since lowercase letters have **higher** ASCII values than uppercase letters:

- `"a"` (97) is **greater than** `"A"` (65)
- `"A"` (65) is **less than** `"a"` (97)

### Key Point — Order Matters

Strings are compared **character by character** in sequence. This ensures that strings with the same characters in a different order are not incorrectly seen as equal.

**Example:** Comparing `"ABC"` and `"BAC"`:
- First character: `"A"` (65) vs `"B"` (66)
- `"A"` is less than `"B"` → result is `-1`

> **Note:** The ASCII total of two differently ordered strings could be equal — but that does not mean the strings match, because character order is always relevant.

---

## 3. The Four String Comparison Functions

### 3.1 `strcmp()` — Case-Sensitive Comparison

Compares two strings exactly, character by character. Returns one of three values:

| Return Value | Meaning |
|---|---|
| `0` | Both strings are exactly equal |
| `1` (positive integer) | First string is **greater than** the second |
| `-1` (negative integer) | First string is **less than** the second |

```php
strcmp($string1, $string2);
```

> Strictly speaking, `strcmp()` returns a positive integer, zero, or a negative integer — but the values are typically `1`, `0`, or `-1`.

### 3.2 `strncmp()` — Case-Sensitive Partial Comparison

Works like `strcmp()` but accepts a **third argument** specifying how many characters from the start of each string to compare.

```php
strncmp($string1, $string2, $numChars);
```

### 3.3 `strcasecmp()` — Case-Insensitive Comparison

Works like `strcmp()` but **ignores case** when comparing. Useful when uppercase and lowercase differences don't matter.

```php
strcasecmp($string1, $string2);
```

### 3.4 `strncasecmp()` — Case-Insensitive Partial Comparison

Combines the behaviour of `strncmp()` and `strcasecmp()` — compares a specified number of characters while ignoring case.

```php
strncasecmp($string1, $string2, $numChars);
```

---

## 4. Companion Functions — `ord()` and `strlen()`

| Function | Purpose | Example |
|---|---|---|
| `ord($char)` | Returns the ASCII value of a character | `ord('A')` → `65` |
| `strlen($string)` | Returns the number of characters in a string | `strlen('PHP')` → `3` |

These are useful for understanding how comparisons work under the hood.

## 5. Full Example — Comparing Characters (`characters.php`)

### Step 1 — Initialise four string variables

```php
<?php

$str1 = 'PHP in easy steps';
$str2 = 'PHP in easy steps';
$str3 = 'PHP In Easy Steps';
$str4 = 'php in easy steps';
```

### Step 2 — Compare the strings using `strcmp()`

```php
echo "'$str1' versus '$str2' : " . strcmp($str1, $str2) . '<br>';
echo "'$str1' versus '$str3' : " . strcmp($str1, $str3) . '<br>';
echo "'$str1' versus '$str4' : " . strcmp($str1, $str4) . '<hr>';
```

### Step 3 — Case-insensitive comparison using `strcasecmp()`

```php
echo 'Comparison Ignoring Case:<br>';
echo "'$str1' versus '$str4' : " . strcasecmp($str1, $str4);
```

### Step 4 — Loop through the string and calculate total ASCII value using `ord()` and `strlen()`

```php
$total = 0;
for ($i = 0; $i < strlen($str1); $i++)
{
    $total += ord($str1[$i]);
}
echo "<hr>ASCII Total '$str1': $total";

?>
```

---

## 6. Complete Script

```php
<?php

// Initialize four string variables
$str1 = 'PHP in easy steps';
$str2 = 'PHP in easy steps';
$str3 = 'PHP In Easy Steps';
$str4 = 'php in easy steps';

// Case-sensitive comparisons using strcmp()
echo "'$str1' versus '$str2' : " . strcmp($str1, $str2) . '<br>';  // 0 — identical
echo "'$str1' versus '$str3' : " . strcmp($str1, $str3) . '<br>';  // 1 — $str1 > $str3 (lowercase > uppercase)
echo "'$str1' versus '$str4' : " . strcmp($str1, $str4) . '<hr>';  // -1 — $str1 < $str4 (uppercase < lowercase)

// Case-insensitive comparison using strcasecmp()
echo 'Comparison Ignoring Case:<br>';
echo "'$str1' versus '$str4' : " . strcasecmp($str1, $str4);       // 0 — equal when ignoring case

// Calculate total ASCII value of $str1 using ord() and strlen()
$total = 0;
for ($i = 0; $i < strlen($str1); $i++)
{
    $total += ord($str1[$i]);
}
echo "<hr>ASCII Total '$str1': $total";

?>
```

## 8. Output Explained

| Comparison | Function | Reason | Result |
|---|---|---|---|
| `$str1` vs `$str2` | `strcmp()` | Strings are identical | `0` |
| `$str1` vs `$str3` | `strcmp()` | `$str1` has lowercase `i`, `e`, `s` (higher ASCII) vs uppercase `I`, `E`, `S` in `$str3` | `1` |
| `$str1` vs `$str4` | `strcmp()` | `$str1` starts with `P` (80) vs `p` (112) in `$str4` — `P` is less | `-1` |
| `$str1` vs `$str4` | `strcasecmp()` | Case is ignored — strings are effectively identical | `0` |

## 9. How the ASCII Loop Works

The `for` loop in Step 4 iterates through every character in `$str1` using its index (`$str1[$i]`), retrieves the ASCII value of each character with `ord()`, and adds it to a running `$total`. After the loop, the total is displayed.

```php
// Step-by-step for first 3 characters of 'PHP in easy steps'
ord('P') = 80
ord('H') = 72
ord('P') = 80
ord(' ') = 32
// ... continues for every character
```

## 10. Function Reference Summary

| Function | Arguments | Case-Sensitive | Partial? | Returns |
|---|---|---|---|---|
| `strcmp($s1, $s2)` | 2 strings | Yes | No | `0`, `1`, or `-1` |
| `strncmp($s1, $s2, $n)` | 2 strings + int | Yes | Yes (first `n` chars) | `0`, `1`, or `-1` |
| `strcasecmp($s1, $s2)` | 2 strings | No | No | `0`, `1`, or `-1` |
| `strncasecmp($s1, $s2, $n)` | 2 strings + int | No | Yes (first `n` chars) | `0`, `1`, or `-1` |
| `ord($char)` | 1 character | — | — | ASCII integer value |
| `strlen($str)` | 1 string | — | — | Length as integer |

---

## 11. Key Rules Summary

| Rule | Detail |
|---|---|
| `strcmp()` returns `0` | Strings are exactly equal |
| `strcmp()` returns `1` | First string is greater than the second |
| `strcmp()` returns `-1` | First string is less than the second |
| Lowercase > Uppercase | `a` (97) > `A` (65) in ASCII — case matters in `strcmp()` |
| Character order matters | `"ABC"` ≠ `"BAC"` even if their ASCII totals were equal |
| Ignore case | Use `strcasecmp()` or `strncasecmp()` instead of `strcmp()` or `strncmp()` |
| Partial comparison | Use `strncmp()` or `strncasecmp()` and pass the number of characters to compare |
| `ord()` | Returns the ASCII integer value of a single character |
| `strlen()` | Returns the number of characters in a string |
