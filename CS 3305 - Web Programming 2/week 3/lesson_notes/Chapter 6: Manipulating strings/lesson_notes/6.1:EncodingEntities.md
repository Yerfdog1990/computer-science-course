# Encoding Entities

---

## 1. What Is Entity Encoding?

HTML has certain characters that carry **special meaning** in the browser — such as `<`, `>`, `&`, and quotes. If these characters appear in content displayed on a web page, the browser may misinterpret them as HTML code rather than plain text.

PHP provides built-in functions to **encode** these characters into safe **HTML entity equivalents** — replacing the raw characters with special codes that the browser will display as text rather than interpret as markup.

> One important reason to encode HTML snippets with PHP is to **prevent malicious JavaScript code** from being executed unintentionally by the web browser. Encoding HTML tags into entities ensures that the HTML is displayed as text, not executed.

---

## 2. The Two Encoding Functions

### 2.1 `htmlentities()` — Encode All Special Characters

Encodes **all characters** that have an HTML entity equivalent — including non-English language characters, accented letters, special symbols, and the core HTML characters.

```php
htmlentities($string);
```

> Use `htmlentities()` when you need to handle **non-English or international characters** that may need entity encoding.

### 2.2 `htmlspecialchars()` — Encode Only HTML-Significant Characters

Encodes only the **five characters of special HTML significance**. This is the more commonly preferred function unless you specifically need to handle non-English characters.

```php
htmlspecialchars($string);
```

> Unless you are concerned about non-English language characters, it is generally **preferable to use `htmlspecialchars()`** over `htmlentities()`.

---

## 3. Characters Encoded by `htmlspecialchars()`

| Raw Character | Name | Entity Equivalent |
|---|---|---|
| `&` | Ampersand | `&amp;` |
| `"` | Double quote | `&quot;` |
| `'` | Single quote | `&#039;` |
| `<` | Less than | `&lt;` |
| `>` | Greater than | `&gt;` |

---

## 4. Why Entity Encoding Matters

Without encoding, if your PHP script outputs a string containing HTML tags, the **browser interprets and executes** the HTML rather than displaying it as text.

**Example — Without encoding:**

```php
<?php

$html = '<a href="index.php">Click here</a>';
echo $html;  // Browser renders this as a clickable link — not what we wanted!

?>
```

**Example — With encoding:**

```php
<?php

$html = '<a href="index.php">Click here</a>';
echo htmlspecialchars($html);
// Browser displays: <a href="index.php">Click here</a> — as plain text

?>
```

> This is especially critical for **preventing XSS (Cross-Site Scripting)** attacks — where malicious JavaScript injected into content could otherwise be executed by the browser.

---

## 5. Viewing the Translation Table

PHP's `get_html_translation_table()` function returns an **array of all characters** and their entity equivalents used by either `htmlentities()` or `htmlspecialchars()`. Pass the appropriate constant as its argument.

```php
// Get all entities used by htmlentities()
$table = get_html_translation_table(HTML_ENTITIES);

// Get all entities used by htmlspecialchars()
$table = get_html_translation_table(HTML_SPECIALCHARS);
```

You can loop through the returned array to inspect all character-to-entity mappings:

```php
<?php

$table = get_html_translation_table(HTML_SPECIALCHARS);

foreach ($table as $char => $entity)
{
    echo "$char → $entity<br>";
}

?>
```

## 6. Full Example — Encoding Entities (`encode.php`)

### Step 1 — Initialise a variable containing an HTML snippet

```php
<?php

$html = '<a href="index.php">Go to Index</a>';
```

### Step 2 — Display the raw unencoded HTML (browser interprets it)

```php
echo $html;       // Browser follows the link — HTML is executed, not displayed
echo '<hr>';
```

### Step 3 — Encode the HTML with `htmlspecialchars()` and display the result

```php
$html = htmlspecialchars($html);

// Statement inserted here — display the now-encoded string
echo $html;       // Browser displays the raw HTML code as plain text

?>
```

---

## 7. Complete Script

```php
<?php

// Initialize a variable with an HTML code snippet
$html = '<a href="index.php">Go to Index</a>';

// Display encoded version — browser shows code as text, not as a link
echo htmlspecialchars($html);
echo '<br>';

// Demonstrate htmlentities() on a string with special/international characters
$special = 'Caf\u00e9 & "Bistro" > <Restaurant>';
echo htmlentities($special);
echo '<br>';

// View the htmlspecialchars translation table
$table = get_html_translation_table(HTML_SPECIALCHARS);
echo '<hr>HTML Special Characters Translation Table:<br>';
foreach ($table as $char => $entity)
{
    echo htmlspecialchars($char) . ' → ' . $entity . '<br>';
}

?>
```

## 8. Expected Output (in Browser)

```
<a href="index.php">Go to Index</a>
Café &amp; &quot;Bistro&quot; &gt; &lt;Restaurant&gt;

HTML Special Characters Translation Table:
& → &amp;
" → &quot;
< → &lt;
> → &gt;
```

> Without `htmlspecialchars()`, the first line would render as a clickable hyperlink — the browser would interpret the `<a>` tag and potentially redirect to `index.php` immediately on page load.

---

## 9. `htmlspecialchars()` vs `htmlentities()` — When to Use Which

| Situation | Recommended Function |
|---|---|
| General web output — English content only | `htmlspecialchars()` |
| Content with international/accented characters (e.g. `é`, `ü`, `ñ`) | `htmlentities()` |
| Preventing XSS attacks in user input | `htmlspecialchars()` |
| Displaying raw HTML code in a browser | Either function |

---

## 10. Function Reference Summary

| Function | Argument | Returns |
|---|---|---|
| `htmlspecialchars($s)` | String | String with 5 special HTML chars encoded as entities |
| `htmlentities($s)` | String | String with all entity-equivalent chars encoded |
| `get_html_translation_table(HTML_SPECIALCHARS)` | Constant | Array of `htmlspecialchars()` character-to-entity mappings |
| `get_html_translation_table(HTML_ENTITIES)` | Constant | Array of `htmlentities()` character-to-entity mappings |

---

## 11. Key Rules Summary

| Rule | Detail |
|---|---|
| `htmlspecialchars()` is preferred | Use unless you need to handle non-English characters |
| `htmlentities()` is broader | Encodes all characters with entity equivalents, including international characters |
| Five core characters | `&`, `"`, `'`, `<`, `>` — always encoded by `htmlspecialchars()` |
| Security benefit | Encoding prevents malicious JavaScript (XSS) from being executed by the browser |
| Browser behaviour | Without encoding, HTML tags in output are **interpreted** by the browser, not displayed |
| `get_html_translation_table()` | Returns the full mapping array — use `HTML_ENTITIES` or `HTML_SPECIALCHARS` as the argument |
