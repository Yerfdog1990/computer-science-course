# Formatting Strings

---

## 1. What Is String Formatting?

PHP provides several built-in functions to **manipulate and format strings** by modifying their characters, structure, or length. These functions allow you to reverse, repeat, pad, trim, and split strings without manually writing complex logic.

---

## 2. String Formatting Functions

### 2.1 `strrev()` — Reverse a String

Accepts a single string argument and returns that string in **reversed character order** — reading back to front.

```php
strrev($string);
```

```php
echo strrev('Hello');  // outputs: olleH
```

---

### 2.2 `str_repeat()` — Repeat a String

Accepts two arguments — a string and an integer — and returns the string **repeated** that many times.

```php
str_repeat($string, $times);
```

```php
echo str_repeat('PHP ', 3);  // outputs: PHP PHP PHP
```

---

### 2.3 `str_pad()` — Pad a String to a Specified Length

Accepts three arguments: the original string, a total target length, and a padding character or pattern. By default, padding is added to the **end** (right) of the string. A fourth optional argument using a special flag can change the padding direction.

```php
str_pad($string, $length, $padChar);                   // pad right (default)
str_pad($string, $length, $padChar, STR_PAD_LEFT);     // pad left
str_pad($string, $length, $padChar, STR_PAD_BOTH);     // pad both sides
```

| Fourth Argument Flag | Effect |
|---|---|
| *(omitted)* | Padding added to the **end** (right) — default |
| `STR_PAD_LEFT` | Padding added to the **start** (left) |
| `STR_PAD_BOTH` | Padding added to **both** sides equally |

```php
echo str_pad('PHP', 10, '*');               // outputs: PHP*******
echo str_pad('PHP', 10, '*', STR_PAD_LEFT); // outputs: *******PHP
```

---

### 2.4 `trim()` — Remove Characters from Both Ends

Accepts a string argument and returns it with all **whitespace** (spaces, line returns, tabs) removed from both the start and end. Optionally, a second argument specifies a character or pattern to remove instead of whitespace.

```php
trim($string);              // remove whitespace from both ends
trim($string, $characters); // remove specified characters from both ends
```

```php
echo trim('  Hello World!  ');    // outputs: Hello World!
echo trim('||Hello||', '|');      // outputs: Hello
```

### Companion Trim Functions

| Function | Removes from |
|---|---|
| `trim($s)` | Both start **and** end |
| `ltrim($s)` | **Start** (left) only |
| `rtrim($s)` | **End** (right) only |

```php
echo ltrim('  Hello  ');  // outputs: 'Hello  '
echo rtrim('  Hello  ');  // outputs: '  Hello'
```

---

### 2.5 `strtok()` — Split a String by a Delimiter Token

Splits a string into parts around a specified **delimiter token**. The first call specifies both the string and the delimiter — it returns the first part of the string up to the delimiter. Subsequent calls need only specify the delimiter and `strtok()` will return the next part, remembering its position in the string.

```php
$first = strtok($string, $delimiter);  // first call — specify both
$next  = strtok($delimiter);           // subsequent calls — delimiter only
```

> You must specify the delimiter on **each** subsequent call to `strtok()` to have it continue forward to the next part of the string.

> The best way to use `strtok()` is in a **loop** — making repeated calls until no further delimiter is found and the function returns `FALSE`.

```php
<?php

$str = 'PHP is easy and fun';
$token = strtok($str, ' ');  // split by space

while ($token)
{
    echo $token . '<br>';
    $token = strtok(' ');    // continue with the same delimiter
}

// outputs:
// PHP
// is
// easy
// and
// fun

?>
```

---

### 2.6 `implode()` and `explode()` — Convert Between Arrays and Strings

PHP also provides functions to convert arrays to strings and strings to arrays:

- `implode($glue, $array)` — joins array elements into a single string using a glue string
- `explode($delimiter, $string)` — splits a string into an array using a delimiter

> These are covered in more detail in the arrays section.

## 3. Full Example — Formatting Strings (`format.php`)

### Step 1 — Initialise a string variable and display it

```php
<?php

$str = '| PHP String Fun |';
echo "Original String: $str";
```

### Step 2 — Reverse, repeat, and trim the string

```php
echo '<hr>Reversed String: ' . strrev($str);
echo '<hr>Repeated String: ' . str_repeat($str, 3);
echo '<hr>Trimmed String: '  . trim($str, '|');
```

### Step 3 — Pad the string to 30 characters with asterisks on the left

```php
$pad = str_pad($str, 30, '*', STR_PAD_LEFT);
echo "<hr>Padded String: $pad";
```

### Step 4 — Split the string by spaces and display each part with an ellipsis

```php
echo '<hr>Split String: ';
$token = strtok($str, ' ');

while ($token)
{
    echo "$token … ";
    $token = strtok(' ');
}

?>
```

---

## 4. Complete Script

```php
<?php

// Initialize the string variable
$str = '| PHP String Fun |';
echo "Original String: $str";

// Reverse the string
echo '<hr>Reversed String: ' . strrev($str);

// Repeat the string 3 times
echo '<hr>Repeated String: ' . str_repeat($str, 3);

// Trim the '|' characters from both ends
echo '<hr>Trimmed String: ' . trim($str, '|');

// Pad the string to 30 characters with '*' added to the left
$pad = str_pad($str, 30, '*', STR_PAD_LEFT);
echo "<hr>Padded String: $pad";

// Split the string around spaces and display each part
echo '<hr>Split String: ';
$token = strtok($str, ' ');

while ($token)
{
    echo "$token … ";
    $token = strtok(' ');
}

?>
```

## 6. Output Explained

### Original String

```
| PHP String Fun |
```
Length = 18 characters.

### `strrev($str)`

Every character is reversed — including the pipe symbols and spaces:

```
| nuF gnirtS PHP |
```

### `str_repeat($str, 3)`

The entire string is concatenated with itself 3 times:

```
| PHP String Fun || PHP String Fun || PHP String Fun |
```

### `trim($str, '|')`

The `|` characters are removed from both ends (along with any surrounding spaces the trim covers):

```
 PHP String Fun 
```

> Note: Spaces adjacent to the `|` remain since only `|` was specified as the character to remove.

### `str_pad($str, 30, '*', STR_PAD_LEFT)`

The original string is 18 characters. The target length is 30, so **12 asterisks** are added to the left:

```
************| PHP String Fun |
```

### `strtok($str, ' ')` in a loop

The string is split wherever a space (`' '`) appears, returning each token one by one:

| Token | Part Returned |
|---|---|
| 1st | `\|` |
| 2nd | `PHP` |
| 3rd | `String` |
| 4th | `Fun` |
| 5th | `\|` |

Each is printed followed by ` … `.

## 7. Function Reference Summary

| Function | Arguments | Returns |
|---|---|---|
| `strrev($s)` | String | Reversed string |
| `str_repeat($s, $n)` | String + integer | String repeated `n` times |
| `str_pad($s, $len, $pad)` | String + length + pad char | Padded string of specified length |
| `str_pad($s, $len, $pad, $flag)` | + direction flag | Padded string (left, right, or both) |
| `trim($s)` | String | String with whitespace removed from both ends |
| `trim($s, $chars)` | String + chars | String with specified chars removed from both ends |
| `ltrim($s)` | String | String with whitespace removed from the start only |
| `rtrim($s)` | String | String with whitespace removed from the end only |
| `strtok($s, $delim)` | String + delimiter | First token (part before first delimiter) |
| `strtok($delim)` | Delimiter only | Next token — remembers position in string |

---

## 8. Key Rules Summary

| Rule | Detail |
|---|---|
| `strrev()` | Reverses all characters including spaces and symbols |
| `str_repeat()` | The integer argument is the **total** number of times — not additional repeats |
| `str_pad()` default | Pads to the **right** (end) unless `STR_PAD_LEFT` or `STR_PAD_BOTH` is specified |
| `str_pad()` length | If the string is already longer than `$length`, no padding is added |
| `trim()` default | Removes whitespace — pass a second argument to remove specific characters instead |
| `ltrim()` / `rtrim()` | One-sided trim — use when you only want to remove from start or end |
| `strtok()` first call | Requires **both** the string and the delimiter |
| `strtok()` subsequent calls | Requires **only** the delimiter — it remembers its position |
| `strtok()` in a loop | Best practice — loop until `strtok()` returns `FALSE` (no more tokens) |
