# Extracting Substrings

---

## 1. What Are Substrings?

A **substring** is a portion of a string — any sequence of characters extracted from within a larger string. PHP provides several built-in functions to extract, count, and replace substrings.

---

## 2. Functions for Working with Substrings

### 2.1 `substr()` — Extract a Substring

Extracts a portion of a string by specifying the string and the **starting index position**. Optionally, a third argument specifies the **length** of the substring to extract.

```php
substr($string, $startIndex);            // extract from index to end
substr($string, $startIndex, $length);   // extract specific length
```

| Argument | Description |
|---|---|
| `$string` | The original string to extract from |
| `$startIndex` | The character index position to begin extraction (starts at `0`) |
| `$length` | *(Optional)* Number of characters to extract |

### 2.2 `substr_replace()` — Replace a Substring

Replaces a portion of a string with a new string, by specifying the original string, the replacement string, the starting index, and the length of the portion to replace.

```php
substr_replace($string, $replacement, $startIndex, $length);
```

| Argument | Description |
|---|---|
| `$string` | The original string |
| `$replacement` | The new string to insert |
| `$startIndex` | The index position to begin replacing |
| `$length` | Number of characters to replace (does not need to match the replacement length) |

> The `$length` argument specifies how many characters are **removed** from the original string — the replacement string can be longer or shorter than this value.

### 2.3 `substr_count()` — Count Occurrences of a Substring

Returns the total number of times a substring appears within a string.

```php
substr_count($string, $substring);
```

## 3. Full Example — Extracting Substrings (`substring.php`)

### Step 1 — Initialise a string variable and count occurrences of a substring

```php
<?php

$str = 'SQL & PHP: Learning SQL and PHP with SQL examples.';
echo "'$str'<br>";
echo "SQL Count: " . substr_count($str, 'SQL');
```

### Step 2 — Extract two substrings using `substr()`

```php
// Extract from index 27 to the end of the string
echo 'Index 27: ' . substr($str, 27);

// Extract 13 characters starting at index 4
echo 'Index 4 Length 13: ' . substr($str, 4, 13);
```

### Step 3 — Initialise a replacement string variable

```php
$sub = 'PHP & MySQL';
```

### Step 4 — Replace a substring and display the modified string

```php
// Replace 3 characters starting at index 0 ('SQL') with 'PHP & MySQL'
$str = substr_replace($str, $sub, 0, 3);
echo "'$str'";

?>
```

## 4. Complete Script

```php
<?php

// Initialize the string variable
$str = 'SQL & PHP: Learning SQL and PHP with SQL examples.';

// Display the string and count occurrences of 'SQL'
echo "'$str'<br>";
echo "SQL Count: " . substr_count($str, 'SQL');   // 3

// Extract from index 27 to the end
echo '<br>Index 27: ' . substr($str, 27);          // 'PHP with SQL examples.'

// Extract 13 characters starting at index 4
echo '<br>Index 4 Length 13: ' . substr($str, 4, 13);  // '& PHP: Learni' (not matching the textbook demo, adjusted below)

// Initialize replacement string
$sub = 'PHP & MySQL';

// Replace the first 3 characters ('SQL') with 'PHP & MySQL'
$str = substr_replace($str, $sub, 0, 3);
echo "<br>'$str'";  // 'PHP & MySQL & PHP: Learning SQL and PHP with SQL examples.'

?>
```

## 5. Textbook Example Breakdown

The original string used in the textbook example is:

```
SQL & PHP: Learning SQL and PHP with SQL examples.
0123456789...
```

### `substr_count($str, 'SQL')`

Counts every occurrence of `'SQL'` in the string:

| Occurrence | Position |
|---|---|
| 1st | Index 0 — `'SQL'` at the very start |
| 2nd | Index 19 — `'SQL'` in `'Learning SQL'` |
| 3rd | Index 37 — `'SQL'` in `'with SQL'` |

**Result:** `3`

### `substr($str, 27)`

Extracts from index 27 to the end of the string.

```
Index: 0         10        20        27
       SQL & PHP: Learning SQL and PHP...
                           ^
                        starts here
```

**Result:** Everything from index 27 onwards.

### `substr($str, 4, 13)`

Extracts **13 characters** starting at index 4.

```
Index: 0    4         17
       SQL  & PHP: Learn...
            ^^^^^^^^^^^^^
            13 characters
```

**Result:** `'& PHP: Learnin'` (13 characters from index 4)

### `substr_replace($str, $sub, 0, 3)`

Replaces **3 characters** starting at index 0 — that is, `'SQL'` at the beginning — with `'PHP & MySQL'`.

```
Before: SQL & PHP: Learning SQL and PHP with SQL examples.
         ^^^
         replaced (3 chars)

After:  PHP & MySQL & PHP: Learning SQL and PHP with SQL examples.
```

> The replacement string `'PHP & MySQL'` (11 characters) is longer than the 3 characters removed — this is perfectly valid. The `$length` argument controls only what is **removed**, not the size of what is **inserted**.

## 7. How `substr_replace()` Length Works

A common point of confusion is that the `$length` argument and the replacement string do **not** need to be the same size.

| Scenario | Behaviour |
|---|---|
| Replacement shorter than `$length` | The difference is simply removed |
| Replacement longer than `$length` | The extra characters are inserted — string grows |
| Replacement same size as `$length` | Direct character-for-character swap |

```php
<?php

$str = 'Hello World!';

// Replace 5 characters (index 6 to 10) with a longer string
echo substr_replace($str, 'PHP Community', 6, 5);
// outputs: Hello PHP Community!

// Replace 5 characters with a shorter string
echo substr_replace($str, 'PHP', 6, 5);
// outputs: Hello PHP!

?>
```

## 8. Function Reference Summary

| Function | Arguments | Returns |
|---|---|---|
| `substr($s, $start)` | String + start index | String from index to end |
| `substr($s, $start, $len)` | String + start index + length | String of specified length from index |
| `substr_replace($s, $rep, $start, $len)` | String + replacement + start + length | Modified string with replacement inserted |
| `substr_count($s, $sub)` | String + substring | Integer — number of occurrences |

---

## 9. Key Rules Summary

| Rule | Detail |
|---|---|
| Index starts at `0` | The first character of a string is always at position `0` |
| `substr()` without length | Extracts from the start index to the **end** of the string |
| `substr()` with length | Extracts exactly that many characters from the start index |
| `substr_replace()` length | Controls how many characters are **removed**, not the replacement size |
| Replacement can be any size | The inserted string can be longer or shorter than the removed portion |
| `substr_count()` | Returns an integer count of non-overlapping occurrences of the substring |
