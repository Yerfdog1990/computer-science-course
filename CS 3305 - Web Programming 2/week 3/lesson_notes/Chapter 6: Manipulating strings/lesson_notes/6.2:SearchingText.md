# Searching Text

---

## 1. What Is Text Searching?

PHP provides several built-in functions to search within a string for a specified **substring** or **single character**. These functions differ in two key ways:

- **Direction** — searching from the start (forward) or from the end (reverse)
- **Return type** — returning an **index position** (integer) or the **remainder of the string** from the match point, or a **Boolean** value

---

## 2. Functions That Return an Index Position

### 2.1 `strpos()` — Forward Search, Returns Index

Searches a string from the **start** and returns the **character index** of the first occurrence of the substring. Returns `FALSE` if no match is found.

```php
strpos($string, $substring);
```

| Outcome | Return Value |
|---|---|
| Match found | Integer — index position of the first character of the match |
| No match | `FALSE` |

### 2.2 `strrpos()` — Reverse Search, Returns Index

Works like `strpos()` but searches from the **end** of the string. Returns the index of the first match found when reading in reverse order.

```php
strrpos($string, $substring);
```

> Index positions always count from the **start** of the string, beginning at `0` — even when `strrpos()` searches in reverse.

---

## 3. Functions That Return the Remainder of the String

### 3.1 `strstr()` — Forward Search, Returns Remainder

Searches from the **start** of the string. When a match is found, returns the **remainder of the string from the match point** onwards (including the matched substring). Returns `NULL` if no match is found.

```php
strstr($string, $substring);
```

### 3.2 `stristr()` — Case-Insensitive Forward Search, Returns Remainder

Works like `strstr()` but performs a **case-insensitive** search. Returns the remainder of the string from the first case-insensitive match.

```php
stristr($string, $substring);
```

> There is **no** `strrstr()` companion — `strstr()` does not have a reverse-search equivalent.

### 3.3 `strchr()` — Forward Search for a Single Character, Returns Remainder

Accepts a **single character** (not a substring) and searches forward. Returns the remainder of the string from the first match.

```php
strchr($string, $character);
```

### 3.4 `strrchr()` — Reverse Search for a Single Character, Returns Remainder

Works like `strchr()` but searches from the **end** of the string. Returns the remainder of the string from the last occurrence of the character.

```php
strrchr($string, $character);
```

---

## 4. Functions That Return a Boolean (PHP 8)

PHP 8 introduced three new functions that simply check whether a match exists and return `TRUE` or `FALSE`. These are cleaner alternatives when you only need to know *if* something exists, not *where*.

> `str_contains()`, `str_starts_with()` and `str_ends_with()` are great new features introduced in **PHP 8**.

### 4.1 `str_contains()` — Check If Substring Exists Anywhere

```php
str_contains($string, $substring);  // returns TRUE or FALSE
```

### 4.2 `str_starts_with()` — Check If String Begins With Substring

```php
str_starts_with($string, $substring);  // returns TRUE or FALSE
```

### 4.3 `str_ends_with()` — Check If String Ends With Substring

```php
str_ends_with($string, $substring);  // returns TRUE or FALSE
```

## 5. Full Example — Searching Text (`search.php`)

### Step 1 — Initialise a string variable and display its length

```php
<?php

$str = 'Most Users usually find PHP useful.';
echo "'$str'<br>String Length: " . strlen($str);
```

### Step 2 — Search for a substring and report its index position

```php
echo "<br>First 'us' found at: " . strpos($str, 'us');
echo "<br>Final 'us' found at: " . strrpos($str, 'us');
```

### Step 3 — Return the remainder of the string from the match point

```php
echo "<hr>Substring from first 'us': " . strstr($str, 'us');
echo "<br>Characters from final 'u': " . strrchr($str, 'u');
```

### Step 4 — Use Boolean search functions to describe the result

```php
$result = str_contains($str, 'PHP') ? 'Found' : 'Absent';
echo "<hr>Contains 'PHP': " . $result;

$result = str_starts_with($str, 'PHP') ? 'True' : 'False';
echo "<br>Starts with 'PHP': " . $result;

?>
```

## 6. Complete Script

```php
<?php

// Initialize string variable
$str = 'Most Users usually find PHP useful.';

// Display string and its length
echo "'$str'<br>String Length: " . strlen($str);

// strpos() — index of first forward match (case-sensitive)
echo "<br>First 'us' found at: " . strpos($str, 'us');   // 14 ('us' in 'usually')

// strrpos() — index of last match found in reverse (case-sensitive)
echo "<br>Final 'us' found at: " . strrpos($str, 'us');  // 28 ('us' in 'useful')

// strstr() — remainder of string from first forward match
echo "<hr>Substring from first 'us': " . strstr($str, 'us');   // 'usually find PHP useful.'

// strrchr() — remainder from last occurrence of a character
echo "<br>Characters from final 'u': " . strrchr($str, 'u');   // 'useful.'

// str_contains() — Boolean check: does 'PHP' appear anywhere?
$result = str_contains($str, 'PHP') ? 'Found' : 'Absent';
echo "<hr>Contains 'PHP': " . $result;  // Found

// str_starts_with() — Boolean check: does string start with 'PHP'?
$result = str_starts_with($str, 'PHP') ? 'True' : 'False';
echo "<br>Starts with 'PHP': " . $result;  // False

?>
```

> Note: The initial `'Us'` at index 5 is **not matched** by the case-sensitive searches — only lowercase `'us'` is matched.

### `strpos($str, 'us')` — index 14

The first lowercase `'us'` appears at index 14, which is the start of `'usually'`.

### `strrpos($str, 'us')` — index 28

Searching in reverse, the last lowercase `'us'` found is at index 28, which is the start of `'useful'`.

### `strstr($str, 'us')` — `'usually find PHP useful.'`

Returns everything from index 14 (`'us'` in `'usually'`) to the end of the string.

### `strrchr($str, 'u')` — `'useful.'`

Searches in reverse for the character `'u'` — the last `'u'` is found at index 28, returning `'useful.'`.

### `str_contains($str, 'PHP')` — `'Found'`

`'PHP'` exists in the string → returns `TRUE` → ternary outputs `'Found'`.

### `str_starts_with($str, 'PHP')` — `'False'`

The string starts with `'Most'`, not `'PHP'` → returns `FALSE` → ternary outputs `'False'`.

## 9. Function Reference Summary

| Function | Direction | Accepts | Returns |
|---|---|---|---|
| `strpos($s, $sub)` | Forward | Substring | Index of first match, or `FALSE` |
| `strrpos($s, $sub)` | Reverse | Substring | Index of last match, or `FALSE` |
| `strstr($s, $sub)` | Forward | Substring | Remainder from first match, or `NULL` |
| `stristr($s, $sub)` | Forward | Substring (case-insensitive) | Remainder from first match, or `NULL` |
| `strchr($s, $char)` | Forward | Single character | Remainder from first match |
| `strrchr($s, $char)` | Reverse | Single character | Remainder from last match |
| `str_contains($s, $sub)` | — | Substring | `TRUE` or `FALSE` |
| `str_starts_with($s, $sub)` | — | Substring | `TRUE` or `FALSE` |
| `str_ends_with($s, $sub)` | — | Substring | `TRUE` or `FALSE` |
| `strlen($s)` | — | String | Integer — length of string |

---

## 10. Key Rules Summary

| Rule | Detail |
|---|---|
| Index starts at `0` | The first character of a string is at position `0` |
| Case-sensitive by default | `strpos()`, `strstr()` etc. treat uppercase and lowercase as different |
| Case-insensitive alternative | Use `stristr()` to ignore case when searching |
| No `strrstr()` | There is no reverse companion to `strstr()` |
| `strpos()` returns `FALSE` | Use strict comparison (`=== FALSE`) to check for no match, since `0` is a valid index |
| `str_contains()` etc. | PHP 8 only — return clean `TRUE`/`FALSE` Booleans |
| `strrchr()` reverses search | Finds the **last** occurrence of a single character |
| `strlen()` for length | Use `strlen()` to find how many characters a string contains |
