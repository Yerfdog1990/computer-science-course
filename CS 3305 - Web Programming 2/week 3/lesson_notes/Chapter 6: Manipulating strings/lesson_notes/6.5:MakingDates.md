# Making Dates

---

## 1. What Is the `date()` Function?

The PHP `date()` function returns a **formatted date string** based on the current date and time. It requires a **format string** as its argument — a combination of letter options that each represent a specific part of the date or time.

```php
date($format);             // returns current date/time in specified format
date($format, $timestamp); // returns date/time for a specific timestamp
```

> You can include **separator characters** such as `/`, `:`, `-`, and spaces directly inside the format string.

---

## 2. Date Format Options

The format string is built from individual letter options. Each letter represents a specific date or time component:

| Option | Description | Example Output |
|---|---|---|
| `Y` | Year as four digits | `2023` |
| `y` | Year as two digits | `14` |
| `n` | Month as one or two digits | `7` |
| `m` | Month as two digits (with leading zero) | `07` |
| `F` | Month full name | `February` |
| `M` | Month name as three letters | `Feb` |
| `j` | Day as one or two digits | `4` |
| `d` | Day as two digits (with leading zero) | `04` |
| `l` | Weekday full name *(lowercase L)* | `Monday` |
| `D` | Weekday as three letters | `Mon` |
| `S` | Ordinal suffix as two letters | `th` |
| `H` | Hour in 24-hour format | `14` |
| `h` | Hour in 12-hour format | `02` |
| `i` | Minutes | `45` |
| `s` | Seconds | `30` |
| `a` | Ante or post meridiem (lowercase) | `am` |

> The weekday full name option `l` is a **lowercase letter L** — not the number 1.

> More date format options are available in the PHP manual at **php.net/manual**.

### Example Format Strings

```php
date('n/j/y');       // e.g. 4/22/16
date('jS F Y');      // e.g. 22nd April 2023
date('l');           // e.g. Monday
date('h:i:s a');     // e.g. 02:45:30 pm
date('l, jS F Y');   // e.g. Monday, 22nd April 2023
date('F jS');        // e.g. July 11th
```

> Some countries prefer `M/D/Y` while others prefer `D/M/Y` — use the format options to produce whichever date order you need.

## 3. Timezones

By default, `date()` uses **UTC (Universal Time Clock)**. You can change this using the timezone functions.

### Set a Timezone

```php
date_default_timezone_set('America/New_York');
```

### Get the Currently Set Timezone

```php
echo date_default_timezone_get();  // outputs: America/New_York
```

> Common timezone strings include `'America/New_York'`, `'Europe/London'`, `'Asia/Bangkok'`, `'Asia/Tokyo'`, `'Australia/Sydney'`.

---

## 4. Creating Custom Timestamps with `strtotime()`

The `strtotime()` function is an **intelligent** function that accepts a date string and converts it into a **Unix timestamp** (an integer representing the number of seconds since January 1, 1970). This timestamp can then be passed as the optional second argument to `date()`.

```php
strtotime($dateString);  // returns a Unix timestamp integer
```

### Acceptable Input Formats

| Input String | Meaning |
|---|---|
| `'July 4, 2023'` | A specific named date |
| `'2023-07-04'` | A specific date in numeric format |
| `'tomorrow'` | The next day from today |
| `'yesterday'` | The previous day |
| `'next Wednesday'` | The coming Wednesday |
| `'+3 months'` | Three months from today |
| `'+1 year'` | One year from today |

### Using `strtotime()` with `date()`

```php
$timestamp = strtotime('July 4, 2023');
echo date('l, jS F Y', $timestamp);  // outputs: Tuesday, 4th July 2023
```

## 5. Full Example — Making Dates (`date.php`)

### Step 1 — Display the current date, day, time, and default timezone

```php
<?php

echo 'Date: '     . date('jS F Y')    . '<br>';
echo 'Day: '      . date('l')         . '<br>';
echo 'Time: '     . date('h:i:s a')   . '<br>';
echo 'Timezone: ' . date_default_timezone_get() . '<hr>';
```

### Step 2 — Change the timezone and display the new local time

```php
date_default_timezone_set('America/New_York');
echo 'Timezone now: ' . date_default_timezone_get();
echo '<br>Time now: '  . date('h:i:s a') . '<hr>';
```

### Step 3 — Create a timestamp for tomorrow and display its day and date

```php
$d = strtotime('tomorrow');
echo 'Tomorrow: ' . date('l, jS F Y', $d) . '<br>';
```

### Step 4 — Create a timestamp for a specific memorable date and display it

```php
$d = strtotime('July 11, 1994');
echo "David's Birthday: " . date('F jS', $d);

?>
```

## 6. Complete Script

```php
<?php

// Display current date, day, time and default timezone (UTC)
echo 'Date: '     . date('jS F Y')             . '<br>';  // e.g. 26th April 2026
echo 'Day: '      . date('l')                  . '<br>';  // e.g. Sunday
echo 'Time: '     . date('h:i:s a')            . '<br>';  // e.g. 10:45:30 am
echo 'Timezone: ' . date_default_timezone_get() . '<hr>'; // UTC

// Change timezone to New York and display updated time
date_default_timezone_set('America/New_York');
echo 'Timezone now: ' . date_default_timezone_get();      // America/New_York
echo '<br>Time now: '  . date('h:i:s a')        . '<hr>'; // time in New York

// Create timestamp for tomorrow and display its formatted date
$d = strtotime('tomorrow');
echo 'Tomorrow: ' . date('l, jS F Y', $d)      . '<br>'; // e.g. Monday, 27th April 2026

// Create timestamp for a specific date and display its month and day
$d = strtotime('July 11, 1994');
echo "David's Birthday: " . date('F jS', $d);             // July 11th

?>
```

## 8. Output Explained

| Statement | Format Used | What It Does |
|---|---|---|
| `date('jS F Y')` | Day + ordinal + full month + 4-digit year | `26th April 2026` |
| `date('l')` | Full weekday name | `Sunday` |
| `date('h:i:s a')` | 12-hour time with minutes, seconds, and am/pm | `10:45:30 am` |
| `date_default_timezone_get()` | — | Returns the active timezone string |
| `date_default_timezone_set(...)` | — | Changes timezone — affects all subsequent `date()` calls |
| `date('h:i:s a')` after timezone change | Same format | Now reflects New York time |
| `date('l, jS F Y', $d)` | Full weekday, day + ordinal, full month, year | `Monday, 27th April 2026` |
| `date('F jS', $d)` | Full month + day + ordinal suffix | `July 11th` |

---

## 9. How `jS` Produces Ordinal Dates

The `j` option returns the day as a number and `S` appends the correct ordinal suffix automatically:

| Day | `j` | `S` | Combined `jS` |
|---|---|---|---|
| 1 | `1` | `st` | `1st` |
| 2 | `2` | `nd` | `2nd` |
| 3 | `3` | `rd` | `3rd` |
| 4–20 | `4`–`20` | `th` | `4th`–`20th` |
| 21 | `21` | `st` | `21st` |
| 22 | `22` | `nd` | `22nd` |

## 10. Function Reference Summary

| Function | Arguments | Returns |
|---|---|---|
| `date($format)` | Format string | Formatted current date/time string |
| `date($format, $timestamp)` | Format string + Unix timestamp | Formatted date/time for given timestamp |
| `date_default_timezone_set($tz)` | Timezone string | Sets the timezone — no return value |
| `date_default_timezone_get()` | *(none)* | Currently set timezone string |
| `strtotime($dateString)` | Date string (text or relative) | Unix timestamp integer, or `FALSE` on failure |

---

## 11. Key Rules Summary

| Rule | Detail |
|---|---|
| Format string required | `date()` always needs a format string as its first argument |
| Separators allowed | Characters like `/`, `:`, `-`, `,`, and spaces can be placed directly in the format string |
| Default timezone | UTC — change with `date_default_timezone_set()` |
| `l` is lowercase L | The weekday full name option — not the number `1` |
| `strtotime()` is intelligent | Accepts natural language like `'tomorrow'`, `'next Wednesday'`, `'+3 months'` |
| `strtotime()` returns a timestamp | Pass it as the second argument to `date()` to format a specific date |
| Timezone affects all calls | Changing timezone with `date_default_timezone_set()` affects every subsequent `date()` call in the script |
| Date order is flexible | Use format options to produce `M/D/Y` or `D/M/Y` as required |
