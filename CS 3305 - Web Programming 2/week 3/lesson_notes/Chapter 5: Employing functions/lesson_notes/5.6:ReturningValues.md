# Returning Values

---

## 1. What Is a Return Value?

A custom PHP function can send a value back to the caller using the `return` keyword. This allows the result of a function's work to be captured and used elsewhere in the script.

- The `return` statement is **optional**
- If omitted, the function returns `NULL` to the caller by default
- A function can only return a **single item** to the caller

---

## 2. The `return` Keyword

### Syntax

```php
function function_name()
{
    statement-to-be-executed;
    statement-to-be-executed;
    return value;
}
```

### Simple Example

```php
<?php

function square(int $number)
{
    return $number * $number;  // returns the result of the expression
}

echo square(3);  // outputs: 9

?>
```

> The `return` statement can include an **expression** to be evaluated — the single result of that expression is what gets returned to the caller.

> Once a `return` statement is reached, the function **stops executing** immediately and control returns to the caller.

---

## 3. Returning Multiple Values via an Array

Functions can only return a **single item**, so returning multiple values directly is not possible. However, you can assign multiple values to an **array** and return that single array to the caller, then unpack the values.

```php
<?php

function get_info() : array
{
    return array('Alice', 25, 'Bangkok');
}

$info = get_info();

echo "Name: $info[0]<br>";   // Alice
echo "Age: $info[1]<br>";    // 25
echo "City: $info[2]<br>";   // Bangkok

?>
```

---

## 4. Return Type Declarations

Just as parameters can have type declarations, a function can also declare the **type of value it will return**. This is specified after the parameter parentheses using a colon (`:`).

### Syntax

```php
function function_name() : int
{
    statement-to-be-executed;
    return value;
}
```

### Valid Return Types

| Type | Description |
|---|---|
| `int` | Integer number |
| `float` | Decimal / floating-point number |
| `string` | Text value |
| `bool` | Boolean (`true` / `false`) |
| `array` | An array value |

> If a function attempts to return a value of a **different type** than declared, PHP throws a **TypeError**.

---

## 5. Full Example — Returning an Array (`return.php`)

### Step 1 — Define a function that must only return an array

```php
<?php

function supply() : array
{
    // Statement to be inserted here.
}
```

### Step 2 — Insert a statement to return an array of four mixed values

```php
function supply() : array
{
    return array(75, 3.142, 'Super PHP', True);
}
```

### Step 3 — Call the function and assign the returned array to a variable

```php
$array = supply();
```

### Step 4 — Loop through and display each element of the returned array

```php
foreach ($array as $data)
{
    echo "Element Value: $data<br>";
}
?>
```

---

## 6. Complete Script

```php
<?php

// Function declared to return only an array
function supply() : array
{
    return array(75, 3.142, 'Super PHP', True);
}

// Call the function and store the returned array
$array = supply();

// Loop through and display each value
foreach ($array as $data)
{
    echo "Element Value: $data<br>";
}

?>
```

---

## 7. Expected Output

```
Element Value: 75
Element Value: 3.142
Element Value: Super PHP
Element Value: 1
```

> In PHP, the Boolean `TRUE` value is represented numerically as **1** when displayed.

## 8. Allowing Union Types

Sometimes a parameter or return value needs to accept **more than one data type**. PHP 8 introduced **union types** — a pipe-separated (`|`) list of acceptable data types.

> Union types is a great new feature introduced in **PHP 8**.

### Union Type for Parameters

```php
function function_name(type|type|type $arg)
{
    // accepts any of the listed types
}
```

### Union Type for Return Values

```php
function function_name(type|type $arg) : type|type
{
    // returns one of the listed types
}
```

### Example

```php
<?php

function format(int|float $number) : int|float
{
    return round($number, 2);
}

echo format(3.14159);  // outputs: 3.14
echo format(5);        // outputs: 5

?>
```

---

## 9. Nullable Union Types

A common requirement is for a function to return either a value of a specific type **or** `null`. This is called a **nullable union**.

### Two Ways to Specify Nullable

```php
// Method 1 — pipe-separated with null
function function_name() : string|null { }

// Method 2 — shorthand notation with ? prefix
function function_name() : ?string { }
```

> The `?type` shorthand can only be used with a **single data type**, not with a full union type.

> `null` can only be used **as part of a union type** — it cannot stand alone as a return type.

### Example

```php
<?php

function find_user(int $id) : ?string
{
    if ($id === 1) {
        return 'Alice';
    }
    return null;  // returns null if user not found
}

echo find_user(1);   // outputs: Alice
echo find_user(99);  // outputs: (nothing — null returned)

?>
```

---

## 10. Union Type Support

Union types support **all PHP data types** except for `void`, but do support the special `null` type.

| Supported | Not Supported |
|---|---|
| `int`, `float`, `string`, `bool`, `array`, `null`, `object`, `callable`, `resource` | `void` |

---

## 11. The `mixed` Pseudo Type

PHP also provides a special `mixed` pseudo type that allows a parameter or return value to be of **any type except `void`**. It is equivalent to the following union type:

```php
string|int|float|bool|null|array|object|callable|resource
```

### Example

```php
<?php

function anything(mixed $value) : mixed
{
    return $value;
}

echo anything(42);         // outputs: 42
echo anything('hello');    // outputs: hello
echo anything(true);       // outputs: 1

?>
```

---

## 12. Key Rules Summary

| Rule | Detail |
|---|---|
| `return` keyword | Sends a single value back to the caller |
| Default return | If `return` is omitted, the function returns `NULL` |
| Single return only | Functions cannot return multiple values directly |
| Return via array | Multiple values can be packed into an array and returned as one item |
| Return type syntax | Declared with `:` after the parentheses — e.g. `: int`, `: array` |
| Return type mismatch | Attempting to return the wrong type throws a **TypeError** |
| Union types | Use `|` to allow multiple types — e.g. `int\|float` (PHP 8+) |
| Nullable types | Use `type\|null` or `?type` shorthand for values that may be null |
| `?type` shorthand | Only works with a single type — not a full union |
| `mixed` pseudo type | Accepts or returns any type except `void` |
