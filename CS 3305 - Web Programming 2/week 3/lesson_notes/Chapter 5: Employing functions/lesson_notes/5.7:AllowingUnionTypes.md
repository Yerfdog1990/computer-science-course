# Allowing Union Types

---

## 1. What Are Union Types?

By default, it is preferable to restrict parameters to **one specific data type**. However, sometimes a parameter or return value needs to accept **more than one data type**. PHP 8 introduced **union types** to handle this.

A union type is a **pipe-separated (`|`) list** of acceptable PHP data types specified in the function definition.

> Union types is a great new feature introduced in **PHP 8**.

> Union types can be used in all places where types can be specified — for **parameters**, **return types**, and for **class properties** in Object Oriented Programming.

---

## 2. Union Types for Parameters

To allow a parameter to accept multiple data types, list the acceptable types separated by `|` before the parameter name.

### Syntax

```php
function function_name(type|type|type $arg)
{
    // $arg can be any of the listed types
}
```

### Example

```php
<?php

function half(int|float $arg) : int|float
{
    return $arg / 2;
}

echo half(100);    // accepts int  → outputs: 50
echo half(3.142);  // accepts float → outputs: 1.571

?>
```

---

## 3. Union Types for Return Values

Multiple acceptable return types can also be specified as a union type using the same `|` pipe syntax after the `:` in the function declaration.

### Syntax

```php
function function_name(type|type $arg) : type|type
{
    return value;  // must be one of the listed return types
}
```

### Example

```php
<?php

function half(int|float $arg) : int|float
{
    return $arg / 2;
}

// passing int 100 → returns float 50 (100/2)
// passing float 3.142 → returns float 1.571

?>
```

---

## 4. What Union Types Support

Union types support **all PHP data types** except for `void`, but **do** support the special `null` type.

| Supported in Union Types | Not Supported |
|---|---|
| `int`, `float`, `string`, `bool`, `array`, `null`, `object`, `callable`, `resource` | `void` |

> The `callable` type is simply a **type hint**. It may be specified for a parameter that accepts a callable function.

---

## 5. Nullable Union Types

A very common requirement is for a function to return either a **specific type or `null`**. This is called a **nullable union**.

### Two Ways to Specify Nullable

```php
// Method 1 — pipe-separated list with null
function function_name() : string|null { }

// Method 2 — shorthand ? prefix
function function_name() : ?string { }
```

### Rules for Nullable

| Rule | Detail |
|---|---|
| `?type` shorthand | Can only be used with a **single data type** — not with a full union type |
| `null` placement | Can only be used **as part of** a union type — not alone as a type |

---

## 6. The `mixed` Pseudo Type

PHP provides a special `mixed` pseudo type that allows a parameter or return value to be of **any type except `void`**. It is equivalent to the following full union type:

```php
string|int|float|bool|null|array|object|callable|resource
```

### Important Rules for `mixed`

- `mixed` **cannot** be used in union with other types — it already represents all acceptable types
- When **no type is specified** for a parameter, PHP assumes the type to be `mixed`
- When **no return type is specified**, PHP assumes the type to be `mixed` or `void`

### Example

```php
<?php

function describe(string $label, mixed $val) : string
{
    return $label . ' ' . $val . ' - ' . gettype($val);
}

echo describe('Value:', 42);       // Value: 42 - integer
echo describe('Value:', 'hello');  // Value: hello - string
echo describe('Value:', true);     // Value: 1 - boolean

?>
```

## 7. Full Example — Union Types in Action (`union.php`)

### Step 1 — Define a function accepting `int` or `float`, returning `int` or `float`

```php
<?php

function half(int|float $arg) : int|float
{
    // Statements to be inserted here.
}
```

### Step 2 — Insert statements to call a helper function and return half the argument value

```php
function half(int|float $arg) : int|float
{
    echo desc('<dt>Argument', $arg);
    return $arg / 2;
}
```

### Step 3 — Define the `desc()` helper function using `mixed` for its second parameter

```php
function desc(string $str, mixed $val) : string
{
    return $str . ' ' . $val . ' - ' . gettype($val);
}
```

> `gettype()` is a built-in PHP function that returns the data type of a variable as a string (e.g. `"integer"`, `"double"`, `"string"`).

### Step 4 — Call the functions passing integer and floating-point values

```php
echo desc('<dd>Return', half(100)) . '<hr>';
echo desc('<dd>Return', half(33)) . '<hr>';
echo desc('<dd>Return', half(3.142));

?>
```

---

## 8. Complete Script

```php
<?php

// Function accepting int or float, returning int or float
function half(int|float $arg) : int|float
{
    echo desc('<dt>Argument', $arg);  // describe the argument
    return $arg / 2;                  // return half the value
}

// Helper function — accepts any mixed type, returns a descriptive string
function desc(string $str, mixed $val) : string
{
    return $str . ' ' . $val . ' - ' . gettype($val);
}

// Call with integer 100
echo desc('<dd>Return', half(100)) . '<hr>';

// Call with integer 33
echo desc('<dd>Return', half(33)) . '<hr>';

// Call with floating-point 3.142
echo desc('<dd>Return', half(3.142));

?>
```

---

## 9. Expected Output

```
Argument 100 - integer
Return 50 - integer

Argument 33 - integer
Return 16.5 - double

Argument 3.142 - double
Return 1.571 - double
```

> In PHP, floating-point numbers are identified by `gettype()` as `"double"` — this is a legacy naming convention.

---

## 10. Output Explained

| Argument Passed | Type | `half()` Returns | Return Type | Notes |
|---|---|---|---|---|
| `100` | `integer` | `50` | `integer` | 100 ÷ 2 = 50 — stays integer |
| `33` | `integer` | `16.5` | `double` | 33 ÷ 2 = 16.5 — becomes float |
| `3.142` | `double` | `1.571` | `double` | float stays float |

---

## 11. Union Type vs `mixed` — When to Use Which

| Situation | Use |
|---|---|
| Parameter accepts two or three specific types | Union type e.g. `int\|float` |
| Return value may be a type or `null` | Nullable union e.g. `string\|null` or `?string` |
| Parameter or return truly accepts any type | `mixed` pseudo type |
| Single optional null type shorthand | `?type` |

---

## 12. Key Rules Summary

| Rule | Detail |
|---|---|
| Union type syntax | Pipe-separated list: `type\|type` before parameter or after `:` for return |
| PHP 8 feature | Union types were introduced in PHP 8 |
| `void` excluded | Union types support all types **except** `void` |
| `null` in union | Supported — allows nullable functions/parameters |
| `?type` shorthand | Only for a single type — cannot be used with a full union |
| `mixed` pseudo type | Accepts any type except `void` — cannot be combined with other types in a union |
| No explicit type | PHP assumes `mixed` for parameters and `mixed\|void` for return values |
| `callable` type | A type hint — used for parameters that accept callable functions |
| `gettype()` | Built-in function that returns the data type of a value as a string |
| Union in OOP | Union types also apply to class properties in Object Oriented Programming |
