# Calling Back (Anonymous Functions)

---

## 1. What Are Anonymous Functions?

PHP allows you to create **anonymous functions** — functions that have **no name** specified in their definition. Like regular functions, they can:

- Accept arguments if parameters are specified
- Optionally return a value when called

Unlike regular function definitions, which are **code constructs**, an anonymous function definition is an **expression**. This means each anonymous function definition must be **terminated by a semicolon (`;`)**.

### Syntax

```php
function()
{
    statement-to-be-executed;
    statement-to-be-executed;
    return value;
};
```

> **Important:** Do not forget to add a terminating `;` semicolon after each anonymous function definition.

---

## 2. Three Uses of Anonymous Functions

On its own, an anonymous function is of little use — without a name, it cannot be called. However, it becomes powerful in three scenarios:

| Use | How | Description |
|---|---|---|
| **Assigned to a variable** | `$var = function() { };` | The variable name acts as the function name — call it using the variable |
| **Passed as a callback** | `func(callable $anon)` | Passed to another function as an argument and called inside it |
| **Returned from a function** | `return function() use(&$var) { };` | Retains access to the returning function's variables — known as **closure** |

---

## 3. Use 1 — Assigning an Anonymous Function to a Variable

By assigning an anonymous function to a variable, you effectively give it a name and can call it just like any other function — using the variable name followed by parentheses.

```php
<?php

$hello = function($user) { echo "Hello $user!<br>"; };

$hello('Mike');  // outputs: Hello Mike!

?>
```

- The anonymous function is stored in `$hello`
- It is called using `$hello('Mike')` — passing `'Mike'` as the argument

---

## 4. Use 2 — Passing an Anonymous Function as a Callback

An anonymous function can be **passed as an argument** to another function. The receiving function declares its parameter as `callable`, then calls it internally using the parameter name — this is known as a **callback**.

```php
<?php

// Regular function that accepts a callable argument
function greet(callable $anon)
{
    $anon('Carole Anne');  // calls the anonymous function passed in
}

// Pass the anonymous function stored in $hello as the argument
greet($hello);  // outputs: Hello Carole Anne!

?>
```

- `callable` is the type hint used when a parameter is expected to be a function
- The anonymous function stored in `$hello` is passed to `greet()` and called inside it

---

## 5. Use 3 — Returning an Anonymous Function (Closure)

A function can **return** an anonymous function. When this happens, the returned anonymous function can retain access to the returning function's local variables using the `use` keyword — this is called a **closure**.

### The `use` Keyword

The `use` keyword allows an anonymous function to **reference variables from its parent scope** (the function that contains or returns it).

```php
return function($name) use(&$time)
{
    return "Good $time, $name!";
};
```

- `use(&$time)` passes the local variable `$time` into the anonymous function **by reference** using `&`
- This gives the anonymous function access to `$time` from the parent scope even after the parent function has finished

> Always use the `&` ampersand prefix with `use` to create a **reference** to the variable value.

---

## 6. Full Example — All Three Uses (`callback.php`)

### Step 1 — Assign an anonymous function to a variable

```php
<?php

$hello = function($user) { echo "Hello $user!<br>"; };
```

### Step 2 — Call the anonymous function using the variable name

```php
$hello('Mike');  // outputs: Hello Mike!
```

### Step 3 — Define a regular function that accepts a callable and calls it

```php
function greet(callable $anon)
{
    $anon('Carole Anne');
}
```

### Step 4 — Call `greet()`, passing the anonymous function stored in `$hello`

```php
greet($hello);  // outputs: Hello Carole Anne!
```

### Step 5 — Define a function that returns an anonymous function using closure

```php
function meet() : callable
{
    $time = 'morning';
    return function($name) use(&$time)
    {
        return "Good $time, $name!";
    };
}
```

### Step 6 — Assign the returned anonymous function to a variable and call it

```php
$meeting = meet();
echo $meeting('Susan');  // outputs: Good morning, Susan!

?>
```

## 7. Complete Script

```php
<?php

// Use 1 — Assign anonymous function to a variable
$hello = function($user) { echo "Hello $user!<br>"; };

// Call the anonymous function via the variable name
$hello('Mike');  // Hello Mike!

// Use 2 — Pass anonymous function as a callback
function greet(callable $anon)
{
    $anon('Carole Anne');  // calls the passed-in anonymous function
}

greet($hello);  // Hello Carole Anne!

// Use 3 — Return an anonymous function with closure
function meet() : callable
{
    $time = 'morning';
    return function($name) use(&$time)
    {
        return "Good $time, $name!";
    };
}

// Assign the returned anonymous function to a variable
$meeting = meet();

// Call it — accesses $time from the parent scope via closure
echo $meeting('Susan');  // Good morning, Susan!

?>
```

## 8. Expected Output

```
Hello Mike!
Hello Carole Anne!
Good morning, Susan!
```

## 9. Output Explained

| Statement | What Happens | Output |
|---|---|---|
| `$hello('Mike')` | Anonymous function called directly via variable | `Hello Mike!` |
| `greet($hello)` | `$hello` passed as callback; called inside `greet()` with `'Carole Anne'` | `Hello Carole Anne!` |
| `$meeting('Susan')` | Anonymous function returned from `meet()`, accessing `$time = 'morning'` via closure | `Good morning, Susan!` |

> Notice that `$meeting('Susan')` retrieves the value `'morning'` from `meet()`'s local scope — this is **closure** in action.

## 10. How Closure Works — Diagram

```
meet() is called
│
├── $time = 'morning'  ← local variable
│
└── returns anonymous function
        │
        └── use(&$time)  ← closure captures $time by reference
                │
                └── when $meeting('Susan') is called later,
                    $time is still accessible → "Good morning, Susan!"
```

## 11. Key Rules Summary

| Rule | Detail |
|---|---|
| Anonymous function | No name — defined as an expression, not a code construct |
| Terminating semicolon | Every anonymous function definition **must** end with `;` |
| Assigned to variable | Variable name acts as the function name; called using `$var()` |
| Callback | Pass as `callable` argument; called inside receiving function using parameter name |
| Closure | Use `use(&$var)` to give anonymous function access to parent scope variables |
| `use` keyword | Passes parent scope variables into an anonymous function |
| `&` with `use` | Reference the variable — use `&` to ensure changes in parent are reflected |
| `callable` type hint | Declares that a parameter expects a callable (function or anonymous function) |
| Return type `: callable` | Declares that a function will return a callable anonymous function |
