# Recognizing Scope

---

## 1. What Is Variable Scope?

**Scope** refers to the accessibility of a variable — where in a script it can be read or modified. In PHP, a variable's scope depends on where it is created.

| Scope | Where Created | Where Accessible |
|---|---|---|
| **Global** | Outside any function | Anywhere in the script — but **not inside functions** by default |
| **Local** | Inside a function | Only within that specific function block |

> This is different from languages like C, where global variables are automatically available inside functions. In PHP, **global variables must be explicitly declared** inside a function before they can be used there.

---

## 2. Global Scope

Variables created outside any function block have **global scope**. They are accessible throughout the main script but are **not automatically available inside function blocks**.

```php
<?php

$number = 1;
echo "Global number: $number<br>";  // accessible here — outputs: 1

function show()
{
    echo $number;  // ERROR — $number is not accessible inside the function
}

?>
```

---

## 3. Local Scope

Variables created **inside** a function have **local scope** — they only exist within that function. Once the function finishes executing, local variables are destroyed and their values are lost.

```php
<?php

function show_local()
{
    $number = 100;
    echo "Local number: $number<hr>";  // outputs: 100
}

show_local();

// $number here is undefined — the local $number inside show_local() no longer exists

?>
```

> Because local variables are isolated, a local variable can share the same **name** as a global variable or a variable in another function — without conflict. Each holds its own separate value.

---

## 4. Using Global Variables Inside a Function

To use a global variable inside a function, you must explicitly declare it using the `global` keyword **before** referencing it.

### Syntax

```php
global $variable_name;
```

### Example

```php
<?php

$number = 10;

function show_global()
{
    global $number;  // declare that $number refers to the global variable
    echo "Global number inside function: $number<br>";  // outputs: 10
}

show_global();

?>
```

> **Note:** You can also access global variables using PHP's special `$GLOBALS` array:
> ```php
> echo $GLOBALS['number'];  // alternative to using the global keyword
> ```

> Making a local variable global by using the `global` keyword in its declaration is **bad practice** and should be avoided, as it makes code harder to understand and maintain.

---

## 5. Static Variables

By default, local variables are destroyed when a function finishes. A **static variable** is a special local variable that **retains its value** between function calls.

### Syntax

```php
static $variable_name;
```

### How It Works

- Declared with the `static` keyword inside a function
- Initialised only on the **first** call — not reset on subsequent calls
- Its updated value is available on every subsequent call to the same function

### Example

```php
<?php

function counter()
{
    static $count = 0;
    $count++;
    echo "Count: $count<br>";
}

counter();  // Count: 1
counter();  // Count: 2
counter();  // Count: 3

?>
```

> If the `static` keyword were removed, `$count` would reset to `0` on every call and always output `Count: 1`.

---

## 6. Recursive Functions

A function can **call itself** — this is called **recursion**. Like loops, a recursive function must have a condition that eventually stops the recursion, otherwise it will run forever.

Ways to control recursion:

- Pass a **counter as an argument** that increments on each call until it exceeds a limit
- Use a **static local variable** that increments across calls
- Use a **global variable** that increments on each recursive call

---

## 7. Full Example — Scope in Action (`scope.php`)

### Step 1 — Initialise a global variable and display it

```php
<?php

$number = 1;
echo "Global number: $number<br>";  // outputs: 1
```

### Step 2 — Define and call a function with a like-named local variable

```php
function show_local()
{
    $number = 100;  // local — does not affect the global $number
    echo "Local number: $number<hr>";  // outputs: 100
}

show_local();
```

### Step 3 — Define a recursive function using global and static variables

```php
function recur()
{
    global $number;       // access the global $number
    static $letter = 'A'; // static — retains value between calls

    if ($number < 14)
    {
        echo "$number:$letter | ";
        $number++;  // increments the global variable
        $letter++;  // increments the static variable (A → B → C ...)
        recur();    // calls itself recursively
    }
}

recur();
```

### Step 4 — Display the modified global variable after recursion

```php
echo "<hr>Global number: $number";  // outputs: 14

?>
```

## 8. Complete Script

```php
<?php

// Initialize global variable
$number = 1;
echo "Global number: $number<br>";  // Global number: 1

// Local scope — same variable name, different value, no conflict
function show_local()
{
    $number = 100;
    echo "Local number: $number<hr>";  // Local number: 100
}
show_local();

// Recursive function using global and static variables
function recur()
{
    global $number;
    static $letter = 'A';

    if ($number < 14)
    {
        echo "$number:$letter | ";
        $number++;
        $letter++;
        recur();
    }
}
recur();

// Display the global variable after recursion has modified it
echo "<hr>Global number: $number";  // Global number: 14

?>
```

## 9. Expected Output

```
Global number: 1
Local number: 100
──────────────────────────
1:A | 2:B | 3:C | 4:D | 5:E | 6:F | 7:G | 8:H | 9:I | 10:J | 11:K | 12:L | 13:M |
──────────────────────────
Global number: 14
```

---

## 10. Output Explained

### `show_local()` call

| Variable | Scope | Value |
|---|---|---|
| `$number` (global) | Global | `1` — unchanged by the function |
| `$number` (local) | Local to `show_local()` | `100` — exists only inside the function |

### `recur()` recursive calls

| Call | `$number` (global) | `$letter` (static) | Output |
|---|---|---|---|
| 1st | 1 | A | `1:A |` |
| 2nd | 2 | B | `2:B |` |
| 3rd | 3 | C | `3:C |` |
| ... | ... | ... | ... |
| 13th | 13 | M | `13:M |` |
| 14th | 14 | N | condition `$number < 14` fails — stops |

> Without `static`, `$letter` would reset to `'A'` on every call, always outputting `1:A`, `2:A`, etc.

---

## 11. The `$GLOBALS` Array

PHP provides a special superglobal array `$GLOBALS` that allows access to any global variable by its name as a string key — without needing the `global` keyword.

```php
<?php

$number = 42;

function display()
{
    echo $GLOBALS['number'];  // outputs: 42 — no global keyword needed
}

display();

?>
```

---

## 12. Key Rules Summary

| Rule | Detail |
|---|---|
| Global scope | Variables outside functions — accessible in the main script but **not inside functions** by default |
| Local scope | Variables inside functions — only accessible within that function; destroyed after the function ends |
| Same name, no conflict | A local and global variable can share the same name and hold different values |
| `global` keyword | Must be declared inside a function to access a global variable |
| `$GLOBALS` array | Alternative to `global` keyword — access global vars via `$GLOBALS['name']` |
| `static` keyword | Keeps a local variable's value between calls instead of resetting it |
| Making local vars global | Possible with `global` but considered **bad practice** |
| Recursive functions | Functions that call themselves — must have a stopping condition to avoid infinite loops |
