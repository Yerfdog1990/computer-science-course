# Defining Functions 

---

## 1. What Are PHP Functions?

PHP provides two categories of functions:

- **Built-in functions** — provided by PHP out of the box (e.g. `sort()`, `strlen()`). Ready to call by name.
- **Custom functions** — written by you to modularize your script into reusable, maintainable sections.

Functions make scripts easier to understand, maintain, and reuse — a core principle of modular programming.

---

## 2. Naming Rules for Custom Functions

- May contain **letters, numbers, and underscores**
- Must **begin with a letter or an underscore** (not a digit)
- Must **not duplicate** an existing built-in function name (e.g. you cannot create a function called `sort()`)

| Allowed | Not Allowed |
|---|---|
| `greet()` | `2go()` — starts with a digit |
| `get_user2()` | `sort()` — duplicates a built-in |
| `_helper()` | `my function()` — contains a space |

> **Important:** Function names are **case-insensitive** — `cube()`, `Cube()`, and `CUBE()` all refer to the same function. However, it is best practice to always use the same case as in the function definition.

> **Remember:** PHP **variable names ARE case-sensitive**, but **function names are NOT**.

---

## 3. Defining a Basic Function

### Syntax

```php
function function_name()
{
    // statements to execute
    statement_1;
    statement_2;
}
```

### Working Example

```php
<?php

function greet()
{
    echo 'Hello User!<br>';
}

greet();  // calls the function → outputs: Hello User!

?>
```

> A function call can appear **before** its definition in the file, but best practice is to **define functions before calling them**.

> Functions may contain any valid PHP code, including further function definitions.

---

## 4. Nested (Inner) Functions

A function definition can contain another function definition inside it. The **inner function does not exist until the outer function has been called**.

```php
<?php

function outer()
{
    function inner()
    {
        echo 'Inner function called.<br>';
    }
    echo 'Inner function created.<br>';
}

outer();  // creates inner() and echoes "Inner function created."
inner();  // now callable → echoes "Inner function called."

?>
```

> **Warning:** If you call `inner()` before calling `outer()`, PHP throws an **undefined function error** — because `inner()` doesn't exist yet.

---

## 5. Passing Arguments to Functions

Data is passed into functions as **arguments** (from the caller) matching **parameters** (in the definition). Arguments must be passed in the **correct order**, and all parameters must receive a value.

### Syntax

```php
function function_name($arg_1, $arg_2, $arg_3)
{
    // use $arg_1, $arg_2, $arg_3 here
}
```

### Example — Adding Two Numbers

```php
<?php

function add($a, $b)
{
    echo $a + $b;
}

add(5, 3);    // outputs: 8
add(10, 20);  // outputs: 30

?>
```

> Parameter names follow the same naming rules as PHP variables and should be **meaningful** to represent the data being passed.

---

## 6. Type Declarations (Typed Parameters)

Optionally, you can enforce the **data type** of each parameter. If the caller passes the wrong type, PHP throws a **TypeError**.

### Valid Type Keywords

| Type | Description |
|---|---|
| `int` | Integer numbers |
| `float` | Decimal / floating-point numbers |
| `string` | Text values |
| `bool` | Boolean (`true` / `false`) |
| `callable` | A callable function or method |
| `array` | An array value |

### Example — Typed Parameters (PHP 8)

```php
<?php

function multiply(int $x, int $y)
{
    echo $x * $y;
}

multiply(4, 5);      // outputs: 20
multiply(4, 'hi');   // TypeError: must be int, string given

?>
```

> Using type declarations is recommended — they catch bugs early and make your code self-documenting.

---

## 7. Complete Example — All Concepts Combined

```php
<?php

// Basic function
function greet()
{
    echo 'Hello User!<br>';
}

// Function with typed parameters
function cube(int $n)
{
    echo $n ** 3 . '<br>';
}

// Nested functions
function outer()
{
    function inner()
    {
        echo 'Inner function called.<br>';
    }
    echo 'Inner function created.<br>';
}

// Calling the functions
greet();   // Hello User!
cube(3);   // 27
outer();   // Inner function created.
inner();   // Inner function called.

?>
```

---

## 8. Key Rules Summary

| Rule | Detail |
|---|---|
| Function names | Case-insensitive. Must start with a letter or underscore. |
| Variable names | Case-sensitive. `$Name` ≠ `$name`. |
| Arguments order | Must match the parameter list exactly. Missing args cause errors. |
| Inner functions | Only exist after the outer function is first called. |
| No built-in duplicates | Cannot reuse names like `sort()`, `strlen()`, etc. |
| Type declarations | Optional but recommended. Enforced at call time in PHP 8. |
