# Varying Parameters

---

## 1. What Are Varying Parameters?

PHP allows function definitions to be flexible in how many arguments they accept. There are two main techniques for this:

- **Default argument values** — allow some arguments to be optional when calling the function
- **The splat operator (`...`)** — allows a function to accept an unknown number of arguments

---

## 2. Default Argument Values

Default values can be assigned directly to parameters in the function definition using `=`. This makes those parameters **optional** in the function call.

### Syntax

```php
function function_name($arg_1, $arg_2 = "Default String")
{
    statement-to-be-executed;
    statement-to-be-executed;
}
```

### How It Works

- If the caller provides a value for that argument, the **provided value** is used
- If the caller omits that argument, the **default value** is used automatically

### Important Rule — Order of Default Parameters

> Default values must appear **to the right** of parameters that have no default value. A parameter with a default value must **never** appear before a parameter without one — otherwise a call with too few arguments causes an error.

```php
// CORRECT — default parameters come last
function greet(string $name, string $title = 'Mr')
{
    echo "Hello, $title $name!";
}

// INCORRECT — default parameter before a required one
function greet(string $title = 'Mr', string $name)  // causes an error
{
    echo "Hello, $title $name!";
}
```

> There is currently **no way to skip a parameter** in a function call when multiple defaults are specified. You cannot selectively assign a value to the second default while skipping the first.

---

## 3. The Splat Operator (`...`)

When you need a function to accept an **unknown number of arguments**, PHP provides the `...` **splat operator** (also known as the **scatter operator**).

### Usage 1 — In a Function Definition (Collect arguments into an array)

Prefixing `...` before a parameter name in the function definition causes all passed arguments to be collected into an **array** inside the function. That array can then be traversed like any normal array.

```php
function function_name(...$args)
{
    // $args is an array of all passed arguments
    statement-to-be-executed;
}
```

### Usage 2 — In a Function Call (Unpack an array into individual arguments)

The `...` splat operator can also be used in the **function call** to **unpack** an array, passing its elements as individual arguments to the function.

```php
function function_name($arg_1, $arg_2, $arg_3)
{
    echo $arg_1 + $arg_2 + $arg_3;
}

$arr = [1, 2, 3];
function_name(...$arr);  // outputs: 6
```

> You can specify regular positional parameters **before** a splat parameter. Only arguments that outnumber the positional parameters will be collected into the splat array.

---

## 4. Full Example — Default Values & Splat Operator (`parameters.php`)

### Step 1 — Define a function with default string values for both parameters

```php
<?php

function drink(string $tmp = 'hot', string $flavor = 'tea')
{
    // Statement to be inserted here.
}
```

### Step 2 — Insert a statement to display the default or passed-in values

```php
function drink(string $tmp = 'hot', string $flavor = 'tea')
{
    echo "Drinking $tmp $flavor.<br>";
}
```

### Step 3 — Call the function with different numbers of arguments

```php
drink();                    // uses both defaults
drink('iced');              // overrides $tmp only, $flavor uses default
drink('cold', 'lemonade');  // overrides both parameters
```

### Step 4 — Define a function using the splat operator to add multiple integers

```php
function add(int ...$numbers)
{
    $total = 0;
    foreach ($numbers as $num) { $total += $num; }
    echo "<hr>Total: $total";
}
```

### Step 5 — Call the add function with three values

```php
add(1, 2, 3);
?>
```

## 5. Complete Script

```php
<?php

// Function with default parameter values
function drink(string $tmp = 'hot', string $flavor = 'tea')
{
    echo "Drinking $tmp $flavor.<br>";
}

// Function calls — using defaults, one override, full override
drink();                    // Drinking hot tea.
drink('iced');              // Drinking iced tea.
drink('cold', 'lemonade'); // Drinking cold lemonade.

// Function using splat operator to accept multiple integer arguments
function add(int ...$numbers)
{
    $total = 0;
    foreach ($numbers as $num) { $total += $num; }
    echo "<hr>Total: $total";
}

// Call add() with three integer arguments
add(1, 2, 3);  // Total: 6

?>
```

## 8. Splat Operator — Two Roles at a Glance

| Where Used | Role | Example |
|---|---|---|
| **Function definition** | Collects multiple arguments into an array | `function add(int ...$numbers)` |
| **Function call** | Unpacks an array into individual arguments | `function_name(...$arr)` |

---

## 9. Key Rules Summary

| Rule | Detail |
|---|---|
| Default values | Assigned with `=` in the parameter list |
| Default parameter order | Default parameters must always come **after** required parameters (rightmost) |
| Skipping defaults | There is **no way** to skip a default parameter to target a later one |
| Splat in definition | `...$args` collects all extra arguments into an array |
| Splat in call | `...$arr` unpacks an array into individual arguments |
| Splat with positional params | Regular parameters can appear before `...`; only extra arguments go into the splat array |
| Type with splat | You can type-declare a splat parameter e.g. `int ...$numbers` |
