# Naming Parameters

---

## 1. Positional Parameters vs Named Parameters

PHP supports two ways of passing arguments to a function:

| Type | Description |
|---|---|
| **Positional parameters** | Arguments must be passed in the **exact same order** as listed in the function definition |
| **Named parameters** | Arguments can be passed in **any order** by specifying the parameter name in the call |

> Named parameters is a great new feature introduced in **PHP 8**.

---

## 2. Positional Parameters (Default Behaviour)

When a function is defined with parameters, the caller must pass arguments in the same order as those parameters appear in the definition. This is the traditional and most common approach.

```php
function function_name($arg_1, $arg_2)
{
    echo $arg_1 . $arg_2;
}

function_name('Hot', 'Tea');  // outputs: Hot Tea
```

The first argument is assigned to `$arg_1` and the second to `$arg_2` — strictly by position.

---

## 3. Named Parameters

Named parameters allow a caller to pass argument values in **any order** by explicitly naming the parameter each value belongs to.

### Syntax

```php
function_name(param_name: value, param_name: value);
```

- The parameter name in the call is the same as in the function definition **but without the `$` prefix**
- Each parameter name and its value are separated by a **colon (`:`)**

### Example

```php
function function_name($arg_1, $arg_2)
{
    echo $arg_1 . $arg_2;
}

function_name(arg_1: 'Hot', arg_2: 'Tea');  // outputs: Hot Tea
function_name(arg_2: 'Tea', arg_1: 'Hot');  // outputs: Hot Tea — same result, different order
```

> Both calls produce identical output because named parameters are matched by name, not by position.

---

## 4. Named Parameters with Default Values

When a function has **default values** for its parameters, named parameters become especially powerful. They allow a caller to pass a value to a **specific parameter** while letting other parameters use their defaults — something positional parameters cannot do.

### The Problem with Positional Parameters and Defaults

With positional parameters, you **cannot skip** the first parameter to only supply the second. You must always pass them in order.

```php
function drink(string $tmp = 'hot', string $flavor = 'tea')
{
    echo "Drinking $tmp $flavor.<br>";
}

// With positional parameters — cannot skip $tmp to only pass $flavor
drink('tea');  // assigns 'tea' to $tmp, not $flavor — not what we wanted!
```

### The Solution — Named Parameters

With named parameters, you can target **any specific parameter** by name, regardless of position.

```php
// Pass value to $flavor only — $tmp uses its default 'hot'
drink(flavor: 'lemonade');  // outputs: Drinking hot lemonade.

// Pass value to $tmp only — $flavor uses its default 'tea'
drink(tmp: 'iced');         // outputs: Drinking iced tea.
```

---

## 5. Mixing Positional and Named Parameters

You can use **both** positional and named parameters in a single function call, but with one strict rule:

> All **positional parameters must appear before** named parameters in the call. Using a positional parameter after a named parameter causes an error because the PHP parser cannot correctly assign the argument value.

```php
// CORRECT — positional first, named second
function_name('baked', food: 'potato');

// INCORRECT — named before positional causes an error
function_name(food: 'potato', 'baked');  // Error!
```

---

## 6. Collecting Named Parameters with the Splat Operator

The `...` splat operator can be used in a function definition to **collect named parameter names and their values**. When named parameters are passed, their names are preserved as the **keys** of the resulting array — allowing you to iterate over both the name and value.

```php
function register(...$args)
{
    foreach ($args as $name => $value)
    {
        echo "<dt>" . $name . "<dd>" . $value;
    }
}

register(Topic: 'PHP', Series: 'Programming');
// outputs:
// Topic
// PHP
// Series
// Programming
```

> Named parameters require all **non-optional parameters** (those without a default value) to be passed an argument value, just as positional parameters do.

## 7. Full Example — Named Parameters (`named.php`)

### Step 1 — Define a function with two default string parameters

```php
<?php

function cook(string $prep = 'fried', string $food = 'rice')
{
    echo "<li>Serving $prep $food";
}
```

### Step 2 — Call with positional parameters and with named parameters

```php
cook('boiled', 'egg');                  // positional — Serving boiled egg
cook(food: 'cheese', prep: 'grilled'); // named, reversed order — Serving grilled cheese
```

### Step 3 — Pass a value to the second parameter only, and mix positional with named

```php
cook(food: 'rice');              // named — $prep uses default 'fried' → Serving fried rice
cook('baked', food: 'potato');  // positional + named → Serving baked potato
```

### Step 4 — Define a function to collect named parameters and display names and values

```php
function register(...$args)
{
    foreach ($args as $name => $value)
    {
        echo "<dt>" . $name . "<dd>" . $value;
    }
}

register(Topic: 'PHP', Series: 'Programming');
```

## 8. Complete Script

```php
<?php

// Function with default parameter values
function cook(string $prep = 'fried', string $food = 'rice')
{
    echo "<li>Serving $prep $food";
}

// Positional parameter call
cook('boiled', 'egg');                   // Serving boiled egg

// Named parameters — any order
cook(food: 'cheese', prep: 'grilled');  // Serving grilled cheese

// Named parameter — second parameter only, first uses default
cook(food: 'rice');                      // Serving fried rice

// Mix — one positional, one named
cook('baked', food: 'potato');           // Serving baked potato

// Collect named parameters using splat operator
function register(...$args)
{
    foreach ($args as $name => $value)
    {
        echo "<dt>" . $name . "<dd>" . $value;
    }
}

register(Topic: 'PHP', Series: 'Programming');

?>
```

## 11. Key Rules Summary

| Rule | Detail |
|---|---|
| Named parameter syntax | Use `param_name: value` — no `$`, separated by `:` |
| Any order | Named parameters can be passed in any order |
| Skipping defaults | Named parameters can target a specific parameter, letting others use their defaults |
| Positional before named | In a mixed call, all positional arguments must come before any named arguments |
| Splat with named params | `...$args` collects named parameters as a key-value array, preserving the names |
| Non-optional parameters | Named parameters still require all required (non-default) parameters to be passed |
| PHP 8 only | Named parameters were introduced in PHP 8 |
