# Passing Arguments

---

## 1. What Are Arguments?

Data can be passed to functions as **arguments**, in the same way built-in PHP functions accept them. For example, the built-in `sort()` function takes the array to be sorted as its argument.

- Functions can accept **any number of arguments**
- When a function is called, data **must be supplied for every parameter** — omitting one causes an error
- Arguments must be passed in the **correct order** matching the parameter list
- Both parameters (in the definition) and arguments (in the call) use **comma-separated lists**

---

## 2. Defining a Function with Parameters

### Syntax

```php
function function_name($arg_1, $arg_2, $arg_3)
{
    statement-to-be-executed;
    statement-to-be-executed;
    statement-to-be-executed;
}
```

### Parameter Naming Rules

Parameter names must follow the same naming conventions as PHP variables:

- Must begin with a `$` sign
- May contain letters, numbers, and underscores
- Should be **meaningful** to represent the nature of the data being passed

---

## 3. Type Declarations (Typed Parameters)

Optionally, you can enforce the **data type** of each parameter by placing a type keyword before the parameter name. If the caller passes the wrong type, PHP throws a **TypeError**.

### Valid Type Keywords

| Type | Description |
|---|---|
| `int` | Integer numbers |
| `float` | Decimal / floating-point numbers |
| `string` | Text values |
| `bool` | Boolean (`true` / `false`) |
| `callable` | A callable function or method |
| `array` | An array value |

### Syntax with Type Declarations

```php
function function_name(int $arg_1, string $arg_2, bool $arg_3)
{
    // only accepts the specified types
}
```

> Using type declarations is recommended — they catch bugs early and make your code self-documenting.

---

## 4. Pass by Value (Default)

By default, arguments are passed **by value** — meaning only a **copy** of the variable's data is sent to the function. The original variable is **not affected** by anything the function does internally.

```php
<?php

function doubleIt(int $val)
{
    $val = $val * 2;
    echo "Inside function: $val<br>";  // outputs: 10
}

$a = 5;
doubleIt($a);
echo "Outside function: $a<br>";  // outputs: 5 — original unchanged

?>
```

> Modifying the argument inside the function **does not** affect the original variable when passed by value.

---

## 5. Pass by Reference

If you want a function to **directly modify** the original variable, you must pass it **by reference**. To do this, prefix an `&` (ampersand) before the parameter name in the **function definition**.

```php
function function_name(int &$ref)
{
    // changes to $ref directly affect the original variable
}
```

> The `&` goes in the **function definition only** — not in the function call.

> Modifying the argument inside the function **will** affect the original variable when passed by reference.

---

## 6. Full Example — By Value vs By Reference (`arguments.php`)

### Step 1 — Initialize two variables with the same value

```php
<?php
$a = $b = 5;
```

### Step 2 — Define a function with one by-value and one by-reference parameter

```php
function modify(int $val, int &$ref)
{
    // Statements to be inserted here.
}
```

### Step 3 — Insert statements to display, increment, and redisplay the values

```php
function modify(int $val, int &$ref)
{
    echo "Passed values: $val, $ref<br>";  // show values on entry

    $val++;  // increments the local copy only
    $ref++;  // increments the original variable directly

    echo "Incremented values: $val, $ref<hr>";  // show incremented values
}
```

### Step 4 — Call the function passing both variables

```php
modify($a, $b);
```

### Step 5 — Display what is now stored in each original variable

```php
echo "Stored values: $a, $b";
?>
```

### Complete Script

```php
<?php

// Initialize two variables with the same integer value
$a = $b = 5;

// $val is passed by value, $ref is passed by reference
function modify(int $val, int &$ref)
{
    echo "Passed values: $val, $ref<br>";

    $val++;  // only modifies the local copy
    $ref++;  // modifies the original $b directly

    echo "Incremented values: $val, $ref<hr>";
}

// Call the function
modify($a, $b);

// Display the stored values after the function call
echo "Stored values: $a, $b";

?>
```

---

## 7. Expected Output

```
Passed values: 5, 5
Incremented values: 6, 6
──────────────────────────
Stored values: 5, 6
```

---

## 8. Output Explained

| Variable | Passed as | What happens inside | Value after function |
|---|---|---|---|
| `$a` | By value (`$val`) | Local copy incremented to `6` | Unchanged → **5** |
| `$b` | By reference (`&$ref`) | Original incremented directly to `6` | Modified → **6** |

---

## 9. Key Rules Summary

| Rule | Detail |
|---|---|
| All parameters required | Data must be supplied for every parameter when calling a function |
| Correct order | Arguments must match the parameter list order exactly |
| Meaningful names | Parameters should describe the data they represent |
| Type declarations | Optional but recommended; enforced at call time in PHP 8 |
| Pass by value | Default behaviour; only a copy is passed; original variable is unchanged |
| Pass by reference | Use `&` before the parameter name; function modifies the original variable directly |
