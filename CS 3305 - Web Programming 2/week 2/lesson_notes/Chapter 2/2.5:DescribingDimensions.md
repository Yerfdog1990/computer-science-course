# Describing Dimensions (Multi-Dimensional Arrays)

---

## What is an Array Index?

The numbering of array elements is more correctly known as the **array index**. Because element numbering starts at zero, it is sometimes referred to as a **zero-based index**.

---

## One-Dimensional Arrays

An array created with a **single index** is a **one-dimensional array**. Elements appear in a single row:

| Element content | A | B | C | D | E |
|---|---|---|---|---|---|
| Index numbers | [0] | [1] | [2] | [3] | [4] |

```php
$letters = array( 'A' , 'B' , 'C' , 'D' , 'E' ) ;

echo $letters[0] ;    // outputs: A
echo $letters[3] ;    // outputs: D
```

---

## Two-Dimensional Arrays

An array created with **two indices** is a **two-dimensional array**. Elements appear in multiple rows:

| | [0] | [1] | [2] | [3] | [4] |
|---|---|---|---|---|---|
| First index [0] | A | B | C | D | E |
| First index [1] | F | G | H | I | J |

With a two-dimensional array, the value in each element is referenced by stating **both index numbers**. For example, the element at `[1][2]` contains the letter **H**.

### Real-world uses
- **Two-dimensional arrays** — useful for storing grid-based information such as XY coordinates
- **Three-dimensional arrays** — allow XYZ coordinates to be stored (three indices)

> Multi-dimensional arrays with more than two indices can produce hard to read source code and may lead to errors.

---

## Creating a Multi-Dimensional Array in PHP

A multi-dimensional array is created by making an **outer array whose elements are themselves arrays**. Key names can optionally be specified for each inner array.

```php
$letters = array( 'A' , 'B' , 'C' ) ;
$numbers = array( 1 , 2 , 3 ) ;

$matrix = array( 'Letter' => $letters , 'Number' => $numbers ) ;
```

This creates a two-dimensional array where:
- `$matrix['Letter']` holds the `$letters` array
- `$matrix['Number']` holds the `$numbers` array

---

## Referencing Values in a Multi-Dimensional Array

Individual values are referenced using the **key name and inner index number**:

```php
$matrix['Letter'][0]    // references 'A'
$matrix['Number'][2]    // references 3
```

### Displaying values inside a string

When using quoted keys inside a string, the array variable **must be enclosed in curly braces** `{}`:

```php
echo "Element value is {$matrix['Letter'][0]} " ;    // outputs: A
```

> **Important:** Array variables that use quoted keys must **always** be enclosed within curly braces when included in a string.

---

## Traversing a Multi-Dimensional Array

All inner arrays can be accessed using a `foreach` loop to iterate through the outer array. A **nested `foreach` loop** then references each element in the inner array:

```php
foreach( $matrix as $array => $list )
{
    echo '<ul>' ;
    foreach( $list as $key => $value )
    { echo "<li>$array [ $key ] = $value " ; }
    echo '</ul>' ;
}
```

---

## Full Example — matrix.php

```php
<?php

# Create two regular arrays
$letters = array( 'A' , 'B' , 'C' ) ;
$numbers = array( 1 , 2 , 3 ) ;

# Create a two-dimensional array with key names
$matrix = array( 'Letter' => $letters , 'Number' => $numbers ) ;

# Display a single stored value (curly braces required for quoted keys in strings)
echo "<p>Start : {$matrix['Letter'][0]} </p>" ;

# Display all keys and values as two unordered lists using nested foreach
foreach( $matrix as $array => $list )
{
    echo '<ul>' ;
    foreach( $list as $key => $value )
    { echo "<li>$array [ $key ] = $value " ; }
    echo '</ul>' ;
}

?>
```

---

## Key Rules to Remember

- Array element numbering starts at **zero** — this is called a **zero-based index**
- A **one-dimensional array** has a single index — elements appear in a single row
- A **two-dimensional array** has two indices — elements appear in multiple rows
- A multi-dimensional array is an **outer array whose elements are inner arrays**
- Reference individual values using both the key name and inner index — e.g. `$matrix['Letter'][0]`
- Array variables with **quoted keys must be wrapped in curly braces** `{}` when used inside a string
- Use **nested `foreach` loops** to traverse all elements of a multi-dimensional array
- Multi-dimensional arrays with **more than two indices** can be hard to read and error-prone
- Common real-world use: HTML forms that allow multiple selections submit data as a multi-dimensional array
