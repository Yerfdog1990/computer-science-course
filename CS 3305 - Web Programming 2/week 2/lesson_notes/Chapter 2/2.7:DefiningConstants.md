# Defining Constants

---

## What is a Constant?

A **constant** is a named container in which numeric or string values can be stored and referenced using the constant's name. Unlike a variable, a constant's value **cannot be changed** as the script proceeds — this safeguards the value from accidental alteration and is considered good programming practice.

Fixed data values that will never change in a script should always be stored in a constant rather than a variable.

### What a constant cannot store:
- Boolean values (`TRUE` or `FALSE`)
- Objects
- `NULL` empty values

---

## Naming Conventions

Constant names follow the same naming rules as variables, with two key differences:

- Constants are **not prefixed with a `$` dollar sign**
- By convention, constant names are written in **UPPERCASE** to easily distinguish them from variable names

---

## Creating a Constant — `define()`

Constants are created using the `define()` function, specifying the constant's name and its value:

```php
define( 'NAME' , value ) ;
```

### Example

```php
define( 'USER' , 'Mike' ) ;
```

---

## Displaying a Constant

Because constants have no `$` prefix, PHP **cannot distinguish a constant name from a regular capitalised string** inside a mixed string. This means constants **cannot be included directly in double-quoted strings**:

```php
define( 'USER' , 'Mike' ) ;

echo "Hello USER" ;    // outputs: Hello USER  (NOT Hello Mike)
```

To display a constant's value correctly, it must be **concatenated** to the string using the `.` operator:

```php
echo 'Hello ' . USER ;    // outputs: Hello Mike
```

---

## Array Constants

Array constants, where all elements contain fixed data values, can also be created using the `define()` function. Square brackets `[]` are used instead of the `array()` function:

```php
define( 'WEEKDAYS' , [ 'Mon', 'Tue' , 'Wed' , 'Thu' , 'Fri' ] ) ;
```

Individual elements are accessed using the constant name and index number:

```php
echo WEEKDAYS[0] ;    // outputs: Mon
echo WEEKDAYS[2] ;    // outputs: Wed
```

---

## Predefined Constants

PHP has a set of built-in predefined constants that can be used in the same way as constants defined by the script author. Two useful examples are:

| Constant | Description |
|---|---|
| `PHP_VERSION` | Returns the current version of PHP |
| `PHP_OS` | Returns the server's operating system |

```php
echo 'You are using PHP version ' . PHP_VERSION ;
echo ' running on ' . PHP_OS ;
```

---

## Full Example — constant.php

```php
<?php

# Create and initialise a string constant
define( 'USER' , 'Mike' ) ;

# Create and initialise an array constant
define( 'PETS' , [ 'Kitten' , 'Puppy' , 'Hamster' ] ) ;

# Display two constant values in a concatenated string
echo '<p>Hello ' . USER . ' how is your ' . PETS[1] . '?</p>' ;
// outputs: Hello Mike how is your Puppy?

# Display the predefined PHP version constant
echo '<p>You are using PHP version ' . PHP_VERSION ;

# Display the predefined operating system constant
echo ' running on ' . PHP_OS . '</p>' ;

?>
```

---

## Variables vs Constants — Quick Comparison

| | Variable | Constant |
|---|---|---|
| Prefix | `$` dollar sign | No prefix |
| Naming style | Any case | UPPERCASE (by convention) |
| Value can change | Yes | No |
| Can store Boolean / NULL | Yes | No |
| Include in mixed strings | Yes (double quotes) | No — must concatenate |
| Created with | `=` assignment | `define()` function |

---

## Key Rules to Remember

- Use constants for values that **will never change** — e.g. `define( 'PI' , 3.14 )`
- Constants are created with the `define()` function, not the `=` assignment operator
- Constant names have **no `$` prefix** and are written in **UPPERCASE** by convention
- Constants **cannot** store Boolean values, objects, or `NULL`
- Constants **cannot be changed** once defined
- Constants **cannot be embedded** in mixed strings — always use the `.` concatenation operator to display them
- Array constants use **square brackets** `[]` and elements are accessed by index number
- PHP has built-in predefined constants such as `PHP_VERSION` and `PHP_OS`
