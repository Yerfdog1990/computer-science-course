# Producing Arrays

---

## What is an Array?

An **array variable** can store multiple items of data in sequential array **elements**. Unlike a regular variable that holds a single value, an array holds many values under one variable name.

---

## Indexed Arrays

In an indexed array, elements are numbered (**indexed**) starting at **zero**. The first value is stored at index `0`, the second at index `1`, and so on.

Individual elements are referenced using the variable name followed by the index number in **square brackets**:

```php
$days[0]    // first element
$days[1]    // second element
$days[2]    // third element
```

### Creating an Indexed Array

**Method 1 — Multiple assignment statements:**
```php
$days[] = 'Monday' ;
$days[] = 'Tuesday' ;
$days[] = 'Wednesday' ;
```

**Method 2 — Single statement using the `array()` function (preferred):**
```php
$days = array( 'Monday' , 'Tuesday' , 'Wednesday' ) ;
```

Both methods produce the same result. Values are accessed using their index number:

```php
echo $days[0] ;    // outputs: Monday
echo $days[1] ;    // outputs: Tuesday
echo $days[2] ;    // outputs: Wednesday
```

> Square brackets denote an **element**. They are not needed after the variable name when using the `array()` function — only when addressing a specific element.

### Setting the First Index to 1

By default the index starts at `0`. To start at `1` instead:

```php
$months = array( 1 => 'January' , 'February' , 'March' ) ;
// $months[1] = January, $months[2] = February, $months[3] = March
```

---

## Associative Arrays

An **associative array** uses named **keys** instead of index numbers to reference each element's value. This makes the data easier to read and reference.

### Creating an Associative Array

**Method 1 — Multiple assignment statements:**
```php
$months['jan'] = 'January' ;
$months['feb'] = 'February' ;
$months['mar'] = 'March' ;
```

**Method 2 — Single statement using the `array()` function with `=>` operator:**
```php
$months = array( 'jan' => 'January' , 'feb' => 'February' , 'mar' => 'March' ) ;
```

Values are accessed using their key name:

```php
echo $months['jan'] ;    // outputs: January
echo $months['feb'] ;    // outputs: February
```

> If you specify key names, you **cannot** reference elements by index number. If the same key name is used twice, the second value **overwrites** the first.

---

## Traversing Arrays

All elements of an array can be traversed (looped through) using a **`foreach` loop**, which references each element's value in turn.

### Looping through values only

```php
foreach( $months as $value )
{
    # Use the current $value on each iteration.
}
```

### Looping through both keys and values

```php
foreach( $months as $key => $value )
{
    # Use the current $key and $value on each iteration.
}
```

> The `foreach` construct exists specifically for arrays and provides an easy way to traverse all array element keys and values.

---

## The `range()` Function

The `range()` function creates arrays containing **sequential numbers or letters** automatically:

```php
$six = range( 1 , 6 ) ;       // array of numbers 1 to 6
$a_z = range( 'a' , 'z' ) ;   // array of letters a to z
```

---

## Full Example — array.php

```php
<?php

# Create and initialise an indexed array
$days = array( 'Monday' , 'Tuesday' , 'Wednesday' ) ;

# Display all indexed array elements as a bulleted list
foreach( $days as $value ) { echo "&bull; $value " ; }

# Create and initialise an associative array with keys and values
$months = array( 'jan' => 'January' ,
                 'feb' => 'February' , 'mar' => 'March' ) ;

# Display all associative array keys and values as a definition list
echo '<dl>' ;
foreach( $months as $key => $value )
{ echo "<dt>$key<dd>$value" ; }
echo '</dl>' ;

?>
```

---

## Key Rules to Remember

- Array elements are **indexed starting at zero** by default
- Use square brackets `[]` to reference a specific element — e.g. `$days[0]`
- Use the `array()` function to create an array in a single statement
- **Indexed arrays** use numbers as keys; **associative arrays** use named keys
- Use the `=>` operator to assign a key to a value in an associative array — e.g. `'jan' => 'January'`
- Use `foreach` to loop through all elements of an array
- Duplicate key names will cause the second value to **overwrite** the first
- Use `range()` to quickly generate arrays of sequential numbers or letters
