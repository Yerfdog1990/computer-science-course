# Creating Variables

---

## What is a Variable?

A **variable** is a named container in a PHP script that stores a data value. The stored value can be referenced using the variable's name and changed (varied) as the script proceeds.

---

## Naming Conventions

Three rules must always be followed:

1. **Must begin with a `$` dollar sign** — e.g. `$name`
2. **Can only contain letters, numbers, and underscores** — no spaces — e.g. `$subtotal_1`
3. **The first character after `$` must be a letter or underscore** — not a number

> Variable names are **case-sensitive** — `$name`, `$Name`, and `$NAME` are three completely separate variables.

> `$this` is a reserved special variable in PHP — never use it as your own variable name.

---

## Creating and Initialising a Variable

A variable is created simply by stating its name and using the `=` assignment operator to give it a value. Every statement must end with a **semicolon** `;`.

```php
$body_temp = 98.6 ;
```

---

## Displaying a Variable

```php
echo $body_temp ;    // outputs: 98.6
```

To display a variable inside a string, enclose both in **double quotes** — PHP will substitute the variable with its value:

```php
echo "Body temperature is $body_temp degrees Fahrenheit" ;
```

> This **only works with double quotes**. Single quotes output the literal text `$body_temp`, not the value.

---

## Reassigning a Variable

A variable can be given a new value at any point in the script:

```php
$body_temp = 98.6 ;
echo "<p>Body temperature is $body_temp degrees Fahrenheit" ;

$body_temp = 37.0 ;
echo "( $body_temp degrees Celsius )</p>" ;
```

---

## Full Example — variable.php

```php
<?php

# Create and initialise the variable
$body_temp = 98.6 ;

# Display the variable value alone
echo $body_temp ;

# Display inside a mixed string
echo "<p>Body temperature is $body_temp degrees Fahrenheit " ;

# Reassign a new value
$body_temp = 37.0 ;

# Display the new value
echo "( $body_temp degrees Celsius )</p>" ;

?>
```

> Variables created in the main body of a script are **globally accessible** throughout the entire PHP script.
