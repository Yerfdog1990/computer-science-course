# Quoting Strings

---

## What is a String?

A **string** is a sequence of text characters that can be stored in a variable, much like a numeric value. When assigning a string, the value must be surrounded by quote marks to mark its beginning and end.

---

## Single vs Double Quotes

Both single and double quote marks can be used to assign a string, but the **opening and closing quote must be the same type**.

```php
$song_title = "Summertime Blues" ;    // double quotes — valid
$song_title = 'Summertime Blues' ;    // single quotes — valid
```

---

## Strings That Contain Quote Marks

When the string itself includes quote marks, there are two ways to handle it:

**Method 1 — Escape with a backslash** `\` (less preferred):
```php
$song_title = "the \"Summertime\" aria by George Gershwin" ;
```

**Method 2 — Use the other quote type inside the string** (preferred):
```php
$song_title = 'the "Summertime" aria by George Gershwin' ;
```

> Method 2 is easier to read and is the preferred approach.

---

## Displaying Strings in a Mixed String

String variable values can be displayed as part of a larger mixed string by enclosing everything in **double quotes**. PHP evaluates the string and substitutes the variable with its stored value:

```php
echo "Many regard $song_title as a popular classic" ;
```

> This **only works with double quotes**. Single quotes will output the literal variable name (e.g. `$song_title`) instead of its value.

---

## Concatenating Strings

Strings can be joined together into a single string using the `.` **concatenation operator**:

```php
$hi = 'Hello' ;
$bye = 'Goodbye' ;
$song_title = $hi . $bye ;    // result: 'HelloGoodbye'
```

Spaces and punctuation can be inserted between strings during concatenation:

```php
$song_title = $hi . ', ' . $bye ;    // result: 'Hello, Goodbye'
```

### Shorthand Concatenation Operator `.=`

Instead of writing `$a = $a . $b`, you can use the shorthand `.=` operator:

```php
$phrase = 'The truth is rarely pure' ;
$phrase .= ' and never simple' ;
// result: 'The truth is rarely pure and never simple'
```

---

## Full Example — string.php

```php
<?php

# Create and initialise two variables
$phrase = 'The truth is rarely pure' ;
$author = 'Oscar Wilde' ;

# Display a variable value alone
echo $phrase ;

# Display the variable substituted in a mixed string
echo "<p>It is often said that <q>$phrase</q> </p>" ;

# Concatenate a new string onto the variable
$phrase = $phrase . ' and never simple' ;

# Display both variables substituted in a mixed string
echo "<p><q>$phrase</q><cite>$author</cite></p>" ;

?>
```

---

## Key Rules to Remember

- Strings must be surrounded by **matching** quote marks — either both single or both double
- Variable substitution in strings **only works inside double quotes**
- Use a backslash `\` to escape quote marks, or use the other quote type (preferred)
- Use the `.` operator to **concatenate** (join) strings together
- Use `.=` as a shorthand to append a string to an existing variable
- Variable names cannot contain spaces — use underscores `_` instead (e.g. `$song_title`)
- Adopt a consistent naming style — either all lowercase `$my_var` or camelCase `$myVar`
