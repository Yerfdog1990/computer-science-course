# Sorting Arrays

---

## Converting Between Arrays and Strings

PHP provides two functions to convert between arrays and strings, as they are frequently used together.

### `implode()` — Array to String

Converts an array into a string and inserts a specified separator between each value. Commonly used to create a comma-separated values (CSV) list:

```php
$csv_list = implode( ' , ' , $array ) ;
```

### `explode()` — String to Array

Converts a string into an array by breaking it up around a specified separator:

```php
$array = explode( ' , ' , $csv_list ) ;
```

## Sorting Arrays — Ascending Order (a–z, 1–9)

PHP provides three functions to sort array elements into **ascending alphanumeric order**:

| Function | Sorts By | Keys |
|---|---|---|
| `sort()` | Value | Discards original keys |
| `asort()` | Value | Retains original keys |
| `ksort()` | Key | Retains original keys |

### Example

```php
$makers = array( 'Ford' , 'Chevrolet' , 'Dodge' ) ;

sort( $makers ) ;     // sorts by value, keys discarded
asort( $makers ) ;    // sorts by value, keys retained
ksort( $makers ) ;    // sorts by key
```

---

## Sorting Arrays — Descending Order (9–1, z–a)

Three equivalent functions sort in **descending alphanumeric order**:

| Function | Sorts By | Keys |
|---|---|---|
| `rsort()` | Value | Discards original keys |
| `arsort()` | Value | Retains original keys |
| `krsort()` | Key | Retains original keys |

```php
rsort( $makers ) ;     // descending by value, keys discarded
arsort( $makers ) ;    // descending by value, keys retained
krsort( $makers ) ;    // descending by key
```

> **Warning:** `sort()` and `rsort()` discard specified key names. Only use these where the key/value relationship is not important. Use `asort()` and `arsort()` to retain keys.

## Other Useful Array Functions

### Check if a variable is an array — `is_array()`

```php
is_array( $var ) ;    // returns TRUE if $var is an array
```

### Count the number of elements — `count()`

```php
$num = count( $array ) ;    // returns the number of elements
```

## Full Example — sort.php

```php
<?php

# Create and initialise an associative array with keys and values
$cars = array( 'Dodge' => 'Viper' ,
               'Chevrolet' => 'Camaro' , 'Ford' => 'Mustang' ) ;

# Display all keys and values in original order
echo '<dl><dt>Original Element Order :<dd>' ;
foreach( $cars as $key => $value )
{ echo ' &bull; ' , $key . ' ' . $value ; }

# Sort by value (retaining keys) and display
asort( $cars ) ;
echo '<dt>Sorted Into Value Order :<dd>' ;
foreach( $cars as $key => $value )
{ echo ' &bull; ' , $key . ' ' . $value ; }

# Sort by key and display
ksort( $cars ) ;
echo '<dt>Sorted Into Key Order :<dd>' ;
foreach( $cars as $key => $value )
{ echo ' &bull; ' , $key . ' ' . $value ; }

echo '</dl>' ;

?>
```

## Key Rules to Remember

- `implode()` converts an **array to a string**, inserting a separator between values
- `explode()` converts a **string to an array**, splitting around a separator
- Ascending sort functions: `sort()`, `asort()`, `ksort()`
- Descending sort functions: `rsort()`, `arsort()`, `krsort()`
- `sort()` and `rsort()` **discard** key names — only use them when keys are not important
- `asort()` and `arsort()` sort by value but **retain** original keys
- `ksort()` and `krsort()` sort by **key**
- Use `is_array()` to check if a variable is an array
- Use `count()` to find the number of elements in an array
