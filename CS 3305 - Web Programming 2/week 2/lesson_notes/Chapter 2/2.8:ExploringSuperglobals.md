# Exploring Superglobals

---

## What are Superglobals?

PHP provides several **predefined variables** that are always globally available anywhere within any script — regardless of scope. These are known as **superglobals**. Unlike regular variables, superglobals do not need to be declared or passed into functions to be accessible.

---

## All PHP Superglobals

| Superglobal | Description |
|---|---|
| `$GLOBALS` | An associative array containing references to all variables currently defined in the global scope of the script. Variable names are the keys. |
| `$_SERVER` | An array containing information such as headers, paths, and script locations provided by the web server. |
| `$_GET` | An associative array of variables passed to the script by appended URL parameters. |
| `$_POST` | An associative array of variables passed to the script by the HTTP POST method. |
| `$_FILES` | An associative array of uploaded file items passed to the script by the HTTP POST method. |
| `$_COOKIE` | An associative array of variables passed to the script via HTTP from cookies on the user's computer. |
| `$_SESSION` | An associative array containing variables available to each script on a website until the user exits. |
| `$_REQUEST` | An associative array that by default contains the combined contents of `$_GET`, `$_POST`, and `$_COOKIE`. |
| `$_ENV` | An associative array of variables passed to the script by the shell environment under which the PHP parser is running. |

---

## `$GLOBALS`

Contains references to all variables currently defined in the global scope. Variable names are the keys of this associative array.

```php
# Display all global variable names as a bulleted list
foreach( $GLOBALS as $key => $var )
{
    echo "&bull; $key " ;
}
```

---

## `$_SERVER`

Contains information provided by the web server such as headers, paths, and script locations. Some commonly used keys include:

| Key | Description |
|---|---|
| `$_SERVER['SERVER_SOFTWARE']` | The web server software being used |
| `$_SERVER['PHP_SELF']` | The filename of the currently executing script |
| `$_SERVER['HTTP_HOST']` | The host name of the server |
| `$_SERVER['REQUEST_METHOD']` | The HTTP method used to access the page (e.g. GET or POST) |

```php
# Display web server software
echo 'Web Server : ' . $_SERVER[ 'SERVER_SOFTWARE' ] . '<br>' ;

# Display the current script name
echo 'This Script : ' . $_SERVER[ 'PHP_SELF' ] . '<br>' ;

# Display the host name
echo 'Host Name : ' . $_SERVER[ 'HTTP_HOST' ] . '<br>' ;

# Display the request method
echo 'Request Method : ' . $_SERVER[ 'REQUEST_METHOD' ] ;
```

---

## `$_GET`

Contains variables passed to the script via **URL parameters** (appended to the URL with `?`). Each parameter becomes a key-value pair in the associative array.

For example, visiting `supers.php?name=mike&lang=PHP` would pass two parameters to `$_GET`.

```php
# Display all URL parameters passed via HTTP GET
foreach( $_GET as $key => $value )
{
    echo '<hr>HTTP GET : ' . $key . '=' . $value ;
}
```

---

## `$_POST`

Contains variables passed to the script via the **HTTP POST method**, typically from an HTML form submission. Used to securely receive form data without exposing it in the URL.

```php
# Example: accessing a form field named 'username'
$username = $_POST['username'] ;
```

---

## `$_FILES`

Contains information about **uploaded files** passed to the script via the HTTP POST method. Used when handling file uploads from HTML forms.

```php
# Example: accessing the name of an uploaded file
$filename = $_FILES['myfile']['name'] ;
```

---

## `$_COOKIE`

Contains variables passed to the script from **cookies** stored on the user's computer via HTTP.

```php
# Example: accessing a cookie named 'user'
$user = $_COOKIE['user'] ;
```

---

## `$_SESSION`

Contains variables that are available to **every script on a website** for the duration of a user's visit — until the user exits or the session expires. Used to persist data across multiple pages.

```php
# Example: storing and accessing a session variable
$_SESSION['username'] = 'Mike' ;
echo $_SESSION['username'] ;
```

---

## `$_REQUEST`

By default contains the **combined contents** of `$_GET`, `$_POST`, and `$_COOKIE`. Useful when you don't need to distinguish between the source of the data.

```php
# Example: accessing a value regardless of whether it came from GET, POST or COOKIE
$value = $_REQUEST['name'] ;
```

---

## `$_ENV`

Contains variables passed to the script by the **shell environment** under which the PHP parser is running. The contents will vary depending on the system and shell being used.

```php
# Example: displaying all environment variables
foreach( $_ENV as $key => $value )
{
    echo "$key = $value <br>" ;
}
```

---

## Full Example — supers.php

```php
<?php

# Display server software details
echo 'Web Server : ' . $_SERVER[ 'SERVER_SOFTWARE' ] . '<br>' ;

# Display the current script name
echo 'This Script : ' . $_SERVER[ 'PHP_SELF' ] . '<br>' ;

# Display the host name
echo 'Host Name : ' . $_SERVER[ 'HTTP_HOST' ] . '<br>' ;

# Display the HTTP request method
echo 'Request Method : ' . $_SERVER[ 'REQUEST_METHOD' ] ;

# Display any URL parameters passed via HTTP GET
foreach( $_GET as $key => $value )
{ echo '<hr>HTTP GET : ' . $key . '=' . $value ; }

?>
```

To test `$_GET`, open the script in a browser and append parameters to the URL:
```
supers.php?name=mike&lang=PHP
```
This will pass `name=mike` and `lang=PHP` into the `$_GET` superglobal.

---

## Key Rules to Remember

- Superglobals are **always globally accessible** — no need to declare them or pass them into functions
- `$GLOBALS` holds references to **all global variables** currently in scope
- `$_SERVER` provides **server and script information** — useful keys include `PHP_SELF`, `HTTP_HOST`, and `REQUEST_METHOD`
- `$_GET` receives data from **URL parameters** appended to the address
- `$_POST` receives data submitted via **HTML form POST method**
- `$_FILES` handles **uploaded file** data
- `$_COOKIE` accesses data stored in **cookies** on the user's computer
- `$_SESSION` stores data that **persists across pages** during a user's visit
- `$_REQUEST` combines the contents of `$_GET`, `$_POST`, and `$_COOKIE`
- `$_ENV` accesses **shell environment variables** — contents vary by system
