# Checking Types

---

## PHP Data Types

PHP variables can store various types of data. It is important to clearly understand each data type:

| Data Type | Description |
|---|---|
| `string` | A series of characters, up to a maximum of 2GB. Single-quoted strings are treated as literals; double-quoted strings interpret special characters and substitute variables. |
| `int` | A non-decimal number between -2,147,483,648 and 2,147,483,647. Can be specified as decimal (base-10), hexadecimal (base-16, prefixed with `0x`), or octal (base-8, prefixed with `0`). |
| `float` | A floating-point decimal number or a number in exponential format. Also known as a **double**. |
| `bool` | A Boolean truth value — can only be `TRUE` or `FALSE`. |
| `array` | An ordered map of multiple data values that associates keys to values. Keys are index-numbered by default or may be explicitly specified labels. |
| `object` | A class containing stored data properties and providing methods to process data. |
| `resource` | A reference to an external resource that is created and used by special functions. |
| `NULL` | A variable with no value whatsoever. This can occur when a variable has not been initialised, has been assigned the `NULL` constant, or has been nullified by the `unset()` function. |

---

## Checking the Data Type — `gettype()`

The data type of any item can be checked by passing it as an argument to the `gettype()` function:

```php
$num = 42 ;
echo gettype( $num ) ;    // outputs: integer

$str = 'Hello' ;
echo gettype( $str ) ;    // outputs: string
```

If the data type cannot be identified, `gettype()` returns `"unknown type"`.

---

## Dumping Type and Value — `var_dump()`

The `var_dump()` function is more detailed than `gettype()`. It checks an item's data type and **dumps structured information** that displays both its type and its value:

```php
$num = 42 ;
var_dump( $num ) ;    // outputs: int(42)

$str = 'Hello' ;
var_dump( $str ) ;    // outputs: string(5) "Hello"
```

## Full Example — types.php

```php
<?php

# Create a filestream resource and an array containing all data types
$filestream = fopen( 'index.http-and-session' , 'r' ) ;

$data = array( 'PHP' , 1 , 2.3 , TRUE , NULL , array() , new Directory , $filestream ) ;

# Display the data type and value stored in each array element
foreach( $data as $type )
{
    var_dump( $type ) ;
    echo '<br>' ;
}

# Destroy the filestream resource
fclose( $filestream ) ;

# Attempt to get the data type of the closed resource
echo gettype( $filestream ) ;    // outputs: resource (closed)

?>
```

### What each element in `$data` represents:

| Element | Value | Type |
|---|---|---|
| `'PHP'` | PHP | string |
| `1` | 1 | int |
| `2.3` | 2.3 | float |
| `TRUE` | true | bool |
| `NULL` | null | NULL |
| `array()` | empty array | array |
| `new Directory` | Directory object | object |
| `$filestream` | file handle | resource |

---

## Key Rules to Remember

- PHP variables are **loosely typed** — a single variable can store any data type
- Use `gettype()` to return the **data type name** of a variable as a string
- Use `var_dump()` for more detail — it displays both the **type and value**
- If `gettype()` cannot identify the type, it returns `"unknown type"`
- `NULL` can result from an uninitialised variable, an assigned `NULL` constant, or the `unset()` function
- `int` values can be written in **decimal**, **hexadecimal** (`0x` prefix), or **octal** (`0` prefix)
- `float` is also known as a **double**
- The Boolean constants `TRUE` and `FALSE` are **not case-sensitive** — `true` and `false` are equally valid
- After a filestream resource is closed with `fclose()`, `gettype()` will return `"resource (closed)"`
