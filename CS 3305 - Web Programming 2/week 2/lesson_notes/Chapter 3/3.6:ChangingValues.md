# Changing Values

---

## Increment and Decrement Operators

PHP provides two operators that alter a given number by `1` and return the resulting new value. These are most commonly used to **count iterations in a loop**:

| Operator | Name | Effect |
|---|---|---|
| `++` | Increment | Increases the value by `1` |
| `--` | Decrement | Decreases the value by `1` |

---

## Prefix vs Postfix

Each operator can be placed **before** (prefix) or **after** (postfix) the variable — with different effects:

| Position | Syntax | Behaviour |
|---|---|---|
| **Prefix** | `++$var` / `--$var` | Changes the value by `1` **first**, then returns the modified value |
| **Postfix** | `$var++` / `$var--` | Returns the **current value first**, then changes the value by `1` |

---

## Prefix Increment `++$var`

The operator is placed **before** the variable. The value is incremented first, then the new value is returned:

```php
$a = 5 ;
echo ++$a ;    // outputs: 6  (incremented first, then returned)
// $a is now 6
```

---

## Prefix Decrement `--$var`

The operator is placed **before** the variable. The value is decremented first, then the new value is returned:

```php
$b = 5 ;
echo --$b ;    // outputs: 4  (decremented first, then returned)
// $b is now 4
```

---

## Postfix Increment `$var++`

The operator is placed **after** the variable. The current value is returned first, then incremented:

```php
$c = 5 ;
echo $c++ ;    // outputs: 5  (current value returned first)
echo $c ;      // outputs: 6  (value has now been incremented)
```

---

## Postfix Decrement `$var--`

The operator is placed **after** the variable. The current value is returned first, then decremented:

```php
$d = 5 ;
echo $d-- ;    // outputs: 5  (current value returned first)
echo $d ;      // outputs: 4  (value has now been decremented)
```

---

## Initialising Multiple Variables at Once

Multiple variables can be assigned the same value in a single statement using chained assignment:

```php
$a = $b = $c = $d = 5 ;    // all four variables are set to 5
```

---

## Full Example — change.php

```php
<?php

# Create and initialise four variables with the same integer value
$a = $b = $c = $d = 5 ;

# Prefix increment and decrement — value changed first, then returned
echo "++A : " . ++$a . " --B : " . --$b . "" ;
// outputs: ++A : 6 --B : 4

# Postfix increment — current value returned first, then incremented
echo "C++ : " . $c++ . " [now C : " . $c . "]" ;
// outputs: C++ : 5 [now C : 6]

# Postfix decrement — current value returned first, then decremented
echo "D-- : " . $d-- . " [now D : " . $d . "]" ;
// outputs: D-- : 5 [now D : 4]

?>
```

### Output Breakdown

| Statement | Output | Reason |
|---|---|---|
| `++$a` | `6` | Prefix — increments `5` to `6` first, then returns `6` |
| `--$b` | `4` | Prefix — decrements `5` to `4` first, then returns `4` |
| `$c++` | `5` | Postfix — returns current value `5` first, then increments to `6` |
| `$c` after | `6` | Value has now been updated |
| `$d--` | `5` | Postfix — returns current value `5` first, then decrements to `4` |
| `$d` after | `4` | Value has now been updated |

---

## Note on Concatenation

The `.` concatenation operator is used throughout the example to join strings and variable values together into a single output. The `.=` concatenating assignment operator can also be used to **append** one string onto another:

```php
$str = 'Hello' ;
$str .= ' World' ;
echo $str ;    // outputs: Hello World
```

---

## Key Rules to Remember

- `++` increments a value by `1`; `--` decrements a value by `1`
- These operators are most commonly used to **count loop iterations**
- **Prefix** (`++$var` / `--$var`) — changes the value **first**, then returns it
- **Postfix** (`$var++` / `$var--`) — returns the **current value first**, then changes it
- Multiple variables can be initialised to the same value in a single chained statement — e.g. `$a = $b = $c = 5`
- Use the `.` operator to concatenate strings and variable values in output
- Use `.=` to append a string onto an existing variable
