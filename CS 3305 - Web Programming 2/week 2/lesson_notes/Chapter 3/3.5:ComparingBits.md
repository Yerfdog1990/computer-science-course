# Comparing Bits

---

## Understanding Bits and Bytes

A **byte** comprises **eight bits**, each of which can contain a `1` or a `0` to store a binary number. A byte can represent decimal values from **0 to 255**.

Each bit contributes a decimal component **only when that bit contains a `1`**. Bit positions are designated from right to left, from the **Least Significant Bit (LSB)** to the **Most Significant Bit (MSB)**.

### Example — Binary 50

The binary number in the bit pattern below represents the decimal value **50**:

| Bit No. | 8 (MSB) | 7 | 6 | 5 | 4 | 3 | 2 | 1 (LSB) |
|---|---|---|---|---|---|---|---|---|
| Decimal | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| Binary | 0 | 0 | 1 | 1 | 0 | 0 | 1 | 0 |

32 + 16 + 2 = **50**

> Each half of a byte (4 bits) is known as a **nibble**.

## What are Bitwise Operators?

**Bitwise operators** allow the evaluation and manipulation of specific individual bits within an integer. They operate directly on binary representations of numbers.

> Do **not** confuse bitwise operators with logical operators. Bitwise operators compare **binary numbers**, whereas logical operators evaluate **Boolean values**.

---

## Bitwise Operators

| Operator | Name | Binary Operation |
|---|---|---|
| `\|` | OR | Returns a `1` in each bit where **either** of two compared bits is a `1` |
| `&` | AND | Returns a `1` in each bit where **both** of two compared bits is a `1` |
| `~` | NOT | Returns a `1` in each bit where the compared bit is **not** a `1` (inverts all bits) |
| `^` | XOR | Returns a `1` in each bit where **only one** of two compared bits is a `1` |
| `<<` | Shift Left | Moves each bit that is a `1` a specified number of positions to the **left** |
| `>>` | Shift Right | Moves each bit that is a `1` a specified number of positions to the **right** |

---

## Bitwise OR `|`

Returns a `1` in each bit position where **either** of the two compared bits is a `1`:

```
1010 | 0101 = 1111
```

```php
$result = 0b1010 | 0b0101 ;    // binary 1111 = decimal 15
echo $result ;                  // outputs: 15
```

---

## Bitwise AND `&`

Returns a `1` in each bit position where **both** of the two compared bits is a `1`:

```
1010 & 1100 = 1000
```

```php
$result = 0b1010 & 0b1100 ;    // binary 1000 = decimal 8
echo $result ;                  // outputs: 8
```

---

## Bitwise NOT `~`

Inverts all bits — returns a `1` where the compared bit is `0` and a `0` where it is `1`:

```
~1010 = 0101
```

```php
$result = ~0b1010 ;    // inverts the bits
echo $result ;
```

---

## Bitwise XOR `^`

Returns a `1` in each bit position where **only one** of the two compared bits is a `1` — not both:

```
1010 ^ 0100 = 1110
```

```php
$result = 0b1010 ^ 0b0100 ;    // binary 1110 = decimal 14
echo $result ;                  // outputs: 14
```

### Practical use of XOR — Swapping Variables

The `^` XOR operator can be used to **exchange values between two variables without needing a third temporary variable**:

```php
$x = 5 ;
$y = 10 ;

$x = $x ^ $y ;    // Step 1
$y = $x ^ $y ;    // Step 2
$x = $x ^ $y ;    // Step 3

echo "X : $x , Y : $y " ;    // outputs: X : 10 , Y : 5
```

The three XOR operations swap the values of `$x` and `$y` using binary bit manipulation.

---

## Shift Left `<<`

Moves each bit that is a `1` a specified number of positions to the **left**, effectively multiplying the value:

```
0010 << 2 = 1000
```

```php
$result = 0b0010 << 2 ;    // binary 1000 = decimal 8
echo $result ;              // outputs: 8
```

---

## Shift Right `>>`

Moves each bit that is a `1` a specified number of positions to the **right**, effectively dividing the value:

```
1000 >> 2 = 0010
```

```php
$result = 0b1000 >> 2 ;    // binary 0010 = decimal 2
echo $result ;              // outputs: 2
```

---

## Full Example — bitwise.php

```php
<?php

# Create and initialise two integer variables
$x = 5 ;
$y = 10 ;

# Display the original assigned values
echo "X : $x , Y : $y " ;    // outputs: X : 5 , Y : 10

# Swap the variable values using three XOR operations (no third variable needed)
$x = $x ^ $y ;
$y = $x ^ $y ;
$x = $x ^ $y ;

# Display the swapped values
echo "X : $x , Y : $y " ;    // outputs: X : 10 , Y : 5

?>
```

---

## Key Rules to Remember

- A **byte** is 8 bits; each bit holds a `1` or `0`; a byte can store decimal values from **0 to 255**
- Bits are ordered from right to left — **LSB** (Least Significant Bit) to **MSB** (Most Significant Bit)
- Each half of a byte (4 bits) is called a **nibble**
- Bitwise operators manipulate **individual bits** of an integer, not Boolean values
- `|` OR — `1` if **either** bit is `1`
- `&` AND — `1` if **both** bits are `1`
- `~` NOT — **inverts** all bits
- `^` XOR — `1` if **only one** bit is `1`
- `<<` shifts bits to the **left** (multiplies); `>>` shifts bits to the **right** (divides)
- The `^` XOR operator can **swap two variables** without a third variable using three XOR operations
- Do **not** confuse bitwise operators with logical operators — they serve different purposes
- Most PHP programmers rarely use bitwise operators, but they are valuable to understand, especially for devices with limited resources
