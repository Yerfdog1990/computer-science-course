# Examining Conditions

---

## The Conditional (Ternary) Operator `?:`

The `?:` conditional operator is also known as the **ternary operator** because it has **three components**. It evaluates an expression for a `TRUE` or `FALSE` Boolean value, then returns one of two specified results depending on the outcome.

### Syntax

```php
( test-expression ) ? result-if-true : result-if-false ;
```

| Component | Description |
|---|---|
| `test-expression` | The condition being evaluated |
| `result-if-true` | Returned if the expression evaluates to `TRUE` |
| `result-if-false` | Returned if the expression evaluates to `FALSE` |

---

## Use Case 1 — Correct Grammar (Singular vs Plural)

The conditional operator can ensure correct grammar in output by checking whether a number is singular or plural — avoiding awkward phrases such as "There is 5":

```php
$number = 8 ;

$verb = ( $number == 1 ) ? 'is' : 'are' ;
echo "There $verb $number" ;    // outputs: There are 8
```

- If `$number` equals `1`, the string `'is'` is assigned to `$verb`
- Otherwise, the string `'are'` is assigned to `$verb`

---

## Use Case 2 — Checking Parity (Odd or Even)

The conditional operator can check whether a number is **odd or even** by examining the remainder after dividing by two using the modulus `%` operator:

```php
$number = 8 ;

$parity = ( $number % 2 != 0 ) ? 'Odd' : 'Even' ;
echo "$number is $parity" ;    // outputs: 8 is Even
```

- If the modulus operation returns a non-zero remainder (`!= 0`), the number is `'Odd'`
- If the remainder is zero, the number is `'Even'`

> Do not use more than one `?:` conditional operator in a single statement — the results may be unpredictable.

## The Null Coalescing Operator `??`

PHP has a special `NULL` value — a built-in constant representing a variable with **no value whatsoever**, not even zero. Variables that have not been assigned a value will evaluate as `NULL`.

The `??` **null coalescing operator** traverses a number of operands from **left to right** and returns the value of the **first operand that is not NULL**. If all operands are `NULL`, the operator itself returns `NULL`.

### Syntax

```php
$result = $a ?? $b ?? $c ;
```

- Checks `$a` first — if not `NULL`, returns its value
- If `$a` is `NULL`, checks `$b` — if not `NULL`, returns its value
- If `$b` is also `NULL`, checks `$c` and returns its value
- If all are `NULL`, returns `NULL`

### Example

```php
$a = NULL ;
$b = 8 ;
$c = 'PHP Fun' ;

$result = $a ?? $b ?? $c ;
echo "abc : $result " ;    // outputs: abc : 8  ($a is NULL, so $b is returned)

$result = $c ?? $b ?? $a ;
echo "cba : $result " ;    // outputs: cba : PHP Fun  ($c is not NULL, so returned immediately)
```

> Notice that the `NULL` value in `$a` is skipped — the operator moves on to the next non-NULL operand.

## Full Example — condition.php

```php
<?php

# Create and initialise three variables
$a = NULL ;
$b = 8 ;
$c = 'PHP Fun' ;

# Output correct grammar based on value of $b
$verb = ( $b == 1 ) ? 'is' : 'are' ;
echo "There $verb $b " ;             // outputs: There are 8

# Display parity of the integer variable $b
$parity = ( $b % 2 != 0 ) ? 'Odd' : 'Even' ;
echo "$b is $parity " ;              // outputs: 8 is Even

# Display the first non-NULL value traversing left to right
$result = $a ?? $b ?? $c ;
echo "abc : $result " ;              // outputs: abc : 8

# Display the first non-NULL value traversing left to right
$result = $c ?? $b ?? $a ;
echo "cba : $result " ;              // outputs: cba : PHP Fun

?>
```

## Key Rules to Remember

- The `?:` conditional operator is called the **ternary operator** — it has three components: test, true result, false result
- Syntax: `( test-expression ) ? result-if-true : result-if-false`
- Use the ternary operator for **grammar correctness** (singular/plural) and **parity checks** (odd/even)
- Do **not** chain more than one `?:` in a single statement — results may be unpredictable
- `NULL` is a built-in PHP constant representing a variable with **no value** — not even zero
- Unassigned variables evaluate as `NULL`
- The `??` null coalescing operator returns the **first non-NULL value** from left to right
- If all operands are `NULL`, the `??` operator itself returns `NULL`
