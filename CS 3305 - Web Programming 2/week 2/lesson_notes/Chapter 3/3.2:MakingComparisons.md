# Making Comparisons

---

## Comparison Operators

The following operators are used in PHP to compare two values. Each comparison returns a Boolean result (`TRUE` or `FALSE`), except the spaceship operator which returns an integer:

| Operator | Comparative Test |
|---|---|
| `==` | Equality |
| `===` | Identicality |
| `!==` | Non-identicality |
| `!=` or `<>` | Inequality |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |
| `<=>` | Spaceship |

---

## Equality Operator `==`

The `==` equality operator compares two operands and returns `TRUE` if both are **numerically equal in value**, otherwise it returns `FALSE`.

Characters and strings are also compared numerically by their **ASCII code value**.

```php
$zero = 0 ;
$nil  = 0 ;
$one  = 1 ;

var_dump( $zero == $nil ) ;    // TRUE  — both are 0
var_dump( $zero == $one ) ;    // FALSE — 0 is not equal to 1
```

> A Boolean `TRUE` value is represented numerically by `1` in PHP.

---

## Inequality Operators `!=` and `<>`

The `!=` (or `<>`) inequality operator returns `TRUE` if the two operands are **not equal**, otherwise it returns `FALSE` — the opposite of `==`.

```php
$upr = 'A' ;    // ASCII value: 65
$lwr = 'a' ;    // ASCII value: 97

var_dump( $upr == $lwr ) ;    // FALSE — 'A' (65) is not equal to 'a' (97)
var_dump( $upr != $lwr ) ;    // TRUE  — they are not equal
```

> The ASCII code value for uppercase `'A'` is `65` and for lowercase `'a'` is `97` — so comparing them with `==` returns `FALSE`.

---

## Greater Than and Less Than Operators `>` `<`

The `>` **greater than** operator returns `TRUE` if the first operand is **greater in value** than the second, otherwise `FALSE`.

The `<` **less than** operator returns `TRUE` if the first operand is **less in value** than the second, otherwise `FALSE`.

```php
$zero = 0 ;
$one  = 1 ;

var_dump( $one > $zero ) ;    // TRUE  — 1 is greater than 0
var_dump( $one < $zero ) ;    // FALSE — 1 is not less than 0
```

---

## Greater Than or Equal To `>=` and Less Than or Equal To `<=`

Adding `=` after `>` or `<` makes the operator also return `TRUE` when the two operands are **exactly equal**:

```php
$zero = 0 ;
$nil  = 0 ;
$one  = 1 ;

var_dump( $zero >= $nil ) ;    // TRUE  — 0 is equal to 0
var_dump( $one  <= $nil ) ;    // FALSE — 1 is not less than or equal to 0
```

---

## Spaceship Operator `<=>`

The `<=>` spaceship operator compares two operands and returns an **integer value**:

| Result | Meaning |
|---|---|
| `1` | First operand is **greater than** the second |
| `-1` | First operand is **less than** the second |
| `0` | Both operands are **equal** |

```php
$zero = 0 ;
$one  = 1 ;

var_dump( $one  <=> $zero ) ;    // int(1)  — 1 is greater than 0
var_dump( $one  <=> $one  ) ;    // int(0)  — equal
var_dump( $zero <=> $one  ) ;    // int(-1) — 0 is less than 1
```

---

## Identicality `===` and Non-identicality `!==`

The `===` identicality operator returns `TRUE` only if both operands are **equal in value AND of the same data type**. The `!==` non-identicality operator returns `TRUE` if they differ in value or type.

```php
$a = 0 ;
$b = '0' ;

var_dump( $a ==  $b ) ;    // TRUE  — equal in value
var_dump( $a === $b ) ;    // FALSE — different types (int vs string)
var_dump( $a !== $b ) ;    // TRUE  — not identical
```

---

## Using `var_dump()` for Comparisons

The `var_dump()` function displays both the **type and value** of a comparison result, making it very useful for checking the outcome of each operator:

```php
var_dump( 1 > 0 ) ;    // bool(true)
var_dump( 1 < 0 ) ;    // bool(false)
var_dump( 1 <=> 0 ) ;  // int(1)
```

## Full Example — comparison.php

```php
<?php

# Create and initialise five variables
$zero = 0 ;
$nil  = 0 ;
$one  = 1 ;
$upr  = 'A' ;
$lwr  = 'a' ;

# Equality comparisons
echo "0 == 0 : " ; var_dump( $zero == $nil ) ;    // bool(true)
echo "0 == 1 : " ; var_dump( $zero == $one ) ;    // bool(false)
echo "A == a : " ; var_dump( $upr  == $lwr ) ;    // bool(false)
echo "A != a : " ; var_dump( $upr  != $lwr ) ;    // bool(true)

# Greater than / less than comparisons
echo "1 > 0 : "  ; var_dump( $one  > $nil  ) ;    // bool(true)
echo "0 >= 0 : " ; var_dump( $zero >= $nil ) ;    // bool(true)
echo "1 <= 0 : " ; var_dump( $one  <= $nil ) ;    // bool(false)

# Spaceship operator comparisons
echo "1 <=> 0 : " ; var_dump( $one  <=> $nil  ) ; // int(1)
echo "1 <=> 1 : " ; var_dump( $one  <=> $one  ) ; // int(0)
echo "0 <=> 1 : " ; var_dump( $nil  <=> $one  ) ; // int(-1)

?>
```

## Key Rules to Remember

- Comparison operators return `TRUE` or `FALSE` — except `<=>` which returns `1`, `0`, or `-1`
- `==` checks **value equality**; `===` checks **value AND type** (identicality)
- `!=` and `<>` both mean inequality — they are interchangeable
- Characters and strings are compared by their **ASCII code value**
    - Uppercase `'A'` = ASCII 65, lowercase `'a'` = ASCII 97 — so `'A' == 'a'` returns `FALSE`
- Adding `=` to `>` or `<` makes the operator return `TRUE` when operands are equal (`>=`, `<=`)
- The `<=>` spaceship operator returns `1` (greater), `-1` (less), or `0` (equal)
- Use `var_dump()` to inspect the **type and value** of any comparison result
- Equality and inequality operators are commonly used for **conditional branching** in PHP scripts
- A Boolean `TRUE` value is represented numerically as `1` in PHP
