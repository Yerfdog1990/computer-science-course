# Doing Arithmetic

---

## Arithmetic Operators

PHP provides the following arithmetic operators for performing mathematical operations:

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus |
| `**` | Exponentiation |

---

## Operands

The numbers used alongside operators to form expressions are known as **operands**. For example, in the expression `2 + 3`, the numbers `2` and `3` are the operands.

---

## Basic Operators

Addition, subtraction, multiplication, and division all work as expected:

```php
$a = 5 ;
$b = 2 ;

$result = $a + $b ;    // 7
$result = $a - $b ;    // 3
$result = $a * $b ;    // 10
$result = $a / $b ;    // 2.5
```

---

## Grouping Expressions

When more than one operator is used in an expression, parentheses `()` should be used to group operations for clarity and to specify evaluation precedence. **Innermost groups are evaluated first.**

```php
$a = $b * $c - $d % $e / $f ;              // Unclear — hard to read

$a = ( $b * $c ) - ( ( $d % $e ) / $f ) ;  // Clear — easier to understand
```

> Always group expressions with parentheses when using multiple operators to avoid ambiguity and errors.

---

## Modulus Operator `%`

The `%` modulus operator divides the first number by the second and **returns the remainder**. This is particularly useful for determining whether a number is odd or even.

```php
$a = 5 ;
$b = 2 ;

$result = $a % $b ;
echo "Modulus : $result " ;    // outputs: Modulus : 1
```

- `5 % 2 = 1` — because 2 goes into 5 twice with a remainder of 1
- If the result is `0`, the number is **even**; if the result is `1`, the number is **odd**

---

## Exponentiation Operator `**`

The `**` operator raises the first operand to the **power of** the second operand:

```php
$a = 5 ;
$b = 2 ;

$result = $a ** $b ;
echo "Exponentiation : $result" ;    // outputs: Exponentiation : 25
```

- `5 ** 2 = 25` — because 5 raised to the power of 2 is 5 × 5

---

## Shorthand Assignment Operators

Arithmetic operators can be combined with the `=` assignment operator to create shorthand expressions:

| Shorthand | Equivalent To | Description |
|---|---|---|
| `$a += $b` | `$a = ( $a + $b )` | Add and assign |
| `$a -= $b` | `$a = ( $a - $b )` | Subtract and assign |
| `$a *= $b` | `$a = ( $a * $b )` | Multiply and assign |
| `$a /= $b` | `$a = ( $a / $b )` | Divide and assign |

```php
$a = 10 ;
$b = 3 ;

$a += $b ;    // $a is now 13
$a -= $b ;    // $a is now 10
$a *= $b ;    // $a is now 30
$a /= $b ;    // $a is now 10
```

## Useful Number Functions

PHP provides built-in functions for working with numbers:

| Function | Description |
|---|---|
| `round($a)` | Rounds `$a` to the nearest integer |
| `number_format($a)` | Adds commas to `$a` to denote groups of thousands |

```php
echo round( 4.7 ) ;             // outputs: 5
echo number_format( 1000000 ) ; // outputs: 1,000,000
```

## Full Example — arithmetic.php

```php
<?php

# Create and initialise two variables
$a = 5 ;
$b = 2 ;

# Addition
$result = $a + $b ;
echo "Addition : $result " ;         // outputs: 7

# Subtraction
$result = $a - $b ;
echo "Subtraction : $result " ;      // outputs: 3

# Multiplication
$result = $a * $b ;
echo "Multiplication : $result " ;   // outputs: 10

# Division
$result = $a / $b ;
echo "Division : $result " ;         // outputs: 2.5

# Modulus
$result = $a % $b ;
echo "Modulus : $result " ;          // outputs: 1

# Exponentiation
$result = $a ** $b ;
echo "Exponentiation : $result" ;    // outputs: 25

?>
```

---

## Key Rules to Remember

- PHP has six arithmetic operators: `+`, `-`, `*`, `/`, `%`, `**`
- Numbers used in expressions are called **operands**
- Use **parentheses** `()` to group expressions and clarify evaluation order — innermost groups are evaluated first
- The `%` modulus operator returns the **remainder** of a division — useful for checking odd/even numbers
- The `**` exponentiation operator raises the first operand to the **power** of the second
- Use **shorthand operators** (`+=`, `-=`, `*=`, `/=`) to write cleaner, more concise code
- Use `round()` to round a number to the nearest integer
- Use `number_format()` to format large numbers with comma separators
