# Assessing Logic

---

## Logical Operators

Logical operators are used with operands that have Boolean values of `TRUE` or `FALSE`, or expressions that can convert to `TRUE` or `FALSE`. The most commonly used logical operators in PHP are:

| Operator | Operation |
|---|---|
| `and` / `&&` | Logical AND |
| `or` / `\|\|` | Logical OR |
| `xor` | Logical eXclusive OR |
| `!` | Logical NOT |

> The term **"Boolean"** refers to a system of logical thought developed by the English mathematician George Boole (1815–1864).

---

## AND Operator `and` / `&&`

The `and` operator evaluates two operands and returns `TRUE` **only if both operands are TRUE**. If either operand is `FALSE`, it returns `FALSE`.

This is used in **conditional branching** where both conditions must be satisfied for the script to go in a certain direction.

### Truth Table

| Operand A | Operand B | Result |
|---|---|---|
| `FALSE` | `FALSE` | `FALSE` |
| `TRUE` | `FALSE` | `FALSE` |
| `FALSE` | `TRUE` | `FALSE` |
| `TRUE` | `TRUE` | `TRUE` |

```php
$yes = TRUE ;
$no  = FALSE ;

$result = ( $no  && $no  ) ? 'TRUE' : 'FALSE' ;
echo "No AND No returns $result <br>" ;     // FALSE

$result = ( $yes && $no  ) ? 'TRUE' : 'FALSE' ;
echo "Yes AND No returns : $result <br>" ;  // FALSE

$result = ( $yes && $yes ) ? 'TRUE' : 'FALSE' ;
echo "Yes AND Yes returns $result <hr>" ;   // TRUE
```

> `FALSE && FALSE` returns `FALSE` — demonstrating the saying "two wrongs don't make a right".

---

## OR Operator `or` / `||`

The `or` operator evaluates two operands and returns `TRUE` if **either one** of the operands is `TRUE`. It only returns `FALSE` if **neither** operand is `TRUE`.

This is useful when an action should be performed if at least one of two conditions has been met.

### Truth Table

| Operand A | Operand B | Result |
|---|---|---|
| `FALSE` | `FALSE` | `FALSE` |
| `TRUE` | `FALSE` | `TRUE` |
| `FALSE` | `TRUE` | `TRUE` |
| `TRUE` | `TRUE` | `TRUE` |

```php
$result = ( $no  || $no  ) ? 'TRUE' : 'FALSE' ;
echo "No OR No returns $result <br>" ;      // FALSE

$result = ( $yes || $no  ) ? 'TRUE' : 'FALSE' ;
echo "Yes OR No returns $result <br>" ;     // TRUE

$result = ( $yes || $yes ) ? 'TRUE' : 'FALSE' ;
echo "Yes OR Yes returns $result <hr>" ;    // TRUE
```

---

## XOR Operator `xor`

The `xor` (eXclusive OR) operator evaluates two operands and returns `TRUE` only if **exactly one** of the operands is `TRUE` — but **not both**. If neither or both operands are `TRUE`, it returns `FALSE`.

XOR performs the equivalent evaluation of AND NOT together.

### Truth Table

| Operand A | Operand B | Result |
|---|---|---|
| `FALSE` | `FALSE` | `FALSE` |
| `TRUE` | `FALSE` | `TRUE` |
| `FALSE` | `TRUE` | `TRUE` |
| `TRUE` | `TRUE` | `FALSE` |

```php
$result = ( $yes xor $no  ) ? 'TRUE' : 'FALSE' ;    // TRUE
$result = ( $yes xor $yes ) ? 'TRUE' : 'FALSE' ;    // FALSE
$result = ( $no  xor $no  ) ? 'TRUE' : 'FALSE' ;    // FALSE
```

---

## NOT Operator `!`

The `!` logical NOT operator is a **unary operator** — it is used before a **single operand** and returns the **inverse** of the given value. If the operand is `TRUE`, it returns `FALSE`, and vice versa.

### Truth Table

| Operand | Result |
|---|---|
| `TRUE` | `FALSE` |
| `FALSE` | `TRUE` |

```php
$result = ( ! $yes ) ? 'TRUE' : 'FALSE' ;
echo "NOT Yes returns $result <br>" ;    // FALSE
```

The `!` operator is also useful to **toggle the value** of a variable in a loop — on each iteration the value is reversed, like flicking a switch on and off:

```php
$var = ! $var ;    // toggles TRUE to FALSE or FALSE to TRUE on each iteration
```

---

## Alternative Operator Forms

PHP provides two forms for AND and OR operators. They behave the same way but `&&` and `||` have **higher precedence** than `and` and `or`:

| Word Form | Symbol Form |
|---|---|
| `and` | `&&` |
| `or` | `\|\|` |

---

## Full Example — logic.php

```php
<?php

# Create and initialise two Boolean variables
$yes = TRUE ;
$no  = FALSE ;

# AND evaluations
$result = ( $no  && $no  ) ? 'TRUE' : 'FALSE' ;
echo "No AND No returns $result <br>" ;         // FALSE

$result = ( $yes && $no  ) ? 'TRUE' : 'FALSE' ;
echo "Yes AND No returns : $result <br>" ;      // FALSE

$result = ( $yes && $yes ) ? 'TRUE' : 'FALSE' ;
echo "Yes AND Yes returns $result <hr>" ;       // TRUE

# OR evaluations
$result = ( $no  || $no  ) ? 'TRUE' : 'FALSE' ;
echo "No OR No returns $result <br>" ;          // FALSE

$result = ( $yes || $no  ) ? 'TRUE' : 'FALSE' ;
echo "Yes OR No returns $result <br>" ;         // TRUE

$result = ( $yes || $yes ) ? 'TRUE' : 'FALSE' ;
echo "Yes OR Yes returns $result <hr>" ;        // TRUE

# NOT evaluation
$result = ( ! $yes ) ? 'TRUE' : 'FALSE' ;
echo "NOT Yes returns $result <br>" ;           // FALSE

?>
```

---

## Key Rules to Remember

- Logical operators work with **Boolean values** (`TRUE` / `FALSE`) or expressions that evaluate to them
- `and` / `&&` returns `TRUE` only when **both** operands are `TRUE`
- `or` / `||` returns `TRUE` when **at least one** operand is `TRUE`
- `xor` returns `TRUE` only when **exactly one** operand is `TRUE` — not both, not neither
- `!` is a **unary operator** that **inverts** the Boolean value of a single operand
- `&&` and `||` have **higher precedence** than `and` and `or`
- Use `!` to **toggle** a variable's value on each loop iteration (`$var = ! $var`)
- `FALSE && FALSE` returns `FALSE` — two false conditions do not produce a true result
