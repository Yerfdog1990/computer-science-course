# If-Else Statements (Providing Alternatives)

---

## What is Conditional Branching?

**Conditional branching** is a fundamental programming technique that offers a script different directions in which to proceed, depending on the result of evaluated expressions. It is achieved using `if`, `else`, and `elseif` statements.

---

## The `else` Statement

An `if` statement can be extended by appending an `else` statement. The statements inside the `else` block execute when the `if` expression is found to be `FALSE`:

### Syntax

```php
if ( test-expression )
{
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
}
else
{
    statement-to-execute-when-false ;
    statement-to-execute-when-false ;
}
```

### Example

```php
if ( 4 > 8 )
{
    echo '4 is greater than 8' ;     // skipped — expression is FALSE
}
else
{
    echo '4 is less than 8' ;        // executes — expression is FALSE
}
```

---

## The `elseif` Statement

Alternative expressions can be evaluated by adding an `elseif` statement between the `if` and `else` blocks. The `elseif` block executes when the `if` expression is `FALSE` but the `elseif` expression is `TRUE`.

An `else` block can also be appended to handle the case where **both** the `if` and `elseif` expressions are `FALSE`.

> The `elseif` keyword can also be written as two separate words: `else if`.

### Syntax

```php
if ( test-expression )
{
    statement-to-execute-when-true ;
}
elseif ( test-expression )
{
    statement-to-execute-when-true ;
}
else
{
    statement-to-execute-when-false ;
}
```

### Example

```php
if ( 4 > 8 )
{
    echo 'This test is True' ;           // skipped — 4 is NOT greater than 8
}
elseif ( 8 > 4 )
{
    echo 'Alternative test is True' ;    // executes — 8 IS greater than 4
}
else
{
    echo 'Both tests are False' ;        // skipped — elseif was TRUE
}
```

---

## Testing Multiple Expressions with `&&`

Multiple expressions can be combined in the `if` test using the `&&` operator. All expressions must be `TRUE` for the block to execute:

```php
if ( ( 4 > 2 ) && ( 8 > 4 ) )
{
    echo '4 is greater than 2 AND 8 is greater than 4' ;    // both TRUE — executes
}
```

---

## A Note on Syntax Style

Some PHP scripts use a `:` colon character instead of curly brackets `{}`. This is **not recommended** — `if` and `else if` (as two words) will only be considered exactly the same when using curly brackets.

```php
// Not recommended
if ( test-expression ) :
    statement ;
endif ;

// Recommended
if ( test-expression )
{
    statement ;
}
```

---

## Full Example — ifelse.php

```php
<?php

# Test a single expression — outputs only when TRUE
if ( 4 > 2 )
{
    echo '<p>Yes, 4 is greater than 2 <br>' ;
}

# Test two expressions using && — outputs only when BOTH are TRUE
if ( ( 4 > 2 ) && ( 8 > 4 ) )
{
    echo '4 is greater than 2 AND 8 is greater than 4<br>' ;
}

# if-else — outputs a result whether the expression is TRUE or FALSE
if ( 4 > 8 )
{
    echo '4 is greater than 8 <br>' ;           // skipped — FALSE
}
else
{
    echo '4 is less than 8 <br>' ;              // executes — FALSE triggers else
}

# if-elseif-else — evaluates two expressions with a fallback
if ( 4 > 8 )
{
    echo 'This test is True </p>' ;             // skipped — FALSE
}
elseif ( 8 > 4 )
{
    echo 'Alternative test is True </p>' ;      // executes — TRUE
}
else
{
    echo 'Both tests are False </p>' ;          // skipped — elseif was TRUE
}

?>
```

### Output

```
Yes, 4 is greater than 2
4 is greater than 2 AND 8 is greater than 4
4 is less than 8
Alternative test is True
```

---

## How the Flow Works

| Condition | `if` result | `elseif` result | Block Executed |
|---|---|---|---|
| `if` is `TRUE` | TRUE | — | `if` block runs |
| `if` is `FALSE`, `elseif` is `TRUE` | FALSE | TRUE | `elseif` block runs |
| Both `if` and `elseif` are `FALSE` | FALSE | FALSE | `else` block runs |

---

## Key Rules to Remember

- `else` executes when the preceding `if` expression is `FALSE`
- `elseif` tests an **alternative expression** when the `if` expression is `FALSE`
- `else` at the end acts as a **fallback** — executes only when all preceding tests are `FALSE`
- `elseif` can be written as one word or two (`else if`) — both are valid when using curly brackets
- Use `&&` to test **multiple expressions** in a single `if` — all must be `TRUE` for the block to execute
- Nested `if` statements can be used so inner blocks only execute when **all** outer tests also pass
- Always use **curly brackets** `{}` — avoid using `:` colon syntax as it can cause inconsistency
- This technique is known as **conditional branching** — one of the most fundamental concepts in programming
