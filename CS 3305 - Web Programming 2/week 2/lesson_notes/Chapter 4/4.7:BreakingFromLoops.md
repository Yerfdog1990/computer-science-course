# Breaking from Loops

---

## The `break` Keyword

The `break` keyword can be used to **prematurely terminate a loop** when a specified condition is met. It is placed inside the loop block, preceded by a test expression. When the test returns `TRUE`, the loop **ends immediately** and the program proceeds to the next task.

In a nested loop, `break` exits the **inner loop** and the program proceeds to execute the next iteration of the **outer loop**.

### Syntax

```php
for ( initializer ; test-expression ; updater )
{
    if ( condition )
    {
        break ;    // exits the loop immediately
    }
    statement/s ;
}
```

### Example

```php
for ( $i = 1 ; $i < 4 ; $i++ )
{
    for ( $j = 1 ; $j < 4 ; $j++ )
    {
        if ( $i == 2 && $j == 1 )
        {
            echo "Breaks inner loop when i = $i and j = $j " ;
            break ;    // exits inner loop when i is 2 and j is 1
        }

        echo "Running i = $i and j = $j " ;
    }
}
```

### What Happens

- The outer loop runs iterations for `$i = 1`, `$i = 2`, and `$i = 3`
- When `$i = 2` and the inner loop reaches `$j = 1`, the `break` condition is `TRUE`
- The `break` statement **halts all remaining iterations** of the inner loop at that point
- The outer loop continues normally to `$i = 3`

## The `continue` Keyword

The `continue` keyword can be used to **skip a single iteration** of a loop when a specified condition is met. It is placed inside the loop block, preceded by a test expression. When the test returns `TRUE`, that single iteration ends and the loop moves on to the next iteration — it does **not** exit the loop entirely.

### Syntax

```php
for ( initializer ; test-expression ; updater )
{
    if ( condition )
    {
        continue ;    // skips the rest of this iteration only
    }
    statement/s ;
}
```

### Example

```php
for ( $i = 1 ; $i < 4 ; $i++ )
{
    for ( $j = 1 ; $j < 4 ; $j++ )
    {
        if ( $i == 1 && $j == 1 )
        {
            echo "Continues inner loop when i = $i and j = $j " ;
            continue ;    // skips this iteration only
        }

        echo "Running i = $i and j = $j " ;
    }
}
```

### What Happens

- When `$i = 1` and the inner loop reaches `$j = 1`, the `continue` condition is `TRUE`
- Only that **single iteration** (`$i = 1`, `$j = 1`) is skipped
- The inner loop resumes normally from `$j = 2` onwards
- All other iterations of both loops execute as normal

---

## `break` vs `continue` — Key Difference

| Keyword | Effect | Loop Continues? |
|---|---|---|
| `break` | **Exits** the loop entirely | No — moves to the code after the loop |
| `continue` | **Skips** the current iteration only | Yes — moves to the next iteration |

---

## Full Example — breakcontinue.php

```php
<?php

# Outer for loop — three iterations
for ( $i = 1 ; $i < 4 ; $i++ )
{
    # Inner for loop — three iterations
    for ( $j = 1 ; $j < 4 ; $j++ )
    {
        # continue — skips the first iteration of the inner loop on the first outer pass
        if ( $i == 1 && $j == 1 )
        {
            echo "Continues inner loop when i = $i and j = $j " ;
            continue ;
        }

        # break — exits the inner loop entirely on the second outer pass
        if ( $i == 2 && $j == 1 )
        {
            echo "Breaks inner loop when i = $i and j = $j " ;
            break ;
        }

        # Normal output on all other iterations
        echo "Running i = $i and j = $j " ;
    }
}

?>
```

### Output

```
Continues inner loop when i = 1 and j = 1
Running i = 1 and j = 2
Running i = 1 and j = 3
Breaks inner loop when i = 2 and j = 1
Running i = 3 and j = 1
Running i = 3 and j = 2
Running i = 3 and j = 3
```

---

## Key Rules to Remember

- `break` **terminates** the loop immediately — no further iterations are made
- `continue` **skips** only the current iteration — the loop carries on from the next iteration
- Both `break` and `continue` are placed **inside** the loop block and preceded by a conditional test
- In **nested loops**, `break` exits only the **inner loop** — the outer loop continues normally
- In **nested loops**, `continue` skips only the current iteration of the **inner loop**
- Without careful use of `break` and `continue`, loops may execute too many or too few iterations
- Always test conditions carefully to ensure `break` and `continue` trigger only when intended
