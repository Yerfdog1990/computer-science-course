# Performing Loops

---

## What is a Loop?

A **loop** is a piece of code in a script that automatically repeats. One complete execution of all statements within a loop is called an **iteration** or a **pass**. The length of a loop is controlled by a **conditional test** made within the loop — while the tested expression is `TRUE` the loop continues, and when it becomes `FALSE` the loop ends.

---

## Types of Loops in PHP

PHP provides four types of loop structure:

| Loop Type | Description |
|---|---|
| `for` | Performs a **specified number** of iterations |
| `while` | Performs iterations only while a test made at the **start** of each iteration evaluates as `TRUE` |
| `do while` | Performs iterations only while a test made at the **end** of each iteration evaluates as `TRUE` |
| `foreach` | Performs iterations to **traverse each element** of an array |

---

## The `for` Loop

The `for` loop is perhaps the most commonly used loop structure. It is ideal when the number of iterations is known in advance.

### Syntax

```php
for ( initializer ; test-expression ; updater )
{
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
}
```

### The Three Components

| Component | Description |
|---|---|
| `initializer` | Sets a starting value for a counter variable. Traditionally named `$i`. Runs **once** at the start. |
| `test-expression` | Evaluated at the start of **each** iteration. Loop continues while `TRUE`, ends when `FALSE`. |
| `updater` | Runs at the end of each iteration to update the counter — usually an increment `$i++` or decrement `$i--`. |

---

## Basic `for` Loop Example — Counting Up

```php
for ( $i = 1 ; $i < 4 ; $i++ )
{
    echo "Outer loop iteration $i" ;
}
```

### How it executes step by step:

| Iteration | `$i` value | Test `$i < 4` | Output |
|---|---|---|---|
| 1st | 1 | TRUE | Outer loop iteration 1 |
| 2nd | 2 | TRUE | Outer loop iteration 2 |
| 3rd | 3 | TRUE | Outer loop iteration 3 |
| End | 4 | FALSE | Loop exits |

---

## Counting Down with `for`

A `for` loop can also **count down** by decrementing the counter value on each iteration using `$i--` in place of `$i++`:

```php
for ( $i = 3 ; $i > 0 ; $i-- )
{
    echo "Countdown: $i" ;
}
// outputs: Countdown: 3, Countdown: 2, Countdown: 1
```

---

## Nested `for` Loops

Loops can be **nested** one within another. On each iteration of the outer loop, the inner loop completes **all** of its iterations before the outer loop moves to its next iteration.

```php
for ( $i = 1 ; $i < 4 ; $i++ )
{
    echo "Outer loop iteration $i" ;

    for ( $j = 1 ; $j < 4 ; $j++ )
    {
        echo "Inner loop iteration $j" ;
    }
}
```

### Output

```
Outer loop iteration 1
    Inner loop iteration 1
    Inner loop iteration 2
    Inner loop iteration 3
Outer loop iteration 2
    Inner loop iteration 1
    Inner loop iteration 2
    Inner loop iteration 3
Outer loop iteration 3
    Inner loop iteration 1
    Inner loop iteration 2
    Inner loop iteration 3
```

> The inner loop runs through all three of its iterations on **each** iteration of the outer loop — 3 × 3 = **9 total inner iterations**.

---

## Full Example — forloop.php

```php
<?php

# Outer for loop — runs 3 iterations
for ( $i = 1 ; $i < 4 ; $i++ )
{
    echo "Outer loop iteration $i" ;

    # Nested inner for loop — runs 3 iterations on each outer iteration
    for ( $j = 1 ; $j < 4 ; $j++ )
    {
        echo "<br>Inner loop iteration $j" ;
    }
}

?>
```

---

## Key Rules to Remember

- A loop repeats automatically — one complete run of its statements is called an **iteration** or **pass**
- The loop continues while the test expression is `TRUE` and ends when it becomes `FALSE`
- PHP has four loop types: `for`, `while`, `do while`, and `foreach`
- The `for` loop has three components: **initializer**, **test expression**, and **updater**
- The counter variable in a `for` loop is traditionally named **`$i`**
- The initializer runs **once** at the start; the test and updater run on **every** iteration
- Use `$i++` to count **up** and `$i--` to count **down**
- Loops can be **nested** — the inner loop completes all its iterations on each pass of the outer loop
- When the test expression becomes `FALSE`, the loop **exits immediately** without executing the statements again
