# If Statements (Seeking Truth)

---

## What is an If Statement?

The `if` keyword performs a **basic conditional test** that evaluates a given expression for a Boolean value of `TRUE` or `FALSE`. Statements within the braces following the test will **only execute** when the expression is found to be `TRUE`. When the expression is `FALSE`, the PHP parser simply moves on to the next part of the script.

> The `if` construct is one of the most important features in PHP and in most other programming languages.

---

## Basic Syntax

```php
if ( test-expression )
{
    statement-to-execute-when-true ;
}
```

---

## Multiple Statements

There may be multiple statements to execute when the test is `TRUE`. Each statement must be terminated by a semicolon `;`:

```php
if ( test-expression )
{
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
}
```

---

## Omitting Braces

When the code to be executed is just a **single statement**, the braces can optionally be omitted. However, it is generally preferred to always include braces for consistency:

```php
if ( test-expression )
    statement-to-execute-when-true ;    // braces omitted — valid but not recommended
```

---

## Testing Multiple Expressions with `&&`

Multiple expressions can be tested using the `&&` (or `and`) logical operator to ensure that statements only execute when **both** expressions are `TRUE`:

```php
if ( ( test-expression ) && ( test-expression ) )
{
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
    statement-to-execute-when-true ;
}
```

### Example

```php
$num = 6 ;

if ( ( $num > 0 ) && ( $num % 2 == 0 ) )
{
    echo "$num is a positive even number" ;
}
```

---

## Nested If Statements

`if` statements can be **nested** inside one another to test multiple expressions. The inner statements only execute when **all** tests are `TRUE`:

```php
if ( test-expression )
{
    if ( test-expression )
    {
        statement-to-execute-when-true ;
        statement-to-execute-when-true ;
        statement-to-execute-when-true ;
    }
}
```

### Example

```php
$num = 8 ;

if ( $num > 0 )
{
    if ( $num < 10 )
    {
        echo "$num is a single-digit positive number" ;
    }
}
```

---

## Multiple If Statements as Alternatives

Multiple `if` statements can be used in sequence to provide **alternative paths** for the script to follow. Each test is evaluated independently:

```php
$num = 6 ;

if ( $num > 5 )
{
    echo "$num exceeds 5" ;
}

if ( $num <= 5 )
{
    echo "$num is below 6" ;
}
```

> When a tested condition is `FALSE`, the PHP parser **ignores** its statement block and simply moves on to the next statement.

---

## Full Example — if.php

```php
<?php

# Initialise an integer variable
$num = 6 ;

# Test if the number exceeds 5
if ( $num > 5 )
{
    echo "$num exceeds 5" ;        // executes if $num is greater than 5
}

# Test if the number is 5 or below
if ( $num <= 5 )
{
    echo "$num is below 6" ;       // executes if $num is 5 or less
}

# Test if the number is even
if ( $num % 2 == 0 )
{
    echo "$num is Even" ;          // executes if remainder is 0
}

# Test if the number is odd
if ( $num % 2 != 0 )
{
    echo "$num is Odd" ;           // executes if remainder is not 0
}

?>
```

### Testing with a Different Value

Edit the variable to `$num = 3` and the output changes:

```php
$num = 3 ;
// outputs: 3 is below 6
//          3 is Odd
```

---

## Key Rules to Remember

- The `if` keyword evaluates an expression for `TRUE` or `FALSE`
- Statements inside the `if` block **only execute** when the expression is `TRUE`
- When the condition is `FALSE`, the parser **skips** the block and moves on
- Each statement inside the block must end with a **semicolon** `;`
- Use **braces** `{}` to group multiple statements — they are optional for single statements but recommended for consistency
- Use `&&` or `and` to test **multiple expressions** — all must be `TRUE` for the block to execute
- **Nested** `if` statements can test multiple conditions in sequence — inner block only runs if all outer tests also pass
- Multiple separate `if` statements can be used to provide **alternative** paths through a script
