# Looping While True

---

## The `while` Loop

A `while` loop is an alternative to the `for` loop. Like the `for` loop, it requires an **initializer**, a **test expression**, and an **updater** — but these are not listed within a single pair of parentheses. Instead:

- The **initializer** appears **before** the loop block
- The **test expression** appears in parentheses after the `while` keyword
- The **updater** appears **inside** the loop block along with the statements to execute

### Syntax

```php
initializer ;

while ( test-expression )
{
    statement/s-to-be-executed ;
    updater ;
}
```

### Example

```php
$i = 0 ;

while ( $i < 3 )
{
    echo "Iteration $i" ;
    $i++ ;
}
// outputs: Iteration 0, Iteration 1, Iteration 2
```

---

## The `do while` Loop

The `do while` loop provides a subtle variation on the `while` loop. The `do` keyword is placed **before** the loop block and the `while` test expression is moved to **after** the loop block:

### Syntax

```php
initializer ;

do
{
    statement/s-to-be-executed ;
    updater ;
}
while ( test-expression ) ;
```

> Note: The `do while` statement must end with a **semicolon** `;` after the closing parenthesis.

### Example

```php
$i = 0 ;

do
{
    echo "Iteration $i" ;
    $i++ ;
}
while ( $i < 3 ) ;
// outputs: Iteration 0, Iteration 1, Iteration 2
```

---

## Key Difference — `while` vs `do while`

The most significant difference between the two loops is **when the test expression is evaluated**:

| Loop | Test Evaluated | Minimum Iterations |
|---|---|---|
| `while` | At the **start** of each iteration | **0** — will not run at all if test is `FALSE` on first check |
| `do while` | At the **end** of each iteration | **1** — always runs at least once before the test is checked |

### Demonstrating the Difference

If the test expression is `FALSE` from the beginning:

```php
$i = 5 ;

# while loop — test is FALSE immediately, so nothing executes
while ( $i < 3 )
{
    echo "while: $i" ;    // never runs
    $i++ ;
}

# do while loop — executes once before checking the test
do
{
    echo "do while: $i" ;    // runs once — outputs: do while: 5
    $i++ ;
}
while ( $i < 3 ) ;
```

---

## Avoiding Infinite Loops

Both `while` and `do while` loops continue iterating until the test expression becomes `FALSE`. It is **essential** that the loop body contains code that will at some point change the result of the test — otherwise an **infinite loop** is created, which will lock the system.

```php
# Dangerous — infinite loop (no updater)
$i = 0 ;
while ( $i < 3 )
{
    echo "This will never stop!" ;
    # $i is never updated — loop runs forever
}

# Correct — updater ensures the loop ends
$i = 0 ;
while ( $i < 3 )
{
    echo "Iteration $i" ;
    $i++ ;    // updater — loop will end when $i reaches 3
}
```

> Always ensure the test expression will **at some point become `FALSE`** to avoid creating an infinite loop.

---

## When to Use Which Loop

| Loop | Best Used When |
|---|---|
| `for` | Performing a **specific number** of iterations |
| `while` | Iterating until a **certain condition** is met |
| `do while` | When the loop body must execute **at least once** regardless of the condition |

---

## Using Loops with Arrays

Loops are the perfect partner for arrays — each iteration can effortlessly read or write into successive array elements.

```php
$numbers = array( 10 , 20 , 30 ) ;

# while loop reading array elements
$i = 0 ;
while ( $i < 3 )
{
    echo "Element $i = $numbers[$i] " ;
    $i++ ;
}

# do while loop reading array elements
$i = 0 ;
do
{
    echo "Element $i = $numbers[$i] " ;
    $i++ ;
}
while ( $i < 3 ) ;
```

## Full Example — whileloop.php

```php
<?php

# Create an array
$numbers = array( 10 , 20 , 30 ) ;

# while loop to output each array element
echo 'While Loop : ' ;
$i = 0 ;
while ( $i < 3 )
{
    echo "<br>Element $i = $numbers[$i] " ;
    $i++ ;
}

# do while loop to output each array element
echo '<br>Do While Loop : ' ;
$i = 0 ;
do
{
    echo "<br>Element $i = $numbers[$i] " ;
    $i++ ;
}
while ( $i < 3 ) ;

?>
```

### Output

```
While Loop :
Element 0 = 10
Element 1 = 20
Element 2 = 30

Do While Loop :
Element 0 = 10
Element 1 = 20
Element 2 = 30
```

> Both loops produce identical output in this case because the test expression is `TRUE` on the first evaluation.

---

## Key Rules to Remember

- The `while` loop requires an **initializer** before the loop, a **test** in parentheses, and an **updater** inside the block
- The `do while` loop places statements **before** the test — guaranteeing at least one iteration
- `while` checks the condition at the **start** — may execute **zero** times
- `do while` checks the condition at the **end** — always executes **at least once**
- Always include an **updater** inside the loop to prevent an **infinite loop**
- The `do while` statement must end with a **semicolon** `;` after the closing `while ( ... )`
- `for` loops are best for a **known number** of iterations; `while` loops for iterating until a **condition is met**
- Loops work excellently with **arrays** — each iteration naturally accesses the next element
