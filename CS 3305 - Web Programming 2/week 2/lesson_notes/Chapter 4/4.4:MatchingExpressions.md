# Matching Expressions

---

## What is a Match Statement?

A **match statement** is an alternative to `switch` statements for conditional branching and is often a better choice. Unlike a `switch` statement block, a match statement is a **single expression that returns a value**.

It takes a given value as its parameter argument and seeks to match that value from a comma-separated list of alternatives enclosed within curly brackets `{}`. The value to be returned when a match is found is specified after a `=>` **fat arrow operator**.

> The `match` statement is a great new feature introduced in **PHP 8**.

---

## Key Differences — `match` vs `switch`

| Feature | `match` | `switch` |
|---|---|---|
| Type | Single expression — returns a value | Statement block |
| Comparison | Identicality (`===`) — value AND type | Equality (`==`) — value only |
| `break` required | No | Yes |
| Multiple values | Comma-separated list | Empty fall-through cases |
| Code length | Significantly shorter | Longer |
| Introduced | PHP 8 | Earlier versions |

---

## Syntax

```php
$result = match ( test-value )
{
    match-value => return-value ,
    match-value => return-value ,
    match-value => return-value ,
    default     => return-value ,
} ;
```

- The match statement must end with a **semicolon** `;` after the closing curly bracket `}`
- No `break` statements are required
- The `default` case handles any value that does not match

---

## How It Works

1. The match statement receives a **test value** as its argument
2. It compares the test value **identically** (`===`) against each match value in order
3. When a match is found, the corresponding **return value** after `=>` is returned
4. The result can be stored in a variable or used directly (e.g. inside `echo`)
5. If no match is found, the **`default`** return value is used

---

## Basic Example — Matching an Integer

```php
$number = 2 ;

echo match ( $number )
{
    1       => 'Number is One' ,
    2       => 'Number is Two' ,       // matches — returns 'Number is Two'
    3       => 'Number is Three' ,
    default => 'Number is Unrecognized' ,
} ;
```

---

## Basic Example — Matching a Character

```php
$letter = 'B' ;

echo match ( $letter )
{
    'A'     => 'Letter is A' ,
    'B'     => 'Letter is B' ,         // matches — returns 'Letter is B'
    'C'     => 'Letter is C' ,
    default => 'Letter is Unrecognized' ,
} ;
```

---

## Matching Multiple Values to the Same Return Value

Where several match values should all return the same value, they can be combined into a **comma-separated single list** on one line:

```php
echo match ( $number )
{
    0, 1, 2 => 'Less than 3' ,         // matches 0, 1, or 2
    3       => 'Exactly 3' ,
    default => 'Greater than 3 or less than zero' ,
} ;
```

This is much cleaner than the equivalent `switch` fall-through approach.

---

## Storing the Result in a Variable

The match statement returns a value, so it can be assigned directly to a variable:

```php
$number = 2 ;

$result = match ( $number )
{
    1       => 'Number is One' ,
    2       => 'Number is Two' ,
    3       => 'Number is Three' ,
    default => 'Number is Unrecognized' ,
} ;

echo $result ;    // outputs: Number is Two
```

---

## Important — `match` Uses Strict Comparison (`===`)

Unlike `switch` which uses loose equality (`==`), the `match` statement uses **identicality** (`===`) — it compares both the **value and the data type**:

```php
$value = '1' ;    // string

// switch — loose comparison (==)
switch ( $value )
{
    case 1 : echo 'Matched integer 1' ; break ;    // MATCHES — '1' == 1 is TRUE
}

// match — strict comparison (===)
echo match ( $value )
{
    1       => 'Matched integer 1' ,               // NO MATCH — '1' === 1 is FALSE
    '1'     => 'Matched string 1' ,                // MATCHES — '1' === '1' is TRUE
    default => 'No match found' ,
} ;
```

## Full Example — match.php

```php
<?php

# Initialise two variables
$number = 2 ;
$letter = 'B' ;

# Match statement to match an integer value
echo match ( $number )
{
    1       => 'Number is One' ,
    2       => 'Number is Two' ,
    3       => 'Number is Three' ,
    default => 'Number is Unrecognized' ,
} ;

# Match statement to match a character value
echo match ( $letter )
{
    'A'     => 'Letter is A' ,
    'B'     => 'Letter is B' ,
    'C'     => 'Letter is C' ,
    default => 'Letter is Unrecognized' ,
} ;

# Match statement matching multiple values to the same return value
echo match ( $number )
{
    0, 1, 2 => 'Less than 3' ,
    default => '3 or more, or less than zero' ,
} ;

?>
```

### Output

```
Number is Two
Letter is B
Less than 3
```

---

## Key Rules to Remember

- A `match` statement is a **single expression** that returns a value — unlike `switch` which is a block
- Use the `=>` **fat arrow operator** to specify the return value for each match
- The match statement must be terminated with a **semicolon** `;` after the closing `}`
- No **`break`** statements are needed — making code significantly shorter than equivalent `switch` blocks
- `match` uses **strict identicality** (`===`) — both value and data type must match
- `switch` uses **loose equality** (`==`) — only the value is compared
- Multiple match values that share the same return value can be combined as a **comma-separated list**
- Always include a **`default`** case to handle unmatched values
- `match` was introduced in **PHP 8** and is generally preferred over `switch` for cleaner, safer code
