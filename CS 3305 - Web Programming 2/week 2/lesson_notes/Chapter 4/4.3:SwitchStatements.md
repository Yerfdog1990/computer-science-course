# Switch Statements (Switching Branches)

---

## What is a Switch Statement?

A **switch statement** is an efficient alternative to multiple `if-elseif-else` statements when the test expression evaluates **one condition** against several possible values. Instead of repeatedly testing a condition, the switch statement takes a given value as its parameter and **seeks to match** that value from a list of `case` statements.

---

## How It Works

1. The switch statement receives a **test value** as its argument
2. It compares the test value against each `case` **match value** in sequence
3. When a match is found, the code in that `case` block executes
4. The `break` keyword exits the switch statement after a match
5. If no match is found, the optional `default` block executes

---

## Syntax

```php
switch ( test-value )
{
    case match-value : statements-to-execute-when-matched ; break ;
    case match-value : statements-to-execute-when-matched ; break ;
    case match-value : statements-to-execute-when-matched ; break ;
    default : statements-to-execute-when-no-match-found ;
}
```

> In switch statements, the `case` keyword, match value, and colon `:` character together are regarded as a unique **label**.

---

## The `break` Keyword

It is important to end each `case` statement with a `break` keyword. This causes the switch statement to **exit immediately** when a match is found, without seeking further matches.

Without `break`, execution will "fall through" into the next case — which can be used deliberately but should be avoided unintentionally.

---

## The `default` Statement

The optional `default` statement appears at the end of the case list and executes when **no match is found** in any of the case statements. It is good practice to always include a `default` — even if just to output an error message:

```php
switch ( $number )
{
    case 1 : echo 'Number is One' ; break ;
    case 2 : echo 'Number is Two' ; break ;
    default : echo 'Number is Unrecognized' ;    // fallback
}
```

> The `default` statement does not need a `break` when placed at the end of the switch block, as there is nothing further to execute.

---

## Matching Multiple Values to the Same Output

Where several match values should all execute the same statements, only the **final case** in the group needs to include the statements and `break`. Earlier cases are left empty and execution falls through to the final one:

```php
switch ( $number )
{
    case 0 :
    case 1 :
    case 2 : echo 'Less than 3' ; break ;     // runs for 0, 1, or 2
    case 3 : echo 'Exactly 3' ; break ;
    default : echo 'Greater than 3 or less than zero' ;
}
```

---

## Rules for `case` Statements

- A switch statement can have **many** case statements
- No two case statements can attempt to match the **same value**
- The `default` statement need not appear at the end of the block, but it is logical to place it there

---

## Full Example — switch.php

```php
<?php

# Initialise two variables
$number = 2 ;
$letter = 'B' ;

# Switch statement to match an integer value
switch ( $number )
{
    case 1 : echo 'Number is One<br>' ; break ;
    case 2 : echo 'Number is Two<br>' ; break ;      // matches — executes this
    case 3 : echo 'Number is Three<br>' ; break ;
    default : echo 'Number is Unrecognized<br>' ;
}

# Switch statement to match a character value
switch ( $letter )
{
    case 'A' : echo 'Letter is A<br>' ; break ;
    case 'B' : echo 'Letter is B<br>' ; break ;      // matches — executes this
    case 'C' : echo 'Letter is C<br>' ; break ;
    default : echo 'Letter is Unrecognized<br>' ;
}

# Switch statement matching multiple values to the same output
switch ( $number )
{
    case 0 : case 1 : case 2 : echo 'Less than 3<br>' ; break ;    // matches 2 — executes
    default : echo '3 or more, or less than zero' ;
}

?>
```

### Output

```
Number is Two
Letter is B
Less than 3
```

---

## switch vs if-elseif-else — When to Use Which

| Scenario | Recommended |
|---|---|
| Testing one value against many specific matches | `switch` |
| Testing ranges or complex conditions | `if-elseif-else` |
| Multiple values executing the same code | `switch` (fall-through) |
| Combining conditions with `&&` or `\|\|` | `if-elseif-else` |

---

## Key Rules to Remember

- A `switch` statement is an efficient alternative to multiple `if-elseif-else` statements
- It compares a **single test value** against a list of `case` match values
- Always end each `case` block with a **`break`** to prevent unintended fall-through
- The **`default`** block executes when no case matches — always include it as a safety net
- Multiple `case` labels with no statements will **fall through** to the next case with code — useful when several values share the same output
- No two `case` statements in the same switch can match the **same value**
- The `default` statement does not require a `break` when placed at the end
- `case` keyword + match value + `:` colon is treated as a unique **label** in PHP
