# Making Sticky Forms

## Overview

When a user attempts to submit a form where a required field has not been completed, it is desirable to retain the entries in the fields they have completed, by making the form "sticky". This is especially so for lengthy forms with many fields – so the user need not complete all fields once more – and is easily achieved with PHP.

## What Are Sticky Forms?

Sticky forms retain user input after form submission, even when validation errors occur. This improves user experience by preventing users from having to re-enter all data when only a few fields need correction.

**Key Benefits:**
- **Better User Experience**: Users don't lose their input on validation errors
- **Reduced Frustration**: Especially important for long forms
- **Higher Conversion Rates**: Users are more likely to complete forms
- **Professional Appearance**: Shows attention to user experience

## Basic Sticky Form Technique

The core technique involves assigning submitted field data from the `$_POST` array to the HTML input tag's `value` attribute:

```html
<input type="text" name="fieldname" value="<?php echo $submitted_value; ?>">
```

**Precaution**: Use the `isset()` function to check that the field was completed before submission:

```html
<input type="text" name="name" value="<?php echo isset($_POST['name']) ? htmlspecialchars($_POST['name']) : ''; ?>">
```

## Complete Example: Sticky Form with Validation

### sticky.php

```php
<!DOCTYPE html>
<html>
<head>
    <title>PHP Sticky Form</title>
</head>
<body>
    <?php
        // Initialize variables
        $name = '';
        $email = '';
        $errors = array();
        
        // Handle form submission
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            // Validate name field
            if (empty($_POST['name'])) {
                $errors[] = 'name';
            } else {
                $name = trim($_POST['name']);
            }
            
            // Validate email field
            if (empty($_POST['email'])) {
                $errors[] = 'email';
            } else {
                $email = trim($_POST['email']);
            }
            
            // Display results
            if (!empty($errors)) {
                echo '<h2 style="color: red;">Error! Please enter your';
                foreach ($errors as $msg) {
                    echo " - $msg";
                }
                echo '</h2>';
            } else {
                echo "<h2 style=\"color: green;\">Success! Thanks $name</h2>";
            }
        }
    ?>
    
    <form action="<?php echo $_SERVER['PHP_SELF']; ?>" method="POST">
        <p>
            Name:<br>
            <input type="text" name="name" value="<?php echo htmlspecialchars($name); ?>">
        </p>
        <p>
            Email:<br>
            <input type="text" name="email" value="<?php echo htmlspecialchars($email); ?>">
        </p>
        <p>
            <input type="submit" value="Submit">
        </p>
    </form>
</body>
</html>
```

## PHP Functions Used

### 1. isset() Function

Checks if a variable exists and is not NULL:

```php
isset($_POST['fieldname'])
```

**Usage in sticky forms:**
```php
// Safe value assignment
$value = isset($_POST['name']) ? $_POST['name'] : '';

// Direct output in HTML
value="<?php echo isset($_POST['name']) ? htmlspecialchars($_POST['name']) : ''; ?>"
```

### 2. trim() Function

Removes leading and trailing whitespace from a string:

```php
trim($string)
```

**Why use trim():**
- Removes accidental spaces
- Prevents "empty" submissions with only spaces
- Cleans up user input for consistent processing

```php
$name = trim($_POST['name']);
$email = trim($_POST['email']);
```

### 3. $_SERVER['PHP_SELF']

Returns the filename of the currently executing script:

```php
action="<?php echo $_SERVER['PHP_SELF']; ?>"
```

**Benefits:**
- Form works even if file is renamed
- Self-referencing forms
- Portable code

## Advanced Sticky Form Techniques

### 1. Multi-Field Sticky Form

```php
<?php
// Initialize arrays
$fields = ['name', 'email', 'phone', 'address'];
$values = array_fill_keys($fields, '');
$errors = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    foreach ($fields as $field) {
        if (empty($_POST[$field])) {
            $errors[] = $field;
        } else {
            $values[$field] = trim($_POST[$field]);
        }
    }
}
?>

<form action="<?php echo $_SERVER['PHP_SELF']; ?>" method="POST">
    <p>Name:<br>
        <input type="text" name="name" value="<?php echo htmlspecialchars($values['name']); ?>">
    </p>
    <p>Email:<br>
        <input type="text" name="email" value="<?php echo htmlspecialchars($values['email']); ?>">
    </p>
    <p>Phone:<br>
        <input type="text" name="phone" value="<?php echo htmlspecialchars($values['phone']); ?>">
    </p>
    <p>Address:<br>
        <textarea name="address"><?php echo htmlspecialchars($values['address']); ?></textarea>
    </p>
</form>
```

### 4. Sticky Form with File Uploads

```php

if ($_SERVER['REQUEST_METHOD'] === 'POST') {

        <?php endif; ?>
    </p>
    <?php if ($file_error): ?>
        <p style="color: red;"><?php echo $file_error; ?></p>
    <?php endif; ?>
</form>
```

## Error Handling Best Practices

### 1. Structured Error Messages

```php
<?php
$error_messages = [
    'name' => 'Please enter your name',
    'email' => 'Please enter a valid email address',
    'phone' => 'Please enter your phone number',
    'address' => 'Please enter your address'
];

$errors = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    foreach (['name', 'email', 'phone', 'address'] as $field) {
        if (empty($_POST[$field])) {
            $errors[$field] = $error_messages[$field];
        }
    }
}
?>

<!-- Display errors -->
<?php if (!empty($errors)): ?>
    <div class="errors">
        <h3>Please correct the following:</h3>
        <ul>
            <?php foreach ($errors as $error): ?>
                <li><?php echo $error; ?></li>
            <?php endforeach; ?>
        </ul>
    </div>
<?php endif; ?>
```

### 2. Field-Specific Error Display

```php
<?php
$field_errors = ['name' => '', 'email' => ''];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (empty($_POST['name'])) {
        $field_errors['name'] = 'Name is required';
    }
    if (empty($_POST['email'])) {
        $field_errors['email'] = 'Email is required';
    }
}
?>

<p>
    Name:<br>
    <input type="text" name="name" 
           value="<?php echo isset($_POST['name']) ? htmlspecialchars($_POST['name']) : ''; ?>">
    <?php if ($field_errors['name']): ?>
        <span class="error"><?php echo $field_errors['name']; ?></span>
    <?php endif; ?>
</p>
```

## Security Considerations

### 1. Always Sanitize Output

```php
// Good practice
value="<?php echo htmlspecialchars($_POST['name'], ENT_QUOTES, 'UTF-8'); ?>"

// Bad practice (vulnerable to XSS)
value="<?php echo $_POST['name']; ?>"
```

### 2. Validate Server-Side

```php
<?php
// Never trust client-side validation
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = trim($_POST['name'] ?? '');
    $email = trim($_POST['email'] ?? '');
    
    // Server-side validation
    if (strlen($name) < 2) {
        $errors[] = 'Name must be at least 2 characters';
    }
    
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors[] = 'Please enter a valid email address';
    }
}
?>
```

## Common Patterns

### 1. Form Class Approach

```php
<?php
class StickyForm {
    private $fields = [];
    private $values = [];
    private $errors = [];
    
    public function __construct($fields) {
        $this->fields = $fields;
        $this->values = array_fill_keys($fields, '');
    }
    
    public function process($data) {
        foreach ($this->fields as $field) {
            if (empty($data[$field])) {
                $this->errors[$field] = ucfirst($field) . ' is required';
            } else {
                $this->values[$field] = trim($data[$field]);
            }
        }
        return empty($this->errors);
    }
    
    public function getValue($field) {
        return htmlspecialchars($this->values[$field]);
    }
    
    public function getError($field) {
        return $this->errors[$field] ?? '';
    }
}

$form = new StickyForm(['name', 'email']);
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $form->process($_POST);
}
?>
```

## Important Notes

- **trim() Function**: It is good practice to use the `trim()` function to remove any leading and trailing spaces from the submitted field value
- **$_SERVER['PHP_SELF']**: Used to ensure the script will still work if renamed
- **Request Method Check**: The if statement tests that the form has been submitted by checking the request method is POST, not the GET method that is used to display the empty form
- **Security**: Always sanitize output with `htmlspecialchars()` to prevent XSS attacks

Sticky forms are an essential technique for creating user-friendly web applications that handle validation gracefully without frustrating users with data loss.
