# 10.3: Getting Cookies

## Overview

Once cookies are set on the client's machine, they become accessible through PHP's `$_COOKIE` superglobal array. This allows scripts to retrieve stored user data across multiple pages and sessions, enabling personalized experiences and persistent user sessions.

## The $_COOKIE Superglobal Array

The `$_COOKIE` superglobal array automatically contains all cookies sent by the client's browser. Each cookie is stored as a key-value pair where:

- **Key**: The cookie name specified during `setcookie()`
- **Value**: The cookie value stored on the client

### Basic Cookie Retrieval Pattern

```php
<?php
// Check if a specific cookie exists
if (isset($_COOKIE['cookie_name'])) {
    // Retrieve and use the cookie value
    $value = $_COOKIE['cookie_name'];
    echo "Cookie value: $value";
}
?>
```

## Cookie Retrieval Techniques

### 1. Basic isset() Check

```php
<?php
// Check if a specific cookie exists
if (isset($_COOKIE['username'])) {
    $username = $_COOKIE['username'];
    echo "Welcome back, $username!";
} else {
    echo "Please log in first.";
}
?>
```

### 2. Multiple Cookie Validation

```php
<?php
// Check for multiple required cookies
if (isset($_COOKIE['user']) && isset($_COOKIE['session'])) {
    $user = $_COOKIE['user'];
    $session = $_COOKIE['session'];
    
    // Additional validation
    if (validate_session($user, $session)) {
        echo "Valid session for $user";
    }
}
?>
```

### 3. Cookie Value Sanitization

```php
<?php
// Always sanitize cookie values
if (isset($_COOKIE['user_preference'])) {
    $preference = filter_var($_COOKIE['user_preference'], FILTER_SANITIZE_STRING);
    
    // Additional validation
    $valid_themes = ['light', 'dark', 'auto'];
    if (in_array($preference, $valid_themes)) {
        set_theme($preference);
    }
}
?>
```

### 4. Cookie Expiration Check

```php
<?php
// Check if cookie has expired (if expiration stored separately)
if (isset($_COOKIE['login_time'])) {
    $login_time = $_COOKIE['login_time'];
    $current_time = time();
    
    if (($current_time - $login_time) > 3600) { // 1 hour
        echo "Session expired";
        // Clear expired cookies
        setcookie('login_time', '', time() - 3600, '/');
    }
}
?>
```

## Advanced Cookie Operations

### Cookie Array Processing

```php
<?php
// Process multiple related cookies
$user_data = [];
$cookie_prefix = 'user_';

foreach ($_COOKIE as $name => $value) {
    if (strpos($name, $cookie_prefix) === 0) {
        $field = substr($name, strlen($cookie_prefix));
        $user_data[$field] = $value;
    }
}

// Now $user_data contains all user_* cookies
if (!empty($user_data)) {
    echo "User data loaded: " . implode(', ', array_keys($user_data));
}
?>
```

### Cookie Backup and Restore

```php
<?php
// Backup current cookies
function backup_cookies() {
    $backup = [];
    foreach ($_COOKIE as $name => $value) {
        $backup[$name] = [
            'value' => $value,
            'time' => time()
        ];
    }
    return $backup;
}

// Restore cookies from backup
function restore_cookies($backup) {
    foreach ($backup as $name => $data) {
        setcookie($name, $data['value'], time() + 3600, '/');
    }
}
?>
```

## Common Cookie Use Cases

### 1. User Authentication Status

```php
<?php
// Check if user is logged in
function is_user_logged_in() {
    return isset($_COOKIE['user_id']) && isset($_COOKIE['session_token']);
}

// Get current user
function get_current_user() {
    if (is_user_logged_in()) {
        return [
            'id' => $_COOKIE['user_id'],
            'username' => $_COOKIE['username'] ?? 'Unknown'
        ];
    }
    return null;
}
?>
```

### 2. User Preferences

```php
<?php
// Get user theme preference
function get_user_theme() {
    return $_COOKIE['theme'] ?? 'light';
}

// Get user language preference
function get_user_language() {
    $supported = ['en', 'es', 'fr', 'de'];
    $lang = $_COOKIE['language'] ?? 'en';
    return in_array($lang, $supported) ? $lang : 'en';
}
?>
```

### 3. Shopping Cart Management

```php
<?php
// Get shopping cart from cookies
function get_shopping_cart() {
    if (isset($_COOKIE['cart'])) {
        return json_decode($_COOKIE['cart'], true) ?? [];
    }
    return [];
}

// Add item to cart
function add_to_cart($product_id, $quantity = 1) {
    $cart = get_shopping_cart();
    
    if (isset($cart[$product_id])) {
        $cart[$product_id] += $quantity;
    } else {
        $cart[$product_id] = $quantity;
    }
    
    setcookie('cart', json_encode($cart), time() + 86400, '/');
}
?>
```

## Error Handling and Edge Cases

### 1. Missing Cookie Handling

```php
<?php
function get_cookie_safely($name, $default = null) {
    return $_COOKIE[$name] ?? $default;
}

// Usage
$username = get_cookie_safely('username', 'Guest');
$theme = get_cookie_safely('theme', 'light');
?>
```

### 2. Corrupted Cookie Data

```php
<?php
function get_json_cookie($name, $default = []) {
    if (isset($_COOKIE[$name])) {
        $data = json_decode($_COOKIE[$name], true);
        return is_array($data) ? $data : $default;
    }
    return $default;
}

// Usage
$cart = get_json_cookie('cart', []);
?>
```

### 3. Cookie Size Validation

```php
<?php
function validate_cookie_size($name, $max_size = 4096) {
    if (isset($_COOKIE[$name])) {
        $size = strlen($_COOKIE[$name]);
        if ($size > $max_size) {
            error_log("Cookie $name exceeds size limit: $size bytes");
            return false;
        }
    }
    return true;
}
?>
```

### Validation Extensions

```php
<?php
// Extended validation allowing underscores
function validate_username_extended($username) {
    // Allow letters, numbers, and underscores, 3-20 characters
    return preg_match('/^[a-zA-Z0-9_]{3,20}$/', $username);
}

// Password validation with minimum length
function validate_password_strong($password) {
    // Minimum 8 characters, at least one letter and one number
    return strlen($password) >= 8 && 
           preg_match('/[a-zA-Z]/', $password) && 
           preg_match('/[0-9]/', $password);
}

// Usage in cookie_set.php

    }
}
?>
```

## Summary
