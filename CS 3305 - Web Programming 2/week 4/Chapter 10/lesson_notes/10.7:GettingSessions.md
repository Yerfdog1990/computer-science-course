# 10.7: Getting Sessions

## Overview

Getting sessions involves retrieving stored session data from the `$_SESSION` superglobal array after calling `session_start()`. This process enables web applications to maintain user state across multiple pages and provide personalized content based on stored session information.

## Session Access Fundamentals

### Session Prerequisites

1. **session_start() Function**: Must be called before any HTML output
2. **$_SESSION Superglobal**: Automatic availability of session variables
3. **isset() Function**: Check for variable existence before access
4. **Conditional Logic**: Provide alternative content for absent sessions

### Session Retrieval Process

1. **Initialize Session**: Call `session_start()` to load session data
2. **Check Variable**: Use `isset()` to verify session variable exists
3. **Retrieve Data**: Assign session value to regular variable if present
4. **Display Content**: Show personalized content or alternative message
5. **Handle Absence**: Provide fallback when session data is missing

## Session Retrieval Techniques

### 1. Basic Session Access

```php
<?php
session_start();

// Check if session variable exists
if (isset($_SESSION['username'])) {
    // Retrieve and assign to regular variable
    $username = $_SESSION['username'];
    echo "Welcome back, $username!";
} else {
    echo "Please log in first.";
}
?>
```

### 2. Multiple Variable Retrieval

```php
<?php
session_start();

// Check multiple session variables
if (isset($_SESSION['user']) && isset($_SESSION['email'])) {
    $user = $_SESSION['user'];
    $email = $_SESSION['email'];
    echo "User: $user, Email: $email";
} else {
    echo "Incomplete session data.";
}
?>
```

### 3. Safe Variable Access

```php
<?php
session_start();

// Safe access with null coalescing operator
$username = $_SESSION['username'] ?? 'Guest';
$email = $_SESSION['email'] ?? 'not@example.com';
$role = $_SESSION['role'] ?? 'user';

echo "Welcome $username ($role)";
?>
```

### 4. Conditional Session Display

```php
<?php
session_start();

// Different content based on session data
if (isset($_SESSION['role'])) {
    switch ($_SESSION['role']) {
        case 'admin':
            echo "Admin Dashboard";
            break;
        case 'user':
            echo "User Dashboard";
            break;
        default:
            echo "Basic User Area";
    }
} else {
    echo "Please log in to access your dashboard.";
}
?>
```

### 5. Session Validation

```php
<?php
session_start();

// Validate session integrity
function validate_session() {
    if (!isset($_SESSION['login_time'])) {
        return false;
    }
    
    // Check session age (30 minutes timeout)
    $session_age = time() - $_SESSION['login_time'];
    if ($session_age > 1800) {
        return false;
    }
    
    return true;
}

if (validate_session()) {
    $user = $_SESSION['user'];
    echo "Valid session for $user";
} else {
    echo "Session expired or invalid";
}
?>
```

## Advanced Session Operations

### Session Array Processing

```php
<?php
session_start();

// Process all session variables
function process_session_data() {
    $processed = [];
    
    foreach ($_SESSION as $key => $value) {
        switch ($key) {
            case 'user':
                $processed['username'] = htmlspecialchars($value);
                $processed['user_valid'] = ctype_alpha($value);
                break;
            case 'pass':
                $processed['password_length'] = strlen($value);
                $processed['password_valid'] = preg_match('/^[A-Za-z0-9._]{8,}$/', $value);
                break;
            case 'login_time':
                $processed['login_date'] = date('Y-m-d H:i:s', $value);
                $processed['session_duration'] = time() - $value;
                break;
            default:
                $processed[$key] = $value;
        }
    }
    
    return $processed;
}

// Usage
$session_data = process_session_data();
echo "User: " . $session_data['username'];
echo "Session Duration: " . $session_data['session_duration'] . " seconds";
?>
```

### Session Expiration Check

```php
<?php
session_start();

// Check if session has expired
function is_session_expired($timeout_minutes = 30) {
    if (!isset($_SESSION['login_time'])) {
        return true;
    }
    
    $elapsed = time() - $_SESSION['login_time'];
    return $elapsed > ($timeout_minutes * 60);
}

// Auto-logout expired sessions
if (is_session_expired()) {
    session_destroy();
    header('Location: login.php?expired=1');
    exit();
}

// Continue with valid session
$user = $_SESSION['user'];
echo "Welcome back, $user!";
?>
```

## Common Session Access Patterns

### User Authentication Check

```php
<?php
session_start();

function is_user_logged_in() {
    return isset($_SESSION['user']) && isset($_SESSION['login_time']);
}

function get_current_user() {
    return $_SESSION['user'] ?? 'Guest';
}

function require_login() {
    if (!is_user_logged_in()) {
        header('Location: login.php');
        exit();
    }
}

// Usage
if (is_user_logged_in()) {
    $user = get_current_user();
    echo "Welcome, $user!";
} else {
    require_login();
}
?>
```

### User Role Management

```php
<?php
session_start();

function get_user_role() {
    return $_SESSION['role'] ?? 'guest';
}

function has_role($required_role) {
    $user_role = get_user_role();
    
    $role_hierarchy = [
        'guest' => 0,
        'user' => 1,
        'moderator' => 2,
        'admin' => 3
    ];
    
    return $role_hierarchy[$user_role] >= $role_hierarchy[$required_role];
}

// Usage
if (has_role('admin')) {
    echo "Admin content";
} elseif (has_role('user')) {
    echo "User content";
} else {
    echo "Guest content";
}
?>
```

### Session Data Caching

```php
<?php
session_start();

// Cache frequently accessed session data
function cache_session_data() {
    if (!isset($_SESSION['cache'])) {
        $_SESSION['cache'] = [];
    }
    
    // Cache user data
    if (isset($_SESSION['user']) && !isset($_SESSION['cache']['user_info'])) {
        $_SESSION['cache']['user_info'] = [
            'username' => $_SESSION['user'],
            'display_name' => ucfirst($_SESSION['user']),
            'is_valid' => ctype_alpha($_SESSION['user'])
        ];
    }
    
    return $_SESSION['cache']['user_info'] ?? [];
}

// Usage
$user_info = cache_session_data();
echo "Welcome, " . $user_info['display_name'];
?>
```

## Security Considerations

### 1. Data Validation

```php
<?php
session_start();

// Always validate session data before use
function get_safe_session_data($key, $type = 'string') {
    if (!isset($_SESSION[$key])) {
        return null;
    }
    
    $value = $_SESSION[$key];
    
    switch ($type) {
        case 'alpha':
            return ctype_alpha($value) ? $value : null;
        case 'alphanumeric':
            return ctype_alnum($value) ? $value : null;
        case 'email':
            return filter_var($value, FILTER_VALIDATE_EMAIL) ? $value : null;
        case 'int':
            return filter_var($value, FILTER_VALIDATE_INT) ? $value : null;
        default:
            return htmlspecialchars($value, ENT_QUOTES, 'UTF-8');
    }
}

// Usage
$username = get_safe_session_data('user', 'alpha');
$email = get_safe_session_data('email', 'email');
?>
```

### 2. Session Timeout

```php
<?php
session_start();

// Implement session timeout
function check_session_timeout($timeout_minutes = 30) {
    if (!isset($_SESSION['last_activity'])) {
        $_SESSION['last_activity'] = time();
        return true;
    }
    
    $inactive = time() - $_SESSION['last_activity'];
    
    if ($inactive > ($timeout_minutes * 60)) {
        session_destroy();
        return false;
    }
    
    $_SESSION['last_activity'] = time();
    return true;
}

// Usage on each page
if (!check_session_timeout()) {
    header('Location: login.php?timeout=1');
    exit();
}
?>
```

### 3. Session Hijacking Prevention

```php
<?php
session_start();

// Validate session integrity
function validate_session_integrity() {
    if (!isset($_SESSION['ip_address']) || !isset($_SESSION['user_agent'])) {
        return false;
    }
    
    if ($_SESSION['ip_address'] !== $_SERVER['REMOTE_ADDR']) {
        return false;
    }
    
    if ($_SESSION['user_agent'] !== $_SERVER['HTTP_USER_AGENT']) {
        return false;
    }
    
    return true;
}

// Usage
if (!validate_session_integrity()) {
    session_destroy();
    header('Location: login.php?security=1');
    exit();
}
?>
```

## Troubleshooting

### Common Issues

1. **Session Not Accessible**
   - Ensure `session_start()` is called before any output
   - Check if session file exists in session.save_path
   - Verify browser has cookies enabled

2. **Empty Session Variables**
   - Check if variables were properly stored in `session_set.php`
   - Verify session ID is consistent across pages
   - Test with `print_r($_SESSION)` for debugging

3. **Session Lost on Redirect**
   - Ensure `session_start()` is called on destination page
   - Check for session.cookie_path configuration
   - Verify domain settings match

4. **Validation Failures**
   - Test with known good data
   - Check for whitespace issues (use `trim()`)
   - Verify regular expression patterns

## Summary

Getting sessions involves:

- **Session Initialization**: Call `session_start()` before any output
- **Variable Checking**: Use `isset()` to verify session variable existence
- **Data Retrieval**: Assign session values to regular variables
- **Conditional Display**: Provide content based on session presence
- **Alternative Content**: Handle cases where session data is missing
- **Data Validation**: Ensure retrieved data is safe and valid
- **Security Management**: Implement timeout and integrity checks

Key functions:
- **session_start()**: Initialize session and load stored data
- **isset()**: Check if session variable exists
- **$_SESSION**: Access stored session variables
- **empty()**: Check if session array is empty
- **count()**: Count number of session variables

This approach provides reliable access to stored session data while maintaining security and providing appropriate fallback behavior when sessions are not available.
