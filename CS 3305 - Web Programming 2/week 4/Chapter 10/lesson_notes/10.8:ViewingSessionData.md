# 10.8: Viewing Session Data

## Overview

Viewing session data involves examining the contents of the `$_SESSION` superglobal array, which stores session variables as key-value pairs. This process enables developers to debug session management, monitor stored data, and implement proper session cleanup procedures.

## Session Data Structure

### $_SESSION Associative Array

The `$_SESSION` superglobal is an associative array that stores:

- **Keys**: String identifiers for session variables
- **Values**: Stored data (strings, numbers, arrays, objects)
- **Session ID**: Unique identifier for each session instance
- **Global Access**: Available across all pages with active sessions

### Array Characteristics

```php
<?php
$_SESSION = [
    'user' => 'John',
    'pass' => 'password123',
    'login_time' => 1645123456,
    'ip_address' => '192.168.1.100'
];
?>
```

### 3. Session Cleanup with Cookie Removal

```php
<?php
session_start();

// Complete session cleanup
function complete_session_cleanup() {
    // Get session cookie parameters
    $params = session_get_cookie_params();
    
    // Remove all session variables
    $_SESSION = [];
    
    // Destroy session data
    session_destroy();
    
    // Delete session cookie
    setcookie(session_name(), '', time() - 42000,
        $params["path"], $params["domain"],
        $params["secure"], $params["httponly"]
    );
    
    echo "<p>Session completely cleaned up</p>";
}

complete_session_cleanup();
?>
```

## Advanced Session Analysis

### 1. Session Data Validation

```php
<?php
session_start();

// Validate session data integrity
function validate_session_data() {
    $issues = [];
    
    foreach ($_SESSION as $key => $value) {
        // Check for empty values
        if (empty($value)) {
            $issues[] = "Empty value for key: $key";
        }
        
        // Check data types
        if ($key === 'login_time' && !is_numeric($value)) {
            $issues[] = "Invalid timestamp for login_time";
        }
        
        // Check string lengths
        if ($key === 'user' && strlen($value) > 50) {
            $issues[] = "Username too long";
        }
    }
    
    return $issues;
}

$validation_issues = validate_session_data();
if (!empty($validation_issues)) {
    echo "<h3>Session Validation Issues:</h3>";
    foreach ($validation_issues as $issue) {
        echo "<p>⚠️ $issue</p>";
    }
} else {
    echo "<p>✅ Session data is valid</p>";
}
?>
```

### 2. Session Statistics

```php
<?php
session_start();

// Calculate session statistics
function get_session_statistics() {
    $stats = [];
    
    $stats['total_variables'] = count($_SESSION);
    $stats['total_size'] = array_sum(array_map('strlen', $_SESSION));
    $stats['largest_variable'] = '';
    $stats['largest_size'] = 0;
    
    foreach ($_SESSION as $key => $value) {
        $size = strlen($value);
        if ($size > $stats['largest_size']) {
            $stats['largest_size'] = $size;
            $stats['largest_variable'] = $key;
        }
    }
    
    $stats['average_size'] = $stats['total_variables'] > 0 ? 
        $stats['total_size'] / $stats['total_variables'] : 0;
    
    return $stats;
}

$session_stats = get_session_statistics();

echo "<h3>Session Statistics:</h3>";
echo "<p>Total Variables: " . $session_stats['total_variables'] . "</p>";
echo "<p>Total Size: " . $session_stats['total_size'] . " bytes</p>";
echo "<p>Largest Variable: " . $session_stats['largest_variable'] . 
     " (" . $session_stats['largest_size'] . " bytes)</p>";
echo "<p>Average Size: " . round($session_stats['average_size'], 2) . " bytes</p>";
?>
```

### 3. Session Data Export

```php
<?php
session_start();

// Export session data to different formats
function export_session_data($format = 'json') {
    switch ($format) {
        case 'json':
            return json_encode($_SESSION, JSON_PRETTY_PRINT);
            
        case 'serialize':
            return serialize($_SESSION);
            
        case 'array':
            return print_r($_SESSION, true);
            
        case 'csv':
            $output = "Key,Value,Type,Size\n";
            foreach ($_SESSION as $key => $value) {
                $output .= "$key,\"$value\"," . gettype($value) . "," . strlen($value) . "\n";
            }
            return $output;
            
        default:
            return "Unknown format: $format";
    }
}

// Display exported data
echo "<h3>Session Data (JSON):</h3>";
echo "<pre>" . export_session_data('json') . "</pre>";

echo "<h3>Session Data (CSV):</h3>";
echo "<pre>" . export_session_data('csv') . "</pre>";
?>
```

## Implementation Steps

1. **Initialize Session**: Call `session_start()` before any HTML output
2. **Check Session Data**: Use `count()` or `empty()` to verify session exists
3. **Loop Through Variables**: Use `foreach` to iterate over `$_SESSION` array
4. **Display Key-Value Pairs**: Show variable names and corresponding values
5. **Show Session ID**: Use `session_id()` to display unique identifier
6. **Debug with var_dump()**: Use `var_dump()` for detailed array structure
7. **Remove Variables**: Use `unset()` to remove specific session variables
8. **Destroy Session**: Use `session_destroy()` to terminate session completely
9. **Handle Absence**: Provide alternative content when session is empty

## Security Considerations

### 1. Data Exposure Prevention

```php
<?php
session_start();

// Sanitize output to prevent XSS
function safe_session_output($key, $value) {
    echo "<p><strong>" . htmlspecialchars($key) . ":</strong> ";
    
    // Mask sensitive data
    if ($key === 'pass' || $key === 'password') {
        echo str_repeat('*', strlen($value));
    } else {
        echo htmlspecialchars($value);
    }
    echo "</p>";
}

foreach ($_SESSION as $key => $value) {
    safe_session_output($key, $value);
}
?>
```

### 2. Session Validation

```php
<?php
session_start();

// Validate session before displaying
function validate_session_for_display() {
    // Check session age
    if (isset($_SESSION['login_time'])) {
        $age = time() - $_SESSION['login_time'];
        if ($age > 3600) { // 1 hour
            return false; // Session too old
        }
    }
    
    // Check required variables
    if (!isset($_SESSION['user'])) {
        return false; // Missing user data
    }
    
    return true;
}

if (validate_session_for_display()) {
    // Display session data
} else {
    // Reject or destroy invalid session
    session_destroy();
}
?>
```

## Troubleshooting

### Common Issues

1. **Empty Session Array**
   - Ensure `session_start()` is called on all pages
   - Check browser cookie settings
   - Verify session.save_path permissions

2. **Session Not Destroying**
   - Use `session_unset()` before `session_destroy()`
   - Clear session cookies manually
   - Check for session_write_close() interference

3. **var_dump() Not Working**
   - Ensure output buffering is enabled
   - Check for HTML entities in output
   - Use `<pre>` tags for proper formatting

4. **Session ID Not Changing**
   - Use `session_regenerate_id()` for new ID
   - Clear browser cookies
   - Check session.cookie_lifetime settings

## Summary

Viewing session data involves:

- **Array Structure**: Understanding `$_SESSION` as key-value pairs
- **Data Access**: Using loops and `var_dump()` to examine contents
- **Session ID**: Unique identifier via `session_id()` function
- **Variable Management**: Adding, modifying, and removing session variables
- **Session Destruction**: Using `unset()` and `session_destroy()` for cleanup
- **Data Isolation**: Each session is unique and isolated from others
- **Debugging Tools**: Various functions for session analysis and troubleshooting

Key functions:
- **session_id()**: Get unique session identifier
- **var_dump()**: Display detailed array structure
- **unset()**: Remove specific session variables
- **session_destroy()**: Completely terminate session
- **count()**: Count number of session variables
- **empty()**: Check if session array is empty

This approach provides comprehensive session data viewing capabilities while maintaining security and enabling effective debugging of session management issues.
