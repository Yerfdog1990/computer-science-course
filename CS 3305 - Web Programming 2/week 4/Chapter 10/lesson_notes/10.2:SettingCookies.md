# 10.2: Setting Cookies

## Overview

Setting cookies involves validating form data, processing it securely, and storing it on the client's machine for future use. This process requires careful validation, proper error handling, and secure storage practices to ensure data integrity and user security.

## Form Validation and Processing

When receiving form submissions, PHP scripts should always validate input before storing it in cookies. The `ctype_alnum()` function is particularly useful for ensuring that usernames and other identifiers contain only alphanumeric characters.

### The ctype_alnum() Function

The `ctype_alnum()` function checks if all characters in a string are alphanumeric (letters and numbers):

```php
ctype_alnum(string $string): bool
```

- **Returns**: `true` if string contains only alphanumeric characters, `false` otherwise
- **Parameters**: String to test
- **Use Case**: Validating usernames, IDs, codes

### The md5() Function

For password security, the `md5()` function creates a hash of the password:

```php
md5(string $string): string
```

- **Returns**: 32-character hexadecimal hash
- **Parameters**: String to hash
- **Use Case**: Storing password hashes instead of plain text
- **Security Note**: MD5 is considered weak for modern applications

## Advanced Validation Techniques

### Multiple Validation Rules

```php
<?php
function validate_username($username) {
    // Length validation
    if (strlen($username) < 3 || strlen($username) > 20) {
        return false;
    }
    
    // Alphanumeric check
    if (!ctype_alnum($username)) {
        return false;
    }
    
    // Reserved names check
    $reserved = ['admin', 'root', 'system', 'guest'];
    if (in_array(strtolower($username), $reserved)) {
        return false;
    }
    
    return true;
}

function validate_password($password) {
    // Length validation
    if (strlen($password) < 6 || strlen($password) > 50) {
        return false;
    }
    
    // Character diversity check
    $has_letter = preg_match('/[a-zA-Z]/', $password);
    $has_number = preg_match('/[0-9]/', $password);
    
    if (!$has_letter || !$has_number) {
        return false;
    }
    
    return true;
}
?>
```

### Enhanced Error Handling

```php
<?php
function handle_validation_error($field, $message) {
    $_SESSION['validation_errors'][] = [
        'field' => $field,
        'message' => $message,
        'time' => date('Y-m-d H:i:s')
    ];
    
    // Log error for debugging
    error_log("Validation Error: $field - $message");
    
    // Return user-friendly response
    echo json_encode([
        'success' => false,
        'error' => $message,
        'field' => $field
    ]);
    exit();
}
?>
```

### 2. Secure Password Handling

```php
<?php
// Modern approach using password_hash()
if (isset($_POST['password'])) {
    $password = $_POST['password'];
    
    // Use secure hashing
    $hashed_password = password_hash($password, PASSWORD_DEFAULT);
    
    // Store hash instead of MD5
    setcookie('password_hash', $hashed_password, time() + 3600, '/', true, true);
}

// Verification
if (isset($_COOKIE['password_hash']) && isset($_POST['login_password'])) {
    $login_password = $_POST['login_password'];
    $stored_hash = $_COOKIE['password_hash'];
    
    if (password_verify($login_password, $stored_hash)) {
        echo "Login successful!";
    }
}

```

## Troubleshooting

### Common Issues

1. **ctype_alnum() Not Working**
   - Check if string contains only ASCII characters
   - Verify no whitespace or special characters
   - Ensure proper string encoding

2. **Cookies Not Setting**
   - Check for output before setcookie() calls
   - Verify proper parameter order
   - Ensure browser accepts cookies

3. **MD5 Hash Issues**
   - Verify input is string type
   - Check for empty strings
   - Consider using modern hashing methods
