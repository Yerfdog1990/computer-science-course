# 10.4: Viewing Cookie Data

## Overview

Viewing cookie data involves inspecting the contents of the `$_COOKIE` superglobal array to understand what cookies are currently stored on the client's browser. This is essential for debugging, user management, and understanding the state of web applications.

## The $_COOKIE Global Array

The `$_COOKIE` superglobal is an associative array that automatically contains all cookies sent by the client's browser. Each cookie is stored as a key-value pair where:

- **Key**: The cookie name specified when the cookie was set
- **Value**: The cookie data stored on the client machine

### Array Structure

```php
$_COOKIE = [
    'user' => 'john123',
    'pass' => '5d41402abc4b2a76b9719d911017c592',
    'theme' => 'dark',
    'language' => 'en'
];
```

### 4. Filtered Cookie Display

```php
<?php
// Display cookies with filtering
function display_cookie_safely($name, $max_length = 20) {
    if (isset($_COOKIE[$name])) {
        $value = $_COOKIE[$name];
        
        // Truncate long values
        if (strlen($value) > $max_length) {
            $value = substr($value, 0, $max_length) . '...';
        }
        
        // Escape HTML special characters
        return htmlspecialchars($value);
    }
    return 'Not set';
}

// Usage
echo 'Username: ' . display_cookie_safely('user');
echo 'Password: ' . display_cookie_safely('pass', 8) . '...';
?>
```

## Cookie Management Operations

### Creating New Cookies

```php
<?php
// Create a new cookie at any time
setcookie('theme', 'dark', time() + 86400, '/'); // 24 hours

// Overwrite existing cookie
setcookie('user', 'new_username', time() + 3600, '/'); // 1 hour

// Create multiple related cookies
$user_preferences = [
    'theme' => 'dark',
    'language' => 'en',
    'timezone' => 'UTC'
];

foreach ($user_preferences as $name => $value) {
    setcookie('pref_' . $name, $value, time() + 2592000, '/'); // 30 days
}
?>
```

### Removing Cookies

```php
<?php
// Method 1: Set empty value with past expiration
setcookie('user', '', time() - 3600, '/');

// Method 2: Use specific cookie name
setcookie($_COOKIE['user'], '', time() - 3600, '/');

// Method 3: Remove multiple cookies
$cookies_to_remove = ['user', 'pass', 'theme'];
foreach ($cookies_to_remove as $cookie_name) {
    setcookie($cookie_name, '', time() - 3600, '/');
}

// Method 4: Clear all cookies for current domain
foreach ($_COOKIE as $name => $value) {
    setcookie($name, '', time() - 3600, '/');
}
?>
```

### Using unset() for Variables

```php
<?php
// Clear local variables (not browser cookies)
$user_cookie = $_COOKIE['user'] ?? null;
unset($user_cookie);
echo '$user_cookie is now: ' . ($user_cookie ?? 'undefined');

// Clear array of cookie data
$all_cookies = $_COOKIE;
unset($all_cookies);
echo '$all_cookies array is now empty';
?>
```

## Advanced Cookie Viewing

### Cookie Analysis Functions

```php
<?php
// Analyze cookie contents
function analyze_cookies() {
    $analysis = [
        'total_cookies' => count($_COOKIE),
        'total_size' => 0,
        'types' => [],
        'security_issues' => []
    ];
    
    foreach ($_COOKIE as $name => $value) {
        $analysis['total_size'] += strlen($value);
        
        // Categorize cookie types
        if (strpos($name, 'pass') !== false) {
            $analysis['types'][] = 'Password/Authentication';
        } elseif (strpos($name, 'theme') !== false || strpos($name, 'pref') !== false) {
            $analysis['types'][] = 'User Preference';
        } elseif (strpos($name, 'cart') !== false) {
            $analysis['types'][] = 'Shopping Cart';
        } else {
            $analysis['types'][] = 'Other';
        }
        
        // Check for security issues
        if (strlen($value) > 4000) {
            $analysis['security_issues'][] = "Cookie $name exceeds 4KB limit";
        }
        
        if (!ctype_print($value)) {
            $analysis['security_issues'][] = "Cookie $name contains non-printable characters";
        }
    }
    
    return $analysis;
}

// Usage
$cookie_analysis = analyze_cookies();
echo "Total cookies: " . $cookie_analysis['total_cookies'];
echo "Total size: " . $cookie_analysis['total_size'] . " bytes";
echo "Cookie types: " . implode(', ', array_unique($cookie_analysis['types']));
?>
```

### Cookie Comparison Tool

```php
<?php
// Compare current cookies with expected values
function validate_cookie_session($expected_user, $expected_pass_hash) {
    $issues = [];
    
    // Check user cookie
    if (!isset($_COOKIE['user'])) {
        $issues[] = 'User cookie missing';
    } elseif ($_COOKIE['user'] !== $expected_user) {
        $issues[] = 'User cookie value mismatch';
    }
    
    // Check password cookie
    if (!isset($_COOKIE['pass'])) {
        $issues[] = 'Password cookie missing';
    } elseif ($_COOKIE['pass'] !== $expected_pass_hash) {
        $issues[] = 'Password cookie hash mismatch';
    }
    
    return $issues;
}

// Usage
$validation_issues = validate_cookie_session('john123', '5d41402abc4b2a76b9719d911017c592');
if (empty($validation_issues)) {
    echo '✅ Cookie session is valid';
} else {
    echo '❌ Cookie validation issues:';
    foreach ($validation_issues as $issue) {
        echo "- $issue";
    }
}
?>
```

## Browser Cookie Management

### Clearing Cookies via Browser Settings

1. **Chrome**
   - Settings → Privacy and security → Clear browsing data
   - Select "Cookies and other site data"
   - Choose time range and clear

2. **Firefox**
   - Options → Privacy & Security → Clear Recent History
   - Select "Cookies" and choose time range

3. **Safari**
   - Develop menu → Show Web Inspector
   - Storage → Cookies → Right-click → Delete

4. **Edge**
   - Settings → Privacy, search, and services → Clear browsing data
   - Select "Cookies and saved website data"

### Developer Tools Cookie Inspection

```javascript
// Browser Console - View all cookies
console.log(document.cookie);

// Browser Console - Parse cookies
function parseCookies() {
    const cookies = {};
    document.cookie.split(';').forEach(cookie => {
        const [name, value] = cookie.trim().split('=');
        if (name && value) {
            cookies[name] = value;
        }
    });
    return cookies;
}
```

## Security Considerations

### 1. Data Exposure

```php
<?php
// Secure cookie display
function display_cookie_securely($name, $show_full = false) {
    if (isset($_COOKIE[$name])) {
        $value = $_COOKIE[$name];
        
        // Never show full sensitive data
        if (!$show_full && in_array($name, ['pass', 'token', 'session'])) {
            return substr($value, 0, 4) . '...';
        }
        
        return htmlspecialchars($value);
    }
    return 'Not set';
}
?>
```

### 2. Access Control

```php
<?php
// Check cookie access permissions
function can_access_cookie($name, $user_role = 'guest') {
    $restricted_cookies = ['admin_token', 'session_id', 'auth_hash'];
    
    if (in_array($name, $restricted_cookies) && $user_role !== 'admin') {
        return false;
    }
    
    return true;
}

// Usage
if (can_access_cookie('admin_token', $_COOKIE['user_role'] ?? 'guest')) {
    echo $_COOKIE['admin_token'];
} else {
    echo 'Access denied';
}
?>
```

### 3. Integrity Verification

```php
<?php
// Verify cookie integrity with checksum
function verify_cookie_integrity($name) {
    if (!isset($_COOKIE[$name])) {
        return false;
    }
    
    $value = $_COOKIE[$name];
    $checksum = $_COOKIE[$name . '_checksum'] ?? null;
    
    if ($checksum === null) {
        return true; // No checksum available
    }
    
    return hash('sha256', $value) === $checksum;
}

// Set cookie with integrity check
$cookie_value = 'sensitive_data';
$checksum = hash('sha256', $cookie_value);
setcookie('data', $cookie_value, time() + 3600, '/');
setcookie('data_checksum', $checksum, time() + 3600, '/');
?>
```

## Troubleshooting

### Common Issues

1. **Cookies Not Displaying**
   - Check if any cookies are actually set
   - Verify page is accessed via HTTP (not file://)
   - Ensure browser hasn't disabled cookies

2. **Empty Array Output**
   - Check cookie expiration times
   - Verify cookie path and domain settings
   - Test with different browsers

3. **var_dump() Showing Empty**
   - Confirm cookies are set with correct names
   - Check for cookie size limitations
   - Verify server configuration

4. **Cookie Removal Not Working**
   - Ensure expiration time is in the past
   - Check cookie path and domain match
   - Try multiple removal methods
