# 10.6: Setting Sessions

## Overview

Setting sessions involves validating form submission data and storing it in the `$_SESSION` superglobal array for server-side persistence. This process ensures data integrity before storage and provides secure user state management across multiple pages.

## Session Validation Process

### Validation Steps

1. **Form Submission Check**: Verify data was submitted via POST method
2. **Field Presence**: Check required fields exist using `isset()`
3. **Data Validation**: Apply validation functions to ensure data quality
4. **Session Storage**: Store validated data in `$_SESSION` array
5. **Redirection**: Redirect to next page using `header()` function

### Validation Functions

#### ctype_alpha() Function

The `ctype_alpha()` function validates that a string contains only alphabetic characters (A-Z, a-z).

```php
<?php
// Returns true if string contains only letters
ctype_alpha('John');     // true
ctype_alpha('John123');  // false
ctype_alpha('John_Doe'); // false
ctype_alpha('');         // false
?>
```

#### preg_match() Function

The `preg_match()` function performs regular expression matching against a string.

```php
<?php
// Password validation pattern
$pattern = '/^[A-Za-z0-9._]{8,}$/';
preg_match($pattern, 'password123');  // true
preg_match($pattern, 'pass');          // false (too short)
preg_match($pattern, 'Password!');     // false (contains !)
?>
```

## Session Data Techniques

### 1. Basic Session Setting

```php
<?php
session_start();

// Set session variables
$_SESSION['username'] = 'john_doe';
$_SESSION['email'] = 'john@example.com';
$_SESSION['role'] = 'user';
$_SESSION['login_time'] = time();
?>
```

### 2. Validation with ctype_alpha()

```php
<?php
session_start();

// Validate username contains only letters
$username = trim($_POST['username']);
if (ctype_alpha($username)) {
    $_SESSION['username'] = $username;
    echo "Username is valid: $username";
} else {
    echo "Username must contain only letters";
}
?>
```

### 3. Pattern Validation with preg_match()

```php
<?php
session_start();

// Password validation patterns
$password_patterns = [
    'basic' => '/^[A-Za-z0-9._]{8,}$/',           // Letters, numbers, dots, underscores, min 8
    'strong' => '/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d]{8,}$/', // At least one lowercase, uppercase, number
    'very_strong' => '/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/' // Plus special character
];

$password = trim($_POST['password']);
if (preg_match($password_patterns['basic'], $password)) {
    $_SESSION['password'] = $password;
    echo "Password meets basic requirements";
} else {
    echo "Password must be at least 8 characters with letters, numbers, dots, and underscores";
}
?>
```

### 4. Header Redirection

```php
<?php
session_start();

// After successful validation and session storage
$_SESSION['user'] = $validated_user;
$_SESSION['pass'] = $validated_password;

// Redirect to next page
header('Location: dashboard.admin');
exit(); // Always call exit() after header()

// Conditional redirection based on user role
if ($_SESSION['role'] === 'admin') {
    header('Location: admin_dashboard.admin');
} else {
    header('Location: user_dashboard.admin');
}
exit();
?>
```

### 5. Error Handling Functions

```php
<?php
session_start();

// Comprehensive error handling function
function handle_validation_error($field, $message, $redirect_page = 'form.html') {
    // Log the error
    error_log("Validation Error: $field - $message");
    
    // Store error in session for display on next page
    $_SESSION['error'] = [
        'field' => $field,
        'message' => $message,
        'timestamp' => time()
    ];
    
    // Redirect back to form
    header("Location: $redirect_page");
    exit();
}

// Usage
$username = trim($_POST['username']);
if (!ctype_alpha($username)) {
    handle_validation_error('username', 'Username must contain only letters');
}
?>
```

## Advanced Session Validation

### Multiple Field Validation

```php
<?php
session_start();

// Validate multiple form fields
function validate_form_data($data) {
    $errors = [];
    
    // Username validation
    if (!isset($data['username']) || !ctype_alpha($data['username'])) {
        $errors[] = 'Username must contain only letters';
    }
    
    // Password validation
    if (!isset($data['password']) || !preg_match('/^[A-Za-z0-9._]{8,}$/', $data['password'])) {
        $errors[] = 'Password must be at least 8 characters with letters, numbers, dots, and underscores';
    }
    
    // Email validation
    if (!isset($data['email']) || !filter_var($data['email'], FILTER_VALIDATE_EMAIL)) {
        $errors[] = 'Valid email address is required';
    }
    
    return $errors;
}

// Usage
$form_data = $_POST;
$validation_errors = validate_form_data($form_data);

if (empty($validation_errors)) {
    // Store all valid data in session
    $_SESSION['user_data'] = $form_data;
    $_SESSION['validated'] = true;
    header('Location: success.admin');
} else {
    // Store errors for display
    $_SESSION['errors'] = $validation_errors;
    header('Location: form.admin?error=1');
}
exit();
?>
```

### Session Data Sanitization

```php
<?php
session_start();

// Sanitize and validate input data
function sanitize_and_validate($input, $type) {
    switch ($type) {
        case 'alpha':
            $sanitized = trim($input);
            return ctype_alpha($sanitized) ? $sanitized : false;
            
        case 'alphanumeric':
            $sanitized = trim($input);
            return ctype_alnum($sanitized) ? $sanitized : false;
            
        case 'password':
            $sanitized = trim($input);
            return preg_match('/^[A-Za-z0-9._]{8,}$/', $sanitized) ? $sanitized : false;
            
        case 'email':
            $sanitized = filter_var(trim($input), FILTER_SANITIZE_EMAIL);
            return filter_var($sanitized, FILTER_VALIDATE_EMAIL) ? $sanitized : false;
            
        default:
            return false;
    }
}

// Usage
$username = sanitize_and_validate($_POST['username'], 'alpha');
$password = sanitize_and_validate($_POST['password'], 'password');
$email = sanitize_and_validate($_POST['email'], 'email');

if ($username && $password && $email) {
    $_SESSION['user'] = $username;
    $_SESSION['pass'] = $password;
    $_SESSION['email'] = $email;
    header('Location: profile.admin');
} else {
    header('Location: login.admin?invalid=1');
}
exit();
?>
```

### Session Security Enhancement

```php
<?php
session_start();

// Secure session setting with additional validation
function secure_session_set($key, $value, $validation_rules = []) {
    // Apply validation rules if provided
    if (!empty($validation_rules)) {
        foreach ($validation_rules as $rule => $parameter) {
            switch ($rule) {
                case 'max_length':
                    if (strlen($value) > $parameter) return false;
                    break;
                case 'min_length':
                    if (strlen($value) < $parameter) return false;
                    break;
                case 'pattern':
                    if (!preg_match($parameter, $value)) return false;
                    break;
                case 'type':
                    if (gettype($value) !== $parameter) return false;
                    break;
            }
        }
    }
    
    // Store in session with timestamp
    $_SESSION[$key] = [
        'value' => $value,
        'set_time' => time(),
        'validated' => true
    ];
    
    return true;
}

// Usage
$success = secure_session_set('username', $_POST['username'], [
    'max_length' => 50,
    'pattern' => '/^[A-Za-z]+$/',
    'type' => 'string'
]);

if ($success) {
    header('Location: dashboard.admin');
} else {
    header('Location: login.admin?error=validation');
}
exit();
?>
```

## Implementation Steps

1. **Initialize Session**: Call `session_start()` before any HTML output
2. **Check Form Submission**: Verify data was sent via POST method
3. **Validate Fields**: Use appropriate validation functions for each field
4. **Handle Errors**: Use rejection functions for invalid data
5. **Store Valid Data**: Assign validated data to `$_SESSION` array
6. **Redirect User**: Use `header()` function to redirect to next page
7. **Exit Script**: Always call `exit()` after header redirection

## Common Validation Patterns

### Username Validation

```php
<?php
// Letters only
ctype_alpha($username)

// Letters and numbers only
ctype_alnum($username)

// Letters, numbers, underscores, hyphens
preg_match('/^[a-zA-Z0-9_-]+$/', $username)

// Email format
filter_var($email, FILTER_VALIDATE_EMAIL)
?>
```

### Password Validation

```php
<?php
// Basic: letters, numbers, dots, underscores, min 8 chars
preg_match('/^[A-Za-z0-9._]{8,}$/', $password)

// Strong: at least one lowercase, uppercase, number
preg_match('/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/', $password)

// Very strong: plus special character
preg_match('/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&]).{8,}$/', $password)
?>
```

### Numeric Validation

```php
<?php
// Integer only
ctype_digit($number)

// Positive integer
filter_var($number, FILTER_VALIDATE_INT, ['options' => ['min_range' => 1]])

// Float number
filter_var($number, FILTER_VALIDATE_FLOAT)

// Phone number format
```

## Troubleshooting

### Common Issues

1. **"Headers already sent" Error**
   - Ensure `session_start()` is called before any HTML output
   - Check for whitespace before PHP opening tag
   - Verify no echo/print statements before session functions

2. **Session Data Not Persisting**
   - Check if `session_start()` is called on all pages
   - Verify session.save_path is writable
   - Check browser cookie settings

3. **Validation Not Working**
   - Verify regular expression patterns are correct
   - Check for whitespace in input strings (use trim())
   - Test validation functions with known good/bad data

4. **Redirection Not Working**
   - Ensure no output before `header()` call
   - Use absolute URLs in Location header
   - Always call `exit()` after `header()`

## Summary

Setting sessions involves:

- **Session Initialization**: Call `session_start()` before any output
- **Form Validation**: Use `ctype_alpha()` and `preg_match()` for data validation
- **Error Handling**: Implement rejection functions for invalid data
- **Session Storage**: Store validated data in `$_SESSION` array
- **User Redirection**: Use `header()` function to redirect to next page

Key validation functions:
- **ctype_alpha()**: Validates alphabetic characters only
- **preg_match()**: Validates using regular expression patterns
- **isset()**: Checks for field presence
- **trim()**: Removes whitespace from input
- **header()**: Redirects to specified URL

This approach ensures data integrity before session storage and provides a secure, reliable method for managing user state across multiple pages.
