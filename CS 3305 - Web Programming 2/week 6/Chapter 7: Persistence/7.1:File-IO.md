# PHP File I/O & Filesystem Operations

## Why Filesystem Operations Matter

Filesystem operations are among the most important in programming. Nearly every PHP application touches the filesystem in some form:

- **Session data storage** — PHP stores session data on disk by default
- **User-uploaded files** — profile pictures, documents, imports
- **Generated report files** — PDFs, CSVs, exports
- **Cached data** — pre-rendered HTML or serialized objects
- **Logs** — error logs, access logs, audit trails

The filesystem is available virtually everywhere and requires no additional installation or infrastructure. Unlike databases or caches, it's always present and ready to use.

---

## Knowing Where Your Script Lives

When working with the filesystem, you often need to reference files *relative to the script's location*, not relative to wherever the script is run from.

**The problem:** if a script lives at `/app/demo/script.php` but is executed from `/root`, a relative path like `source/data.csv` resolves to `/root/source/data.csv` — not `/app/demo/source/data.csv`.

**The solution:** PHP's magic constants.

### PHP Magic Constants

Magic constants are special values whose content changes depending on where they are used:

| Constant | Description |
|---|---|
| `__DIR__` | The directory of the current script file |
| `__FILE__` | The full path and filename of the current script |
| `__LINE__` | The current line number in the file |
| `__FUNCTION__` | The name of the current function |
| `__CLASS__` | The name of the current class |
| `__METHOD__` | The name of the current class method |
| `__NAMESPACE__` | The name of the current namespace |

For filesystem work, `__DIR__` is the most useful. To reliably reference a `source/` folder next to your script:

```php
$lookupDir = __DIR__ . '/source';
```

This works correctly regardless of the directory you call `php` from.

### `DIRECTORY_SEPARATOR`

PHP also provides the `DIRECTORY_SEPARATOR` constant, which automatically uses the correct path separator for the host OS:

- **Windows:** `\`
- **Linux / macOS:** `/`

Use it when writing cross-platform scripts:

```php
$path = __DIR__ . DIRECTORY_SEPARATOR . 'sample' . DIRECTORY_SEPARATOR . 'data.csv';
```

## Reading Files

PHP provides multiple approaches to reading files, each suited to different file sizes and use cases.

### 1. `file_get_contents()` — Simple, All-at-Once Read

The simplest way to read a file: load its entire contents into a string.

```php
file_get_contents(
    string $filename,
    bool $use_include_path = false,
    resource $context = null,
    int $offset = 0,
    int $maxlen = null
): string|false
```

| Parameter | Required | Description |
|---|---|---|
| `$filename` | Yes | Path to the file to read |
| `$use_include_path` | No | If `true`, searches PHP's include path |
| `$context` | No | A stream context created with `stream_context_create()` |
| `$offset` | No | Byte offset to start reading from |
| `$maxlen` | No | Maximum bytes to read; defaults to end of file |

**Example:**

```php
<?php
echo file_get_contents(__DIR__ . '/sample/users_list.csv');
```

**⚠️ Important limitation:** `file_get_contents()` loads the *entire file into memory* before returning anything. This makes it unsuitable for large files. If a file exceeds PHP's `memory_limit` setting (typically 128 MB by default), the script will crash with a fatal error:

```
PHP Fatal error: Allowed memory size of 134217728 bytes exhausted
(tried to allocate 268443680 bytes)
```

**When to use it:** Only when you know the file is small (well under PHP's `memory_limit`).

---

### 2. `fread()` — Chunked Reading for Large Files

For large files, read the file in chunks using a stream resource. This keeps memory usage constant regardless of file size.

The process uses three functions together:

#### `fopen()` — Open a file stream

```php
fopen(string $filename, string $mode): resource|false
```

The `$mode` parameter controls how the file is opened:

| Mode | Description |
|---|---|
| `r` | Read only; pointer at start |
| `r+` | Read and write; pointer at start |
| `w` | Write only; truncates file; creates if missing |
| `w+` | Read and write; truncates file; creates if missing |
| `a` | Write only (append); pointer at end; creates if missing |
| `a+` | Read and write (append); pointer at end; creates if missing |
| `x` | Write only; fails if file exists |
| `x+` | Read and write; fails if file exists |

Think of the **file pointer** like a cursor in a text editor — it marks your current position in the file.

#### `fread()` — Read a chunk

```php
fread(resource $handle, int $length): string|false
```

Reads up to `$length` bytes from the stream and advances the pointer.

#### `feof()` — Check for end of file

```php
feof(resource $handle): bool
```

Returns `true` when the pointer has reached the end of the file. Use this to control your read loop.

#### `fclose()` — Release the resource

```php
fclose(resource $handle): bool
```

Always close the stream when done to free system resources.

#### Complete example:

```php
<?php
$filePath = __DIR__ . '/sample/users_list.csv';
$fileResource = fopen($filePath, 'r');

if ($fileResource === false) {
    exit(sprintf('Cannot read [%s] file.', $filePath));
}

$readLength = 64; // bytes per chunk
$iterations = 0;

while (!feof($fileResource)) {
    $iterations++;
    $chunk = fread($fileResource, $readLength);
    echo $chunk;
}

fclose($fileResource);
echo sprintf("\n%d iteration(s)", $iterations);
```

**How it works:** At each iteration, `fread()` loads only `$readLength` bytes into memory, outputs them, then frees that memory. The file is never fully loaded at once.

### 3. `fgets()` — Read Line by Line

When your file has one logical record per line (like logs or simple CSVs), reading line by line is the most natural approach.

```php
fgets(resource $handle, int $length = null): string|false
```

Returns one line at a time. Useful when one entry = one line.

```php
<?php
$filePath = __DIR__ . '/sample/users_list.csv';
$fileResource = fopen($filePath, 'r');

if ($fileResource === false) {
    exit(sprintf('Cannot read [%s] file.', $filePath));
}

$lineNumber = 0;
while (!feof($fileResource)) {
    $lineNumber++;
    $line = fgets($fileResource);
    echo sprintf("Line %d: %s", $lineNumber, $line);
}

fclose($fileResource);
```

> **Note:** Watch out for empty lines at the end of files. Always check `if (!empty(trim($line)))` before processing each line's data.

---

### 4. `fgetcsv()` — Parse CSV Records

For proper CSV parsing — including fields that contain newlines, quotes, or custom delimiters — use `fgetcsv()`.

```php
fgetcsv(
    resource $handle,
    int $length = 0,
    string $separator = ',',
    string $enclosure = '"',
    string $escape = '\\'
): array|false|null
```

Unlike `fgets()`, `fgetcsv()` returns **one CSV record** (which may span multiple lines if a field contains enclosed newlines), parsed into an array.

```php
<?php
$filePath = __DIR__ . '/sample/users_list_enclosed.csv';
$fileResource = fopen($filePath, 'r');

if ($fileResource === false) {
    exit(sprintf('Cannot read [%s] file.', $filePath));
}

$recordNumber = 0;
while (!feof($fileResource)) {
    $recordNumber++;
    $line = fgetcsv($fileResource);
    echo sprintf("Record %d: %s", $recordNumber, print_r($line, true));
}

fclose($fileResource);
```

This correctly handles multiline fields like addresses wrapped in quotes:

```csv
John,Smith,2019-03-31T10:20:30Z,"4452 Norma Lane
Alexandria
71302 Louisiana"
```

## Memory & Performance: Benchmarking File Reading

Understanding the trade-offs between reading methods helps you choose the right tool.

### Results Summary

| Method | File Size | Memory Used | Time |
|---|---|---|---|
| `file_get_contents()` | 10 MB | ~12 MB | 0.03s |
| `file_get_contents()` | 256 MB | **Fatal error** | — |
| `fread()` (4 KB chunks) | 10 MB | 2 MB | 0.05s |
| `fread()` (1 MB chunks) | 10 MB | 4 MB | 0.03s |
| `fread()` (4 KB chunks) | 256 MB | 2 MB | 0.30s |
| `fread()` (1 MB chunks) | 256 MB | 4 MB | 0.08s |

**Key takeaways:**

- `file_get_contents()` is fastest for small files but will crash on large ones
- `fread()` with a small chunk size uses minimal memory but takes more iterations
- Increasing the chunk size reduces iterations and improves speed, at the cost of slightly more memory
- `fread()` successfully reads a 256 MB file in 0.08 seconds using only 4 MB of RAM

Use `memory_get_peak_usage(true)` to measure peak allocated memory in your own benchmarks:

```php
echo sprintf("Peak memory: %.2f MB\n", memory_get_peak_usage(true) / 1024 / 1024);
```

## Downloading a File

To send a file to a browser as a download without loading it entirely into memory, use `readfile()`. It reads the file and writes it directly to the output buffer.

```php
readfile(string $filename, bool $use_include_path = false, resource $context = null): int|false
```

Pair it with the appropriate HTTP headers:

```php
<?php
$filePath = 'sample/users_list.csv';

header('Content-Type: text/csv');
header('Content-Length: ' . filesize($filePath));
header(sprintf('Content-Disposition: attachment; filename="%s"', basename($filePath)));

readfile($filePath);
```

- `Content-Type` tells the browser the file type
- `Content-Length` provides the file size so the browser can show download progress
- `Content-Disposition: attachment` triggers a download dialog rather than inline display
- `basename()` strips the directory path, leaving just the filename

> **Always verify the file exists** before calling `readfile()`. If the file is missing, the function outputs nothing and the browser may receive a malformed response.

## Writing Files

### `file_put_contents()` — Simple Write

The simplest write function — equivalent to calling `fopen()`, `fwrite()`, and `fclose()` in sequence.

```php
file_put_contents(
    string $filename,
    mixed $data,
    int $flags = 0,
    resource $context = null
): int|false
```

`$data` can be a string, a resource stream, or a single-dimension array of strings (written sequentially).

Key flags:

| Flag | Description |
|---|---|
| `FILE_APPEND` | Append to the file instead of overwriting |
| `LOCK_EX` | Acquire an exclusive lock while writing |

```php
<?php
$written = file_put_contents('sample/output.txt', "Hello, world!\n");

if ($written === false) {
    echo 'Write failed.' . PHP_EOL;
} else {
    echo sprintf("Wrote %d bytes.\n", $written);
}
```

---

### `fwrite()` — Write via Stream Resource

For writing multiple times within the same script (e.g., a file logger), `fwrite()` is more efficient than `file_put_contents()` because the stream resource stays open between writes, avoiding repeated `fopen()`/`fclose()` overhead.

```php
fwrite(resource $handle, string $string, int $length = null): int|false
```

Returns the number of bytes written, or `false` on failure.

```php
<?php
$filePath = 'sample/write-with-fwrite.txt';
$fp = fopen($filePath, 'w+');

$written = fwrite($fp, 'File written with fwrite().' . PHP_EOL);

if ($written === false) {
    echo 'Write failed.' . PHP_EOL;
} else {
    echo sprintf("Wrote %d bytes to [%s]\n", $written, $filePath);

    // Move pointer back to start to read what was written
    fseek($fp, 0);
    echo fread($fp, filesize($filePath));
}

fclose($fp);
```

---

### `fseek()` — Move the File Pointer

After writing, the file pointer is at the end. Use `fseek()` to move it before reading.

```php
fseek(resource $handle, int $offset, int $whence = SEEK_SET): int
```

| `$whence` value | Description |
|---|---|
| `SEEK_SET` | Set pointer to `$offset` bytes from the start (default) |
| `SEEK_CUR` | Move pointer `$offset` bytes from the current position |
| `SEEK_END` | Set pointer to `$offset` bytes from the end of the file |

```php
fseek($fp, 0);           // Go to the beginning of the file
fseek($fp, 0, SEEK_END); // Go to the end of the file
fseek($fp, -10, SEEK_END); // Go 10 bytes before the end
```

---

### Appending to Files

To add content to an existing file without overwriting it:

**With `fopen()`:** use mode `a` or `a+`

```php
$fp = fopen($filePath, 'a+');
fwrite($fp, "New line appended.\n");
fclose($fp);
```

**With `file_put_contents()`:** pass the `FILE_APPEND` flag

```php
file_put_contents($filePath, "New line appended.\n", FILE_APPEND);
```

Running the same script repeatedly appends a new line each time — ideal for log files.

> **When to use `fwrite()` vs `file_put_contents()`:** Use `fwrite()` when a single PHP process writes to the same file multiple times (e.g., loggers). Use `file_put_contents()` for one-off writes — it's simpler and more readable.

## Other Common Filesystem Functions

### Deleting Files — `unlink()`

```php
unlink(string $filename, resource $context = null): bool
```

Returns `true` on success, `false` on failure. Before deleting, verify the path points to an actual file:

```php
<?php
$filepath = 'sample/to-delete.txt';

if (is_file($filepath)) {
    if (unlink($filepath)) {
        echo sprintf('Deleted [%s].', $filepath) . PHP_EOL;
    } else {
        echo sprintf('Could not delete [%s].', $filepath) . PHP_EOL;
    }
} else {
    echo sprintf('[%s] does not exist.', $filepath) . PHP_EOL;
}
```

`is_file()` returns `true` only if the path exists *and* is a regular file (not a directory).

---

### Moving Files — `rename()`

```php
rename(string $from, string $to, resource $context = null): bool
```

Works for both files and directories. If the target directory doesn't exist, create it first with `mkdir()`.

```php
<?php
$filePath       = 'sample/to-move.txt';
$targetDirectory = 'sample/archive/2019';

if (!is_file($filePath)) {
    exit(sprintf('[%s] does not exist.', $filePath) . PHP_EOL);
}

if (!is_dir($targetDirectory)) {
    mkdir($targetDirectory, 0777, true); // true = create parent dirs recursively
}

$targetFilePath = $targetDirectory . DIRECTORY_SEPARATOR . basename($filePath);

if (rename($filePath, $targetFilePath)) {
    echo sprintf('Moved [%s] to [%s].', basename($filePath), $targetDirectory) . PHP_EOL;
} else {
    echo 'Move failed.' . PHP_EOL;
}
```

`mkdir($path, $mode, $recursive)`:
- `$mode` — permissions (default `0777`)
- `$recursive = true` — creates missing parent directories automatically

---

### Copying Files — `copy()`

```php
copy(string $source, string $dest, resource $context = null): bool
```

Creates a copy of `$source` at `$dest`. If the destination file already exists, it is **overwritten**.

```php
<?php
$sourceFilePath = 'sample/to-copy.txt';
$targetFilePath = 'sample/to-copy.txt.bak';

if (!is_file($sourceFilePath)) {
    exit(sprintf('[%s] does not exist.', $sourceFilePath) . PHP_EOL);
}

if (copy($sourceFilePath, $targetFilePath)) {
    echo sprintf('Copied [%s] as [%s].', $sourceFilePath, $targetFilePath) . PHP_EOL;
} else {
    echo 'Copy failed.' . PHP_EOL;
}
```

Use `copy()` when you need to preserve the original — for example, taking a backup before modifying a file.

## Quick Reference

| Task | Function(s) |
|---|---|
| Read entire small file | `file_get_contents()` |
| Read large file in chunks | `fopen()` + `fread()` + `feof()` + `fclose()` |
| Read line by line | `fopen()` + `fgets()` + `fclose()` |
| Parse CSV records | `fopen()` + `fgetcsv()` + `fclose()` |
| Send file as download | `readfile()` |
| Write (simple) | `file_put_contents()` |
| Write (repeated/logging) | `fopen()` + `fwrite()` + `fclose()` |
| Append to file | `fopen('a+')` + `fwrite()` or `file_put_contents(..., FILE_APPEND)` |
| Move file pointer | `fseek()` |
| Delete a file | `unlink()` |
| Check if file exists | `is_file()` |
| Check if directory exists | `is_dir()` |
| Create a directory | `mkdir()` |
| Move / rename a file | `rename()` |
| Copy a file | `copy()` |
| Get file size | `filesize()` |
| Get filename from path | `basename()` |
| Get peak memory usage | `memory_get_peak_usage(true)` |
