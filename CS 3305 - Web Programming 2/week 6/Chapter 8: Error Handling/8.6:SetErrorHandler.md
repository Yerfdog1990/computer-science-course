# set_error_handler() Function

## Overview

`set_error_handler()` is a PHP function that sets a user-defined error handler function to handle errors in a script. This allows developers to customize how errors are processed, logged, and displayed, instead of relying on PHP's built-in error handling.

---

## Function Signature

```php
set_error_handler(?callable $callback, int $error_levels = E_ALL): ?callable
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `$callback` | callable/null | Yes | — | The error handler function, or `null` to reset to default |
| `$error_levels` | int | No | `E_ALL` | Bitmask of error types to handle |

**Return Value:** Returns the previously defined error handler (callable), or `null` if the built-in handler was used.

---

## Error Handler Callback Signature

The callback function must accept the following parameters:

```php
handler(
    int $errno,           // Error level constant (e.g., E_WARNING)
    string $errstr,       // Error message
    string $errfile = ?,  // File where error occurred (optional)
    int $errline = ?,     // Line number (optional)
    array $errcontext = ? // Array of variables in scope (REMOVED in PHP 8.0)
): bool
```

| Parameter | Type | Description |
|---|---|---|
| `$errno` | int | The error level (E_WARNING, E_NOTICE, etc.) |
| `$errstr` | string | The error message text |
| `$errfile` | string | Full path to the file where the error occurred |
| `$errline` | int | Line number in that file |
| `$errcontext` | array | **DEPRECATED in PHP 7.2, REMOVED in PHP 8.0** - Active symbol table at error point |

> **Important:** The `$errcontext` parameter was removed in PHP 8.0. If your handler defines this parameter without a default value, it will cause a "too few arguments" error.

---

## Error Types That Can Be Handled

### Can Be Handled

| Error Type | Description |
|---|---|
| `E_WARNING` | Runtime warnings (non-fatal) |
| `E_NOTICE` | Runtime notices |
| `E_USER_ERROR` | User-generated fatal errors |
| `E_USER_WARNING` | User-generated warnings |
| `E_USER_NOTICE` | User-generated notices |
| `E_USER_DEPRECATED` | User-generated deprecation warnings |
| `E_DEPRECATED` | Runtime deprecation notices |
| `E_RECOVERABLE_ERROR` | Catchable fatal errors |
| `E_STRICT` | Runtime suggestions (most cases) |

### Cannot Be Handled

| Error Type | Reason |
|---|---|
| `E_ERROR` | Fatal runtime errors (use `register_shutdown_function()` instead) |
| `E_PARSE` | Compile-time parse errors |
| `E_CORE_ERROR` | Fatal errors during PHP startup |
| `E_CORE_WARNING` | Warnings during PHP startup |
| `E_COMPILE_ERROR` | Fatal compile-time errors |
| `E_COMPILE_WARNING` | Compile-time warnings |

> **Note:** Errors that occur before the script is executed (e.g., file upload errors) cannot be handled because the custom handler is not registered yet.

## Basic Usage

### Simple Error Handler

```php
<?php
function myErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    echo "<b>Error:</b> [$errno] $errstr<br />\n";
    echo "Error on line $errline in file $errfile<br />\n";

    // Don't execute PHP internal error handler
    return true;
}

// Set the custom error handler
set_error_handler('myErrorHandler');

// Trigger an error
echo $undefinedVariable; // Triggers E_NOTICE
```

### Reset to Default Handler

```php
<?php
// Reset to PHP's built-in error handler
set_error_handler(null);
```

## Advanced Examples

### Example 1: Comprehensive Error Handler

```php
<?php
function customErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Check if this error should be reported based on error_reporting()
    if (!(error_reporting() & $errno)) {
        // Let PHP's default handler handle it
        return false;
    }

    // Escape the error message for HTML output
    $errstr = htmlspecialchars($errstr);

    switch ($errno) {
        case E_USER_ERROR:
            echo "<b>USER ERROR:</b> [$errno] $errstr<br />\n";
            echo "Fatal error on line $errline in file $errfile<br />\n";
            echo "Aborting...<br />\n";
            exit(1);

        case E_USER_WARNING:
            echo "<b>USER WARNING:</b> [$errno] $errstr<br />\n";
            break;

        case E_USER_NOTICE:
            echo "<b>USER NOTICE:</b> [$errno] $errstr<br />\n";
            break;

        case E_WARNING:
            echo "<b>WARNING:</b> [$errno] $errstr<br />\n";
            break;

        case E_NOTICE:
            echo "<b>NOTICE:</b> [$errno] $errstr<br />\n";
            break;

        default:
            echo "Unknown error type: [$errno] $errstr<br />\n";
            break;
    }

    // Don't execute PHP internal error handler
    return true;
}

set_error_handler('customErrorHandler');
```

### Example 2: Logging Errors to File

```php
<?php
function logErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    $logFile = __DIR__ . '/error.log';
    $timestamp = date('Y-m-d H:i:s');

    $logEntry = sprintf(
        "[%s] [%d] %s in %s on line %d\n",
        $timestamp,
        $errno,
        $errstr,
        $errfile,
        $errline
    );

    file_put_contents($logFile, $logEntry, FILE_APPEND);

    // Don't display to user
    return true;
}

set_error_handler('logErrorHandler');
ini_set('display_errors', 'Off');
```

### Example 3: Environment-Specific Handlers

```php
<?php
define('DEBUG', true);

if (DEBUG) {
    // Development: verbose error display
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        echo "<pre>";
        echo "Error: $errstr\n";
        echo "File: $errfile\n";
        echo "Line: $errline\n";
        echo "Code: $errno\n";
        debug_print_backtrace();
        echo "</pre>";
    });
    ini_set('display_errors', 'On');
} else {
    // Production: log only
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        error_log(sprintf(
            "[%s] Error in %s:%d - %s",
            date('Y-m-d H:i:s'),
            $errfile,
            $errline,
            $errstr
        ));
    });
    ini_set('display_errors', 'Off');
}
```

### Example 4: Converting Errors to Exceptions

```php
<?php
set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
    // Ignore errors suppressed with @ operator
    if (error_reporting() === 0) {
        return false;
    }

    throw new ErrorException($errstr, 0, $errno, $errfile, $errline);
});

try {
    // This will throw an exception instead of a notice
    echo $undefinedVariable;
} catch (ErrorException $e) {
    echo "Caught exception: " . $e->getMessage();
}
```

## Handler Return Values

### Return `true`

Prevents PHP's internal error handler from running:

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Handle the error
    error_log("Error: $errstr");

    // Prevent PHP's default handler
    return true;
}
```

### Return `false`

Lets PHP's internal error handler continue:

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Only handle specific errors
    if ($errno === E_USER_ERROR) {
        error_log("User error: $errstr");
        return true;
    }

    // Let PHP handle other errors
    return false;
}
```

---

## Handling @ Operator

The `@` operator sets `error_reporting()` to 0 temporarily. Your handler should respect this:

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // If error was suppressed with @, don't handle it
    if (error_reporting() === 0) {
        return false;
    }

    // Handle the error
    error_log("Error: $errstr");
    return true;
}

// This error will be suppressed
@undefinedFunction();
```

---

## Chaining Error Handlers

You can chain multiple error handlers by calling the previous handler:

```php
<?php
$previousHandler = set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) use (&$previousHandler) {
    // Your custom handling
    error_log("Custom handler: $errstr");

    // Call the previous handler if it exists
    if ($previousHandler) {
        return $previousHandler($errno, $errstr, $errfile, $errline);
    }

    // Otherwise, let PHP handle it
    return false;
});
```

## Using Class Methods as Handlers

### Static Method

```php

class ErrorHandler
{
    public static function handle(int $errno, string $errstr, string $errfile, int $errline): bool

    {
        error_log("Error: $errstr");
        return true;
    }

$handler = new ErrorHandler();
set_error_handler([$handler, 'handle']);
```

### Namespaced Classes

```php

        error_log("Error: $errstr");

    }

// Use fully qualified name
set_error_handler(['My\App\ErrorHandler', 'handle']);
```

## Handling Fatal Errors

`set_error_handler()` cannot handle fatal errors (`E_ERROR`, `E_PARSE`, etc.). Use `register_shutdown_function()` instead:

```php
<?php
function shutdownHandler()
{
    $error = error_get_last();

    if ($error && in_array($error['type'], [E_ERROR, E_PARSE, E_CORE_ERROR, E_COMPILE_ERROR])) {
        error_log(sprintf(
            "Fatal error: %s in %s on line %d",
            $error['message'],
            $error['file'],
            $error['line']
        ));

        // Display user-friendly message
        echo "A fatal error occurred. Please try again later.";
    }
}

register_shutdown_function('shutdownHandler');
set_error_handler('customErrorHandler');
```

## Best Practices

### 1. Always Check error_reporting()

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Respect current error_reporting() setting
    if (!(error_reporting() & $errno)) {
        return false;
    }

    // Handle the error
    error_log("Error: $errstr");
    return true;
}
```

### 2. Use restore_error_handler() Instead of Stacking

```php
<?php
// BAD - causes memory leak
function doSomething()
{
    $old = set_error_handler('myHandler');
    // ... do work ...
    set_error_handler($old);
}

// GOOD - properly restore
function doSomething()
{
    set_error_handler('myHandler');
    // ... do work ...
    restore_error_handler();
}
```

### 3. Escape HTML for Browser Output

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Escape to prevent XSS
    $errstr = htmlspecialchars($errstr, ENT_QUOTES, 'UTF-8');
    $errfile = htmlspecialchars($errfile, ENT_QUOTES, 'UTF-8');

    echo "Error: $errstr in $errfile:$errline";
    return true;
}
```

### 4. Don't Expose Sensitive Information

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Log full details
    error_log("Error: $errstr in $errfile:$errline");

    // Show generic message to user
    if (ini_get('display_errors')) {
        echo "An error occurred. Please contact support.";
    }

    return true;
}
```

### 5. Handle @ Operator Correctly

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Respect @ operator
    if (error_reporting() === 0) {
        return false;
    }

    // Handle the error
    error_log("Error: $errstr");
    return true;
}
```

## Common Use Cases

### 1. Centralized Error Logging

```php
<?php
function logErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    $logData = [
        'timestamp' => date('Y-m-d H:i:s'),
        'level' => $errno,
        'message' => $errstr,
        'file' => $errfile,
        'line' => $errline,
        'request_uri' => $_SERVER['REQUEST_URI'] ?? 'CLI',
        'user_agent' => $_SERVER['HTTP_USER_AGENT'] ?? 'Unknown'
    ];

    file_put_contents(
        __DIR__ . '/errors.json-example',
        json_encode($logData) . "\n",
        FILE_APPEND
    );

    return true;
}

set_error_handler('logErrorHandler');
```

### 2. Email Alerts for Critical Errors

```php
<?php
function emailErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // Only email for critical errors
    if (!in_array($errno, [E_ERROR, E_USER_ERROR, E_RECOVERABLE_ERROR])) {
        return false;
    }

    $message = sprintf(
        "Critical Error:\n\nType: %d\nMessage: %s\nFile: %s\nLine: %d\n\nTime: %s",
        $errno,
        $errstr,
        $errfile,
        $errline,
        date('Y-m-d H:i:s')
    );

    mail('admin@example.com', 'Critical Error Alert', $message);
    return true;
}

set_error_handler('emailErrorHandler');
```

### 3. Development vs Production

```php
<?php
define('ENVIRONMENT', 'production');

if (ENVIRONMENT === 'development') {
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        echo "<div style='background: #ffeeee; border: 1px solid red; padding: 10px;'>";
        echo "<strong>Error:</strong> $errstr<br>";
        echo "<strong>File:</strong> $errfile<br>";
        echo "<strong>Line:</strong> $errline<br>";
        echo "</div>";
    });
    ini_set('display_errors', 'On');
} else {
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        error_log("[$errno] $errstr in $errfile:$errline");
    });
    ini_set('display_errors', 'Off');
}
```

## Limitations and Constraints

### 1. Cannot Handle Fatal Errors

```php
<?php
// This will NOT be caught by set_error_handler()
undefinedFunction(); // E_ERROR
```

Use `register_shutdown_function()` for fatal errors.

### 2. Handler Recursion

Error handlers do not run recursively. If an error occurs within the handler, PHP's default handler is used:

```php
<?php
function myHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // If this causes an error, PHP's default handler runs
    $undefined = $variable; // This won't trigger myHandler again

    return true;
}
```

### 3. errcontext Removed in PHP 8.0

```php
<?php
// PHP 7.x and earlier
function oldHandler(int $errno, string $errstr, string $errfile, int $errline, array $errcontext): bool
{
    // errcontext available
}

// PHP 8.0+
function newHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    // errcontext removed - use debug_backtrace() instead
    $backtrace = debug_backtrace();
}
```

### 4. Errors Before Script Execution

Errors that occur before the script starts (e.g., during file upload) cannot be handled because the handler isn't registered yet.

| **PHP 7.2+** | `$errcontext` parameter deprecated |
| **PHP 7.x** | Full support for all handleable error types |
| **PHP 5.x** | Basic support; some differences in error handling |

## Summary

| Concept | Key Point |
|---|---|
| **Purpose** | Sets a custom function to handle errors instead of PHP's built-in handler |
| **Callback Signature** | `handler(int $errno, string $errstr, string $errfile, int $errline): bool` |
| **Return Value** | Previous handler (callable) or `null` |
| **Return `true`** | Prevents PHP's internal handler from running |
| **Return `false`** | Lets PHP's internal handler continue |
| **Cannot Handle** | `E_ERROR`, `E_PARSE`, `E_CORE_*`, `E_COMPILE_*` |
| **Fatal Errors** | Use `register_shutdown_function()` with `error_get_last()` |
| **@ Operator** | Check `error_reporting() === 0` to respect suppression |
| **errcontext** | Removed in PHP 8.0; use `debug_backtrace()` instead |
| **Chaining** | Store and call previous handler from return value |
| **Restoration** | Use `restore_error_handler()` to avoid memory leaks |
| **Best Practice** | Always check `error_reporting()` in your handler |

---

> **Remember:** `set_error_handler()` is a powerful tool for customizing error handling, but it cannot handle fatal errors. Combine it with `register_shutdown_function()` for complete error coverage, and always respect the `error_reporting()` setting and the `@` operator in your custom handlers.
