# trigger_error() Function

## Overview

`trigger_error()` is a PHP function that generates user-level error, warning, or notice messages. It allows developers to manually trigger error conditions during runtime, which can then be handled by the built-in error handler or a custom error handler registered with `set_error_handler()`.

---

## Function Signature

```php
trigger_error(string $message, int $error_level = E_USER_NOTICE): true
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `$message` | string | Yes | — | The error message (limited to 1024 bytes) |
| `$error_level` | int | No | `E_USER_NOTICE` | The error type (must be an `E_USER_*` constant) |

**Return Value:** Always returns `true`

---

## Available Error Levels

`trigger_error()` only works with the `E_USER_*` family of constants:

| Constant | Value | Severity | Script Behaviour | Use Case |
|---|---|---|---|---|
| `E_USER_NOTICE` | 1024 | Notice | Continues | Informational hints, debugging info |
| `E_USER_WARNING` | 512 | Warning | Continues | Recoverable issues, deprecated features |
| `E_USER_DEPRECATED` | 16384 | Notice | Continues | Marking your own code as deprecated |
| `E_USER_ERROR` | 256 | Fatal | Halts | Critical failures (deprecated in PHP 8.4) |

> **Important:** As of PHP 8.4, using `E_USER_ERROR` with `trigger_error()` is deprecated. Use `throw new Exception()` or `exit()` instead.

---

## Basic Usage

### Simple Notice

```php
<?php
// Trigger a user notice (informational)
trigger_error('Cache miss for key: user_123', E_USER_NOTICE);
```

### Warning

```php
<?php
// Trigger a user warning (script continues)
trigger_error('Using deprecated function oldFunction()', E_USER_WARNING);
```

### Fatal Error (Deprecated in PHP 8.4)

```php
<?php
// DEPRECATED in PHP 8.4 - use exceptions instead
trigger_error('database connection failed', E_USER_ERROR);

// RECOMMENDED approach:
throw new Exception('database connection failed');
```

## Practical Examples

### Example 1: Input Validation

```php
<?php
function divide(int $a, int $b): float
{
    if ($b === 0) {
        trigger_error('Division by zero is not allowed', E_USER_ERROR);
    }

    return $a / $b;
}

// This will halt execution
$result = divide(10, 0);
```

### Example 2: Empty Password Warning

```php
<?php
$password = $_POST['password'] ?? '';

if ($password === '') {
    trigger_error('Using an empty password is unsafe', E_USER_WARNING);
}

$hash = password_hash($password, PASSWORD_DEFAULT);
```

### Example 3: Deprecating Your Own Functions

```php
<?php
function oldFunction(): string
{
    trigger_error(
        'oldFunction() is deprecated. Use newFunction() instead.',
        E_USER_DEPRECATED
    );

    // Old logic still runs
    return 'result from old function';
}

// Usage generates a deprecation notice
$result = oldFunction();
```

### Example 4: Configuration Validation

```php
<?php
function validateConfig(array $config): void
{
    if (!isset($config['database_host'])) {
        trigger_error('Missing required config: database_host', E_USER_ERROR);
    }

    if (!isset($config['cache_ttl'])) {
        trigger_error('Missing optional config: cache_ttl, using default', E_USER_NOTICE);
        $config['cache_ttl'] = 3600;
    }
}
```

## Integration with Custom Error Handlers

`trigger_error()` is designed to work with custom error handlers registered via `set_error_handler()`.

### Basic Custom Handler

```php
<?php
function customErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    $date = date('Y-m-d H:i:s');

    switch ($errno) {
        case E_USER_ERROR:
            error_log("[FATAL] $date: $errstr in $errfile:$errline");
            exit(1);

        case E_USER_WARNING:
            error_log("[WARNING] $date: $errstr in $errfile:$errline");
            break;

        case E_USER_NOTICE:
            error_log("[NOTICE] $date: $errstr in $errfile:$errline");
            break;

        case E_USER_DEPRECATED:
            error_log("[DEPRECATED] $date: $errstr in $errfile:$errline");
            break;
    }

    return true; // Prevent PHP's default error handler
}

set_error_handler('customErrorHandler');

// Now trigger_error() calls will be handled by customErrorHandler
trigger_error('This is a custom notice', E_USER_NOTICE);
```

### Environment-Specific Handlers

```php
<?php
define('DEBUG', true);

if (DEBUG) {
    // Verbose handler for development
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        echo "[DEBUG] $errstr in $errfile:$errline\n";
    });
} else {
    // Clean handler for production
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        error_log("[ERROR] $errstr in $errfile:$errline");
    });
}
```

## Advanced Techniques

### Improving Error Location Reporting

By default, `trigger_error()` reports the line where it was called, not where the actual error occurred. You can use `debug_backtrace()` to report the caller's location:

```php
<?php
function triggerCustomError(string $message, int $level = E_USER_NOTICE): void
{
    $caller = next(debug_backtrace());

    $enhancedMessage = sprintf(
        '%s in %s() called from %s on line %d',
        $message,
        $caller['function'] ?? 'unknown',
        $caller['file'] ?? 'unknown',
        $caller['line'] ?? 0
    );

    trigger_error($enhancedMessage, $level);
}

function validateNumber($value): void
{
    if (!is_numeric($value)) {
        triggerCustomError('Value must be numeric', E_USER_WARNING);
    }
}

// Reports: "Value must be numeric in validateNumber() called from script.http-and-session on line 10"
validateNumber('not a number');
```

### Conditional Error Triggering

```php
<?php
function checkFileSize(int $size): void
{
    $maxSize = 10 * 1024 * 1024; // 10MB

    if ($size > $maxSize) {
        trigger_error(
            sprintf('File size %d bytes exceeds maximum %d bytes', $size, $maxSize),
            E_USER_WARNING
        );
    }
}

// Only triggers warning if condition is met
checkFileSize(15 * 1024 * 1024);
```

### Error Context with Additional Data

```php
<?php
function validateUser(array $user): void
{
    $required = ['name', 'email', 'password'];
    $missing = array_diff($required, array_keys($user));

    if (!empty($missing)) {
        trigger_error(
            sprintf(
                'Missing required fields: %s (user data: %s)',
                implode(', ', $missing),
                json_encode($user)
            ),
            E_USER_ERROR
        );
    }
}
```

## Security Considerations

### HTML Entity Escaping

`trigger_error()` does **not** escape HTML entities in the message. If the error will be displayed in a browser, you must escape it:

```php
<?php
// DANGEROUS - XSS vulnerability if displayed in browser
trigger_error("<script>alert('XSS')</script>", E_USER_WARNING);

// SAFE - escape the message
$message = htmlentities("<script>alert('XSS')</script>", ENT_QUOTES, 'UTF-8');
trigger_error($message, E_USER_WARNING);
```

### Information Disclosure

Avoid exposing sensitive information in error messages:

```php
<?php
// BAD - exposes database credentials
trigger_error(
    "Failed to connect to database with user 'admin' and password 'secret123'",
    E_USER_ERROR
);

// GOOD - generic message
trigger_error(
    "database connection failed. Check configuration.",
    E_USER_ERROR
);
```

## Limitations and Constraints

### Message Length Limit

The error message is limited to **1024 bytes**. Any characters beyond this limit will be truncated:

```php
<?php
// This message will be truncated at 1024 bytes
$longMessage = str_repeat('A', 2000);
trigger_error($longMessage, E_USER_NOTICE);
```

### Invalid Error Levels

As of PHP 8.0, passing an invalid error level throws a `ValueError`:

```php
<?php
// THROWS ValueError in PHP 8.0+
trigger_error('Test', E_ERROR); // E_ERROR is not an E_USER_* constant

// CORRECT - use E_USER_* constants only
trigger_error('Test', E_USER_ERROR);
```

### Scope of $php_errormsg

The `$php_errormsg` variable is only available within the scope where the error occurred. `trigger_error()` does not populate this variable in the calling scope:

```php
<?php
ini_set('track_errors', true);

function testError(): void
{
    trigger_error('My error');
}

@testError();
echo $php_errormsg; // Empty - error occurred inside function scope
```

## Comparison with Exceptions

### When to Use trigger_error()

- **Legacy codebases** that rely on error handlers
- **Logging informational messages** that don't affect flow
- **Deprecation warnings** for your own functions
- **Situations where you want the error handler to decide the outcome**

### When to Use Exceptions

- **Critical failures** that should halt execution (replaces `E_USER_ERROR`)
- **Object-oriented code** with try-catch blocks
- **Situations where different error types need different handling**
- **When you need to bundle additional context with the error**

### Migration Example

```php
<?php
// OLD (deprecated in PHP 8.4)
function connectToDatabase(): void
{
    if (!$connection) {
        trigger_error('database connection failed', E_USER_ERROR);
    }
}

// NEW (recommended)
function connectToDatabase(): void
{
    if (!$connection) {
        throw new RuntimeException('database connection failed');
    }
}
```

## Best Practices

### 1. Use Descriptive Messages

```php
<?php
// BAD - vague
trigger_error('Error occurred', E_USER_ERROR);

// GOOD - specific
trigger_error('Failed to open file /path/to/file: Permission denied', E_USER_ERROR);
```

### 2. Choose Appropriate Error Levels

```php
<?php
// Use E_USER_NOTICE for informational messages
trigger_error('Cache miss for key: user_123', E_USER_NOTICE);

// Use E_USER_WARNING for recoverable issues
trigger_error('Using deprecated API endpoint', E_USER_WARNING);

// Use E_USER_DEPRECATED for deprecation notices
trigger_error('oldMethod() is deprecated, use newMethod()', E_USER_DEPRECATED);

// Use exceptions instead of E_USER_ERROR (PHP 8.4+)
throw new Exception('Critical failure');
```

### 3. Combine with Custom Error Handlers

```php
<?php
// Register a handler that logs to file
set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
    $logEntry = sprintf(
        "[%s] [%d] %s in %s:%d\n",
        date('Y-m-d H:i:s'),
        $errno,
        $errstr,
        $errfile,
        $errline
    );

    file_put_contents(__DIR__ . '/error.log', $logEntry, FILE_APPEND);
});

// Now all trigger_error() calls are logged
trigger_error('Something happened', E_USER_NOTICE);
```

### 4. Don't Expose Sensitive Data

```php
<?php
// BAD
trigger_error("SQL query failed: SELECT * FROM users WHERE password = '$password'", E_USER_ERROR);

// GOOD
trigger_error('database query failed', E_USER_ERROR);
error_log("SQL error: " . $sqlError); // Log details separately
```

### 5. Use for Deprecation Warnings

```php
<?php
/**
 * @deprecated 2.0 Use newFunction() instead
 */
function oldFunction(): string
{
    trigger_error(
        'oldFunction() is deprecated since version 2.0. Use newFunction() instead.',
        E_USER_DEPRECATED
    );

    // Implementation continues for backward compatibility
    return 'result';
}
```

## Common Use Cases

### 1. Input Validation

```php
<?php
function validateEmail(string $email): void
{
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        trigger_error("Invalid email format: $email", E_USER_WARNING);
    }
}
```

### 2. Resource Availability Checks

```php
<?php
function checkDiskSpace(string $path): void
{
    $freeSpace = disk_free_space($path);
    $minSpace = 100 * 1024 * 1024; // 100MB

    if ($freeSpace < $minSpace) {
        trigger_error(
            sprintf('Low disk space: %d bytes remaining', $freeSpace),
            E_USER_WARNING
        );
    }
}
```

### 3. API Rate Limiting

```php
<?php
function checkRateLimit(string $apiKey): void
{
    $requests = getRequestsCount($apiKey);
    $limit = 1000;

    if ($requests >= $limit) {
        trigger_error(
            "Rate limit exceeded for API key: $apiKey",
            E_USER_WARNING
        );
    }
}
```

### 4. Configuration Validation

```php
<?php
function validateConfig(array $config): void
{
    $required = ['host', 'port', 'username', 'password'];

    foreach ($required as $key) {
        if (!isset($config[$key])) {
            trigger_error(
                "Missing required configuration: $key",
                E_USER_ERROR
            );
        }
    }
}
```

## Debugging with trigger_error()

### Development Mode

```php
<?php
define('DEBUG', true);

if (DEBUG) {
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        echo "<pre>";
        echo "Error: $errstr\n";
        echo "File: $errfile\n";
        echo "Line: $errline\n";
        echo "Trace:\n";
        debug_print_backtrace();
        echo "</pre>";
    });
}

// Use trigger_error for debugging
function debugLog(string $message): void
{
    if (DEBUG) {
        trigger_error("[DEBUG] $message", E_USER_NOTICE);
    }
}

debugLog('User logged in: user_123');
```

### Production Mode

```php
<?php
define('DEBUG', false);

if (!DEBUG) {
    set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
        // Log to file only
        error_log(sprintf(
            "[%s] Error in %s:%d - %s",
            date('Y-m-d H:i:s'),
            $errfile,
            $errline,
            $errstr
        ));

        // Show generic message to user
        if (in_array($errno, [E_USER_ERROR, E_ERROR])) {
            http_response_code(500);
            echo "An error occurred. Please try again later.";
            exit(1);
        }
    });
}
```

## PHP Version Compatibility

| PHP Version | Notable Changes |
|---|---|
| **PHP 8.4+** | `E_USER_ERROR` with `trigger_error()` deprecated; return type changed to `true` |
| **PHP 8.0+** | Throws `ValueError` for invalid error levels (previously returned `false`) |
| **PHP 7.x** | Full support for all `E_USER_*` constants |
| **PHP 5.x** | Basic support; some error handling differences |

---

## Summary

| Concept | Key Point |
|---|---|
| **Purpose** | Manually trigger user-level errors, warnings, and notices |
| **Error Levels** | Only `E_USER_*` constants: `E_USER_NOTICE`, `E_USER_WARNING`, `E_USER_DEPRECATED`, `E_USER_ERROR` |
| **Deprecation** | `E_USER_ERROR` deprecated in PHP 8.4; use exceptions instead |
| **Message Limit** | 1024 bytes maximum |
| **Return Value** | Always returns `true` |
| **Security** | HTML entities not escaped; use `htmlentities()` for browser output |
| **Integration** | Works with `set_error_handler()` for custom handling |
| **Best For** | Deprecation warnings, logging, validation, legacy error handling |
| **Not For** | Critical failures in PHP 8.4+ (use exceptions) |
| **Location** | Reports line where `trigger_error()` called; use `debug_backtrace()` for caller location |

---

> **Remember:** `trigger_error()` is a powerful tool for generating custom error conditions, but with PHP 8.4's deprecation of `E_USER_ERROR`, the modern approach is to use exceptions for critical failures and reserve `trigger_error()` for warnings, notices, and deprecation messages.
