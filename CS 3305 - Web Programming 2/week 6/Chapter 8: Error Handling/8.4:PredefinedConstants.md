# PHP Predefined Error Constants

## Overview

PHP provides a set of predefined constants that represent different error levels. These constants are used as a **bitmask** to specify which errors should be reported by the PHP engine. They can be combined using bitwise operators to create custom error reporting configurations.

---

## Why Use Constants Instead of Numbers?

Using symbolic names like `E_ERROR` instead of raw numbers like `1` provides:

- **Readability** — Code is self-documenting
- **Maintainability** — Easier to understand and modify
- **Portability** — Constant values may change between PHP versions
- **IDE Support** — Better autocomplete and type hinting

## Categories of Error Constants

### 1. PHP Engine Errors (Runtime)

These are generated automatically by PHP during script execution:

| Constant | When It Occurs |
|---|---|
| `E_ERROR` | Memory allocation failure, calling undefined function (PHP 5) |
| `E_WARNING` | Failed `include()`, invalid file permissions |
| `E_NOTICE` | Using undefined variable, array index out of bounds |

### 2. PHP Core Errors (Startup)

Generated during PHP's initial startup phase:

| Constant | When It Occurs |
|---|---|
| `E_CORE_ERROR` | PHP cannot load required extension |
| `E_CORE_WARNING` | Extension loaded but with warnings |

### 3. Compile-Time Errors

Generated by the parser or Zend scripting engine:

| Constant | When It Occurs |
|---|---|
| `E_PARSE` | Missing semicolon, unclosed brace |
| `E_COMPILE_ERROR` | Invalid syntax detected by Zend Engine |
| `E_COMPILE_WARNING` | Non-fatal compile-time issues |

### 4. User-Generated Errors

Manually triggered by developers using `trigger_error()`:

| Constant | When To Use |
|---|---|
| `E_USER_ERROR` | Invalid input that makes execution impossible |
| `E_USER_WARNING` | Recoverable issues (e.g., deprecated feature usage) |
| `E_USER_NOTICE` | Informational hints |
| `E_USER_DEPRECATED` | Marking your own functions as deprecated |

> **Important:** As of PHP 8.4, using `E_USER_ERROR` with `trigger_error()` is deprecated. Use `throw new Exception()` or `exit()` instead.

### 5. Forward Compatibility & Deprecation

| Constant | Purpose |
|---|---|
| `E_STRICT` | Suggestions for forward compatibility (deprecated in PHP 8.4) |
| `E_DEPRECATED` | Warnings about code that won't work in future PHP versions |
| `E_USER_DEPRECATED` | Mark your own code as deprecated |

### 6. Special Constants

| Constant | Purpose |
|---|---|
| `E_RECOVERABLE_ERROR` | Catchable fatal errors (must use `set_error_handler()`) |
| `E_ALL` | Bitmask containing every error type |

## Bitmask Operations

### Understanding Bitmasks

Each error constant is a power of 2, meaning each occupies a single bit in a binary number:

```
E_ERROR           = 1  = 0000000000000001 (bit 0)
E_WARNING         = 2  = 0000000000000010 (bit 1)
E_PARSE           = 4  = 0000000000000100 (bit 2)
E_NOTICE          = 8  = 0000000000001000 (bit 3)
E_CORE_ERROR      = 16 = 0000000000010000 (bit 4)
...
```

This allows combining multiple error types into a single integer.

### Bitwise Operators

| Operator | Symbol | Purpose | Example |
|---|---|---|---|
| OR | `|` | Combine error types | `E_ERROR \| E_WARNING` |
| AND NOT | `&~` | Exclude error types | `E_ALL &~ E_NOTICE` |
| AND | `&` | Check if error type is set | `error_reporting() & E_ERROR` |

### Common Combinations

```php
// Report everything
error_reporting(E_ALL);

// Report everything except notices
error_reporting(E_ALL & ~E_NOTICE);

// Report only errors and warnings
error_reporting(E_ERROR | E_WARNING);

// Report only user-generated errors
error_reporting(E_USER_ERROR | E_USER_WARNING | E_USER_NOTICE);

// Report everything except deprecated warnings
error_reporting(E_ALL & ~E_DEPRECATED & ~E_USER_DEPRECATED);
```

---

## Using Constants in php.ini

In `php.ini`, you can use either the constant names or their numerical values:

```ini
; Using constant names (recommended)
error_reporting = E_ALL & ~E_DEPRECATED

; Using numerical values (less readable)
error_reporting = 22527
```

**Important:** Only the `|`, `~`, `^`, `!`, and `&` operators are understood in `php.ini`. You cannot use function calls or complex expressions.

## Using Constants in Code

### Setting Error Reporting at Runtime

```php
// Report all errors
error_reporting(E_ALL);

// Report all except notices
error_reporting(E_ALL & ~E_NOTICE);

// Report only fatal errors and warnings
error_reporting(E_ERROR | E_WARNING);

// Restore default
error_reporting(E_ALL);
```

### Checking Current Error Level

```php
$currentLevel = error_reporting();

// Check if E_NOTICE is enabled
if ($currentLevel & E_NOTICE) {
    echo "Notices are enabled";
}

// Check if E_WARNING is disabled
if (!($currentLevel & E_WARNING)) {
    echo "Warnings are disabled";
}
```

## User-Generated Errors with trigger_error()

### Basic Usage

```php
// Trigger a user error (fatal - halts script)
trigger_error('Database connection failed', E_USER_ERROR);

// Trigger a user warning (script continues)
trigger_error('Using deprecated function', E_USER_WARNING);

// Trigger a user notice (informational)
trigger_error('Cache miss for key: user_123', E_USER_NOTICE);

// Trigger a user deprecation warning
trigger_error('oldFunction() is deprecated, use newFunction()', E_USER_DEPRECATED);
```

### Practical Example: Input Validation

```php
function divide(int $a, int $b): float
{
    if ($b === 0) {
        trigger_error('Division by zero is not allowed', E_USER_ERROR);
    }

    return $a / $b;
}

// This will halt execution with a fatal error
$result = divide(10, 0);
```

## Custom Error Handler with Constants

```php
function customErrorHandler(int $errno, string $errstr, string $errfile, int $errline): bool
{
    $date = date('Y-m-d H:i:s');

    switch ($errno) {
        case E_ERROR:
        case E_CORE_ERROR:
        case E_COMPILE_ERROR:
        case E_USER_ERROR:
            // Fatal errors
            error_log("[FATAL] $date: $errstr in $errfile:$errline");
            exit(1);

        case E_WARNING:
        case E_CORE_WARNING:
        case E_COMPILE_WARNING:
        case E_USER_WARNING:
            // Warnings
            error_log("[WARNING] $date: $errstr in $errfile:$errline");
            break;

        case E_NOTICE:
        case E_USER_NOTICE:
            // Notices
            error_log("[NOTICE] $date: $errstr in $errfile:$errline");
            break;

        default:
            // Unknown error types
            error_log("[UNKNOWN] $date: $errstr in $errfile:$errline");
            break;
    }

    return true; // Prevent PHP's default error handler
}

set_error_handler('customErrorHandler', E_ALL);
```

## Getting Error Name from Error Code

### Method 1: Using get_defined_constants()

```php
function getErrorName(int $code): string
{
    $constants = get_defined_constants(true)['Core'];
    $flipped = array_flip($constants);

    return $flipped[$code] ?? 'UNKNOWN_ERROR';
}

echo getErrorName(1);   // E_ERROR
echo getErrorName(256); // E_USER_ERROR
echo getErrorName(8);   // E_NOTICE
```

### Method 2: Using a Lookup Array

```php
$errorNames = [
    E_ERROR             => 'E_ERROR',
    E_WARNING           => 'E_WARNING',
    E_PARSE             => 'E_PARSE',
    E_NOTICE            => 'E_NOTICE',
    E_CORE_ERROR        => 'E_CORE_ERROR',
    E_CORE_WARNING      => 'E_CORE_WARNING',
    E_COMPILE_ERROR     => 'E_COMPILE_ERROR',
    E_COMPILE_WARNING   => 'E_COMPILE_WARNING',
    E_USER_ERROR        => 'E_USER_ERROR',
    E_USER_WARNING      => 'E_USER_WARNING',
    E_USER_NOTICE       => 'E_USER_NOTICE',
    E_STRICT            => 'E_STRICT',
    E_RECOVERABLE_ERROR => 'E_RECOVERABLE_ERROR',
    E_DEPRECATED        => 'E_DEPRECATED',
    E_USER_DEPRECATED   => 'E_USER_DEPRECATED',
    E_ALL               => 'E_ALL'
];

echo $errorNames[256] ?? 'UNKNOWN'; // E_USER_ERROR
```

## Dynamic Error Reporting Configuration

### Enable/Disable Specific Error Types

```php
$errorsActive = [
    E_ERROR             => true,
    E_WARNING           => true,
    E_PARSE             => true,
    E_NOTICE            => false,  // Disable notices
    E_CORE_ERROR        => true,
    E_CORE_WARNING      => true,
    E_COMPILE_ERROR     => true,
    E_COMPILE_WARNING   => true,
    E_USER_ERROR        => true,
    E_USER_WARNING      => true,
    E_USER_NOTICE       => false,  // Disable user notices
    E_STRICT            => false,  // Disable strict
    E_RECOVERABLE_ERROR => true,
    E_DEPRECATED        => false,  // Disable deprecation warnings
    E_USER_DEPRECATED   => true,
];

// Calculate the bitmask
error_reporting(array_sum(array_keys($errorsActive, true)));
```

## Displaying All Active Error Types

```php
function displayActiveErrorTypes(): void
{
    $currentLevel = error_reporting();
    $constants = get_defined_constants(true)['Core'];

    echo "Current error reporting level: $currentLevel\n";
    echo "Active error types:\n";

    foreach ($constants as $name => $value) {
        if (strpos($name, 'E_') === 0 && ($currentLevel & $value)) {
            echo "  - $name ($value)\n";
        }
    }
}

displayActiveErrorTypes();
```

## Best Practices

### Development Environment

```php
// Report everything during development
error_reporting(E_ALL);
ini_set('display_errors', 'On');
```

### Production Environment

```php
// Report everything except deprecation warnings in production
error_reporting(E_ALL & ~E_DEPRECATED & ~E_USER_DEPRECATED);
ini_set('display_errors', 'Off');
ini_set('log_errors', 'On');
```

### When to Use User-Generated Errors

| Situation | Use E_USER_ERROR | Use E_USER_WARNING | Use E_USER_NOTICE |
|---|---|---|---|
| Invalid input that makes execution impossible | ✅ | ❌ | ❌ |
| Deprecated function usage | ❌ | ✅ | ❌ |
| Informational logging | ❌ | ❌ | ✅ |
| Configuration issue that can be recovered | ❌ | ✅ | ❌ |

### PHP Version Compatibility

| PHP Version | E_ALL Value | Notable Changes |
|---|---|---|
| PHP 8.4+ | 30719 | `E_STRICT` deprecated, `E_USER_ERROR` with `trigger_error()` deprecated |
| PHP 7.x - 8.3 | 32767 | `E_STRICT` still available |
| PHP 5.x | 30719 | Different bitmask structure |

## Common Pitfalls

### 1. Using -1 Instead of ~0

```php
// WRONG -1 is semantically meaningless as a bit field
error_reporting(-1);

// CORRECT - Use ~0 to set all bits
error_reporting(~0);

// BEST - Use E_ALL
error_reporting(E_ALL);
```

### 2. Forgetting to Apply Changes

```php
// Setting the constant doesn't change error reporting
E_ALL;

// You must call error_reporting()
error_reporting(E_ALL);
```

### 3. Mixing Constants in php.ini

```ini
; WRONG - Complex expressions not supported
error_reporting = E_ALL | (E_WARNING & E_NOTICE)

; CORRECT - Simple bitwise operations only
error_reporting = E_ALL & ~E_NOTICE
```

### 4. Using Symbolic Names Outside PHP

```apache
# WRONG in httpd.conf - symbolic names not understood
php_value error_reporting E_ALL

# CORRECT - Use numerical value
php_value error_reporting 30719
```

## Quick Reference

### Setting Error Levels

```php
// All errors
error_reporting(E_ALL);

// All except notices
error_reporting(E_ALL & ~E_NOTICE);

// Only errors and warnings
error_reporting(E_ERROR | E_WARNING);

// Only user errors
error_reporting(E_USER_ERROR | E_USER_WARNING | E_USER_NOTICE);

// Disable all error reporting
error_reporting(0);
```

### Checking Error Levels

```php
// Check if specific error type is enabled
if (error_reporting() & E_NOTICE) {
    // Notices are enabled
}

// Check if specific error type is disabled
if (!(error_reporting() & E_DEPRECATED)) {
    // Deprecation warnings are disabled
}
```

### Triggering User Errors

```php
// Fatal error (halts script)
trigger_error('Critical failure', E_USER_ERROR);

// Warning (script continues)
trigger_error('Non-critical issue', E_USER_WARNING);

// Notice (informational)
trigger_error('Informational message', E_USER_NOTICE);

// Deprecation warning
trigger_error('Function deprecated', E_USER_DEPRECATED);
```

## Summary

| Concept | Key Point |
|---|---|
| **Constants vs Numbers** | Always use symbolic names (`E_ERROR`) for readability |
| **Bitmask** | Each constant is a power of 2, allowing combination with bitwise operators |
| **Categories** | Engine, Core, Compile-time, User-generated, Deprecation |
| **Bitwise OR (`|`)** | Combine error types: `E_ERROR \| E_WARNING` |
| **Bitwise AND NOT (`&~`)** | Exclude error types: `E_ALL &~ E_NOTICE` |
| **php.ini** | Only simple bitwise operators allowed; use names or numbers |
| **User errors** | Generated with `trigger_error()`; `E_USER_ERROR` deprecated in PHP 8.4 |
| **Development** | Use `E_ALL` with `display_errors=On` |
| **Production** | Use `E_ALL & ~E_DEPRECATED` with `display_errors=Off` |
| **E_ALL value** | 30719 in PHP 8.4+, was 32767 in earlier versions |

---

> **Remember:** Error constants are fundamental to PHP's error reporting system. Understanding how to combine them with bitwise operators gives you fine-grained control over which errors your application reports and how it handles them.
