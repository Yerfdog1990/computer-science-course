# set_exception_handler() Function

## Overview

`set_exception_handler()` is a PHP function that sets a user-defined exception handler function to handle uncaught exceptions. When an exception is thrown but not caught within a `try/catch` block, this handler is called instead of PHP's default exception handling, which would display a fatal error message and stack trace.

---

## Function Signature

```php
set_exception_handler(?callable $callback): ?callable
```

| Parameter | Type | Required | Description |
|---|---|---|---|
| `$callback` | callable/null | Yes | The function to call when an uncaught exception occurs, or `null` to reset to default |

**Return Value:** Returns the previously defined exception handler (callable), or `null` if no previous handler was defined or on error.

---

## Exception Handler Callback Signature

The callback function must accept one parameter - a `Throwable` object:

```php
handler(Throwable $exception): void
```

| Parameter | Type | Description |
|---|---|---|
| `$exception` | Throwable | The uncaught exception object (both `Exception` and `Error` implement `Throwable`) |

> **Important:** As of PHP 7, both `Exception` and `Error` implement the `Throwable` interface, so the handler can catch both application exceptions and PHP engine errors.

---

## Basic Usage

### Simple Exception Handler

```php
<?php
function exception_handler(Throwable $exception)
{
    echo "Uncaught exception: " . $exception->getMessage() . "\n";
}

set_exception_handler('exception_handler');

throw new Exception('Uncaught Exception');
echo "Not Executed\n"; // This line never runs
```

### Reset to Default Handler

```php
<?php
// Reset to PHP's built-in exception handler
set_exception_handler(null);
```

## Advanced Examples

### Example 1: Comprehensive Exception Handler with Logging

```php
<?php
function exception_handler(Throwable $exception)
{
    $timestamp = date('Y-m-d H:i:s');
    $message = sprintf(
        "[%s] Uncaught %s: %s in %s on line %d\nStack trace:\n%s",
        $timestamp,
        get_class($exception),
        $exception->getMessage(),
        $exception->getFile(),
        $exception->getLine(),
        $exception->getTraceAsString()
    );

    // Log to file
    error_log($message, 3, __DIR__ . '/exceptions.log');

    // Display user-friendly message
    http_response_code(500);
    echo "<h1>An error occurred</h1>";
    echo "<p>We're sorry, but something went wrong. Please try again later.</p>";
}

set_exception_handler('exception_handler');
```

### Example 2: Environment-Specific Handlers

```php
<?php
define('DEBUG', true);

if (DEBUG) {

        echo "<strong>Line:</strong> " . $exception->getLine() . "<br>";
        echo "<strong>Trace:</strong><pre>" . $exception->getTraceAsString() . "</pre>";
        echo "</div>";
    });
} else {
    // Production: log and show generic message
    set_exception_handler(function (Throwable $exception) {
        error_log(sprintf(

            date('Y-m-d H:i:s'),
            get_class($exception),
            $exception->getMessage(),
            $exception->getFile(),
            $exception->getLine()
        ));

        http_response_code(500);
        echo "<h1>Internal Server Error</h1>";
        echo "<p>Please contact support if the problem persists.</p>";
    });
}
```

## Important Behavior Notes

### Execution Stops After Handler

Once the exception handler is called, script execution stops. The handler cannot return to the script:

```php
<?php
function exception_handler(Throwable $exception)
{
    echo "Handling exception...\n";
    // Execution stops here - cannot return to script
}

set_exception_handler('exception_handler');

throw new Exception('Test');
echo "This will never be executed\n";
```

### Cannot Throw from Within Handler

Throwing an exception from within the exception handler causes a fatal error:

```php
<?php
function exception_handler(Throwable $exception)
{
    throw $exception; // FATAL ERROR: Exception thrown without a stack frame
}

set_exception_handler('exception_handler');
throw new Exception('Test');
```

**Solution:** Wrap handler code in try-catch:

```php
<?php
function exception_handler(Throwable $exception)
{
    try {
        // Handle the exception
        error_log($exception->getMessage());
    } catch (Throwable $e) {
        error_log("Error in exception handler: " . $e->getMessage());
    }
}

set_exception_handler('exception_handler');
```

### Handler Not Recursive

If an error occurs within the exception handler, it will not trigger the exception handler again:

```php
<?php
function exception_handler(Throwable $exception)
{
    $undefined = $variable; // This won't trigger exception_handler again
}

set_exception_handler('exception_handler');
throw new Exception('Test');
```

## Best Practices

### 1. Always Log Exception Details

```php
<?php
function exception_handler(Throwable $exception)
{
    // Log full details for debugging
    error_log(sprintf(
        "[%s] %s: %s in %s:%d",
        date('Y-m-d H:i:s'),
        get_class($exception),
        $exception->getMessage(),
        $exception->getFile(),
        $exception->getLine()
    ));

    // Show generic message to user
    echo "An error occurred.";
}

set_exception_handler('exception_handler');
```

### 2. Escape HTML Output

```php
<?php
function exception_handler(Throwable $exception)
{
    // Escape to prevent XSS
    $message = htmlspecialchars($exception->getMessage(), ENT_QUOTES, 'UTF-8');
    $file = htmlspecialchars($exception->getFile(), ENT_QUOTES, 'UTF-8');

    echo "Error: $message in $file";
}

set_exception_handler('exception_handler');
```

### 3. Set Appropriate HTTP Status Code

```php
<?php
function exception_handler(Throwable $exception)
{
    http_response_code(500);
    echo "Internal Server Error";
}

set_exception_handler('exception_handler');
```

### 4. Use restore_exception_handler() for Temporary Handlers

```php
<?php
// Set temporary handler
$previousHandler = set_exception_handler('temporary_handler');

// Do something that might throw exceptions

// Restore previous handler
restore_exception_handler();
```

### 5. Don't Expose Sensitive Information in Production

```php
<?php
define('DEBUG', false);

function exception_handler(Throwable $exception)
{
    if (DEBUG) {
        // Show full details in development
        echo "<pre>" . $exception->getTraceAsString() . "</pre>";
    } else {
        // Generic message in production
        error_log($exception->getMessage());
        echo "An error occurred. Please contact support.";
    }
}

set_exception_handler('exception_handler');
```

## Common Use Cases

### 1. Unified Error and Exception Handling

```php
<?php
// Convert errors to exceptions
set_error_handler(function (int $errno, string $errstr, string $errfile, int $errline) {
    if (error_reporting() === 0) {
        return false;
    }
    throw new ErrorException($errstr, 0, $errno, $errfile, $errline);
});

// Handle all exceptions
set_exception_handler(function (Throwable $exception) {
    error_log("Exception: " . $exception->getMessage());
    echo "An error occurred.";
});
```

### 2. JSON API Error Responses

```php
<?php
function api_exception_handler(Throwable $exception)
{
    http_response_code(500);

    echo json_encode([
        'error' => true,
        'message' => 'Internal server error',
        'code' => $exception->getCode()
    ]);
}

set_exception_handler('api_exception_handler');
```

### 3. Custom Error Pages

```php
<?php
function exception_handler(Throwable $exception)
{
    http_response_code(500);

    include __DIR__ . '/error_pages/500.html';
    exit();
}

set_exception_handler('exception_handler');
```

### 4. Sensitive Data Protection in Stack Traces

```php
<?php
function exception_handler(Throwable $exception)
{
    $trace = $exception->getTrace();

    // Sanitize arguments in stack trace
    foreach ($trace as $key => $stackPoint) {
        if (isset($stackPoint['args'])) {
            $trace[$key]['args'] = array_map('gettype', $stackPoint['args']);
        }
    }

    $message = sprintf(
        "Uncaught %s: %s\nStack trace:\n%s",
        get_class($exception),
        $exception->getMessage(),
        print_r($trace, true)
    );

    error_log($message);
    echo "An error occurred.";
}

set_exception_handler('exception_handler');
```

## Limitations and Constraints

### 1. Cannot Return to Script

The exception handler cannot return execution to the script. Once called, the script will terminate.

### 2. Cannot Throw from Handler

Throwing an exception from within the handler causes a fatal error ("Exception thrown without a stack frame").

### 3. Handler Not Recursive

Errors within the handler won't trigger the exception handler again.

### 4. CLI -r Flag Issues

When running PHP with the `-r` flag, `set_exception_handler()` may not work as expected. Use a file instead.

### 5. Exit Status Code

On GNU/Linux, when an exception handler is called, PHP ends with exit status code 0 instead of 255. You can change this with `exit()` at the end of your handler.

---

## PHP Version Compatibility

| PHP Version | Notable Changes |
|---|---|
| **PHP 7+** | Handler accepts `Throwable` (both `Exception` and `Error`) |
| **PHP 5.x** | Handler accepts `Exception` only (not `Error`) |
| **PHP 5.4.11+** | Exceptions thrown within handler bypass the exception handler |
| **PHP 7.4+** | Exceptions thrown in shutdown function can be caught by exception handler |
| **PHP 8.3+** | Exceptions thrown in shutdown function can be caught by global exception handler |

## Comparison with try-catch

| Aspect | try-catch | set_exception_handler() |
|---|---|---|
| Scope | Local to specific code block | Global for entire script |
| Execution | Can continue after handling | Script terminates after handling |
| Use Case | Expected exceptions you can recover from | Unexpected/uncaught exceptions |
| Control | Fine-grained control | Last-resort handler |

## Complete Example: Production-Ready Exception Handler

```php
<?php
class ExceptionHandler
{
    private static $logFile;
    private static $adminEmail;

    public static function init(string $logFile, string $adminEmail): void
    {
        self::$logFile = $logFile;
        self::$adminEmail = $adminEmail;

        set_exception_handler([self, 'handle']);
    }

    public static function handle(Throwable $exception): void
    {
        try {
            // Log the exception
            self::logException($exception);

            // Email admin for critical exceptions
            if (self::isCritical($exception)) {
                self::emailAdmin($exception);
            }

            // Display user-friendly message
            self::displayErrorPage();

        } catch (Throwable $e) {
            // Fallback if handler fails
            error_log("Exception handler failed: " . $e->getMessage());
            echo "A critical error occurred.";
        }

        exit(1);
    }

    private static function logException(Throwable $exception): void
    {
        $logEntry = sprintf(
            "[%s] %s: %s in %s:%d\nStack trace:\n%s\n",
            date('Y-m-d H:i:s'),
            get_class($exception),
            $exception->getMessage(),
            $exception->getFile(),
            $exception->getLine(),
            $exception->getTraceAsString()
        );

        file_put_contents(self::$logFile, $logEntry, FILE_APPEND);
    }

    private static function isCritical(Throwable $exception): bool
    {
        return $exception instanceof Error ||
               $exception instanceof RuntimeException;
    }

    private static function emailAdmin(Throwable $exception): void
    {
        $message = sprintf(
            "Critical Exception:\n\nType: %s\nMessage: %s\nFile: %s\nLine: %d",
            get_class($exception),
            $exception->getMessage(),
            $exception->getFile(),
            $exception->getLine()
        );

        mail(self::$adminEmail, 'Critical Exception Alert', $message);
    }

    private static function displayErrorPage(): void
    {
        http_response_code(500);
        echo "<!DOCTYPE html>
<html>
<head><title>Error</title></head>
<body>
<h1>Internal Server Error</h1>
<p>We're sorry, but something went wrong. Please try again later.</p>
</body>
</html>";
    }
}

// Initialize the handler
ExceptionHandler::init(__DIR__ . '/exceptions.log', 'admin@example.com');
```

## Summary

| Concept | Key Point |
|---|---|
| **Purpose** | Sets a global handler for uncaught exceptions |
| **Callback Signature** | `handler(Throwable $exception): void` |
| **Return Value** | Previous handler (callable) or `null` |
| **Execution** | Script stops after handler is called |
| **Cannot Throw** | Throwing from handler causes fatal error |
| **Not Recursive** | Errors in handler won't trigger handler again |
| **PHP 7+** | Accepts `Throwable` (both `Exception` and `Error`) |
| **PHP 5.x** | Accepts `Exception` only |
| **Best Practice** | Always log details, hide sensitive info in production |
| **Use Case** | Last-resort handling for unexpected exceptions |
| **Related** | Use try-catch for expected, recoverable exceptions |

---

> **Remember:** `set_exception_handler()` is a safety net for uncaught exceptions. It should be used to log errors, notify administrators, and display user-friendly messages. For expected exceptions that you can recover from, use try-catch blocks instead. Never throw exceptions from within the exception handler, as this will cause a fatal error.
