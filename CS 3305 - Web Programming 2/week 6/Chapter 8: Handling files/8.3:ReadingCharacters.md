# Reading Characters

## Overview
Once a **filestream** object is created, its contents can be read one character at a time using the PHP `fgetc()` function. This is useful for processing text files character by character.

## Reading Characters with fgetc()

The `fgetc()` function reads a single character from a filestream.

### fgetc() Function Syntax
```php
fgetc(filestream)
```

This function requires one argument:
- **filestream**: The filestream object created by `fopen()`

- **Returns**: A single character from the file, or `false` when the end of the file is reached

## Reading Every Character

To read every character in a file, the `fgetc()` function can be called repeatedly in a loop.

## Detecting End of File

Unlike `feof()`, the `fgetc()` function itself returns `false` when the end of the file is reached. This can be used to end the loop naturally.

## Complete Example

```php
<?php
// Attempt to open a plain text file for reading, or exit the script upon failure
$file = fopen("title.txt", "r") or die("Unable to open file!");

// Loop through each character until end of file is reached
while (($char = fgetc($file)) !== false) {
    // Display the character
    echo $char;
}

// Close the filestream
fclose($file);
?>
```

## Key Points

1. **Character-by-Character Reading**: Use `fgetc()` to read one character at a time from a filestream
2. **Loop Structure**: Call `fgetc()` repeatedly in a loop to read all characters
3. **End Detection**: `fgetc()` returns `false` when the end of file is reached
4. **Loop Condition**: Use `($char = fgetc($file)) !== false` as the while loop condition
5. **Cleanup**: Always close the filestream with `fclose()` after reading is complete
6. **Assignment in Condition**: The character is assigned to a variable within the loop condition

## Important Notes

- **Filestream Creation**: Must create a filestream with `fopen()` before reading characters
- **Error Handling**: Use `die()` function to handle file opening failures
- **Return Value**: `fgetc()` returns a single character or `false` at EOF
- **Comparison**: Use strict comparison `!== false` to distinguish between actual character '0' and EOF
- **File Placement**: Save the PHP script in the web server's `/htdocs` directory alongside the text file to be read
- **Testing**: Open the page via HTTP to see the text file characters displayed

## Comparison: Reading Methods

| Method | Function | Unit of Reading | Use Case |
|--------|----------|-----------------|----------|
| Entire file | `fread()` with `filesize()` | Entire file content | When you need the entire file content at once |
| Line by line | `fgets()` in a loop | One line at a time | When you need to process file content line by line |
| Character by character | `fgetc()` in a loop | One character at a time | When you need to process file content character by character |

## Workflow Summary

1. Open file with `fopen()` using appropriate mode (typically "r" for reading)
2. Use `while (($char = fgetc($file)) !== false)` loop to iterate through characters
3. Process or display each character as needed inside the loop
4. Close the filestream with `fclose($file)` when done

## When to Use Character Reading

Character-by-character reading is useful when:
- You need to analyze individual characters (e.g., counting specific characters)
- You need to implement custom parsing logic
- You need to process data character by character for encryption/decryption
- You need to handle special character sequences
- Memory efficiency is critical for very large files
