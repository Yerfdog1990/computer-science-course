# Writing a File

## Overview
Once a **filestream** object has been created specifying a write mode, a text file can be created. Text can be written into the file using the PHP `fwrite()` function.

## Creating a Filestream for Writing

To write to a file, you must create a filestream using `fopen()` with an appropriate write mode:

- **`w`**: Discard all contents of an existing file or create a new file if none exists
- **`w+`**: Open a file to write to or read from. Discard all contents of an existing file or create a new file if none exists
- **`a`**: Open an existing file and preserve all contents (append mode)
- **`a+`**: Open a file to read from or write to and preserve all contents (append mode)

## Writing Text with fwrite()

The `fwrite()` function writes text to a file.

### fwrite() Function Syntax
```php
fwrite(filestream, text)
```

This function requires two arguments:
- **filestream**: The filestream object created by `fopen()`
- **text**: The string of text to write to the file

- **Returns**: The number of bytes written, or `false` on failure

## Formatting with Non-Printing Characters

To format the text, non-printing invisible characters can also be written to create line breaks and tab spacing:

| Character | Description | Action |
|-----------|-------------|--------|
| `\n` | Newline | Move to a new line down |
| `\r` | Carriage return | Move to the beginning of the line |
| `\t` | Tab | Move along the line to the next tab stop |

## Complete Example

```php
<?php
// Assign text, including non-printing characters for formatting
$text = "This is the first line.\n";
$text .= "This is the second line with a tab:\tIndented text.\n";
$text .= "This is the third line.\r\n";

// Create a filestream in write mode (creates new file or overwrites existing)
$file = fopen("output.txt", "w") or die("Unable to open file!");

// Write the text to the file
fwrite($file, $text);

// Close the filestream
fclose($file);

echo "File written successfully!";
?>
```

## Key Points

1. **Write Mode Selection**: Choose appropriate write mode (`w`, `w+`, `a`, `a+`) based on your needs
2. **File Creation**: Using `w` or `w+` mode creates a new file or overwrites existing content
3. **Text Assignment**: Assign text to a variable before writing, including formatting characters
4. **Writing**: Use `fwrite()` to write text to the filestream
5. **Formatting**: Use escape sequences (`\n`, `\r`, `\t`) for line breaks and spacing
6. **Cleanup**: Always close the filestream with `fclose()` after writing is complete

## Important Notes

- **Filestream Creation**: Must create a filestream with `fopen()` using a write mode before writing
- **Error Handling**: Use `die()` function to handle file opening failures
- **Overwriting**: Mode `w` will discard all existing file contents - use with caution
- **Appending**: Use mode `a` or `a+` to preserve existing content and add new data
- **Escape Sequences**: Non-printing characters must be enclosed in double quotes
- **File Permissions**: Ensure the web server has write permissions to the target directory
- **Return Value**: `fwrite()` returns the number of bytes written, useful for verification

## Write Mode Comparison

| Mode | Existing File | Non-Existing File | Read Capability |
|------|---------------|------------------|----------------|
| `w` | Overwrites content | Creates new file | Write only |
| `w+` | Overwrites content | Creates new file | Read and write |
| `a` | Appends to end | Creates new file | Write only |
| `a+` | Appends to end | Creates new file | Read and write |

## Workflow Summary

1. Prepare the text content with appropriate formatting (including `\n`, `\r`, `\t`)
2. Open file with `fopen()` using appropriate write mode
3. Use `fwrite()` to write the text to the filestream
4. Close the filestream with `fclose()` when done
5. Verify the file was created/written successfully

## Common Use Cases

Writing files is useful for:
- **Logging**: Recording user actions, errors, or system events
- **Data Export**: Saving data in text format for external use
- **Configuration**: Creating or updating configuration files
- **Content Generation**: Dynamically creating web content or reports
- **Data Storage**: Storing simple data structures in text format

## Example: Creating a Log File

```php
<?php
// Get current date and time
$timestamp = date("Y-m-d H:i:s");

// Create log entry with formatting
$logEntry = "[$timestamp] User accessed the page.\n";
$logEntry .= "[$timestamp] Action completed successfully.\r\n";

// Open file in append mode to preserve existing logs
$file = fopen("log.txt", "a") or die("Unable to open file!");

// Write the log entry
fwrite($file, $logEntry);

// Close the filestream
fclose($file);

echo "Log entry added!";
?>
```

## Example: Creating a Formatted Report

```php
<?php
// Create formatted report text
$report = "SALES REPORT\n";
$report .= "============\n\n";
$report .= "Item\t\tQuantity\tPrice\n";
$report .= "----\t\t--------\t-----\n";
$report .= "Product A\t10\t\t$100.00\n";
$report .= "Product B\t5\t\t$50.00\n";
$report .= "\nTotal:\t\t15\t\t$150.00\n";

// Open file in write mode
$file = fopen("report.txt", "w") or die("Unable to open file!");

// Write the report
fwrite($file, $report);

// Close the filestream
fclose($file);

echo "Report generated successfully!";
?>
```
