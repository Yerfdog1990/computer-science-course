# Reading Lines

## Overview
Once a **filestream** object is created, its contents can be read one line at a time using the PHP `fgets()` function. This is useful for processing text files line by line.

## Reading Lines with fgets()

The `fgets()` function reads a single line from a filestream.

### fgets() Function Syntax
```php
fgets(filestream)
```

This function requires one argument:
- **filestream**: The filestream object created by `fopen()`

## Reading Every Line

To read every line in a file, the `fgets()` function can be called repeatedly in a loop.

## Detecting End of File

The `feof()` function can determine when the end of the file is reached and can end the loop.

### feof() Function Syntax
```php
feof(filestream)
```

- **Returns**: `true` when the end of the file is reached, `false` otherwise

## Complete Example

```php
<?php
// Attempt to open a plain text file for reading, or exit the script upon failure
$file = fopen("manifesto.txt", "r") or die("Unable to open file!");

// Loop through each line until end of file is reached
while (!feof($file)) {
    // Read one line at a time
    $line = fgets($file);
    
    // Display the line
    echo $line . "<br>";
}

// Close the filestream
fclose($file);
?>
```

## Key Points

1. **Line-by-Line Reading**: Use `fgets()` to read one line at a time from a filestream
2. **Loop Structure**: Call `fgets()` repeatedly in a loop to read all lines
3. **End Detection**: Use `feof()` to detect when the end of file is reached
4. **Loop Condition**: Use `!feof($file)` as the while loop condition to continue reading until EOF
5. **Cleanup**: Always close the filestream with `fclose()` after reading is complete
6. **Newline Characters**: The last line may appear empty but contains an invisible newline character

## Important Notes

- **Filestream Creation**: Must create a filestream with `fopen()` before reading lines
- **Error Handling**: Use `die()` function to handle file opening failures
- **File Placement**: Save the PHP script in the web server's `/htdocs` directory alongside the text file to be read
- **Testing**: Open the page via HTTP to see the text file lines displayed
- **Newline Handling**: Be aware that what appears to be an empty line may actually contain a newline character

## Comparison: Reading Entire File vs. Reading Lines

| Method | Function | Use Case |
|--------|----------|----------|
| Entire file | `fread()` with `filesize()` | When you need the entire file content at once |
| Line by line | `fgets()` in a loop | When you need to process file content line by line |

## Workflow Summary

1. Open file with `fopen()` using appropriate mode (typically "r" for reading)
2. Use `while (!feof($file))` loop to iterate through lines
3. Call `fgets($file)` inside the loop to read each line
4. Process or display each line as needed
5. Close the filestream with `fclose($file)` when done
