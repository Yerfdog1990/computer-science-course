# Reading Files

## Overview
The ability to read and write files located on the web server is useful to:
- Log information
- Provide page content

## Filestream Objects
To process files, a **filestream** object must first be created using the PHP `fopen()` function.

### fopen() Function Syntax
```php
fopen(filename, mode)
```

This requires two arguments:
1. **filename**: The name or path of the file
2. **mode**: A file "mode" that determines the nature of the operation

## File Modes

The file mode determines the operation to be performed and places the file pointer at a suitable position within the file:

| Mode | Operation | File Pointer Position |
|------|-----------|----------------------|
| `r` | Open an existing file to read | Starts at the beginning of the file |
| `w` | Discard all contents of an existing file or create a new file if none exists | Starts at the beginning of the file |
| `a` | Open an existing file and preserve all contents | Starts at the end of the file |
| `r+` | Open a file to read from or write to | Starts at the beginning of the file |
| `w+` | Open a file to write to or read from. Discard all contents of an existing file or create a new file if none exists | Starts at the beginning of the file |
| `a+` | Open a file to read from or write to and preserve all contents | Starts at the end of the file |

**Important**: The file mode specifier must appear within quote marks when supplied as an argument to the `fopen()` function.

## Error Handling

It is good practice to always provide an alternative with the `die()` function in case the attempt to create a filestream fails. Specify an explanatory message as an argument to the `die()` function.

```php
$file = fopen("filename.txt", "r") or die("Unable to open file!");
```

## Reading Files

When a filestream is created successfully, the file can be read by specifying the filestream and byte size as arguments to the `fread()` function.

### fread() Function Syntax
```php
fread(filestream, byte_size)
```

If the whole file is to be read, it is convenient to use the `filesize()` function to specify the byte size of the file to be read.

```php
$content = fread($file, filesize("filename.txt"));
```

## Closing Files

Upon completion of any file operation, the filestream must be destroyed by specifying it as an argument to the `fclose()` function.

```php
fclose($file);
```

## Complete Example

```php
<?php
// Attempt to open a plain text file for reading, or exit the script upon failure
$file = fopen("manifesto.txt", "r") or die("Unable to open file!");

// Read the entire file
$content = fread($file, filesize("manifesto.txt"));

// Close the filestream
fclose($file);

// Display the content
echo $content;
?>
```

## Key Points Summary

1. **Filestream Creation**: Always use `fopen()` with appropriate mode
2. **Mode Selection**: Choose the correct mode based on your needs (read, write, append, or combinations)
3. **Error Handling**: Use `die()` to handle file opening failures gracefully
4. **Reading**: Use `fread()` with `filesize()` to read entire files
5. **Cleanup**: Always close filestreams with `fclose()` when done
6. **Quote Marks**: File modes must be enclosed in quote marks
