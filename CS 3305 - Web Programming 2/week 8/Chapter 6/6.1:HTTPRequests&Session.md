# HTTP Requests & Sessions

---

## 1. What is HTTP?

**Hypertext Transfer Protocol (HTTP)** is the foundational protocol that enables structured communication between clients (typically browsers) and servers. Every website you visit, every form you submit, and every file you download is powered by HTTP.

HTTP works in two directions:
- **Client → Server**: The *request*
- **Server → Client**: The *response*

This back-and-forth is called the **Request-Response Cycle**.

---

## 2. The Request-Response Cycle

```
[Browser/Client]  →  GET /register  →  [Server]
[Browser/Client]  ←  200 OK + HTML  ←  [Server]
```

### Step-by-Step Process

1. **Request** — The client (browser) sends a request, e.g., `GET /path`
2. **Routing** — The server checks if a static file (CSS, image, PDF) matches the URI. If not, it forwards to the application
3. **Application Processing** — The PHP application processes the request and prepares a response
4. **Response** — The server forwards the response back to the client

> **Key Insight:** The cycle applies to everything — HTML pages, images, CSS files, AJAX calls. Every browser interaction is an HTTP request.

---

## 3. HTTP Request Methods

### GET

Used to **fetch/read data** from a server. Data is passed through the URL query string or path.

```
GET /books?category=Comics&page=2 HTTP/1.1
Host: www.bookstore.com
```

**URL Anatomy:**
```
https://www.bookstore.com/books/?category=Comics&page=2
│─────│  │────────────────│ │─────│ │───────────────────│
protocol      hostname      path         query string
```

**Query String Rules:**
- Key-value pairs separated by `&`
- Delimited from the path by `?`
- Arrays: `tags[]=comics&tags[]=recent` → `["comics", "recent"]`
- Associative: `filter[category]=php&filter[year]=2024`

**⚠️ Security Warning:** NEVER use GET for sensitive data (passwords, tokens). Query strings are:
- Visible in the URL bar
- Stored in browser history
- Logged by servers

**✅ Good GET use cases:** search filters, pagination, sorting, shareable/bookmarkable URLs.

---

### POST

Used to **create, update, or delete** resources. Unlike GET, POST has a **request body**, making it more secure for sensitive data.

```html
<!-- URL-encoded (default) — for text data -->
<form method="post" enctype="application/x-www-form-urlencoded">
    <input type="text" name="username">
    <input type="submit" value="Save">
</form>

<!-- Multipart — required for file uploads -->
<form method="post" enctype="multipart/form-data">
    <input type="file" name="avatar">
    <input type="submit" value="Upload">
</form>
```

| Feature | GET | POST |
|---------|-----|------|
| Data location | URL query string | Request body |
| Visible in URL | ✅ Yes | ❌ No |
| Browser history | ✅ Stored | ❌ Not stored |
| Data size limit | ~1,024 chars (server-dependent) | 8 MB default in PHP |
| File uploads | ❌ No | ✅ Yes |
| Use for sensitive data | ❌ Never | ✅ Yes |

**✅ Good POST use cases:** login, registration, form submissions, file uploads, newsletter subscriptions, posting comments.

---

## 4. HTTP Response Status Codes

| Code | Meaning | Example |
|------|---------|---------|
| `200 OK` | Success | Page loaded |
| `201 Created` | Resource created | Registration successful |
| `301 Moved Permanently` | Redirect (permanent) | Old URL → New URL |
| `302 Found` | Redirect (temporary) | After login |
| `400 Bad Request` | Invalid request | Malformed data |
| `401 Unauthorized` | Not authenticated | Login required |
| `403 Forbidden` | No permission | Access denied |
| `404 Not Found` | Resource missing | Wrong URL |
| `500 Internal Server Error` | Server crashed | PHP error |

### Common Response Headers

- **`Content-Type`** — Media type of the response (e.g., `text/html`, `application/json`)
- **`Cache-Control`** — Caching directives
- **`Expires`** — Date/time after which response is stale
- **`Content-Encoding`** — Compression used (e.g., `gzip`)
- **`Set-Cookie`** — Instructs browser to store a cookie

## 5. PHP Superglobals

PHP automatically parses HTTP requests into built-in variables called **superglobals**, accessible anywhere in your script.

### `$_SERVER` — Server & Request Info

```php
echo $_SERVER['REQUEST_METHOD'];   // "GET" or "POST"
echo $_SERVER['REQUEST_URI'];      // "/register?ref=EVENT19"
echo $_SERVER['REMOTE_ADDR'];      // Client IP address
echo $_SERVER['HTTP_USER_AGENT'];  // Browser info
echo $_SERVER['PATH_INFO'];        // Extra path info
echo $_SERVER['QUERY_STRING'];     // "ref=EVENT19"
```

---

### `$_GET` — Query String Data

Populated from the URL query string, regardless of request method.

```php
// URL: /students?year=2024&major=cs
echo $_GET['year'];    // "2024"
echo $_GET['major'];   // "cs"

// Arrays: /filter?tags[]=http-and-session&tags[]=web
print_r($_GET['tags']); // ["http-and-session", "web"]
```

---

### `$_POST` — POST Body Data

Populated from form submissions using the POST method.

```php
// From: <input type="text" name="email">
echo $_POST['email'];   // "student@example.com"
echo $_POST['password']; // "secret123"
```

---

### `$_FILES` — Uploaded Files

Contains data for file upload attempts.

```php
$file = $_FILES['avatar'];
echo $file['name'];      // Original filename: "photo.png"
echo $file['tmp_name'];  // Temp path: "/tmp/phpXXXXXX"
echo $file['type'];      // MIME type: "image/png" (do NOT trust this)
echo $file['size'];      // Size in bytes: 204800
echo $file['error'];     // 0 = UPLOAD_ERR_OK (success)
```

**Upload error constants:**

| Constant | Value | Meaning |
|----------|-------|---------|
| `UPLOAD_ERR_OK` | `0` | Success |
| `UPLOAD_ERR_INI_SIZE` | `1` | File too large |
| `UPLOAD_ERR_NO_FILE` | `4` | No file submitted |

**⚠️ Always validate MIME type server-side:**
```php
$detectedType = mime_content_type($file['tmp_name']); // Use this
// NOT $file['type'] — client can fake it
```

**Moving uploaded files:**
```php
// Use move_uploaded_file(), NOT rename() — it's safer
move_uploaded_file($file['tmp_name'], '/uploads/avatar.png');
```

---

### `$_COOKIE` — Browser Cookies

HTTP is **stateless** (each request is independent). Cookies solve this by persisting small pieces of data in the browser.

```php
// Set a cookie (must be called before any output)
setcookie('ref', 'EVENT19', time() + 60*60*24*30); // Expires in 30 days

// Read a cookie
if (array_key_exists('ref', $_COOKIE)) {
    echo $_COOKIE['ref']; // "EVENT19"
}
```

**`setcookie()` parameters:**

```php
setcookie(
    string $name,           // Cookie name
    string $value = "",     // Cookie value
    int    $expires = 0,    // Unix timestamp (0 = session cookie)
    string $path = "",      // URL path scope
    string $domain = "",    // Domain scope
    bool   $secure = false, // HTTPS only
    bool   $httponly = false // No JavaScript access
);
```

---

### `$_SESSION` — Server-Side Session Data

Sessions store data **on the server** (not the browser). The browser only holds a session ID (in a cookie named `PHPSESSID`).

```php
session_start(); // Must call this before using $_SESSION

// Write session data
$_SESSION['user_id'] = 42;
$_SESSION['username'] = 'john_doe';

// Read session data
echo $_SESSION['username']; // "john_doe"

// Destroy session (logout)
session_destroy();
```

**Session vs Cookie comparison:**

| Feature | Cookie | Session |
|---------|--------|---------|
| Storage location | Browser | Server |
| Accessible by user | ✅ Yes | ❌ No |
| Can be deleted by user | ✅ Yes | ❌ No (only via logout) |
| Size limit | ~4 KB | Essentially unlimited |
| Best for | Preferences, referral codes | Auth data, cart, CSRF tokens |

## 6. Database Connection with PDO

PHP Data Objects (**PDO**) is the recommended way to connect to a database. It supports multiple database drivers (MySQL, PostgreSQL, SQLite, etc.) and uses **prepared statements** to safely handle user input.

### The Singleton `Database` Class

A common pattern is to wrap PDO in a **Singleton** — a class that allows only one instance to exist, ensuring a single shared database connection throughout the request lifecycle.

```php
<?php

class Database
{
    private static ?\Database $instance = null;
    private PDO $pdo;

    // Private constructor — prevents direct instantiation with `new database()`
    private function __construct()
    {
        $dsn = "mysql:host=127.0.0.1;port=3306;dbname=student_db;charset=utf8mb4";

        $options = [
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,  // Return rows as associative arrays
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION, // Throw exceptions on error
            PDO::ATTR_EMULATE_PREPARES   => false,              // Use real prepared statements
        ];

        $this->pdo = new PDO($dsn, 'http-and-session-user', 'http-and-session-pass', $options);
    }

    // The single access point — creates the instance only once
    public static function getInstance(): static
    {
        if (is_null(static::$instance)) {
            static::$instance = new static();
        }

        return static::$instance;
    }

    // Expose the PDO object for queries
    public function getPdo(): PDO
    {
        return $this->pdo;
    }
}
```

### How to Use It

```php
// Get the shared database instance
$db = Database::getInstance();
$pdo = $db->getPdo();

// SELECT — fetch all students
$stmt = $pdo->query("SELECT * FROM students");
$students = $stmt->fetchAll(); // returns array of associative arrays

// SELECT with a filter — always use prepared statements for user input
$stmt = $pdo->prepare("SELECT * FROM students WHERE major = :major");
$stmt->execute([':major' => $_GET['major']]);
$students = $stmt->fetchAll();

// INSERT — save a new student
$stmt = $pdo->prepare("
    INSERT INTO students (name, email, major, photo, referral_code)
    VALUES (:name, :email, :major, :photo, :referral)
");
$stmt->execute([
    ':name'     => $_POST['name'],
    ':email'    => $_POST['email'],
    ':major'    => $_POST['major'],
    ':photo'    => $photoPath,
    ':referral' => $referralCode,
]);
```

### DSN (Data Source Name) Breakdown

```
mysql : host=127.0.0.1 ; port=3306 ; dbname=student_db ; charset=utf8mb4
│────│  │─────────────│  │────────│  │────────────────│  │──────────────│
driver     DB server      DB port      database name      character set
```

### Key PDO Options Explained

| Option | Value | Effect |
|--------|-------|--------|
| `ATTR_DEFAULT_FETCH_MODE` | `FETCH_ASSOC` | Rows returned as `['col' => 'val']` arrays |
| `ATTR_ERRMODE` | `ERRMODE_EXCEPTION` | DB errors throw a `PDOException` (catchable) |
| `ATTR_EMULATE_PREPARES` | `false` | Use true prepared statements (safer, more efficient) |

### Why Singleton?

```php
// Without Singleton — creates a NEW connection every time (wasteful)
$db1 = new Database(); // connection #1
$db2 = new Database(); // connection #2 — unnecessary!

// With Singleton — reuses the same connection
$db1 = Database::getInstance(); // creates connection
$db2 = Database::getInstance(); // returns the SAME instance
// $db1 === $db2 → true
```

### Database Schema

Run this query once to set up the database and table:

```sql
-- Create and select the database
CREATE DATABASE IF NOT EXISTS student_db
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

USE student_db;

-- Create the students table
CREATE TABLE IF NOT EXISTS students (
    id            INT          NOT NULL AUTO_INCREMENT,
    name          VARCHAR(100) NOT NULL,
    email         VARCHAR(150) NOT NULL,
    major         VARCHAR(100) NOT NULL,
    photo         VARCHAR(255)     NULL,
    referral_code VARCHAR(50)      NULL,
    created_at    TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uq_students_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**Column breakdown:**

| Column | Type | Notes |
|--------|------|-------|
| `id` | `INT AUTO_INCREMENT` | Primary key, auto-incremented by MySQL |
| `name` | `VARCHAR(100)` | Student full name, required |
| `email` | `VARCHAR(150) UNIQUE` | Must be unique — prevents duplicate registrations |
| `major` | `VARCHAR(100)` | Selected major, required |
| `photo` | `VARCHAR(255) NULL` | Relative file path to uploaded photo, optional |
| `referral_code` | `VARCHAR(50) NULL` | Sourced from cookie, optional |
| `created_at` | `TIMESTAMP` | Auto-set to current date/time on insert |

### `register.php` — Registration Form with POST, File Upload & DB Insert

```php
<?php
session_start();
require_once 'database.http-and-session';

$errors  = [];
$success = false;
$uploadsDir = __DIR__ . '/uploads';

// Create uploads dir if it doesn't exist
if (!is_dir($uploadsDir)) {
    mkdir($uploadsDir, 0755, true);
}

// --- COOKIE: Track referral code from URL ---
// Visit: register.http-and-session?ref=SCHOLARSHIP2024
if (array_key_exists('ref', $_GET)) {
    setcookie('referral', $_GET['ref'], time() + 60 * 60 * 24 * 30);
    $referralCode = $_GET['ref'];
} else {
    $referralCode = $_COOKIE['referral'] ?? null;
}

// --- POST: Handle form submission ---
if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    // 1. Read POST data
    $name  = trim($_POST['name']  ?? '');
    $email = trim($_POST['email'] ?? '');
    $major = trim($_POST['major'] ?? '');

    if (empty($name)) {
        $errors[] = "Full name is required.";
    }
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errors[] = "A valid email address is required.";
    }
    if (empty($major)) {
        $errors[] = "Please select a major.";
    }

    // 2. Handle profile photo upload ($_FILES)
    $photoPath = null;
    if (isset($_FILES['photo']) && $_FILES['photo']['error'] !== UPLOAD_ERR_NO_FILE) {
        $photo = $_FILES['photo'];

        switch ($photo['error']) {
            case UPLOAD_ERR_OK:
                // Always detect MIME type server-side — never trust $photo['type']
                $detectedMime = mime_content_type($photo['tmp_name']);
                $allowedTypes = ['image/jpeg', 'image/png', 'image/gif'];

                if (!in_array($detectedMime, $allowedTypes)) {
                    $errors[] = "Profile photo must be JPEG, PNG, or GIF.";
                } else {
                    $ext      = pathinfo($photo['name'], PATHINFO_EXTENSION);
                    $filename = uniqid('student_', true) . '.' . strtolower($ext);
                    $target   = $uploadsDir . '/' . $filename;

                    if (move_uploaded_file($photo['tmp_name'], $target)) {
                        $photoPath = '/uploads/' . $filename;
                    } else {
                        $errors[] = "Failed to save uploaded photo.";
                    }
                }
                break;

            case UPLOAD_ERR_INI_SIZE:
                $errors[] = "Photo is too large (max 2 MB).";
                break;

            default:
                $errors[] = "Photo upload failed (error code: {$photo['error']}).";
        }
    }

    // 3. If valid, INSERT into database using PDO prepared statement
    if (empty($errors)) {
        $pdo  = Database::getInstance()->getPdo();
        $stmt = $pdo->prepare("
            INSERT INTO students (name, email, major, photo, referral_code)
            VALUES (:name, :email, :major, :photo, :referral)
        ");
        $stmt->execute([
            ':name'     => $name,
            ':email'    => $email,
            ':major'    => $major,
            ':photo'    => $photoPath,
            ':referral' => $referralCode,
        ]);

        // Store the new student ID in the session (e.g., for a success banner)
        $_SESSION['last_registered_id'] = $pdo->lastInsertId();
        $success = true;
    }
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Registration</title>
</head>
<body>
    <h1>Student Registration Form</h1>
    <p><strong>Referral Code (from cookie):</strong>
        <?= $referralCode ? htmlspecialchars($referralCode) : 'None' ?>
    </p>

    <?php if ($success): ?>
        <p style="color: green;">
            ✅ Registration successful! (Student ID: <?= $_SESSION['last_registered_id'] ?>)
            <a href="index.php">View all students →</a>
        </p>
    <?php endif; ?>

    <?php if (!empty($errors)): ?>
        <ul style="color: red;">
            <?php foreach ($errors as $error): ?>
                <li><?= htmlspecialchars($error) ?></li>
            <?php endforeach; ?>
        </ul>
    <?php endif; ?>

    <!-- POST form with multipart encoding for file upload -->
    <form method="post" enctype="multipart/form-data" action="register.php">
        <label>Full Name:
            <input type="text" name="name" value="<?= htmlspecialchars($_POST['name'] ?? '') ?>">
        </label><br>

        <label>Email:
            <input type="email" name="email" value="<?= htmlspecialchars($_POST['email'] ?? '') ?>">
        </label><br>

        <label>Major:
            <select name="major">
                <option value="">-- Select --</option>
                <option value="Computer Science">Computer Science</option>
                <option value="Information Technology">Information Technology</option>
                <option value="Data Science">Data Science</option>
            </select>
        </label><br>

        <label>Profile Photo (PNG/JPEG, max 2MB):
            <input type="file" name="photo" accept="image/*">
        </label><br>

        <input type="submit" value="Register">
    </form>

    <!-- Debug: Show all superglobal data -->
    <hr>
    <h3>$_POST:</h3>
    <pre><?= var_export($_POST, true) ?></pre>

    <h3>$_FILES:</h3>
    <pre><?= var_export($_FILES, true) ?></pre>

    <h3>$_COOKIE:</h3>
    <pre><?= var_export($_COOKIE, true) ?></pre>
</body>
</html>
```

## 8. Quick Reference Cheat Sheet

```php
// Start session (always first, before any output)
session_start();

// Read GET parameter safely
$page = isset($_GET['page']) ? (int)$_GET['page'] : 1;

// Read POST parameter safely
$email = trim($_POST['email'] ?? '');

// Set a cookie (30 days)
setcookie('name', 'value', time() + 86400 * 30);

// Read a cookie safely
$ref = $_COOKIE['ref'] ?? null;

// Store in session
$_SESSION['user_id'] = 42;

// Check request method
if ($_SERVER['REQUEST_METHOD'] === 'POST') { /* ... */ }

// Validate file upload
if ($_FILES['photo']['error'] === UPLOAD_ERR_OK) {
    $mime = mime_content_type($_FILES['photo']['tmp_name']);
    move_uploaded_file($_FILES['photo']['tmp_name'], '/uploads/file.png');
}

// Build a query string
$url = '/students?' . http_build_query(['major' => 'CS', 'page' => 2]);
// → /students?major=CS&page=2

// Get the shared DB connection (Singleton)
$pdo = Database::getInstance()->getPdo();

// SELECT all rows
$students = $pdo->query("SELECT * FROM students")->fetchAll();

// SELECT with user input — always use prepared statements
$stmt = $pdo->prepare("SELECT * FROM students WHERE major = :major");
$stmt->execute([':major' => $_GET['major']]);
$students = $stmt->fetchAll();

// INSERT a new row
$stmt = $pdo->prepare("INSERT INTO students (name, email) VALUES (:name, :email)");
$stmt->execute([':name' => $name, ':email' => $email]);
$newId = $pdo->lastInsertId();
```
