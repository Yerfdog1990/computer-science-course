# 10.5 Persisting Data in PHP — REST CRUD API Practice

---

## Overview

This guide builds a complete REST CRUD API in PHP using PDO and MySQL. The API manages a **books** resource, covering all four CRUD operations mapped to the appropriate HTTP methods:

| Operation | HTTP Method | Endpoint | Description |
|-----------|-------------|----------|-------------|
| Create | `POST` | `/api/books` | Add a new book |
| Read (all) | `GET` | `/api/books` | Retrieve all books |
| Read (one) | `GET` | `/api/books/{id}` | Retrieve a single book |
| Update | `PUT` | `/api/books/{id}` | Replace a book record |
| Delete | `DELETE` | `/api/books/{id}` | Remove a book |

## Step 1 — Database Connection (Singleton)

**`config/database.php`**

```php
<?php

class Database
{
    private static ?Database $instance = null;
    private PDO $pdo;

    private function __construct()
    {
        $dsn = "mysql:host=127.0.0.1;port=3306;dbname=books_api;charset=utf8mb4";

        $options = [
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_EMULATE_PREPARES   => false,
        ];

        $this->pdo = new PDO($dsn, 'php-user', 'php-pass', $options);
    }

    public static function getInstance(): static
    {
        if (is_null(static::$instance)) {
            static::$instance = new static();
        }

        return static::$instance;
    }

    public function getPdo(): PDO
    {
        return $this->pdo;
    }
}
```

**Key points:**
- `private function __construct()` — prevents creating instances with `new Database()`
- `static::$instance` — stored as a class-level variable, persists across all calls
- `PDO::ERRMODE_EXCEPTION` — throws a `PDOException` on any error instead of silently failing
- `PDO::ATTR_EMULATE_PREPARES => false` — uses real MySQL prepared statements

## Step 3 — The API Router

**`api/books.php`**

This single file handles all routes and HTTP methods for the `/api/books` resource.

```php
<?php

require_once __DIR__ . '/../config/database.php';

// ── Response helpers ──────────────────────────────────────────────────────────

/**
 * Send a JSON response with the given status code and exit.
 */
function respond(int $status, mixed $data): never
{
    http_response_code($status);
    header('Content-Type: application/json-example');
    echo json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    exit;
}

/**
 * Return 400 Bad Request with a message.
 */
function badRequest(string $message): never
{
    respond(400, ['error' => $message]);
}

/**
 * Return 404 Not Found.
 */
function notFound(string $message = 'Resource not found'): never
{
    respond(404, ['error' => $message]);
}

// ── Parse the request ─────────────────────────────────────────────────────────

$method = $_SERVER['REQUEST_METHOD'];

// Extract ID from URI: /api/books or /api/books/5
$uri    = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$parts  = explode('/', trim($uri, '/'));
$id     = isset($parts[2]) && is_numeric($parts[2]) ? (int) $parts[2] : null;

// Parse JSON request body for POST and PUT
$body = [];
if (in_array($method, ['POST', 'PUT'])) {
    $raw  = file_get_contents('php://input');
    $body = json_decode($raw, true) ?? [];
}

// ── Database connection ───────────────────────────────────────────────────────
$pdo = Database::getInstance()->getPdo();

// ── Route requests ────────────────────────────────────────────────────────────

match (true) {

    // GET /api/books — retrieve all books
    $method === 'GET' && $id === null => (function () use ($pdo) {
        $stmt = $pdo->query("SELECT * FROM books ORDER BY id ASC");
        respond(200, $stmt->fetchAll());
    })(),

    // GET /api/books/{id} — retrieve one book
    $method === 'GET' && $id !== null => (function () use ($pdo, $id) {
        $stmt = $pdo->prepare("SELECT * FROM books WHERE id = :id");
        $stmt->execute([':id' => $id]);
        $book = $stmt->fetch();

        if (!$book) {
            notFound("Book with id $id not found.");
        }

        respond(200, $book);
    })(),

    // POST /api/books — create a new book
    $method === 'POST' => (function () use ($pdo, $body) {
        $required = ['title', 'author', 'genre', 'published', 'isbn'];

        foreach ($required as $field) {
            if (empty($body[$field])) {
                badRequest("Missing required field: '$field'.");
            }
        }

        $stmt = $pdo->prepare("
            INSERT INTO books (title, author, genre, published, isbn, available)
            VALUES (:title, :author, :genre, :published, :isbn, :available)
        ");

        $stmt->execute([
            ':title'     => $body['title'],
            ':author'    => $body['author'],
            ':genre'     => $body['genre'],
            ':published' => (int) $body['published'],
            ':isbn'      => $body['isbn'],
            ':available' => isset($body['available']) ? (bool) $body['available'] : true,
        ]);

        $newId = (int) $pdo->lastInsertId();

        // Fetch and return the newly created record
        $fetch = $pdo->prepare("SELECT * FROM books WHERE id = :id");
        $fetch->execute([':id' => $newId]);

        header("Location: /api/books/$newId");
        respond(201, $fetch->fetch());
    })(),

    // PUT /api/books/{id} — replace a book record entirely
    $method === 'PUT' && $id !== null => (function () use ($pdo, $id, $body) {
        // Confirm the book exists
        $check = $pdo->prepare("SELECT id FROM books WHERE id = :id");
        $check->execute([':id' => $id]);
        if (!$check->fetch()) {
            notFound("Book with id $id not found.");
        }

        $required = ['title', 'author', 'genre', 'published', 'isbn'];
        foreach ($required as $field) {
            if (empty($body[$field])) {
                badRequest("Missing required field: '$field'.");
            }
        }

        $stmt = $pdo->prepare("
            UPDATE books
            SET title     = :title,
                author    = :author,
                genre     = :genre,
                published = :published,
                isbn      = :isbn,
                available = :available
            WHERE id = :id
        ");

        $stmt->execute([
            ':title'     => $body['title'],
            ':author'    => $body['author'],
            ':genre'     => $body['genre'],
            ':published' => (int) $body['published'],
            ':isbn'      => $body['isbn'],
            ':available' => isset($body['available']) ? (bool) $body['available'] : true,
            ':id'        => $id,
        ]);

        // Return the updated record
        $fetch = $pdo->prepare("SELECT * FROM books WHERE id = :id");
        $fetch->execute([':id' => $id]);
        respond(200, $fetch->fetch());
    })(),

    // DELETE /api/books/{id} — remove a book
    $method === 'DELETE' && $id !== null => (function () use ($pdo, $id) {
        $check = $pdo->prepare("SELECT id FROM books WHERE id = :id");
        $check->execute([':id' => $id]);
        if (!$check->fetch()) {
            notFound("Book with id $id not found.");
        }

        $stmt = $pdo->prepare("DELETE FROM books WHERE id = :id");
        $stmt->execute([':id' => $id]);

        respond(204, null);
    })(),

    // No matching route
    default => respond(405, ['error' => 'Method not allowed or invalid endpoint.'])
};
```

## Step 4 — URL Rewriting (Apache)

**`.htaccess`** — routes all requests to `api/books.php`:

```apache
RewriteEngine On

RewriteCond %{REQUEST_FILENAME} !-d

```

## Step 6 — Testing with Postman (Alternative to curl)

Postman is a graphical API testing tool that lets you build, send, and inspect HTTP requests without writing terminal commands. It is the most widely used tool for API development and testing.

1. Download and install Postman from [postman.com](https://www.postman.com/downloads/)
2. Open Postman and create a new **Collection** named `Books API`
3. Inside the collection, add a **Request** for each endpoint

Rather than typing `http://localhost:8080` in every request, create a Postman environment with a base URL variable:

1. Click **Environments** → **+** to create a new environment
2. Name it `Books API Local`
3. Add a variable:

|----------|--------------|---------------|
| `base_url` | `http://localhost:8080` | `http://localhost:8080` |

4. Select the environment from the dropdown in the top-right corner of Postman

### Using Postman Tests (Automated Assertions)

Postman includes a **Tests** tab on each request where you can write JavaScript assertions that run automatically after each response. This removes the need to manually check the status code and body every time.

**Example — Add to the GET All Books request:**

```javascript
// Tests tab in Postman

pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

pm.test("Response is a JSON array", function () {
    const body = pm.response.json();
    pm.expect(body).to.be.an('array');
});

pm.test("Each book has required fields", function () {
    const books = pm.response.json();
    books.forEach(function (book) {
        pm.expect(book).to.have.property('id');
        pm.expect(book).to.have.property('title');
        pm.expect(book).to.have.property('author');
        pm.expect(book).to.have.property('isbn');
    });
});
```

**Example — Add to the POST Create request:**

```javascript
pm.test("Status code is 201", function () {
    pm.response.to.have.status(201);
});

pm.test("Response contains the new book id", function () {
    const body = pm.response.json();
    pm.expect(body).to.have.property('id');
    pm.expect(body.id).to.be.a('number');
});

pm.test("Location header is set", function () {
    pm.response.to.have.header('Location');
});

// Save the new ID to an environment variable for use in later requests
const body = pm.response.json();
pm.environment.set("new_book_id", body.id);
```

**Example — Add to the DELETE request:**

```javascript
pm.test("Status code is 204", function () {
    pm.response.to.have.status(204);
});

pm.test("Response body is empty", function () {
    pm.expect(pm.response.text()).to.be.empty;
});
```

After adding tests, click **Run collection** from the collection menu to execute all requests in sequence and see a pass/fail report.

### Chaining Requests with Environment Variables

Postman environment variables let you pass data between requests. For example, after a `POST` creates a new book, automatically use its ID in the subsequent `GET`, `PUT`, and `DELETE` requests:

1. In the `POST` **Tests** tab, save the returned ID:

```javascript
const body = pm.response.json();
pm.environment.set("new_book_id", body.id);
```

2. In the `GET /api/books/{id}` URL field, use:

```
{{base_url}}/api/books/{{new_book_id}}
```

3. Do the same for `PUT` and `DELETE` — they all use `{{new_book_id}}` automatically.

This makes the collection fully automated: run `POST` first, then all other requests resolve the correct ID without any manual copy-pasting.

### curl vs Postman — Comparison

| Feature | curl | Postman |
|---------|------|---------|
| Interface | Terminal command line | Graphical UI |
| Setup required | None — available on most systems | Download and install |
| Sending headers | `-H "Key: Value"` flag | Headers tab |
| Sending JSON body | `-d '{"key":"value"}'` flag | Body tab → raw → JSON |
| Viewing response | Terminal output | Formatted response panel |
| Automated assertions | Manual inspection | Tests tab with JavaScript |
| Saving requests | Shell scripts / aliases | Collections |
| Sharing requests | Share scripts | Export collection as JSON |
| Environment variables | Shell variables (`$BASE_URL`) | Built-in environments |
| Best for | Quick checks, CI/CD pipelines, scripting | Development, team collaboration, full test suites |

Both tools are valid — use `curl` for quick one-off checks and CI/CD pipelines, and Postman for systematic testing during development.

## Step 7 — How Each Concept Maps to the Theory

| Concept | Where It Appears |
|---------|-----------------|
| **Stateless requests** | Every request carries all needed data (ID in URI, body for POST/PUT) |
| **HTTP methods as verbs** | `GET` reads, `POST` creates, `PUT` replaces, `DELETE` removes |
| **HTTP status codes** | `200`, `201`, `204`, `400`, `404`, `405` returned appropriately |
| **Resource-based URLs** | `/api/books` (collection) and `/api/books/{id}` (specific item) |
| **JSON as format** | `Content-Type: application/json` used throughout |
| **PDO connection** | Singleton pattern — one connection per request lifecycle |
| **Prepared statements** | Every query with user input uses `:named` placeholders |
| **SQL injection prevention** | No raw `$_GET`/`$_POST` values interpolated into SQL strings |
| **`lastInsertId()`** | Used after `POST` to retrieve and return the new record |
| **`rowCount()`** | Available after `PUT` and `DELETE` to confirm rows affected |
| **`errorInfo()`** | Available on any `PDOStatement` for error detail on failure |
| **`FETCH_ASSOC`** | Set globally in `PDO::ATTR_DEFAULT_FETCH_MODE` at connection |

## Common Errors and Fixes

| Error | Cause | Fix |
|-------|-------|-----|
| `SQLSTATE[HY000]: No database selected` | `dbname` missing from DSN | Add `dbname=books_api` to the DSN string |
| `SQLSTATE[23000]: Integrity constraint violation` | Duplicate ISBN on insert | Return `409 Conflict` and check for duplicate before inserting |
| `json_decode` returns `null` | Request body is not valid JSON | Check `Content-Type: application/json` header is set in the request |
| `405 Method Not Allowed` | Wrong HTTP method for the endpoint | Check the `curl -X` flag matches the expected method |
| `PDOException: Access denied` | Wrong MySQL username or password | Verify credentials in `config/database.php` |
| `0 rows affected` on UPDATE | ID does not exist | Check existence first and return `404` if not found |
